# 黎曼理论的现代表述（geometry-19th 补充材料）

*首次发表于 1999 年 7 月 26 日；2016 年 10 月 20 日实质修订。*

## 黎曼理论的现代表述

黎曼所关注的多维连续统，本质上就是如今所谓的实 **n 维光滑流形**。为简便计，称之为“**n 流形**”。（例如，球面、莫比乌斯带以及亨利·摩尔雕塑的表面，都可视为 2 流形；当代宇宙学的时空模型则是 4 流形。）条件 (a) – (c) 完整刻画了 *n* 流形。

> (a) 一个 *n* 流形 $\mathbf{M}$ 是可由若干部分重叠的坐标片拼合而成的点集，且 $\mathbf{M}$ 的每一点都至少落在一个坐标片之内。
>
> (b) $\mathbf{M}$ 被赋予一种邻域结构（一种拓扑），使得：若 *U* 是 $\mathbf{M}$ 的一个坐标片，则存在 *U* 到 $\mathbf{R}^{n}$ 某区域上的连续一一映射 *f*，其逆 *f* ^{−1} 亦连续。（$\mathbf{R}^{n}$ 在此指一切实数 *n* 元组的集合，配以由开球生成的标准拓扑。）*f* 是 $\mathbf{M}$ 的一个坐标系或 **坐标卡**；坐标卡 *f* 赋予其坐标片内一点 *P* 的 *n* 元组中第 *k* 个数，称为 *P* 在 *f* 下的第 *k* 个坐标；坐标卡 *f* 的第 *k* 个坐标函数，是把坐标片内每一点对应到其在 *f* 下第 *k* 个坐标的实值函数。
>
> (c) 存在 $\mathbf{M}$ 的一个坐标卡集合 $\mathbf{A}$，它在 $\mathbf{M}$ 的每个坐标片上都至少含有一个定义于其上的坐标卡，并且：若 *g* 与 *h* 属于 $\mathbf{A}$，则复合映射 *h* ○ *g*^{−1} 与 *g* ○ *h*^{−1}——称为 **坐标变换**——在其有定义之处任意阶可微。（用 $\mathbf{a}$ 表示实数 *n* 元组 <*a*₁, … , *a*_{*n*}>。若 $\mathbf{a}$ 是 *g* 赋予 $\mathbf{M}$ 中某点 *P* 的值，而 *h* 也赋予 *P* 一个值，则映射 *h* ○ *g*^{−1} 在 $\mathbf{a}$ 处有定义。设后一值为 *h*(*P*) = <*b*₁, … ,*b*_{*n*}> = $\mathbf{b}$；那么 $\mathbf{b}$ = *h* ○ *g*^{−1}($\mathbf{a}$)。既然 *h* ○ *g*^{−1} 把 $\mathbf{R}^{n}$ 的一个区域映入 $\mathbf{R}^{n}$，说 *h* ○ *g*^{−1} 可微便有意义。）这样的集合 $\mathbf{A}$ 称为 $\mathbf{M}$ 的一个 **图册**。[^note-sup1]

严格说来，正是有序对 <$\mathbf{M}$, $\mathbf{A}$> 才是上述意义上的 *n* 流形。若 <$\mathbf{M}_1$,$\mathbf{A}_1$> 与 <$\mathbf{M}_2$,$\mathbf{A}_2$> 分别是一个 *n* 流形与一个 *m* 流形，那么完全可以说：映射 *f* 在 $\mathbf{M}_1$ 的点 *P* 处可微，意为对于定义于 *P* 的坐标卡 *h* 与定义于 *f*(*P*) 的坐标卡 *g*，复合映射 *g* ○ *f* ○ *h*^{−1} 在 *h*(*P*) 处可微。（条件 (c) 表明，此要求能否满足并不取决于 *h* 与 *g* 的选取。）*f* 若在 $\mathbf{M}_1$ 的每一点处皆可微，便是可微的。

设 <$\mathbf{M}$,$\mathbf{A}$> 是一个 *n* 流形。对 $\mathbf{M}$ 的每一点 *P*，都配上一个向量空间，称为 *P* 处的 **切空间**，记作 $T_{P}\mathbf{M}$。此念基于曲面在给定点处切平面这一直觉。构造如下：设 γ 是实数开区间 **I** 到 $\mathbf{M}$ 的一一可微映射。可把 γ 的相继取值，看作一点在 **I** 所代表的时间区间内穿行 $\mathbf{M}$ 的路径。称 γ 为 $\mathbf{M}$ 中的一条 **曲线**（以 *u* ∈ **I** 为参数）。取 *I* 中固定数 *t*_{0}，令 γ(*t*_{0}) = *P*。考虑定义于 *P* 某邻域上的一切可微实值函数所成之集 $\mathbf{F}(P)$。在通常的函数加法与数乘之下，$\mathbf{F}(P)$ 具有向量空间结构。$\mathbf{F}(P)$ 中每个函数 *f*，沿 γ 的路径在 *P* 的某邻域内随 *u* 光滑变化；它在 *P* = γ(*t*_{0}) 处的变率，恰由导数 *d*(*f* ○γ)/*d**u* 在 *u* = *t*_{0} 处的值表出。当 *f* 遍历 $\mathbf{F}(P)$ 时，*d*(*f* ○γ)/*d**u* 在 *u* = *t*_{0} 处的值在 **R** 中变动。于是得到 $\mathbf{F}(P)$ 到 **R** 的一个映射，记作 γ·(*u*)。它实际上是线性函数，因而是 $\mathbf{F}(P)$ 上实值线性函数所成对偶空间 F*(*P*) 中的一向量。称之为 γ 在 *P* 处的 **切向量**。过 *P* 的一切曲线在 *P* 处的切向量，张成 F*(*P*) 的一个 *n* 维子空间；此子空间按定义即切空间 $T_{P}\mathbf{M}$。*n* 流形 $\mathbf{M}$ 各点处的切空间可自然地汇拢成一个 2*n* 流形 $T\mathbf{M}$。投影映射 π 把 $T\mathbf{M}$ 映到 $\mathbf{M}$ 上，对 $T_{P}\mathbf{M}$ 中每个切向量 $\mathbf{v}$ 指派它在 $\mathbf{M}$ 上的切点 π($\mathbf{v}$)。结构 <$T\mathbf{M}$,$\mathbf{M}$,π> 即 $\mathbf{M}$ 上的 **切丛**。$\mathbf{M}$ 上的向量场是 $T\mathbf{M}$ 的一个截面，即 $\mathbf{M}$ 到 $T\mathbf{M}$ 的可微映射 *f*，使 π ○ *f* 把 $\mathbf{M}$ 的每一点 *P* 送到自身；这样的映射显然为 *P* 指派了 $T_{P}\mathbf{M}$ 中的一个向量。

任何向量空间 **V** 都自动与其他向量空间相联系，例如 **V** 上线性函数所成的对偶空间 V*，以及 **V** 上、V* 上、**V** 与 V* 各种可能组合上的多重线性函数空间。这对 *n* 流形 $\mathbf{M}$ 的每个切空间当然都成立。$T_{P}\mathbf{M}$ 的对偶称为 *P* 处的 **余切空间**。有一种自然的方式把 $\mathbf{M}$ 的各余切空间汇拢成一个 2*n* 流形，即 **余切丛**。一般说来，与 $\mathbf{M}$ 的切空间、余切空间相联系的一切确定类型的向量空间，都可自然地汇拢成一个 *k* 流形（*k* 为适当整数，视所汇拢对象的性质而定）。这类丛的任一截面，都是 $\mathbf{M}$ 上的一个 **张量场**（若所汇拢者为 *r* 重线性函数，则秩为 *r*）。

*n* 流形 <$\mathbf{M}$,$\mathbf{A}$> 上的一个 **黎曼度量** $\mathbf{g}$，是 $\mathbf{M}$ 上的二阶张量场。于是 $\mathbf{g}$ 为 $\mathbf{M}$ 中每个 *P* 指派 $T_{P}\mathbf{M}$ 上的一个双线性函数 $\mathbf{g}_{P}$。对 $\mathbf{M}$ 中任一 *P*，以及 $T_{P}\mathbf{M}$ 中任二向量 $\mathbf{v}$、$\mathbf{w}$，$\mathbf{g}_{P}$ 必须满足下列要求：

1. $\mathbf{g}_{P}$($\mathbf{v}$,$\mathbf{w}$) = $\mathbf{g}_{P}$($\mathbf{w}$,$\mathbf{v}$)　　（对称性）
2. 对 $T_{P}\mathbf{M}$ 中一切向量 $\mathbf{w}$，$\mathbf{g}_{P}$($\mathbf{v}$,$\mathbf{w}$) = 0 当且仅当 $\mathbf{v}$ 是零向量　　（非退化性）
3. 除非 $\mathbf{v}$ 是零向量，否则 $\mathbf{g}_{P}$($\mathbf{v}$,$\mathbf{v}$) > 0　　（正定性）。

值得注意的是，相对论在其时空模型上定义的所谓洛伦兹度量，满足要求 (i) 与 (ii)，却不满足 (iii)，故通常称为 **半黎曼** 度量或 **伪黎曼** 度量。

$T_{P}\mathbf{M}$ 中向量 $\mathbf{v}$ 的长度 λ($\mathbf{v}$)，由 |λ($\mathbf{v}$)|² = $\mathbf{g}_{P}$($\mathbf{v}$,$\mathbf{v}$) 定义。设 γ 是 $\mathbf{M}$ 中的一条曲线，γ·(*u*) 是 γ 在点 γ(*u*) 处的切线。则 γ 的路径自 γ(*a*) 至 γ(*b*) 的长度，由下述积分测度：

> | ∫ | *b* *a* | λ(γ·(*u*))*du* |
> | --- | --- | --- |

可见，在黎曼几何中，切向量 γ·(*u*) 的长度见证了曲线 *g* 经过点 γ(*u*) 时的推进。曲线长度的定义随即引出 **测地线**（或最直曲线）的概念：其特征为长度取极值；换言之，测地线在同样两点之间描出邻近路径的一切曲线中，或最长，或最短。

高斯研究曲面时引入过一个实值函数——**高斯曲率**，它依曲面的内蕴几何度量曲面局部偏离平坦的程度。黎曼把这一曲率概念推广到黎曼 *n* 流形。他注意到，这种流形中经过一点的每条测地线，完全由它在该点处的切向量决定。考虑黎曼 *n* 流形 <$\mathbf{M}$,$\mathbf{A}$,$\mathbf{g}$> 中的一点 *P*，以及 $T_{P}\mathbf{M}$ 中两个线性无关的向量 $\mathbf{v}$ 与 $\mathbf{w}$。由 $\mathbf{v}$ 与 $\mathbf{w}$ 的一切线性组合所确定的测地线，在 *P* 周围构成一个 2 流形，并在 *P* 处具有确定的高斯曲率 *K*_{*P*}($\mathbf{v}$,$\mathbf{w}$)。实数 *K*_{*P*}($\mathbf{v}$,$\mathbf{w}$) 度量 $\mathbf{M}$ 在 *P* 处沿 $\mathbf{v}$ 与 $\mathbf{w}$ 所确定的“曲面方向”（Riemann 1854, p. 145）的曲率。特别地，若 *n* = 3，且对点 *P* 与向量 $\mathbf{v}$、$\mathbf{w}$ 的每一种选择，*K*_{*P*}($\mathbf{v}$,$\mathbf{w}$) 都取同一常数值 *k*，则流形 <$\mathbf{M}$,$\mathbf{A}$,$\mathbf{g}$> 在 *k* = 0 时实现欧几里得空间，*k* < 0 时实现罗巴切夫斯基空间，*k* > 0 时实现球面空间或椭圆空间。黎曼（1861）构想出一个全局映射，它依赖度量 $\mathbf{g}$，在适当的自变量 *P*、$\mathbf{v}$、$\mathbf{w}$ 上给出 *K*_{*P*}($\mathbf{v}$,$\mathbf{w}$) 的适当值。如今此对象被设想为一个四阶张量场，它给黎曼 *n* 流形 <$\mathbf{M}$,$\mathbf{A}$,$\mathbf{g}$> 中每一点 *P* 指派切空间 $T_{P}\mathbf{M}$ 上的一个四重线性函数，故称 **黎曼张量**。由上述 *K*_{*P*}($\mathbf{v}$,$\mathbf{w}$) 的定义显然可见，若 *n* = 2，黎曼张量便归结为高斯曲率函数。

## 脚注

[^note-sup1]: 补充材料中对 *n* 流形的非形式刻画并不完全准确，可能涵盖某些我们不愿以这一概念涵盖的离奇怪物。对略知拓扑的读者，下述刻画更为可取。

> (a) 设 $\mathbf{M}$ 是一个点集。选取 $\mathbf{M}$ 的一族部分重叠子集，即 **坐标片**，使 $\mathbf{M}$ 的每一点都至少落在一个坐标片内。
>
> (b) 若 *U* 是 *M* 的一个坐标片，则存在 *U* 到 $\mathbf{R}^{n}$ 某开集上的一一映射 *f*，其逆记作 *f*^{−1}。（$\mathbf{R}^{n}$ 在此指一切实数 *n* 元组的集合，配以由开球生成的标准拓扑。）*f* 是 $\mathbf{M}$ 的一个坐标系或 **坐标卡**；坐标卡 *f* 赋予其定义域内一点 *P* 的 *n* 元组中第 *k* 个数，称为 *P* 在 *f* 下的第 *k* 个坐标；坐标卡 *f* 的第 *k* 个坐标函数，是把坐标片内每一点对应到其在 *f* 下第 *k* 个坐标的实值函数。
>
> (c) 存在 $\mathbf{M}$ 的一个坐标卡集合 $\mathbf{A}$，它在 $\mathbf{M}$ 的每个坐标片上都至少含有一个定义于其上的坐标卡，并且：若 *g* 与 *h* 属于 $\mathbf{A}$，则复合映射 *h*○*g*^{−1} 与 *g*○*h*^{−1}——称为 **坐标变换**——在其有定义之处任意阶可微。（用 $\mathbf{a}$ 表示实数 *n* 元组 (*a*₁, ... , *a*_{*n*})。若 $\mathbf{a}$ 是 *g* 赋予 $\mathbf{M}$ 中某点 *P* 的值，而 *h* 也赋予 *P* 一个值，则 *h*○*g*^{−1} 在 $\mathbf{a}$ 处有定义。设后一值为 *h*(*P*) = (*b*₁,...., *b*_{*n*}) = $\mathbf{b}$；那么 $\mathbf{b}$ = *h*○*g*^{−1}($\mathbf{a}$)。既然 *h*○*g*^{−1} 把 $\mathbf{R}^{n}$ 的一个区域映入 $\mathbf{R}^{n}$，说 *h*○*g*^{−1} 可微便有意义。）这样的集合 $\mathbf{A}$ 称为 $\mathbf{M}$ 的一个 **图册**。
>
> (d) 给定 $\mathbf{M}$ 的图册 $\mathbf{A}$，可唯一地把它扩张为极大图册 $\mathbf{A}_{\max}$，办法是：向 $\mathbf{A}$ 添加每一个把 $\mathbf{M}$ 的某子集一一映到 $\mathbf{R}^{n}$ 某开集上的映射 *g*，只要它与 $\mathbf{A}$ 中任一坐标卡 *h* 复合时满足 (c) 所陈述的可微性条件。
>
> (e) $\mathbf{M}$ 被赋予使 $\mathbf{A}_{\max}$ 中每个坐标卡 *g* 都成为同胚的最弱豪斯多夫拓扑。（拓扑空间若任两点都有互不重叠的开邻域，即称豪斯多夫空间。）

有序对 ($\mathbf{M}$,$\mathbf{A}$) 是一个 *n* 流形。
