# 钟的搬移（spacetime-convensimul 补充材料）

> （《spacetime-convensimul》词条补充材料，源：plato.stanford.edu/entries/spacetime-convensimul/transport-clocks.html）

#### 《同时性的约定性》词条补充材料

## 钟的搬移

有一种诉诸现象的方案特别值得一提，因为它多年来受到了大量关注：用钟在位置 *A* 与 *B* 之间搬移、取零速度极限来定义同步。Eddington（1924, 15）讨论了这种同步法，并指出它与用电磁信号得到的结果相同（电磁信号法就是这里所说的标准同步）。他对这两种方法评论如下（1924, 15–16）：“我们很难认为，这两种比较不同地点时间的方法，就像用循环机制在同一地点的测量那样，是我们原初时间观念的本质部分；因此，最好把它们看作约定。”

对用慢速搬移方案同步时钟的一个反对意见是：在诸钟同步之前，没有办法测量被搬运钟的单向速度。布里奇曼（Percy Bridgman；1962, 26）用“自测”速度来避免这个问题；所谓自测速度，是用被搬运的钟自己来测量时间间隔。在这种速度含义下，他提出（1962, 64–67）一个与 Eddington 等价的修正程序，但不要求从无穷过去开始。Bridgman 会以各种速度把若干钟从 *A* 搬到 *B*；这些钟在 *B* 处的读数互不相同。然后他挑出其中一只钟，比如速度最小的那只，求出它与其余各钟读数的差。最后，他把这些差对相应钟的速度作图，外推到零速度。与 Eddington 一样，Bridgman 并不认为这个方案与约定性论题相抵触。他说（1962, 66）：“爱因斯坦坚持他设定远距时钟的方法——即给 ε 取值 1/2——构成远距同时性的一种‘定义’，这一坚持后来怎样了？在我看来，爱因斯坦的评论丝毫没有失效。”

Ellis 与 Bowman（1967）持不同看法。他们用缓慢搬移同步时钟的方法（1967, 129–130）与上述方法又有些不同，但与之等价。他们在 *A* 与 *B* 处放置任意设定的钟。然后在 *A* 处放第三只钟，与已在那里的钟同步。接着他们把这只第三钟以他们所说的“介入‘速度’”搬到 *B*；这一速度由放在 *A* 与 *B* 处的钟测量时间间隔而定。他们会以递减的速度重复这一程序，外推求出 *B* 处的钟与被搬运钟读数之差的零速度极限。最后，他们把 *B* 处的钟往回拨这个极限量。基于对这一程序的分析，他们论证说：虽然自洽的非标准同步看起来可能，但有充分的物理学理由（假定狭义相对论的经验预测正确）偏好标准同步。他们的结论（如其 1967, 116 摘要所概括）是：“赖欣巴哈与格吕恩鲍姆尤力主张的远距同时性约定性论题，由此或者流于琐碎，或者遭到驳斥。”

针对 Ellis 与 Bowman 的上述看法，有多种回应（例如 Grünbaum *et al*. 1969；Winnie 1970b, 223–228；以及 Redhead 1993, 111–113）论证说：选择用缓慢搬移法同步时钟，本身就隐含非平凡的约定。例如，Grünbaum（Grünbaum *et al*. 1969, 5–43）论证说：以无穷慢速从 *A* 走到 *B* 的钟测得的间隔，等同于留在 *A* 处且与 *B* 处钟保持标准同步的钟测得的间隔，这本身就是非平凡约定；van Fraassen（Grünbaum *et al*. 1969, 73）的结论则是：“Ellis 与 Bowman 并没有证明标准同时性关系是非约定的——它确实不是——他们只是成功地展示了一些同样给出那个同时性关系的替代约定（*alternative conventions*）。”Winnie（1970b）用他把狭义相对论按任意同步重新表述的方案，明确表明：当两者都以 0 < ε < 1 范围内任意的 ε 值来描述时，慢钟搬移同步与标准光信号法同步一致；他还论证说，Ellis 与 Bowman 的错误在于论证中假定了 ε=1/2 形式的时间膨胀公式。他的结论是（Winnie 1970b, 228）：“在狭义相对论的非约定成分的框架内，慢速搬移方法或任何别的同步方法，都不可能把 ε 固定到任何一个特定值上而排除其他特定值。”Redhead（1993）也论证说，缓慢搬移钟给不出无约定的同时性定义。他说（1993, 112）：“‘慢’这个词没有绝对的事实意义。如果我们相对于运动参照系 *K*′ 来估计‘慢’，那么慢钟搬移将在 *K*′ 中挑出标准同步，但这……对应于 *K* 中的非标准同步。”

另一种搬钟方案避免了“慢”的问题：让钟从 *A* 运动到 *B* 再返回（每个方向都沿直线路径），整个往返保持相同的自测速度（Mamone Capria 2001, 812–813；如 Mamone Capria 所说，他的方案与 Brehme（1985, 57–58；1988, 811–812）所提方案类似）。若运动钟于时刻 *t*₁（由静止于该处的钟测量）离开 *A*，到达 *B* 时恰好与 *B* 处的事件 *E* 重合，并于时刻 *t*₂ 回到 *A*，那么标准同步就是：*E* 与 *A* 处发生在时刻 (*t*₁ + *t*₂)/2 的事件同时。这个搬钟方案看来与慢速搬移方案足够相似，会引起大体相同的争论——除了争论中专门聚焦“慢”问题的那些方面。
