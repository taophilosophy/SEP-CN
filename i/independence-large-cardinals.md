# 大基数与独立性 independence and large cardinals (Peter Koellner)

*首次发表于 2010 年 4 月 20 日。*

算术与集合论中的独立性结果导致数学系统的激增。研究可能数学系统之空间的一个非常一般的方式，是在可解释性关系之下来考察。在这种关系下，可能数学系统的空间形成了一个由越来越强的系统构成的复杂层级。大基数公理为攀登这一层级提供了典范性的手段，并在比较来自概念上不同领域的系统时扮演着核心角色。

本文是对独立性、可解释性、大基数及其相互关系的一个导论。第 1 节概览算术与集合论中的经典独立性结果。第 2 节介绍可解释性层级，并描述其一些基本特征。第 3 节介绍大基数公理的概念，并讨论一些核心例子。第 4 节把前述主题汇聚起来，讨论大基数公理如何为攀登可解释性层级提供典范性手段，并充当比较来自概念上不同领域的系统的中介。第 5 节简要触及一些哲学思考。

## 1 独立性

让我们从 **公理系统** 的概念开始。为了引出这一概念，请考虑传统上数学中的辩护是如何进行的。在关于某个数学领域（事实上，任何领域）进行推理时，辩护问题被一步步地不断推回，直到最终达到一些不容更根本辩护的原则。这一终末阶段的陈述被选为 **公理**，然后该主题便依据从公理基中的可推演性来组织。在算术的情形，这导致公理系统 PA（皮亚诺算术）；在集合论的情形，这导致公理系统 ZFC（策梅洛-弗兰克尔集合论加上选择公理）。

两个自然的问题出现：（1）如果公理不容更根本的辩护，那么人们如何为它们辩护？（2）公理基是否足够丰富，使人能在此基础上判定每个语句？

关于公理的认识论地位，有两种传统观点。第一种观点认为，公理不容进一步的辩护，因为它们是 **自明** 的。第二种观点认为，公理不容进一步的辩护，因为它们是 **对主题具有界定性** 的。关于我们第一个问题的这两种观点，各自导致一个关于我们第二个问题的相应乐观看法——根据第一种乐观看法，一切数学真理都（在一阶逻辑中）可从自明真理推演出来；而根据第二种乐观看法，一切数学真理都（在一阶逻辑中）可从对主题具有界定性的陈述推演出来。倘若这两种乐观看法中有任何一种被证明是正确的，那么数学中的辩护问题就会呈现一个特别简单的形式：要么一个陈述是公理（在这种情况下它是自明的或对主题具有界定性的，取决于所考虑的观点），要么它可以在一阶逻辑中从若干此类陈述推演出来。

不幸的是，这些乐观看法在 1931 年受到哥德尔不完备性定理的挑战。以下是第二不完备性定理的一个版本：

> **定理 1.1**（Gödel, 1931）。设 PA 是一致的，则 PA 不证明 Con(PA)。

这里 Con(PA) 是一个算术陈述，表达 PA 一致这一非形式陈述。[^note-1] 在稍强一些的假设下（例如，PA 是 Σ01 可靠的[^note-2]），可以把结论加强，加上 PA 不证明 ¬Con(PA)；换言之，在这个更强的假设下，Con(PA) 对 PA 是 **独立** 的。这样，我们这里就有一个算术陈述（事实上是一个非常简单的陈述）不能被标准公理判定的情形。此外，该定理是完全一般的——它不仅对 PA 成立，而且对任何足够强的形式系统 *T* 成立。

这对前述两种关于数学真理本性的乐观看法提出了挑战。首先它表明，我们不能用一个 **固定** 的公理系统 *T* 来工作。我们总是需要引入新公理。更重要的是，它引出一个问题：人们如何为这些新公理辩护？因为随着人们不断加入越来越强的公理，关于它们要么自明、要么对主题具有界定性的主张，将变得越来越难以辩护。

早在 1931 年，哥德尔就指出了一种为公理辩护的自然方式。他指出，如果人们越过自然数并攀登类型层级（自然数的集合、自然数集合的集合，等等），就会达到一些公理（二阶算术 PA₂ 的公理、三阶算术 PA₃ 的公理，等等），这些公理判定了他所发现的那些未决陈述。第二层的公理系统 PA₂ 判定第一层留下的未决陈述，即 Con(PA)；事实上，PA₂ 证明 Con(PA)，这正是所期望的结果。但现在我们在第二层有了一个问题。因为第二不完备性定理表明（在类似前述的背景假设下）PA₂ 不判定 Con(PA₂)。幸运的是，第三层的公理系统 PA₃ 判定第二层留下的未决陈述，即 Con(PA₂)。这种模式继续下去。对每个问题都有一个解，对每个解都有一个新问题。这样，通过攀登类型层级，人们达到一些系统，它们相继判定沿途出现的那些一致性陈述。

上述类型层级可以在集合论的统一框架中重铸。集合论层级通过归纳定义：从空集开始，在后继阶段 α+1 取幂集，在极限层级 λ 取并集：

| *V*₀ | = ∅ |
| --- | --- |
| *V*_{α+1} | = *P*(*V*_{α}) |
| *V*_{λ} | = ∪_{α < λ} *V*_{α} |

**集合宇宙** *V* 是所有此类阶段的并：*V*=∪_{α∈On} *V*_{α}，其中 On 是序数类。第一个无穷层级 *V*_{ω} 由所有遗传有限集合组成[^note-3]，这个层级满足 ZFC-Infinity。此层级的集合可用自然数编码，由此可以证明 PA 与 ZFC-Infinity 相互可解释。[^note-4] 第二个无穷层级 *V*_{ω+1} 本质上就是 *P*(ℕ)（或等价地，ℝ），这个层级满足（与 PA₂ 相互可解释的理论）。第三个无穷层级 *V*_{ω+2} 本质上就是 *P*(*P*(ℕ))（或等价地，作为实数函数的集合），这个层级满足（与 PA₃ 相互可解释的理论）。前三个无穷层级因此涵盖算术、分析与泛函分析，进而涵盖标准数学的大部分。这样，集合的层级及其关联的集合论系统涵盖了标准数学的对象与系统。

现在，如果事实证明一致性语句（以及哥德尔在 1931 年发现的其他相关语句）是 **唯一** 的不可判定语句实例，那么上述层级中的系统序列就会抓住出现的每个问题。而且，尽管我们永远不会有一个给出数学真理完全公理化的 **单一** 系统，我们却会有一个 **系列** 的系统，它们集体涵盖了数学真理的总和。

不幸的是，事情并非如此简单。麻烦在于，当人们以这种方式攀登集合层级时，可用的更丰富的表达资源会导致更棘手的不可判定语句实例，这在第二和第三个无穷层级上已经如此。例如，在第二个无穷层级上可以表述语句 PM（所有射影集合都是勒贝格可测的），在第三个无穷层级上可以表述 CH（康托尔连续统假设）。[^note-5] 这些语句在集合论的早期时代被深入探究，但进展甚微。解释最终由哥德尔与科恩随后的独立性技术提供。

哥德尔（1938 年）发明了 **内模型** 方法，定义了极小内模型 *L*。这个模型的定义方式与 *V* 相同，只是在后继阶段不是取前一阶段的 **完全幂集**，而是取前一阶段的 **可定义幂集**；对于给定集合 *X*，*X* 的可定义幂集 Def(*X*) 是 *X* 的、可在 *X* 上以 *X* 中的参数定义的全体子集组成的集合：

| *L*₀ | = ∅ |
| --- | --- |
| *L*_{α+1} | = Def(*L*_{α}) |
| *L*_{λ} | = ∪_{α < λ} *L*_{α} |

内模型 *L* 是所有此类阶段的并：*L* = ∪_{α∈On} *L*_{α}。哥德尔证明了 *L* 满足（任意大片段）ZFC 以及 CH。由此推出 ZFC 不能否证 CH。科恩（1963 年）发明 **力迫**（或 **外模型**）方法，补全了这一结果。给定一个完备布尔代数 **B**，他定义了一个模型 *V*^{B}，并证明了 ¬CH 在 *V*^{B} 中成立。[^note-6] 其后果是 ZFC 不能证明 CH。这样，这些结果一起表明 CH 对 ZFC 是独立的。类似的结果对 PM 以及集合论中的许多其他问题也成立。

这些独立性实例更棘手，因为类型层级的简单迭代不会导致它们的解决。它们引出了对新公理更深刻的探索。

哥德尔再次为新公理的探索提供了最初几步。1946 年，他提出把 **大基数公理** 作为新公理——这些无穷公理断言类型层级有非常巨大的层级存在——他甚至走得如此之远，以致设想这类公理的一个广义完备性定理，根据它，集合论的所有陈述都能被这类公理判定（Gödel 1946, 151）。[^gödel-1946]

本词条余下部分的目的是描述独立性的本性（连同可解释性层级）以及独立性与大基数公理之间的联系。

**延伸阅读**：关于不完备性定理的更多内容，见 Smoryński（1977）、Buss（1998a）与 Lindström（2003）。关于集合论中独立性技术的更多内容，见 Jech（2003）与 Kunen（1980）。

## 2 可解释性层级

我们的目标是考察数学理论（被理解为递归可枚举公理系统）的空间。我们将考虑的这种理论空间上的序，是 **可解释性**。可解释性的非形式概念在数学中无处不在；例如，庞加莱在单位圆的欧氏几何中提供了二维双曲几何的一个解释；戴德金在集合论中提供了分析的一个解释；哥德尔在算术中提供了形式语法理论的一个解释。

我们将使用这一非形式概念的一个精确形式化版本。设 *T*₁ 和 *T*₂ 是递归可枚举公理系统。我们说 *T*₁ 在 *T*₂ 中 **可解释**（*T*₁ ≤ *T*₂），粗略地说，当存在一个从 *T*₁ 的语言到 *T*₂ 的语言的翻译 τ，使得对 *T*₁ 的语言的每个语句 φ，若 *T*₁⊢φ 则 *T*₂⊢τ(φ)。[^note-7] 当 *T*₁≤ *T*₂ 且 *T*₂≰ *T*₁ 时，我们写作 *T*₁ < *T*₂；当 *T*₁≤ *T*₂ 且 *T*₂≤ *T*₁ 时，写作 *T*₁≡ *T*₂。在后一情形，*T*₁ 与 *T*₂ 称为 **相互可解释**。与 *T* 相互可解释的所有理论的等价类，称为 *T* 的 **可解释度**。

为便于阐述，我们对所考虑的理论作三个简化假设。第一，我们假设所有理论都用集合论的语言表述。这一假设不失一般性，因为每个理论都与一个在此语言中表述的理论相互可解释。例如，如前所述，PA 与 ZFC-Infinity 相互可解释。第二，我们假设所有理论都包含 ZFC-Infinity。第三，我们假设所有理论都是 Σ01 可靠的。

**可解释性层级** 是满足我们三个简化假设的所有理论按关系 ≤ 排序而成的类。现在我们转向对这一层级结构的讨论。

首先，关系 ≤ 有一个有用的刻画。让我们写作 *T*₁ ⊆ _{Π01} *T*₂ 来表示：在 *T*₁ 中可证明的每个 Π01 语句也在 *T*₂ 中可证明。可解释性理论的一个中心结果是（在我们简化假设成立的前提下）*T*₁≤ *T*₂ 当且仅当 *T*₁ ⊆ _{Π01} *T*₂。由这一刻画和第二不完备性定理推出，对任何理论 *T*，理论 *T* + Con(T) 严格强于 *T*，即 *T* < T + Con(T)。此外，由算术化完备性定理推出，理论 *T* + ¬Con(T) 在 *T* 中可解释，因此 *T* ≡ *T* + ¬Con(*T*)。

就可解释性而言，一个语句 φ 对理论 *T* 独立有三种可能方式。

1. 单跳。φ 或 ¬φ 中只有其一导致强度的跳升，即 *T* + φ > *T* 且 *T* + ¬φ ≡ *T*（或 φ 与 ¬φ 互换亦然）。
2. 无跳。φ 与 ¬φ 都不导致强度的跳升，即 *T* + φ ≡ *T* 且 *T* + ¬φ ≡ *T*。
3. 双跳。φ 与 ¬φ 都导致强度的跳升，即 *T* + φ > *T* 且 *T* + ¬φ > *T*。

事实证明，这些可能性每种都被实现。对第一种，取 Π01 语句 Con(T) 即可。对第二种，容易看出不存在 Π01 的例子；这类语句的最简单可能复杂度是 Δ02，事实证明存在这样的例子；这类独立性实例称为 **奥雷语句**。对第三种独立性，存在 Π01 实例。（这是 Lindström（2003）第 128–129 页引理 14 的一个推论。）

这些全是元数学的例子，是只有逻辑学家才会构造的那类例子。自然会问：是否存在“自然的”例子，即大致在数学正常进程中出现的例子？在集合论情形，这类例子在前两种情形中是丰富的。例如，PM 是第一种独立性的例子，CH 是第二种独立性的例子。第三种独立性没有已知的“自然的”例子。在算术情形，这类例子是罕见的。有第一种独立性的例子（其中最著名的是帕里斯与哈林顿的一个经典例子），但没有第二或第三种独立性的例子。

注意，在第三种例子的情形，*T* 之上的两个理论在可解释性序中不可比较。为了构造这样一对 Π01 语句，人们使用对角线引理的一个互反形式来构造两个相互指涉的 Π01 语句。使用这类技术可以表明可解释性序相当复杂。例如，对任意两个理论 *T*₁ 和 *T*₂ 满足 *T*₁ < *T*₂，存在第三个理论 *T* 使得 *T*₁ < *T* < *T*₂。这样，可解释度上的序既不是线序，也不是良基的。（见 Feferman（1960）。）

值得注意的是，当人们限制到那些“自然出现的”理论时，事实证明可解释性序相当简单：没有下降链，也没有不可比较的元素——在“自然界中出现的”理论上的可解释性序是良序。特别地，尽管有第一和第二种独立性的自然例子（例如 PM 与 CH，我们下面会回头讨论），但没有已知的第三种独立性的自然例子。

所以，对于“自然界中出现的”理论，我们在可解释性序下有一个良序层级。在该序的底部，有我们的极小理论 ZFC-Infinity 所代表的那个度，而且只有一种前进方式，即按强度向上。

我们已经看到攀登可解释度层级的一种方式，即加入一致性语句。这种方法有两个缺点。第一，如果从一个“自然出现的”理论开始并加入一致性语句，就落入一个没有已知“自然出现的”代表的度。第二，一致性语句不会把人们带得很高。这两个缺点都由一个非常自然的公理类——大基数公理——所补救。

**延伸阅读**：关于可解释性层级结构的更多内容，见 Lindström（2003）第 6–8 章。

## 3 大基数公理

设 Z₀ 是理论 ZFC-Infinity-Replacement。（这个理论逻辑等价于我们的基理论 ZFC-Infinity。）我们将通过反射式地加入断言集合宇宙的某些层级存在的公理，相继加强 Z₀。

Z₀ 的标准模型是 *V*_{ω}。无穷公理（在一种表述中）只是断言这个集合存在。所以，当我们加入无穷公理时，所得理论 Z₁（称为策梅洛集合论加上选择公理）不仅证明 Z₀ 的一致性；它还证明 Z₀ 有一个标准模型。现在 Z₁ 的标准模型是 *V*_{ω+ω}。替换公理蕴含这个集合存在。所以，当我们加入替换公理时，所得理论 Z₂（称为 ZFC）不仅证明 Z₁ 的一致性；它还证明 Z₁ 有一个标准模型。

Z₂ 的一个标准模型具有 *V*_{κ} 的形式，其中 κ 是一个正则基数，使得对所有 α < κ，2^{α} < κ。这样的基数称为（强）**不可达** 基数。所考虑的层级中的下一个公理，是断言这样一个基数存在的陈述。所得理论 ZFC + “存在强不可达基数”证明宇宙有一个满足 ZFC 的层级。以这种方式继续，人们达到越来越强的公理，断言集合宇宙有越来越大层级的存在。在继续勾勒这类公理之前，让我们先建立与可解释性层级的联系。

回想我们对三种独立性类型的分类。我们注意到，第三种独立性没有已知的自然例子，但有第一和第二种独立性的自然例子。

第二种独立性的自然例子由内模型与外模型的双重方法提供。例如，这些方法表明，理论 ZFC+CH 与 ZFC+¬CH 与 ZFC 相互可解释，即这三个理论位于同一度。换言之，CH 关于 ZFC 是一个奥雷语句。我们引入的另一个语句 PM 呢？

使用内模型方法，哥德尔证明了 ¬PM 在 *L* 中成立。由此推出 ZFC+¬PM 与 ZFC 相互可解释。但 PM 呢？为了证明 ZFC+PM 与 ZFC 相互可解释，一个自然的进路是沿用 CH 所用方法，构造一个满足 PM 的 ZFC 外模型。然而，已知这不能单从 ZFC 出发做到。因为事实证明（由 Shelah（1984）的一个结果）ZFC+PM 蕴含 ZFC 的一致性，而这（由第二不完备性定理）蕴含 ZFC+PM 不在 ZFC 中可解释。某种意义上，我们这里有一个独立性的独立性情形。更确切地说，即使我们假设 ZFC 是一致的，我们也不能（与 CH 的情形相对照）证明 PM 对 ZFC 独立。为了确立 PM 对 ZFC 的独立性，我们需要假设一个 **更强** 的理论的一致性，即 ZFC + “存在强不可达基数”的一致性。因为事实证明，ZFC+PM 不在 ZFC 的可解释度中，而在 ZFC + “存在强不可达基数”的可解释度中。概括来说：CH 是第二种独立性的情形，PM 是第一种独立性的情形；它类似于 Con(ZFC)，因为它是一个语句 φ，使得 φ 或 ¬φ 中只有其一导致强度跳升，只是现在有两个差别；跳升落入一个强得多的度，而且它由一个自然理论代表。

一般而言，（已知的）集合论语句要么像 CH，要么像 PM。有些像 CH，因为 ZFC+φ 与 ZFC+¬φ 都位于 ZFC 的度。另一些像 PM，因为 ZFC+φ 与 ZFC+¬φ 中有一个位于 ZFC 的度，而另一个位于经由大基数公理的 ZFC 扩张的度。

现在回到我们的大基数公理概览。在强不可达基数之后，有马洛基数、不可描述基数与不可言状基数。所有这些大基数公理都能用传统的各类反射原理以统一方式推得（见 Tait 2005），但这类反射原理能把人们带多远是有限制的。因为在这种原则的一个非常一般的刻画下，已知它们不能产生厄多斯基数 κ(ω)。见 Koellner（2009）。

迄今所考虑的大基数（包括 κ(ω)）称为 **小** 大基数。一个大基数是 **小** 的，如果相应的大基数公理能在哥德尔的可构造宇宙 *L* 中成立，即如果“*V* ⊨ κ 是 φ-基数”一致，则“*L* ⊨ κ 是 φ-基数”一致。否则大基数是 **大** 的。

有一个用于表述（大）大基数公理的简单模板，以初等嵌入为术语。一般地，这样的公理断言存在一个传递类 *M* 和一个非平凡初等嵌入

> *j* : *V* → *M*。

说嵌入是非平凡的，只是说它不是恒等映射，在这种情况下必然有一个被移动的极小序数。这个序数称为 *j* 的 **临界点**，记为 crit(*j*)。临界点（典型地）是与该嵌入关联的大基数。一个基数 κ 称为 **可测** 的，当且仅当它是某个此类嵌入的临界点。[^note-8]

容易看出，对任何此类嵌入，*V*_{κ+1}⊆ *M*，其中 κ = crit(*j*)。这种程度的一致使人能够证明 κ 是强不可达、马洛、不可描述、不可言状等等。为说明这一点，让我们假设我们已经证明 κ 是强不可达的，并证明 κ 具有强得多的大基数性质。因为 κ 在 *V* 中是强不可达的，且因为 (*V*_{κ+1})^{*M*} =*V*_{κ+1}，*M* 也认为 κ 是强不可达的。特别地，*M* 认为在 *j*(κ) 之下有一个强不可达基数（即 κ）。但由 *j* 的初等性，*V* 必定对 *j*(κ) 的原像即 κ 认为同样的事，即 *V* 必定认为在 κ 之下有一个强不可达基数。所以 κ 不能是最小的强不可达基数。以这种方式继续，人们可以证明在 κ 之下有许多强不可达基数，事实上 κ 是马洛、不可描述、不可言状等等。所以可测基数包摄小大基数。

事实上，斯科特证明了（与小大基数相对照）可测基数不能在哥德尔的可构造宇宙中存在。让我们对此精确化。设 *V*=*L* 是断言所有集合都是可构造的陈述。那么对每个小大基数公理 φ（准确说，上述列出的那些），如果理论 ZFC+φ 一致，那么理论 ZFC+φ+*V*=*L* 也一致。相对照，理论 ZFC + “存在可测基数”证明 ¬*V*=*L*。这似乎有点反直觉，因为 *L* 包含所有序数，所以如果 κ 是可测基数，那么 κ 是 *L* 中的一个序数。要点在于，*L* 不能“识别”κ 是可测基数，因为它太“薄”了，无法包含见证 κ 可测性的超滤子。

基于上述模板加强大基数公理的一种方式，是要求 *M* 与 *V* 之间有更大的一致。例如，如果人们要求 *V*_{κ+2}⊆ *M*，那么 κ 可测这一事实（由 *P*(κ) 的一个子集所见证）就能被 *M* 识别。于是，恰好用我们上面使用的论证，在 κ 之下必定有一个可测基数。

这导致一个越来越强的大基数公理的序列。讨论这一层级中的一些主要踏脚石将是有用的。

如果 κ 是一个基数且 η>κ 是一个序数，那么 κ 是 η- **强** 的，如果存在一个传递类 *M* 和一个非平凡初等嵌入 *j*: *V* → *M*，使得 crit(*j*)=κ、*j*(κ)>η 且 *V*_{η}⊆ *M*。一个基数 κ 是 **强** 的，当且仅当它对所有 η>κ 是 η-强的。人们也可以要求嵌入保持某些类：如果 *A* 是一个类，κ 是一个基数，且 η>κ 是一个序数，那么 κ 是 η-*A*- **强** 的，如果存在一个 *j*: *V* → *M*，它见证 κ 是 η-强的，并具有附加特征 *j*(*A* ∩ *V*_{κ}) ∩ *V*_{η} = *A* ∩ *V*_{η}。下列大基数概念在新公理探索中扮演核心角色。

> **定义 3.1**. 一个基数 κ 是 **伍丁基数**，如果 κ 是强不可达的，且对所有 *A*⊆ *V*_{κ} 存在一个基数 κ_{*A*} < κ，使得
>
> > κ_{*A*} 是 η-*A*-强的，
>
> 对每个满足 κ_{*A*} < η < κ 的 η。[^note-9]

人们可以通过在嵌入 *j* 与 *M* 和 *V* 的相似程度之间锻造联系，获得更强的大基数公理。例如，一个基数 κ 是 **超强** 的，如果存在一个传递类 *M* 和一个非平凡初等嵌入 *j*: *V* → *M*，使得 crit(*j*)=κ 且 *V*_{j(κ)}⊆ *M*。如果 κ 是超强的，那么 κ 是伍丁基数，且在 κ 之下有任意大的伍丁基数。

人们也可以通过给目标模型 *M* 施加闭包条件获得强大基数公理。例如，令 γ ≥ κ，一个基数 κ 是 γ- **超紧** 的，如果存在一个传递类 *M* 和一个非平凡初等嵌入 *j*: *V* → *M*，使得 crit(*j*)=κ 且 ^{γ}*M*⊆ *M*，即 *M* 在 γ-序列下封闭。（容易看出，如果 *M* 在 γ-序列下封闭，那么 *H*(γ^{*+*})⊆ *M*；所以这种方法包摄前一种方法。）一个基数 κ 是 **超紧** 的，如果它对所有 γ ≥ κ 是 γ-超紧的。现在，正如前一种方法，人们可以通过在嵌入 *j* 与目标模型上的闭包条件之间锻造联系来加强这些公理。一个基数 κ 是 *n*- **巨大** 的，如果存在一个传递类 *M* 和一个非平凡初等嵌入 *j*:*V* → *M*，使得 ^{*j* *n*}(κ)*M* ⊆ *M*，其中 κ=crit(*j*)，且 *j* ^{*i*+1}(κ) 定义为 *j*(*j* ^{*i*}(κ))。

人们可以继续这一路数，要求 *M* 与 *V* 之间有更大的一致。这一方向的终极公理当然会要求 *M* = *V*。这个公理由赖因哈特提出，不久后由库嫩证明在（ZFC 中）不一致。事实上，库嫩证明了，假设 ZFC，可以有一个传递类 *M* 和一个非平凡初等嵌入 *j*: *V* → *M*，使得 *j* ‘’ λ ∈ M，其中 λ=sup_{*n* < ω} *j* ^{*n*}(κ) 且 κ=crit(*j*)。特别地，不能存在这样的 *M* 和 *j* 使得 *V*_{λ+1}⊆ *M*。这对目标模型的闭包量（相对于嵌入）施加了一个限制。（译注：此句按原文照录；按 Kunen 不一致性定理的标准表述，应为“不存在”这样的传递类 *M* 与嵌入 *j*，原文疑脱 no 一词。）[^note-10]

然而，在上述上界之下有很大空间。例如，一个非常强的公理是：存在一个非平凡初等嵌入 *j*:*V*_{λ+1}→ *V*_{λ+1}。当前文献中最强的大基数公理是：存在一个非平凡初等嵌入 *j*: *L*(*V*_{λ+1})→ *L*(*V*_{λ+1})，使得 crit(*j*)<λ。在最近的工作中，伍丁发现了远强于此的公理。

**延伸阅读**：关于大基数公理的更多内容，见 Kanamori（2003）。

## 4 大基数公理与可解释性层级

上文讨论的大基数公理在强度上自然地良序。[^note-11] 这提供了攀登可解释性层级的一种自然方式。在底部，我们从理论 ZFC-Infinity 开始，然后攀登到 ZFC，并向上穿过 ZFC+Φ（对各种大基数公理 Φ）。注意，对两个大基数公理 Φ 和 Ψ，如果 Ψ 强于 Φ，那么 Ψ 蕴含 Φ 有一个标准模型，于是我们有 ZFC+Φ 在 ZFC+Ψ 中的一个自然解释。

我们已经注意到，ZFC+¬PM 与 ZFC+LC 相互可解释，其中 LC 是大基数公理“存在强不可达基数”，而且这是用内模型与外模型论的双重技术证明的。这是一个显著的经验事实：对集合论语言中的任何“自然的”语句 φ，人们通常能找到一个大基数公理 Φ，使得 ZFC+φ 与 ZFC+Φ 相互可解释。同样，这是用内模型与外模型论的双重技术确立的，只是现在大基数也参与进来。为了确立 ZFC+Φ 解释 ZFC+φ，人们通常从一个 ZFC+Φ 的模型出发，用力迫构造一个 ZFC+φ 的模型。在许多情形，力迫构造涉及“坍塌”与 Φ 关联的大基数，并以使 φ 在“废墟”中成立的方式安排坍塌。在另一方向，人们通常从一个 ZFC+φ 的模型出发，然后构造一个内模型（一个类似 *L* 但能容纳大基数公理的模型），它包含 Φ 断言存在的大基数。集合论中被称为 **内模型理论** 的分支，致力于为越来越强的大基数公理构造此类“*L*-类”模型。

这样，ZFC+LC 形式的理论（其中 LC 是大基数公理）为衡量理论的强度提供了一个标尺。它们也充当比较来自概念上不同领域的理论的中介：给定 ZFC+φ 与 ZFC+ψ，人们找到大基数公理 Φ 与 Ψ，使得（用内模型与外模型方法）ZFC+φ 与 ZFC+Φ 相互可解释，且 ZFC+ψ 与 ZFC+Ψ 相互可解释。然后人们（就可解释性而言）比较 ZFC+φ 与 ZFC+ψ，经由 ZFC+Φ 与 ZFC+Ψ 之间的自然可解释性关系作中介。所以大基数公理（连同内模型与外模型的双重方法）居于这一显著经验事实的核心：来自完全不同领域的自然理论就能按可解释性相互比较。

## 5 若干哲学思考

独立性结果引出的主要问题是：人们能否为判定标准公理所留下的未决陈述的新公理辩护。有两种观点。第一种观点认为答案是否定的，人们拥抱一种激进形式的多元主义，其中有大量同样合法的标准公理扩张。第二种观点认为答案（至少部分地）是肯定的，这些结果只是表明 ZFC 太弱，不足以捕获数学真理。这个话题相当复杂，超出本文的范围。

但有其他与本文主题更直接相关的哲学问题。第一，大基数公理似乎在可解释性下良序这一经验事实的意义是什么？第二，大基数公理在比较许多来自概念上不同领域的理论时扮演核心角色这一经验事实的意义是什么？让我们依次考虑这两个问题。

人们或许试图论证，大基数公理在可解释性下良序这一事实是支持它们的一个考量。然而，这会是一个薄弱论证。因为，正如我们上面注意到的，所有“自然的”理论似乎都在可解释性下良序，这包括彼此不相容的理论。例如，很容易从良序序列中越来越高度的理论中选出彼此不相容的“自然的”理论。由此推出，在可解释性下良序这一特征，尽管显著，却不能成为支持真理的一个论点。

但大基数公理具有把它们从良序度的序列中的自然理论类中单独挑出来的额外特征。首先，它们提供了攀登可解释性层级的最自然方式——它们是纯粹数学力量的最简单、最自然的体现。但更重要的是上述第二个成分，即大基数公理充当比较来自概念上不同领域的理论的中介。因为回想这如何运作：给定 ZFC+φ 与 ZFC+ψ，人们找到大基数公理 Φ 与 Ψ，使得（用内模型与外模型方法）ZFC+φ 与 ZFC+Φ 相互可解释，且 ZFC+ψ 与 ZFC+Ψ 相互可解释。然后人们（就可解释性而言）比较 ZFC+φ 与 ZFC+ψ，经由 ZFC+Φ 与 ZFC+Ψ 之间的自然可解释性关系作中介。

事实证明，在许多情形这是比较 ZFC+φ 与 ZFC+ψ 的 **唯一已知方式**，即在许多情形，任一方向都没有直接解释，相反人们 **必须经由大基数公理**。能否用这一额外特征为大基数公理辩护？答案不清楚。然而，清楚的是大基数公理在集合论中的绝对核心地位。
