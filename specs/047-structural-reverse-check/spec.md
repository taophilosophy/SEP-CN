# 047 — 结构反向核验：md ↔ HTML 结构比对补 I2 自证盲区

**版本** v1.0 ｜ **状态** 方案（待实施）｜ **日期** 2026-11-18 ｜ **权威** 用户“全部批准”（ADR-0072 决策 2）｜ **承接** ADR-0070 建议⑤

## 0. 方向声明

- **目标**：补 B1 的 I2 自证盲区。I2 只证“md == convert(en)”（没手改、没漂移），不证“convert 本身对不对”——转换器 bug 会让两边都错、I2 全绿。结构反向核验把 md 解析回结构，与 HTML 结构比对，抓这类盲区。
- **非目标**：不改 en/、不改 yuanwen/、不产译文、不全量翻译。机检性质，可全量；初期用测试词条验证判据。

## 1. 判据（结构轴，非词元流）

| 维度 | 判据 |
|---|---|
| 分节 | h2/h3 数量与层级序列一致 |
| 脚注 | sup 引用键位 ↔ 脚注定义一一对应，序一致 |
| 图/表/公式块 | 数量与文档序一致 |
| 列表 | 有序/无序层级一致 |
| 引用 | citation meta / 参考文献条目数一致 |

## 2. 方案

1. md → 结构树：从 `yuanwen/<letter>/<slug>.md` 解析 blocks（标题、脚注、图、表、公式块、列表）。
2. HTML → 结构树：复用 `tools/parser.parse_entry`。
3. 树比对：数量 + 层级 + 顺序；差异分三类（真丢文 / 合法移位含书目转脚注 / 纯格式差）。
4. 差异只报不判——真丢文交人审，合法移位白名单须人审登记（承接 ADR-0070 建议④）。

## 3. 落点

- `specs/047-structural-reverse-check/bin/verify_structure.py`：比对判定器（只读）。
- `specs/047-structural-reverse-check/results/structure-scan.json`：机读结果。
- 负向测试：构造丢一节/丢一脚注的 md，判定器须报出。

## 4. 边界

- 判据先用测试词条（1–5）校准，再评估全量；全程不产译文。
- 与 ADR-0063 §7 “LaTeX 反向格式化否决”不冲突：本方案用标准库 `html.parser` + 自有 md 解析，不引入 LaTeX 中转层。
