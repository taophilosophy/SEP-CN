## 2 定理

### CT1 节点计数守恒

**陈述**：∑_{s∈S} |σ(s)| ＝ 22。
**证明**：由 AX1（每个节点至少入一次）与 AX2（至多入一次），{σ(s)} 恰为 N 的一个划分，故基数和不增不减＝|N|＝22。本卡分派 5（1.2.1–1.2.3＋1.3.3–1.3.4）＋5＋9＋3＝22，与 |N| 相等。∎
**机检**：check_stages ② 计数比对。

### CT2 状态映射守恒

**陈述**：|dom(μ)| ＝ 19。
**证明**：Σ 的定义为 16 节点态 ∪ 3 非节点态，且 naming.json 的 `non_node_states` 与有状态节点集不相交（`pending/cleared/done` 无 `_checked` 后缀，结构上互斥），故 |Σ|＝19。AX3 要求 μ 全定义，故 |dom(μ)|＝19。∎
**注**：任务书 §4 原写 18，此处证伪并回修（§7 C1）。

### CT3 派生唯一（stage_of 全函数）

**陈述**：∀e∈E，`stage_of(e)` 有唯一值。
**证明**：任一时刻 `state(e)` 唯一（任务状态机单值）。若 `state(e)∈dom(μ)`，由 AX3＋AX4 得唯一值。若 `state(e)` 对应无状态节点（ex-01/02/03/05、tr-01/05），取“最近前驱有状态节点”——前驱关系由 pipeline 链给出，CT5 证明该链为全序，故“最近前驱”存在且唯一；再由 AX3＋AX4 得唯一值。两条分支互斥且穷尽，故全函数且唯一。∎
**前提**：CT5（链为全序）。

### CT4 链序同构

**陈述**：若 `prev(a)＝b`，则 `ord(stage(b)) < ord(stage(a))`。
**证明**：枚举 21 条 `prev` 边（pipeline.json 实读）：

| 边 | stage(b) → stage(a) | ord 比较 |
| ---- | ---- | ---- |
| ex-01→ex-02 | 1.2.1 → 1.2.2 | 10201 < 10202 ✓ |
| ex-02→ex-03 | 1.2.2 → 1.2.3 | ✓ |
| ex-03→ex-04 | 1.2.3 → 1.3.3 | 10203 < 10303 ✓ |
| ex-04→ex-05 | 1.3.3 → 1.3.4 | 10303 < 10304 ✓ |
| ex-05→tr-01 | 1.3.4 → 2.1 | 10304 < 20100 ✓ |
| tr-01→tr-02 | 2.1 → 2.2 | ✓ |
| tr-02→tr-03 | 2.2 → 2.3 | ✓ |
| tr-03→tr-04 | 2.3 → 2.4 | ✓ |
| tr-04→tr-05 | 2.4 → 2.5 | ✓ |
| tr-05→rv-01 | 2.5 → 3.1 | 20500 < 30100 ✓ |
| rv-01→…→rv-09 | 3.1 → … → 3.9 | 逐条 +100 ✓ |
| rv-09→sg-01 | 3.9 → 4.1 | 30900 < 40100 ✓ |
| sg-01→sg-02 | 4.1 → 4.2 | ✓ |
| sg-02→sg-03 | 4.2 → 4.3 | ✓ |

13 组（含 rv 内部 8 条展开后共 21 条）全部严格递增，无例外。∎
**推论**：非节点子节（1.2.4–1.2.8、1.1.x、1.3.1–1.3.2）插入期间不破坏单调性——它们不在链上，AX8 的 M＝节点号只约束节点子节。**但**这同时说明阶段号不承诺与执行序一致（§7 C2）。

### CT5 号域不相交

**陈述**：阶段号域 𝒮、战役号域 𝒦、标记号域 ℳ 两两不相交。
**证明**：𝒮 的首字符为数字 1–9（AX5）；𝒦 的首字符为 `s`（`specs/`，AX6）；ℳ 的首字符为大写或小写字母（marks 表 8 项）。三域首字符类互斥，故不相交。数字域内部与文档小节号（`§1.2`）、标准条款号（`GB/T 3.2.5`）同形问题，由 AX5 的“三级号仅大段 1”＋体例前缀（引用写“阶段 N.M”）压缩歧义面（残量见 §6 B5）。∎

### CT6 无悬空引用

**陈述**：marks 与 campaigns 的每个 `attach` 都能解析。
**证明**：AX7 要求 attach 元素存在于 S 或 K；AX6 要求 K 的 identifier 目录存在。两公理合取即“每个引用有指称”。∎

### CT7 完备性主定理

**陈述**：五个对象族 × 三个性质面（存在、唯一、可判定）全部有公理承载，且公理→谓词映射为满射。

| 族 | 存在 | 唯一 | 可判定 |
| ---- | ---- | ---- | ---- |
| N（22） | AX1 | AX2 | struct ✓ |
| Σ（19） | AX3 | AX4 | struct ✓ |
| S（60） | AX10（非节点子节落点）＋AX5（号合法） | AX5 | struct ✓ |
| K（6） | AX6 | AX6 | struct ✓ |
| M（8） | AX7 | AX7（attach 唯一解析） | struct／gate ✓ |
| C（26） | AX14 | AX14 | struct ✓ |

**满射检验**（每个 check_stages 谓词至少承载一条公理）：①←AX5,AX10；②←AX1,AX2；③←AX8；④←AX9；⑤←AX6,AX7,AX13；⑥←AX10；⑦←AX11；⑧←AX3,AX4,AX12；⑨←AX14。九谓词均非空，满射成立。
**覆盖检验**（每条公理至少被一个谓词承载）：AX1–AX13 逐条命中，无孤儿公理。∎

### CT8 跃迁相容（rev 6 增补）

**陈述**：任何改变 `state(e)` 的操作后，`stage_of(e)` 自动反映新值，无需额外写入。
**证明**：`stage_of = μ ∘ state`（CT3）；μ 为静态表。故 state 变则 stage 随之变，AX4 保证无歧义。不改 state 的操作（`--unblock`、`source-audit`）阶段不变，与规范一致。∎
**推论**：阶段轨不需要跃迁引擎——7 种状态机操作的阶段语义全部免费获得（详表见 `spec.md` §1.11 与 `flow-audit.md` §3 G4）。

### CT9 判据阶段可导出（rev 6 增补）

**陈述**：∀c∈C（|C|＝26），`stage(c) = stage(owner(c))` 唯一可导（公理 AX14）。
**证明**：pipeline 声明检查器硬拦点唯一 → `criteria_owner[c]` 单元素；σ 由 AX2 单值 → 复合函数唯一。∎
**必要性反证**：审计实测手编必错三处（`register_audit`→rv-06、`check_pairs`→tr-03、`check_academic`→rv-02），故 stages 的 `criteria` 字段只能派生、禁手编（`flow-audit.md` §3 G1）。

## 3 一致性（无矛盾模型）

构造模型 𝔐：S 取本卡 §1.3 的 60 项，σ 取寄居表，μ 取 §1.7 的 19 行，K 取 §1.4 六项，M 取 §1.8 八项。逐条核验：

1. AX9 要求 ex-04→1.3.3，而 pipeline 中 ex-04 的 prev 是 ex-03（1.2.3）——CT4 的边 ex-03→ex-04 已验 10203 < 10303，**相容**。
2. 1.3 父节 status＝registered、子节 1.3.3＝accepted——status 不在公理域内（§1.1 规则三规定父子独立），**不构成矛盾**。
3. `cleared`（1.3.2）→`ex-04_checked`（1.3.3）→`tr-02_checked`（2.2）：跨过 2.1（tr-01 无状态），μ 不必满射，**相容**。
4. `done` 与 `sg-03_checked` 同映射 4.3——μ 不要求单射，但**要求值可机读**；“4.3＋发布”是复合值，违 AX4（函数须有单值）→ 这是模型与公理的**唯一冲突**，处置见 §7 C3。

除第 4 条外，𝔐 满足 AX1–AX13，故公理集**相容**（若 C3 按 §7 修正，则完全相容）。

## 5 可判定性

- AX1–AX12 全部为只读结构谓词，输入 naming.json＋pipeline.json＋tasks/，判定 O(|S|+|N|)，无人工判断。
- AX13 为 diff 白名单比对，机检可得。
- 公理与谓词的映射是满射（CT7），故**每个公理都可被现行 check_stages 九谓词判定**，无“写了但查不了”的公理。

## 6 边界（不可自证项，如实登记）

| # | 不可证项 | 归属 | 说明 |
| ---- | ---- | ---- | ---- |
| B1 | label／attach／μ 的**语义恰当性** | audit（人审，ADR-0070） | 结构公理只证“有号、唯一、可解析”，不证“挂得对”。如 G1–G5 挂 1.1.2 是否恰当，属判据所有权问题 |
| B2 | 26 个 `reserved` 的语义 | 未定 | 结构上号位占住（AX11 可判），语义留待分配时裁定 |
| B3 | ex-05 无状态位（D10） | 已知缺口 | μ 对其无定义，CT3 靠“最近前驱”补救；该补救的正确性**依赖 CT5**，故 CT5 是 CT3 的前提而非独立装饰 |
| B4 | campaigns 登记**完备性** | 审计分类判断 | AX6 只保证“已登记者标识合法”，不保证“所有战役都已登记”。库内 62 个 spec 中战役型远多于 6——若某战役未登记，体系不报错。补救＝登记判据＋定期与 specs/README 全量对照（后续项） |
| B5 | 裸写 `N.M` 的残余歧义 | 体例纪律 | 文档小节号（`§1.2` 带 §）、版本号（`v1.0` 带 v）与阶段号同形；AX5 已禁三级号出大段 1，余量靠“引用必带‘阶段’二字” |

**B4 是最实质的边界**：完备性在本证明中限定为“注册表内部完备”，不含“注册完备”。二者差异已量化登记，不掩盖。
