# 术语在线不可用期间的替代通道评估（2026-11-25）

前提：术语在线 allSearch 在突发请求后长时间回“success=true 且全库零”，实测超过一小时未恢复；慢速扫描（词间 15 秒、探针失败退避 120 秒 ×6）也整轮打空并自动停批（退出码 2），未写任何假凭证。

本轮把可想到的替代通道逐个试过，结论如下。

## 一、术语在线自身

| 通道 | 可用性 | 说明 |
| ---- | ---- | ---- |
| `tmWord/allSearch`（页面内 fetch，带 JSON 里的 `value` 令牌） | 窗口期可用 | 健康时上千条；被限流时全零。同一 URL 连发两次常见“首空次有”，但持续请求会把窗口耗尽 |
| 站点 UI 搜索（点按钮） | 可用 | 渲染“找到 1032 条结果”，可读 page text；速度约一词/十秒，只适合零星核对 |
| `tmWord/standardSearch`（匿名） | 可用 | 只覆盖标准文件术语库，哲学词基本无对口（harm principle 命中全是电气/玩具安全标准），不作依据 |
| `tmWord/queryById` | 可用 | 需 id，只能做已知条目的详情补全，不能检索 |
| `tsWordSearch/searching`、`tmWord/tips` | 可用 | 只回中文词名（en 为 null），做不了英中对照 |
| 官方“接口服务” | 未开通 | 站点声明为对外接口，需申请账号/密钥，本会话无法办理 |

## 二、其他公开源

| 源 | 结果 |
| ---- | ---- |
| 台湾乐词网 terms.naer.edu.tw | 首页可取（200、164 KB），检索结果为前端渲染；直接查 `/search/?q=` 只回壳页，随后连续请求被断连（curl 000）。要用得走浏览器页内。且其为两岸名词对照，权威性低于审定库，只宜作旁证 |
| 中国大百科全书 zgbk.com | 站点可达，`/ecph/words` 返回壳页，条目列表由前端接口拉取，未找到可用匿名接口。要继续得抓其内部 API 或走页内 fetch |
| Wikidata 人名回填 | 可用但慢：wbsearchentities + wbgetentities，0.6 次/秒即 429，须 1.2 秒间隔并 60 秒退避重试 |

## 三、Wikidata 人名试点的实情

先按“名字命中＋描述像学者”筛，30 行得 5 个候选，但错配明显：Alan Macdonald 命中英国作家、Michael Ash 命中 2000 年出生的澳洲天文学家、Marc Artiga 命中“西班牙作家”。

加 P106 职业白名单（哲学家、逻辑学家、数学家、学术人员等）后，10 行只剩 1 个候选（V. Michele Abrusci，意大利逻辑学家，命中正确），但该行只缺籍属，Wikidata 无 P27，补不上。

判断：召回太低、且补的多是已有生卒的行，不值得对 780 行整批跑。工具保留（`bin/wikidata_person_sweep.py`，带职业过滤与限流退避），只在定点核查时用。

## 四、结论与下一步

* 批量取审定库数据目前只有一条路：等限流窗口，按“每词 ≥15 秒、每 10 词一探针、连续失败即停”的节奏慢慢走。`bin/throttled_sweep.py` 已按此实现，可续跑（进度文件）。
* 短期可交付的是**优先词**：按英文侧语料频次取前 100 条（`results/recheck-priority-2026-11-25.json`），窗口一开就跑，跑多少算多少。
* 零星关键术语用页面 UI 直查，人工读“找到 N 条结果”页确认，再把命中写进依据；这条路径不依赖 API 限流窗口，适合个位数条目。
* 不建议把 `standardSearch`、乐词网、大百科的数据直接写成“审定名词库”依据——它们的库属不同，依据列必须如实标注来源，否则等于伪造凭证。

## 五、界面直查的验证（不依赖 API 限流窗口）

用内置浏览器打开 `/search?searchText=<词>`，点“精确匹配”，页面直接渲染“找到 N 条结果”与每条的规范用词／英文／学科／来源。这条路径在 API 全零时照样出结果：

* abduction → 2 条（自然辩证法名词 2024 溯因；运动医学名词 2019 外展），与 allSearch 的 1351 条总量对得上；
* political obligation、narrow content、higher-order evidence、metaphysical explanation → 精确匹配均 0 条（模糊匹配分别 210／…条，全是不相干词），说明这四个高频词**审定库确实不收**。

这同时给批 29“733 行确无对口”的结论添了一道独立旁证：不是抓取失败，而是审定库本身没有这些英文多词术语。界面直查每词约 7 秒，适合个位数关键条的定点核对。
