# 规格：全库术语二次提取与 A–Z 总表（specs/058）

**Spec ID**: `058-term-full-reextraction` | **Created**: 2026-11-22 | **Status**: 执行中

## 1. 方向（用户裁定 2026-11-22）

用户指令原文要点：按 A–Z 顺序重新从每篇提取哲学、其他学科专业术语、著作名、人名等名词，长度也可能是一句话；联网学习其他类似项目的做法；注意去重。

会话内三项口径确认（2026-11-22）：

1. **交付物**：直接补登两登记册（`shu-yu-biao.md`、`ren-ming-biao.md`），不是只出报告。
2. **清单口径**：全量列出＋状态标注（已登记／池内已有／本轮新增），不静默丢候选。
3. **排序基准**：按词首字母 A–Z 总表，篇名只作来源列。

## 2. 目标与非目标

**目标**

1. 对 `yuanwen/` 全库（2421 篇，312 MB）做第二轮逐篇提取，覆盖：哲学术语、其他学科术语、著作名、人名、外来语原形、句级长词条；类型标签区分 `term / person / work / sentence / foreign / script`。
2. 以折叠键去重（`register_lib.norm_key_quote`，ADR-0033 A 口径），同键合并频次与来源篇目。
3. 产出全量 A–Z 总表（每字母一文件＋JSON 索引），每行标注：键、类型、频次、来源篇数、档位、状态（已登记／池内已裁定／池内 new／本轮新增）。
4. 从总表中筛出可确证的新条目，按 manifest → `tools/term_flow.py` 落册，A 档直接登记；B 档挂 `held`；C 档 `rejected`。
5. 调研类似项目做法并留凭证（见 `results/research-evidence-2026-11-22.md`）。

**非目标**

* 不改任何译文正文，不重译词条。
* 不整批改写既有登记行；既有行只读。
* 不把泛搭配、书目残片、LaTeX 残渣写进登记册。

## 3. 方法与依据

### 3.1 提取路线（继承 specs/008，精度增强）

| 路线 | 规则 | 类型 |
| --- | --- | --- |
| 斜体 | `*...*`，2–200 字符，剥句界与书目残片 | work（题名式）／term（其余） |
| 引语 | 弯引号内 2–300 字符；≤80 且无子句标志 → term；更长或含子句标志 → sentence | term／sentence |
| ‑ism 词族 | 5 字母以上，去假词干（organism 等） | term |
| 人名 | 2–4 个首字母大写词元，允许 J. / van / de / ibn / al- 等颗粒；句首泛词、题名式术语排除 | person |
| 原文文字 | 阿拉伯／希腊／希伯来／西里尔／天城体／汉字 | script |
| 罗马化外来语 | 非 ASCII 拉丁扩展、德语名词后缀、经典词小词典 | foreign |
| 章节主题 | H1/H2 标题，剥节号与括注 | topic |
| 定义语境 | `X is a Y`、`X refers to`、`called X`、`the term X` 邻域加权，不单独产候选 | 加权信号 |

### 3.2 精度控制（借鉴术语工程与双语抽取文献）

* **术语性守卫**复用 `tools/term_harvest.py`（specs/050）：数学残渣、书目缩写、结构标题、泛词、子句标志。
* **来源广度**：`spread = 来源篇数`；`spread ≥ 3` 为跨条目概念，孤例降档。
* **C-value 式嵌套计分**：多词术语按 `log2(len) * (freq - nested_freq/|nested|)` 近似，抑制高频片段的子串。
* **类型互斥**：同一折叠键按 person > work > term > sentence 优先级定类型；阿位专名优先。
* **档位**：T1（freq ≥ 20 且 spread ≥ 5）、T2（freq ≥ 5 且 spread ≥ 2）、T3（其余且通过守卫）、T4（仅孤例）。
* **注册门槛**：只登记 T1/T2 且语义可确证者；T3/T4 留池，不写册。

### 3.3 登记依据

* 依据档位照 ADR-0012：审定名词库（术语在线，ADR-0074 已解禁）→ 权威译本／学术出版通行译法 → 学界惯例。禁维基百科。
* 每条登记行依据列写来源＋凭证日期；无通行译名者按 ADR-0022 保留英文原名并记“查无”。
* 著作名按 `rules/03` §154：有正式中译本用中译名并括注原名；无中译本保留英文原名；论文／刊名保持英文。

## 4. 验收判据

1. `results/az/` 下 A–Z 各节文件齐备，行数总和等于池内候选数＋本轮新增数（守恒）。
2. 每个字母文件首行注明：节内行数、T1–T4 分布、已登记数。
3. 登记批次过 `tools/term_flow.py --dry-run` 零锚点缺失，实写后 `registry_azsort.py --apply` 幂等。
4. `python tools/check_terms.py` 与 `python tools/check_all.py` 全绿（若存量在途改动致红，须定位到与本规格无关并记录）。
5. 调研凭证落盘，含来源 URL、访问日期、采纳结论。

## 5. 风险与开放项

* **规模**：池内 71,913 条，其中 `new` 58,460 条；全量人工裁定不可行，本轮只登记高置信子集，余量保留状态并记账。
* **噪声**：现有池 `person` 型混入 Title Case 术语（如 Propositional Logic），`italic` 混入 Figure／et al。本轮重新分型，不沿用旧型。
* **并发会话**：工作区存在其他会话的在途改动（121 个文件），本规格只动 `specs/058-*`、`tasks/manifests/` 与本规格产出的登记行。
