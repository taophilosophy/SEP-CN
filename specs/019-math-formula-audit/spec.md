## 目标 / 非目标

**目标**

1. en/ 全量 148,037 条公式逐条判定：MathJax 3（站点实际渲染器）编译可渲染性、上游逐词条联网比对（漂移/损坏分类）、定界符与 LaTeX 形态格式检查。
2. 译文 74 词条逐词条复核：公式与 en/ 对齐（顺序+内容）、一致性（记号/体例）、可渲染性、格式（`$`/`$$` 定界符，清零 59 条 `\(\)` 违规）；公式内文字按新体例翻译（术语先登记）。
3. 规则修订：ADR-0036（公式体例：内嵌文字翻译细则、译文侧公式门禁、上游漂移处置）+ rules/02 相应条文 + 译文侧公式检查器并入 `check_all.py`。
4. 全程台账：每词条一行（en/ 侧按字母分册、译文侧按字母分册），每条公式判定可回溯。

**非目标**

1. 不重译、不润色语体（011/015 职责）；只纠公式与公式内文字。
2. 不重复 018 的 yuanwen↔en 逐段人眼比对；yuanwen 转换保真归 018 + `check_math.py`；019 对 yuanwen 只做可渲染性编译维度，发现转换缺陷移交 018。
3. 不静默修改 en/：仅对定性为「快照损坏」的公式修复并留痕；「上游漂移」只记录并转 update 流程（specs/001 契约）。
4. 不动他会话在途件（S/U 批在途词条、`tools/yuanwen.py`、`ledger.json` 等 2026-11-13 上午未提交改动）。

## 方法

1. **机械全量判定**（禁抽样=每条都有显式判定）：`bin/validate_mathjax.mjs` 用 mathjax-full 逐条编译；`bin/align.py` 对 en↔zh 公式序列规范化对齐 diff；上游抓取脚本按 018 同口径 MATH_RE 抽取比对。一致类批量记判定，差异类**逐条人眼定性**。
2. **人工复核**：差异类 + 74 个译文词条逐个走查（公式对齐、\text 文字、格式）；每词条台账一行。
3. **礼貌抓取**：≥5 秒间隔，4xx/5xx/超时退避重试并记录，禁止静默跳过（rules/05）。
4. **并行会话安全**：编辑前重查 `tasks/<letter>/<slug>.json` state 与文件 mtime；提交只圈本战役文件，提交前重查 reflog。
