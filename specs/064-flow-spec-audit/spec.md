## 6 规范化

### 6.1 编号

| 域 | 形态 | 规则 |
| ---- | ---- | ---- |
| 节点 | `(ex\|tr\|rv\|sg)-NN` | 永不改、不复用；退役保留 |
| 阶段 | `N.M[.K]`；三级号仅大段 1 | 引用必带“阶段”二字 |
| 战役 | 主 spec 号 | 不发字母号（避 C1–C4） |
| ADR | `NNNN-中文标题` | 只追加，取代链在 README |
| spec | `NNN-kebab`，三位 | 撞车让位 |

### 6.2 命名
