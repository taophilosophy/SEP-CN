## 3 命题复核（旧证明撤销或降格）

### CT13 登记计数

旧证明由 `id` 唯一推出 `path` 一一对应，**无效**。修正：`id` 全局唯一；`path` 仅要求 active 条目唯一；`superseded`／`pruned` 可保留同 path 历史。故“条目数＝path 数”只在 active 集合上成立，且需额外约束。

### CT14 清理幂等

原证明忽略时间流逝与外部写入。修正为条件命题：**在固定时钟、同一登记表快照、无外部文件变化的同一事务内**，第二次 `prune` 为空操作。跨时间运行不保证幂等。

### CT15 语言边界

原证明由进程边界推出“替换一侧另一侧无感”，过强。修正：进程边界只使**调用面局部化**；协议语法相同不保证语义、性能、错误码、超时与文件副作用相同，仍需契约测试与回滚开关。

### CT16 迁移等价（旧“反定理”撤销）

“无黄金测试不可证等价”不成立：形式证明、穷举、差分测试、性质测试与人工审查都可提供证据。正确命题是：**在本仓库的替换门中，缺少可复核的行为对照证据，不足以批准替换**。这是治理要求，不是逻辑必然；黄金测试也只是证据类型之一。

### CT17 体系自指

原证明仅由“spec／plan／tasks 三文件存在”推出自洽，**无效**。修正为“形态存在性”命题；内容自洽须逐节审计，且 AX29 本身的卡型判定仍是启发式／需显式元数据。

## 4 一致性与独立性

- **一致性**：无全局模型可声称满足全部 AX；AX21 字段口径、AX24 删除、AX26 锁文件、AX28 退出码均未定案。当前只能逐条给“设计草案”，不得写“全成立”。
- **独立性**：AX21 与 AX23 共享时间字段、AX24 与 AX28 共享清理语义、AX27 与 CT16 是规范与论证关系；未经分别验证不得声称独立。
- 结论：**候选集，待设计定稿与独立复核**。
