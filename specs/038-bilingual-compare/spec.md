# 中英比较界面重做（specs/038）

**版本** v1.0 ｜ **状态** 已实施（2026-11-16 验收，凭证见 `results/`） ｜ **日期** 2026-11-16 ｜ **权威** 2026-11-16 用户指令“中英比较界面必须重新设计，学习文言文现代汉语比较 https://zhuangzi.5000yan.com/1.html 等多语言比较网站的 ui”＋两问两答（形态 C 混合、默认跟随上次选择）

## 1. 目的与非目标

把词条页的中英对照从“iframe 双栏 + postMessage 同步”重做为一套**同页**比较界面：默认双栏，可一键切“段间交错”精读；三态（对照／仅中文／仅英文）在两种形态下通用；视觉语汇取自 5000yan 的文言/白话对照（英文侧=浅底附注块）。

**非目标**：不动内容管线（词条 md、`yuanwen/`、SUMMARY、登记册、baseline 一律不改）；不改 `config.mts` 数据层（SUMMARY 解析、中英配对、pagefind、git-stamps、死链守卫）；不复刻参考站的阅读设置面板（字号/行距/背景亮度/繁简切换）——如需另案；不新增第三方依赖。

## 2. 裁定（Assumptions）

1. **形态 C（用户选）**：默认同页双栏（左右/上下可切），工具条可切“交错”，交错只对正文区段逐块配对，参考文献类区段整段并列。
2. **默认状态跟随上次选择（用户选）**：沿用 `localStorage` 的 `bili-open`；未选择过时默认关闭（干净单语阅读）。
3. **去 iframe（工程裁定）**：英文内容由 `fetch(enPath)` → `DOMParser` → 注入同页容器；不再跨窗口传消息。理由：iframe 带来滚动/键盘/选区三套跨窗口缺陷，且中文侧点击无法直接命中英文 DOM。
4. **中文为主（沿用 2026-10-31 裁定）**：中文滚动驱动英文跟随；英文滚动只更新高亮与进度，不回驱中文——双向互驱实测会振荡收敛到错位平衡。
5. **对齐口径沿用 `bili-paragraph.ts` 的 (h, b)**：标题序 h + 区段内块序 b；实测正文区段基本逐块对齐，参考文献区段系统性不齐（489 对中英页面中仅 1 条每区段行数完全相等；例 abduction 该段中文 251 个 `li`、英文 2 块）。
6. **桥接层纪律（specs/037 §2.5）**：新增规则里凡引用 VitePress 内部类名（`.VPDoc`、`.VPContent`、`.vp-doc` 等）一律写进 `vp-compat.css`；`custom.css` 只放自有类名与 `--vp-*` 令牌。

## 3. 方案要点

### 3.1 同页双栏（默认）

- 工具条：`⇔ 对照原文` 开/关（记忆 `bili-open`）；面板条内含三态分段、布局切换（左右 → 上下 → 交错 循环）、段落同步开关、进度、新窗口、关闭。
- 英文内容注入 `.bili-doc`（自带 `overflow:auto` 的滚动区），注入前统一改写：
  - `script/style` 剔除；`id` 加 `en-` 前缀，`href="#…"` 同步改写（避免与中文页脚注 id 冲突）；
  - 相对链接与图片按原文页 URL 解析为站内绝对路径（`new URL(href, enUrl)`）；
  - 每个块标注 `data-bili-h` / `data-bili-b`（`mapPoint` 口径），供同步查表；
  - 含 `.math-tex` 时用 MathJax `typesetPromise` 复排。
- 同步：中文滚动 → 当前段 (h,b) → 英文区 `scrollIntoView`（软跟随，900 ms 驱动锁）；英文滚动 → 只更新中文高亮与英文进度。点击中文段落 → 英文滚到对应段＋双侧句级高亮；点击英文段落 → 中文滚到对应段。`j`/`k`、`Esc` 保留。
- 视觉：英文侧用次要文字色、`--vp-c-bg-alt` 底、8 px 圆角块间距 1.4 em（参考站 `.para-fanyi` 的语汇），不做第二套版式。

### 3.2 段间交错（精读）

- 按区段配对：`min(zh, en)` 逐块交错（英文块以 `.bili-en-block` 包壳插在中文块之后）；多出的英文块在该区段末尾成组插入。
- **退化规则**：同区段中英块数比值 < 0.5 或差 > 8（参考文献、延伸阅读、致谢等），该区段不逐块配对，改为整段并列（`.bili-en-block.bili-en-section`，标注“English 对应区段”），避免 251 个中文条目各配 0 个英文条目式的碎块。
- 交错模式下面板收为**固定底栏**（参考站 bottom-nav 语汇），只留控制条，正文占满；正文底部预留底栏高度。
- 退出交错即移除所有 `.bili-en-block`，中文页恢复原样（交错是对 DOM 的临时增强，不改源）。
- 仅英文态：中文块在构建交错时打 `.bili-zh-block` 标，`bili-en-only` 下隐藏。

### 3.3 三态与持久化

| 键 | 取值 | 含义 |
| ---- | ---- | ---- |
| `bili-open` | `1` / `0` | 对照是否开启 |
| `bili-layout` | `side` / `stack` / `inter` | 布局（新增 `inter`） |
| `bili-show` | `compare` / `zh` / `en` | 三态（新增） |
| `bili-sync` | `1` / `0` | 段落同步（交错下无意义，禁用） |
| `hide-sidebar` | `1` / `0` | 左侧目录隐藏（保留） |
| `bili-scroll:<path>` | 像素 | 每页中文阅读位（保留） |

2. 交错模式在 `abduction`（正文对齐、参考文献不齐）与 `zhu-xi`（长条目）上人工走查：无错位碎块、无重复标题、参考文献整段并列。
3. 双栏：滚动跟随、点击跳段、句级高亮、`j/k`、`Esc`、进度、滚动记忆逐项可用；英文侧公式与脚注可读。
4. `SEP_SHARD=ek bun --bun x vitepress build` 通过（死链检查开启，不新增豁免）；`check_all.py` 不新增失败项（既有三项外部失败照旧）。
5. 移动端（≤959 px）双栏降为整宽面板、交错正常；无横向滚动。
