## 1 结论摘要

1. **登记册三分**：规范事实散在 `rules/README.md`（29 行引用清单）、`rules/standards.json`（9 项采纳＋1 项不采纳）与 `specs/025-standards-alignment/`（研读日志）；三者无交叉校验，同一标准可在一处“现行”、另一处缺席。这是本轮最严重的结构问题（G1）。
2. **三条已过期或即将过期**：`ISO/IEC/IEEE 12207:2017` 已于 2026-04-29 废止、由 `12207:2026` 取代；`ISO 15489-1:2016` 于 2026-11-06 进入修订（90.92）；`ISO 17100:2015` 于 2025-08-04 进入修订（90.92，新项目 ISO/AWI 17100，预计约 2029）。`ISO 18587` 修订版（DIS，扩为 non-human translation output）在票，预计 2026 年底发布（G2）。
3. **两条国标缺失于机器登记册**：`GB/T 19682-2005`（译文质量要求：基本要求／特殊要求／评定与检测）与 `GB/T 19363.1-2022`（IDT 采标 ISO 17100）在 README 有、在 `standards.json` 无；前者是唯一直接规定“译文质量评定与检测”的国标（G7、G3）。
4. **中文译著行业标准未登记**：`CY/T 123-2015 学术出版规范 中文译著` 的结构（部件顺序、篇章一致、删略说明）、人名／地名／术语首现括注原文、世纪-年代、非 SI 单位换算、译者注独立注码、**原文错误用译者注更正而不改正文**等条款，与本项目 ADR-0062/0063 高度同构，却未进登记册，导致规则无法回溯到条款（G9）。
5. **三审同人存在制度性偏离**：`图书质量保障体系`（1997 署令第 8 号）第八条要求初审／复审／终审“任何两个环节不能由一人担任”，第十一条要求“三校一读”；ISO 17100 亦要求复核由译者以外的人执行。项目 ADR-0020 允许同一 actor 以“冷置／密度统计”补偿。这是**已执行但未在标准登记册声明的偏离**（G3）。
6. **LLM 定位未对齐译后编辑标准**：项目使用 LLM 辅助初译（ADR-0021），但既未按人类翻译（ISO 17100）声明“CAT 辅助、输出由译者负责”，也未按译后编辑（ISO 18587:2017／GB/T 40036-2021）定义 PE 级别、能力与留痕。2026 年底 ISO 18587 新版将把范围扩到“非人类译文输出”，窗口期只剩数月（G5）。
7. **术语数据模型落后于标准**：ISO 704:2022／1087:2019／10241-1:2011 与 TBX（ISO 30042:2019；国标 GB/T 44227-2024 修改采用）要求概念、定义、概念关系、学科域；现有两登记册为表格（词形／译法／首现／依据），无可交换模型（G8）。
8. **引用与转写只登记了“代码”未登记“系统”**：ISO 24229:2022 是转写系统**代码**标准，不是具体转写规则；希腊、西里尔、阿拉伯、希伯来、日文、梵文等系统的具体标准（ISO 843／9／233／259／3602／15919）未列入，rv-03 的“补原文”在非拉丁文字上缺执行基准（G11）。
9. **记录管理与刚发生的全库清史冲突**：README 将 ISO 15489-1／GB/T 26162／GB/T 18894／DA/T 22 列为采纳，而 ADR-0082 已按用户授权清空 journal 与 steps。偏离尚未登记，登记册与事实不一致（G12）。
10. **体例类标准“引用而未登记”普遍**：`CY/T 118／121／170／171` 在 rules 正文被直接引用，但 README 表与 `standards.json` 均无条目；`GB/T 8170` 在 q5 M-8 被引用亦未登记（G10、G13）。

## 2 方法与口径

* **三层对照**：①机器登记册 `rules/standards.json`（“采纳—承接—工具”三元组，供 `verify_standards` 求值）；②引用清单 `rules/README.md`（体例与流程的版本基准）；③流程正文 actual practice（rules/01–09、pipeline 22 节点、六轴清单）。
* **版本核验**：以 ISO 官网 stage 码、国家标准全文公开系统（openstd.samr.gov.cn）、全国标准信息公共服务平台（std.samr.gov.cn）、国家新闻出版署行业标准页为准；结论与检索日写入 `version-audit.md`。日期一律标“发布／实施／现行状态”，不把“复审继续有效”写成“新版本”。
* **判定词**：`符合`＝有条款级承接且行为一致；`部分`＝有承接但缺条款或口径不同；`偏离`＝行为与条款不一致且未登记；`缺失`＝无承接。**本项目是内部流程，不是认证实体**：以下“符合 ISO 17100”均指自愿对齐，不构成认证声明。
