# 019 — 表格与图片逐个复核战役（正确性·一致性·可渲染·格式）

## 背景与意图复述

用户指令（2026-11-13）：

> 不计成本，禁止抽样，逐个复核en/表格，图片的正确性，一致性，可渲染否，格式是否正确，同时修订规则，表格中的文字也需要一并翻译。

一句话转述：对源自 `en/` 的全部表格与图片做**三层逐个复核**（en 源 → `yuanwen/` 镜像 → 中文译文），维度四个——正确性（内容与源一致）、一致性（全库体例统一）、可渲染否（站点实际能渲染）、格式正确（markdown 语法合规）；发现即修。同时修订规则（已落：ADR-0036 + rules/02 排版元素两条），并把已译词条表格中未译的文字按裁定口径翻译。

## 战场规模（2026-11-13 清点）

| 层 | 表格 | 图片 |
| ---- | ---- | ---- |
| en/ 源 | 344 词条 / 1478 张（大量为公式盒子表） | 约 893 张真图 / 334 词条 |
| yuanwen/ 镜像 | 365 件 | 334 件 |
| 中文译文 | 48 词条 / 710 表行（17 词条有未译英文单元格） | 39 词条（alt 全英文，路径基座混用） |

## 目标 / 非目标

**目标**

1. 台账覆盖全部表格图片词条（365 表件 + 334 图件并集，含未译词条），零抽样。
2. 每表逐行、每图逐处比对三层：en html ↔ yuanwen md ↔ 中文 md（无译文的词条只比对前两层）。
3. 译文侧修复：表格文字按 ADR-0036 口径翻译；图片 alt/图注译中文；引用基座归一根级 `assets/`（违例即改并补齐资产）。
4. yuanwen 侧修复：转换缺件、格式走样、图片引用断链。
5. 规则侧已落 ADR-0036 + rules/02 两条；新增预检器 `tools/check_tables_images.py`。

**非目标**

1. 不动 en/ 原始 HTML（不可变事实源）。
2. 不做 yuanwen 全文逐段审计（018 战役职责；本战役只做表格图片两维，台账互链避免重复走查）。
3. 不做机械批量替换；每处发现逐处定性（015 战役教训）。
4. 不重译语体（011/015 职责），只修表格图片维度的缺陷。
5. 不碰并行会话正在写的文件；动手前逐文件查 `git status` 与 mtime。

## 方法（每词条协议）

1. 列出该词条 en html 的全部 `<table>`（排除 Academic Tools 通用表）与正文 `<img>`。
2. 对照 yuanwen md 的表格与图片：行数、列数、单元格文字、图片 src/alt 逐处核对。
3. 有译文的词条再对照中文 md：表头与单元格文字是否按 ADR-0036 译出；文献条目骨架照录＋书名括注汉译（查证到实书才译）；图片 alt/图注中文；引用 `../assets/<slug>/` 且资产在根级。
4. 可渲染判定：表格语法合法（列数一致、无裸 HTML、无断管道）、图片引用可解析（本地文件在场、大小写一致）。
5. 发现项 → 登记 → 修 yuanwen / 译文 / 资产 → 台账记行。
6. 机械预检器（check_tables_images.py）先行扫出候选清单，人眼逐处定性后修复；机器不替代人眼。

## 验收判据

1. 台账覆盖全部并集词条，无缺行；每发现项有修复留痕（三层侧别注明）。
2. 译文 48 表件表内文字按 ADR-0036 处理完毕（译出/照录括注/登记待查三态）；39 图件 alt/图注中文、路径合规。
3. `python tools/check_tables_images.py` 候选清零或逐条豁免登记；`python tools/check_all.py` 全绿。
4. 保持原样的书名清单落台账，转术语/文献查证通道。

## Assumptions（用户裁定登记处）

- A1 [用户裁定 2026-11-13]：表内西文文献条目**骨架照录＋书名括注汉译**，查证到实书才译，查不到保持原样并登记。
- A2 [用户裁定 2026-11-13]：图片 **alt 与图注都译中文**；SEP 占位 alt 译说明性中文。
- A3 [假设]：本战役允许机械预检（表格形状、alt 语言、路径合规）；正确性与一致性由人眼逐处定性——018 的「禁止编程」限于其逐段比对协议，本战役指令未重申该禁令，预检器只出候选清单不判语义。
- A4 [假设]：推进次序＝先译文侧 48 表件 + 39 图件（约 80 词条，修复与翻译并做），后 yuanwen 全量余量（含未译词条）；每字母内按 slug 字母序，台账接力禁止跳条。
- A5 [假设]：与 018 的关系——018 刚立项未开跑（台账 a 批 0/160）；本战役的表格图片发现项同时记入 018 台账对应词条行（防 018 后续重复走查时误判）。
- A6 [已证伪更正]：018 spec A3 称「yuanwen/ 为 gitignore 本地库」不实——yuanwen/ 自 ADR-0027 起入库（4260 文件），018 台账已记更正。
- A7 [假设]：图片引用基座以 rules/01 现行契约为准（中文词条 → 根级 assets），存量违例（如 bohr-correspondence）属定向修复对象，非「两种基座均可」。

## 代价与边界

- 并集约 600+ 词条、800+ 张表、900+ 张图，单会话只能推进一部分；台账必须可续接（后继会话按台账接力，禁止凭记忆跳条）。
- 书名括注汉译逐条查证（中译本实书），未证实即保持原样——不得为完成率造译名。
- 修复遵守 rules/05 批量改写纪律：幂等、逐行身份追踪、写回前残余归零。
