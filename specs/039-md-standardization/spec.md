# specs/039: 中文 Markdown 标准化（s2.4 三轴与派生保真）

- 状态：进行中（P1 治理、P2 工具已落地 2026-11-16；I2-lite 全库零异常；I3 列审计档待标定）
- 决策依据：[ADR-0063](../../rules/adr/0063-中文体例归一入s2.4双轴与转换保真不变量.md)（accepted）、[ADR-0062](../../rules/adr/0062-en原始物文字冻结与全局勘误表.md)、[ADR-0043](../../rules/adr/0043-s2.5-checked前置阶段合并与全量回退.md)
- 用户裁定记录（2026-11-16）：见 §Assumptions

## 目标

1. **中文 markdown 可判标准化**：体例（尾序、编号、H1、pubinfo、脚注位次、参考文献承载）与格式（空白类）分档判定，结构硬、空白告警；判定位置固定在 s2.4 体例轴，不再散落 s3/r2。
2. **英文 markdown 只做格式归一**：`yuanwen` 文字与 `en/` 一致（不变量 I2/I3），唯一合法偏离是格式补丁；不引入 LaTeX，不新增 markdown 标准化以外的 CI 步骤。
3. **勘误落地可判**：全局勘误表"中文承载"三值对应三动作，s2.4 勘误轴机检（禁含上游错字形／必含参考读法与译注）。
4. **存量收编**：416 件（s2.5_checked 395＋r2 16＋r3 1＋checked 1＋done 3）受控回退重走 s2.4；编号加点 2076 处、脚注移段 87 件一次性归一。

## 非目标

* 不引入 LaTeX／Typst 参与判定（第三轮否决，ADR-0063 §7；Typst 仅作 specs/035 渲染产物，不反向）。
* 不加跨语槽位键（用户裁定）；中英配对靠标题词表与顺序，位次不一致由体例轴钉死补偿。
* 不新建第二套结构校验体系：体例判定扩进 `check_pairs`。
* 不改 `en/` 任何字节；不改译文措辞（体例归一不得连带改文字，rules/05 适用范围排除）。
* 不改状态机状态名与位次（只扩职责与回退目标态）。

## 契约（不变量与判定权）

| 号 | 不变量 | 判官（只读） |
| ---- | ---- | ---- |
| I1 | `en/` 字节 == 原始钉 | `divergence.py verify`（既有） |
| I2 | `yuanwen` 字节 == `convert(en ⊕ patches)` | `tools/check_yuanwen_fidelity.py`（新） |
| I3 | `yuanwen` 文字流 == `en` 文字流（模转换器构造白名单） | 同上 |
| I4 | 补丁 ⇄ 全局勘误表双向可追溯 | `tools/check_en_patches.py`（扩） |
| I5 | 中文体例 canonical（尾序/编号/H1/pubinfo/脚注末位/文献承载） | `tools/check_pairs.py`（扩硬档） |
| I6 | 译文禁机械替换 | `mech_audit.py`＋人工（既有） |

补丁准入谓词（I3 的判定面）：去空白后 `find ≡ replace` **或** 剥标签后 `find ≡ replace`，二者皆不成立即文字层，禁入池、禁改 `yuanwen`。

补丁正本（2026-11-16 用户裁定“补丁不是虚拟的”）：`baseline/en-patches/<id>.patch` **一补丁一文件**（unified diff 正文＋头注释字段，带 1 行上下文），`INDEX.json` 为生成物禁手改；解析唯一实现 `tools/en_patch_lib.py`；应用为行锚定（命中==`expect`、上下文须在场），失配即该件转换硬失败；`git apply --check` 只读预演。删除单文件旧池 `baseline/en-patches.json`。

四关：C1 结构有效（`en_source_audit`＋`html.parser`）→ C2 准入谓词＋`expect` 命中 → C3 单调改善且全库其余件 diff=0 → C4 重放等值。

## 作废条件（开工即钉）

| 现象 | 处置 |
| ---- | ---- |
| 补丁命中 ≠ `expect` | 该件转换硬失败，查上游漂移 |
| 重转后非预期件 diff ≠ 0 | 该批作废，回退基线重来 |
| 机械归一命中 ≠ 预期（2076／87） | 整批作废，先查规则再跑 |
| 幂等二次运行非空 diff | 该规则禁用，回炉重写 |
| I3 白名单外差异 | 必须定性为转换器缺陷（修）或白名单缺项（登记），**禁止静默放行** |
| 回退件缺 evidence | 该批重做 |

## Assumptions（用户裁定登记）

* 2026-11-16：**标准化对象为中文 markdown**；英文 markdown 仅格式归一，文字与 HTML 一致，不走 LaTeX，不增设 markdown 标准化以外的 CI 步骤。
* 2026-11-16：**在途件一律回退重走 s2.4**；**done 亦回退**（3 件）。
* 2026-11-16：**先回退比较 HTML 生成补丁与勘误表，再把勘误表应用到既有在途译文**。
* 2026-11-16：**编号加点，与原文一致**（`## N. 标题`）。
* 2026-11-16：**`脚注` 定末位**（随 EN `Notes（原文脚注）` 位次）。
* 2026-11-16：**不加跨语槽位键**；配对靠标题与顺序。
* 2026-11-16：**判官只读**；"格式被破坏"由既有审计器与 HTML 解析器判，markdown 格式化工具只判中文格式，LaTeX 不参与。
* 2026-11-16：**yuanwen 文字 ≡ en**；仅格式被破坏时允许入勘误表并同时改 yuanwen（补丁池＋勘误表双登）。
