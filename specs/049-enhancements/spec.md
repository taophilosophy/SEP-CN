# 049 — 翻译增强三件：术语自动提取回填 / 回译核验 / 实时术语提示

**版本** v1.0 ｜ **状态** 方案（待实施）｜ **日期** 2026-11-18 ｜ **权威** 用户“全部批准”（ADR-0072 决策 4）｜ **承接** `开源翻译.md` §3.2/§5.3、ADR-0070

## 0. 方向声明

- **目标**：三项增强——①术语自动提取回填（s2.4 前辅助）；②reverse-check 回译核验（R 链辅助）；③实时术语提示（P4 之外轻量通道）。
- **非目标**：不全量翻译、不替代既有节点、不自动改稿。

## 1. 三项判据与方案

### 1.1 术语自动提取回填（s2.4 辅助）

- 方案：LLM 从源文提取术语对（源词 → 译名候选），与 `shu-yu-biao.md`／`ren-ming-biao.md` 比对，标出“漏译术语／未登记新术语”。
- 凭据：MachineTranslation.io 实测术语对提取准确率 >95%（阿/法/西）。
- 落点：s2.4 证据增“术语候选清单”，供人审核销；**不自动登记**（登记仍走 rules/03 人工）。

### 1.2 reverse-check 回译核验（R 链辅助）

- 方案：对关键句段，把译文回译成英文，与 en 原文比对核心信息（数字/专名/逻辑连接），差异交人审。
- 凭据：郭尚兴团队“AI 生成—人工深编”质量环（`开源翻译.md` §5.3）。
- 落点：R 链 evidence 增“回译核验差异”，作为人审补充证据，不判终审。

### 1.3 实时术语提示（P4 之外轻量通道）

- 方案：参照 OmegaT 术语高亮，翻译时对源文命中的登记册术语实时提示译名（不改变 P4 提示词注入主通道）。
- 落点：P4 提示词增“命中术语清单”段（已有注入的轻量强化）。

## 2. 落点

- `specs/049-enhancements/spec.md`（本文件）＋ 各 `bin/`（待实施）。
- 测试词条（1–5）逐项验证。

## 3. 边界

- 全部仅测试词条验证，符合“不进行全量翻译”。
- 任何 LLM 产出均为“候选/证据”，登记与定稿仍归人工（ADR-0070）。
