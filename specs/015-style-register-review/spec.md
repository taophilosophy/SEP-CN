# specs/015 译文语体全局复核（禁文言与破折号滥用）

日期：2026-11-10。触发：用户指令——「为何 jayaraasi.md 正文除了引用，通篇都是文言文？不允许出现这种情况，加入规则门禁。全局复核。」并补充「禁止机械判断，必须语义分析」「正文不要滥用破折号，视为 AI 味的一部分」。

## 意图复述

用户要的是：译文正文（引文除外）必须是现代汉语学术书面语，不得整篇文言或半文半白，也不得滥用破折号；这个判断必须由复核人**通读语义**作出，不能靠关键词命中；并且要对全库既有译文做一次复核，把不符合的改掉。

## 目标 / 非目标

**目标**

1. 规则层：`rules/02-style.md` 立“语体与文风（语义判定）”条款；`rules/04` 在二校与 r1 增加语体通读；ADR-0033 记录决策与门禁形态。
2. 门禁层：`check_academic.py` 的 `task-style-attest` 只校验 s2/r1 是否留下**语义复核结论**（`语体：……`），不判断文本语体；生效时点后的 done 任务适用。
3. 复核层：对 306 条 done 词条逐条通读（排除引文、碑铭、题记原引文、参考文献照录条目），判定语体为“现代汉语／混合／文言”，记录证据句与处理动作。
4. 不合规处置（用户 2026-11-10 裁定）：判为文言或半文半白的，**一律置空**——`task_ops.py reopen` → `clear` 回到 H1，重新进入重译队列；不修补、不以旧译为底稿。已知违例 `j/jayaraasi.md` 同此处置。

**非目标**

* 不做关键词扫描判定（“之／其／而／则”命中数不作证据）；脚本只用于枚举条目、生成队列、校验记录完备，不产生语体结论。
* 不对不合规件做定点修补或改写；置空后另行重译。
* 不做术语与人名改判（另行走登记册流程）。

## 判定口径（语义）

1. 通读正文；排除 `>` 引块中的直接引文、典籍原文、碑铭、题记原引文与参考文献照录条目（这些保持原文语体）。
2. 判“现代汉语”：当代中文学术读者无需先译成白话即可自然读懂；句式、虚词、连接方式属现代汉语书面语。
3. 判“混合”：整体可读，但成段或连续多句出现文言句式／仿古修辞。
4. 判“文言”：正文主体（题目、导言、节下叙述）以文言或仿古四六写就。
5. 破折号：另记“是否滥用”——破折号充当默认停顿／连接，或同段多处、可替换为冒号／括号／分句而未替换。
6. 每条结论必须附**证据句**（从该词条抄出 1–3 句）与处理动作；无证据句的结论视为未复核。
7. 破折号滥用的修复（用户 2026-11-10 裁定）：以含破折号的原句为单位、回英文源句（`yuanwen/` 镜像）整句重新翻译，禁止符号层机械替换（已入 `rules/02`“破折号滥用的修复方式”）；重译只重整句法与停顿，不得改变命题内容。脚本只枚举用量排优先级（`results/dash-scan.jsonl`），滥用与否均为语义判定。

## 队列与记录

* `results/queue.jsonl`：全部 done 词条（slug、路径、字节数、done 时间戳），只作枚举与断点，不含判定。
* `results/verdicts.jsonl`：逐条 `{slug, path, verdict, dash, evidence, action, cleared_at, reviewer, at}`；`verdict` ∈ modern／mixed／classical，`action` ∈ none／clear。
* `results/dash-verdicts.jsonl`（破折号专项线，与语体线并行）：逐条 `{slug, path, dash, evidence, action, reviewer, at}`；`dash` ∈ ok／abused，`action` ∈ none／fix／pending（fix=需整句重译修复，完成复核后追加 `dash=ok` 新记录）。先做 `dash-scan.jsonl` 密度 ≥6/千字的高密度段（共 51 条），余量按密度续推。
* 顺序：先复核 J 批 done（已知违例所在批次），再按 done 时间升序推进；每批交接写 `results/handoff.md`。
