## 3. 单条标准作业（本会话）

1. `python tools/task_ops.py create <slug> --kind retranslate` → `clear <slug>`（基线哈希门禁）。
2. `python script/lq.py init <L> <slug>` 起账本骨架（source 逐字符取自 `yuanwen/`）。
3. 分批翻译：读账本 source 段 → 写 `script/<slug>_pN.json`（`{"id": [step1, step2]}`）→ `python -I script/lq_fill.py <L> <slug> <json>`；**每批即提交账本**（防中断丢失）。
4. `lq.py check` HARD=0 → `lq.py compose --write` → `script/italic_to_bold_cjk.py`（中文强调斜体转粗体）→ `advance draft`。
5. s1 逐节核销（MTPE 顺序：幻觉/漏译/增译 → 术语漂移 → 语言）；s2 `check_prose` 逐条修或豁免留痕；s3 四检（`check_style`/`check_academic --strict`/`check_math`/`check_summary`）→ `advance s3`（学术门禁挂钩）。
6. 术语人名：先查 `yi-zhe-shuo-ming.md`/`ren-ming-biao.md`，缺则按表体例补登（六列，先查后登，bisect 定位）；正文用词与登记册 grep 一致。
7. r1→r2→r3→done：冷置回读 + 逐句回核原文 + 结构五维（标题集合/defs/脚注键/公式/年份）对账。
8. 收口：`PROGRESS.md` 由 `tools/progress.py` 再生成（不手改）；`check_all` 全绿。
