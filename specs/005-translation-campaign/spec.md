## 1. 范围（G0）

* **目标**：1791 个正式词条完成三审三校（done）；74 条上游增量全部接入；技术债务登记表 13 项全部解除或显式豁免；抓取→比较→更新→翻译→发布全流程例行化（存档季节奏）。
* **范围内**：词条翻译与审校（含集群子词条与补充材料）、intake 接入、yuanwen.py 单测、双站构建验证、更新流程例行调度。**不备份**（用户 2026-10-27 裁定：禁止任何备份文件，项目由 git 管理；en/ 原始物为可再生的抓取物——流水线重抓即恢复，版本钉元数据在 git）。
* **范围外/非目标**：VitePress 前端重构、SEP 官方合作、机器翻译质量评估基准建设、英文原版的修改。
* **平台与约束**：SEP 抓取礼貌 ≥5 秒（并发节拍按 2026-10-27 裁定，实测 16/64 路无限流）；SEP 内容 CC BY-NC-SA（译文沿用仓库 BSD-2-Clause 与现行发布方式，"reprinted with permission" 图片标注来源）；零信任（既有译文不作底稿）；多会话并行（推送先 pull --rebase）。
* **代价承担者**：用户（决策、验收、算力成本）；AI 会话（执行、凭证、门禁）。
* **阻塞登记**：无（D2 备份已由用户裁定豁免，见 FR-004）。

## 3. 功能需求

### FR-001 intake 接入（P1）
* 描述：74 条上游增量按批次接入 SUMMARY 并建桩。
* 失败路径：slug 冲突或译名未登记 → 记入批次报告待裁定，不静默猜测。
* 验收判据：`summary_sync report` 显示 add 队列清空；`rebuild_dir check` 镜像 1872/1872；每条有任务记录。
* 证伪条件：出现未建任务直接建桩的条目。

### FR-002 三审三校实跑（P0）
* 描述：每词条经 clear→draft→s1→s2→s3→r1→r2→r3→done，s3/r3 学术挂钩拦截。
* 失败路径：任一门禁拦截 → 任务 blockers 登记，修复后 unblock。
* 验收判据：任务 JSON 全步骤有 actor/at/evidence；`check_academic --docs --strict` 0 硬错误；done 时 check_all 全绿。
* 证伪条件：存在 done 任务缺任一凭证或跳过挂钩。

### FR-003 数学/表格/脚注/图片保真（P0）
* 描述：译文忠实转换产物（check_math 金样本精确断言 + 全量抽样双层）。
* 失败路径：公式内容缺失 → check_math 硬错误，回炉。
* 验收判据：logic-classical 1545 处行内公式逐一在译文可见；bayes 25 表格齐；action-perception 图注齐。
* 证伪条件：金样本词条的任一公式/表格在译文缺失且无译注说明。

### FR-004 原始物备份（已豁免，D2）
* 用户 2026-10-27 裁定：**不备份，禁止任何备份文件**，项目由 git 管理。en/ 原始物为可再生抓取物（重抓即恢复），版本钉元数据（哈希/存档版名/pubinfo）已入库 specs/004 与 baseline/。本需求豁免，无验收判据。

### FR-005 yuanwen.py 金样本单测（P1，D6）
* 验收判据：tools/tests 覆盖公式定界符、脚注配对、表格计数、图片引用；断言基于 9 个 fixtures。
* 证伪条件：任一金样本转换产物与断言不符而测试仍绿。

### FR-006 双站构建验证（P2，D8）
* 验收判据：`vitepress build` 0 错误，产物含全部 SUMMARY 链接页面；GitBook 侧边栏同步。
* 证伪条件：构建产物缺任一词条页。

### FR-007 更新例行调度（P1，D11 顺带）
* 验收判据：存档季 compare 全量报告入 specs/001；漂移条目 100% 有变更文件与 update 任务。
* 证伪条件：存档季后 7 天内仍有漂移未进队列。

### FR-008 版本标签与归档（P2，D10 已起步）
* 验收判据：每存档季打不可改写 tag；发布说明指向可复现哈希；已知限制公开。

## 4. 非功能需求

* NFR-001 质量：done 词条 `check_all` 全绿 + 学术挂钩通过（0 硬错误）。
* NFR-002 可回溯：每词条可由 en/ 原始物重算复核；译文修改可锚定英文节号。
* NFR-003 速度：单词条三审三校目标 ≤1 会话日；批量波次按字母区并发（子代理 4–8 路）。
* NFR-004 零信任：验收用"换命令/换环境"复核（随机抽 3 词条独立重算并 diff）。
* NFR-005 经济：礼貌抓取；并发不触发限流（429 即收敛，记录实测阈值）。
