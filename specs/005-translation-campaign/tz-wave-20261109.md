## 3. 单条标准作业（本会话）

1. `task_ops.py create <slug> --kind retranslate` → `clear <slug>`（基线哈希门禁）。
2. `script/lq.py init <L> <slug>` 起账本骨架（source 逐字符取自 yuanwen）。
3. 分批翻译：读账本 source 段 → 写 `script/<slug>_pN.json`（`{"id": [step1, step2]}`）→ `script/lq_fill.py <L> <slug> <json>` → **每批即提交账本**（防中断丢失）。
4. `lq.py check` HARD=0 → `lq.py compose --write` → `script/italic_to_bold_cjk.py`（如适用）→ `advance draft`。
5. s1 逐节核销（MTPE 顺序：幻觉/漏译/增译 → 术语漂移 → 语言）；s2 `check_prose` 逐条修或豁免留痕；s3 四检（style/academic --strict/math）→ `advance s3`（学术门禁挂钩）。
6. 术语人名：登记用 `tools/term_flow.py` 或手工按表体例（六列，先查后登，bisect 定位）；正文用词与登记册 grep 一致。
7. r1→r2→r3→done：冷置回读（本会话初译的条目须先做他条再回读，evidence 记明冷置）。
