## 2. 单条标准作业（翻译线）

> 铁律：零信任（只以 `yuanwen/s/<slug>.md` 与 `en/` 原始物为底稿，不参考任何既有中文译文）；逐段双版（step1 忠实、step2 优化）；禁止跳步；禁止批量机械替换。

1. **建任务**（未建者）：`python tools/task_ops.py create <slug> --kind retranslate`；然后 `python tools/task_ops.py clear <slug>`（基线哈希门禁）。
2. **起账本**：`python script/lq.py init s <slug>`（source 逐字符取自 yuanwen，step1/step2 为 TBD）。
3. **分批翻译**：`python script/lq.py show s <slug>` 看段号与体量；按批（建议 10–20 段/批）通读 source，写 `script/<slug>_pN.json`（格式 `{"1": ["step1 文本", "step2 文本"], ...}`），再
   `python -I script/lq_fill.py s <slug> script/<slug>_pN.json`
   已填段默认拒覆写（`--force` 才覆写）；**每批落盘后立即 `python script/s_commit.py <slug> "<slug> 账本 pN 段 a–b"` 防中断丢失**。
4. **守恒门**：`python script/lq.py check s <slug>` → HARD=0 才可 compose；SOFT 标旗逐条判读（机械段/斜体→书名号可过，长度比越界须核漏译）。
5. **成稿**：`python script/lq.py compose s <slug> --write` → `python script/italic_to_bold_cjk.py s/<slug>.md`（中文强调斜体→粗体；标题/列表/脚注定义/表格/pubinfo 行豁免）。
6. **补料**（有 `<slug>.<x>` 者，见 §3）。
7. **定点门禁**：`python script/s_gate.py <slug>`（内部跑 ledger-check/style/academic/prose/math/summary/terms）。FAIL 逐项修，直到全绿。
8. **术语/人名登记**（§4）→ 再跑 `python script/s_gate.py <slug>` 确认。
9. **推进状态**（evidence 一律写临时文件，避免 PowerShell 长引号转义；evidence 要可复核，见 §6）：
   ```
   python script/s_adv.py <slug> draft <actor> script/ev_<slug>_draft.md
   python script/s_adv.py <slug> s1    <actor> script/ev_<slug>_s1.md
   python script/s_adv.py <slug> s2    <actor> script/ev_<slug>_s2.md
   python script/s_adv.py <slug> s3    <actor> script/ev_<slug>_s3.md
   ```
   `s3` 会触发学术规范挂钩（`check_academic --strict`，硬错误即拒绝推进）。
10. **提交**：`python script/s_commit.py <slug> "<slug> draft+s1+s2+s3：<要点>"`。
11. **交评审**：把词条 slug、s_gate 输出、登记 rowspec 路径、异常留痕报给 Lead（见 §7 报告格式）。

## 3. 补充材料（随主词条同周期，模板 #19）

- `lq.py` 只覆盖主文页；补料**手建账本 + 手工装配**：
  1. 账本 `tasks/s/<slug>.<x>.ledger.yaml`：`version: 1`、`slug: <slug>.<x>`、`params`（model/temperature/batch_segments/rate_limit_s/timeout_s）、`segments` 每段 `id/kind: body/source/step1/step2`。
     **本批约定**：段 = yuanwen `<slug>.<x>.md` 的正文块（跳过头部三块：`# …（supplement）`、`> （…源：…）`、`#### Supplement to …`），**含 `## 节标题` 块**（机械装配、可校验）。
  2. 守恒：`python script/s_ledger_check.py <slug>.<x>` → HARD=0。
  3. 装配 `s/<slug>.<x>.md`：
     ```

     > （《<slug>》词条补充材料，源：plato.stanford.edu/entries/<slug>/<x>.html）

     <step2 各段按序、段间空行>
     ```
  4. 主文引用处写 `（见[补充材料](<slug>.<x>.md)）`；补料文件一并过 `s_gate`（脚本自动纳入 `<slug>.*.md`）。

## 6. 证据（evidence）要素（task JSON 可复核的最低要求）

- **draft**：方向声明（一句话复述范围/目标/非目标/判据）＋账本段数与构成（body/oir/note）＋`lq.py check` HARD=0 ＋compose 字符数＋补料文件＋账本 params。
- **s1**：逐节对照清单（节数/数字多重集/年份/人名/脚注键/文献定义）＋实修列表（处数+例子）＋残留外文说明＋Critical/Major 计数。
- **s2**：`check_prose` 告警 N→M＋实修分类计数（长句/的链/被字/弱动词）＋逐条豁免留痕。
- **s3**：`check_style` 0 ＋`check_math` ＋`check_academic --strict` ＋`check_summary` ＋术语/人名登记行数（含 rowspec 路径）＋相关词条匹配数＋斜体→粗体行数。
- **r1/r2/r3**（评审线）：结构对位＋论证链核销＋逐句回核实修＋冷置说明（先做他条再回读）＋Critical/Major 计数；r3 另附 `check_all` 结果与定点五检。
- **done**：终稿字符数＋账本段数＋登记行数＋门禁摘要。

## 10. 已知陷阱（模板 §6.5 摘要 + 本批新增）

- `compose` 的 H1 取自 SUMMARY 行；行内有转义括号时 s1 手工补全。
- `map_related` 同题误配：相关词条英文名可能撞上另一长题词条 → s1 逐条核对 SUMMARY 主名。
- 脚注键 / `$` / `**` 计数是硬门；step2 不得给源文斜体词加粗（`**` 计数漂移即 HARD）。
- 中文强调用 `**粗体**`，拉丁术语/书名保留斜体（`*dharma*`）；references 节照录豁免。
- 现制 References（2026 新修订页）：保留 `## References（引用注释）` 节说明与文末 `[^key]:` 定义区；伪脚注 `[^unless-nd]` 等照录。
- 中国文献条目一律译为中文（ADR-0011）；`tools/biblio_audit.py <slug>` 定位疑似条目。
- 学术工具固定四行 bullet（v1.3）。
- 相关词条站内链接不造死链（保留名称，管线统一挂接；译注占位按既有成例）。
