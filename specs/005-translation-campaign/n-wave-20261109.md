## 4. 单条标准作业（本会话）

1. `task_ops.py create <slug> --kind retranslate` → `clear <slug>`（基线哈希门禁；已有 pending 任务者直接 advance clear）。
2. `script/lq.py init n <slug>` 起账本骨架（source 逐字符取自 yuanwen）。
3. 分批翻译：读账本 source 段 → 写 `script/<slug>_pN.json`（`{"id": [step1, step2]}`）→ `script/lq_fill.py n <slug> <json>` → **每批即提交账本**（防中断丢失）。
4. `lq.py check` HARD=0 → `lq.py compose --write` → `script/italic_to_bold_cjk.py n/<slug>.md`（如适用）→ `advance draft`。
5. s1 逐节核销（MTPE 顺序：幻觉/漏译/增译 → 术语漂移 → 语言）；s2 `check_prose` 逐条修或豁免留痕；s3 四检 → `advance s3`（学术门禁挂钩）。
6. 术语人名：先查后登（六列体例），正文用词与登记册 grep 一致。
7. r1→r2→r3→done：r1 冷置回读（**本线初译条目须先做他条再回读**，evidence 记明冷置）；r3 过学术门禁后收口。

## 5. 本会话已固化的判据（从 necessary-sufficient 得到）

| 事项 | 做法 | 理由 |
| --- | --- | --- |
| 账本 `**` 计数 | step2 保持 `*中文*` 斜体原形，粗体化只留正文 | `lq.py check` 要求 `**` 计数与源相等（HARD）；`*` 计数差仅 SOFT |
| 正文终稿与 compose | italic-cjk / 脚注修订后正文与 compose 不再逐字节一致，属正常（newton 3 行、本件 16 段+1 行） | 粗体化与 biblio 修订是正文侧后处理；**禁再 `compose --write` 回退** |
| 源 HTML 字面星 | `<em>…</em>* (Subtitle: *<em>…</em>)` 这类源文本自带 `*`，按仓库先例用 `\*` 转义保留显示 | 显示字符与原页一致，且 markdown 语义正确 |
| 转换器残渣 | `…/li>` 等零星残渣在正文侧删（镜像三处同型，属转换器偶发） | 残渣无意义，照录会污染成品 |
| 源文自身不一致 | 正文 Nebel 2018 vs 文献 2019、von Fintel 1998 vs 键 von-1997 等一律照录保留 | 零信任：不代改源文内容 |
