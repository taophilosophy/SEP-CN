## 3. 单条标准作业（沿用 o-wave-20261110 §3）

1. `task_ops.py create <slug> --kind retranslate` → `clear <slug>`（基线哈希门）。
2. `python -I script/lq.py init i <slug>` 起账本；通读 `yuanwen/i/<slug>.md` 后分片填 segments（step1 忠实初译 + step2 语言优化，双版必不同），每批落盘即提交账本。
3. `python -I script/lq.py check i <slug>`（守恒门 HARD=0）→ `compose --write` → `script/italic_to_bold_cjk.py`。
4. 四检：`check_style --docs --strict`、`check_academic --docs --strict`、`check_math <slug>`、`check_summary`；`check_prose` 逐条实修或按 ADR-0020 豁免留痕。
5. s1 逐段回核原文（对账五维：段落/节数/脚注键/defs 键集/公式）→ s2 prose 实修 → s3 四检 → r1/r2/r3 冷置回读 → done。
6. 登记册：术语入 `yi-zhe-shuo-ming.md`、人名入 `ren-ming-biao.md`，先查后登，正文与登记行一致。
