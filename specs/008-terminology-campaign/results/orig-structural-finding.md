# 原文列结构性取证结论（2026-11-10 补遗轮）

## 问题

`tools/check_terms.py` 报“非英语术语缺原文”265 条（登记册 85 ＋ 人名表 180）。`rules/03-terminology.md` 对该列的规定是：

> 非英语条目必须回填且逐词联网复核——**只采来源页面显式给出的“转写 ↔ 原生文字”配对**，**禁止**用 IAST／DIN 31635／Wylie 等映射表正推或逆推。

因此能否回填，取决于来源页面（`en/<slug>/index.html`）是否显式给出原生文字。本次对该前提做了全量实测。

## 方法

1. 遍历 `en/` 下全部 1881 个词条目录的 `index.html`，剥离 `<script>/<style>/<标签>`、解码十进制字符实体（SEP 页面用 `&#NNNN;` 承载非拉丁字符）。
2. 按 Unicode 区块抽取原生文字串：天城体、藏文、阿拉伯文（含扩展）、希腊文、希伯来文、平假名、片假名、谚文、西里尔文、泰文。
3. 统计含原生文字的词条数与原生串总数，并逐条查看原生串的上下文，判断是否构成“转写 ↔ 原生文字”配对。
4. 对 265 条缺原文行，按其“出处”列所指词条（去除非 slug 文字后按目录存在性过滤）检索配对。

脚本为本地一次性工具 `script/orig_candidates.py`（`script/` 不入库，ADR-0027）。

## 结果

| 指标 | 数值 |
| --- | --- |
| 词条目录总数 | 1881 |
| 含原生文字的词条数 | **32**（1.7%） |
| 原生文字串总数 | **109** |
| 与 265 条缺原文行构成合格配对的 | **0** |

109 处原生串按文种分布：西里尔文 46、谚文 36、希腊文 12、希伯来文 8、阿拉伯文 3、平假名 3、天城体 1。逐条查看后归为四类，**无一是 265 条登记项所需的“转写 ↔ 原生文字”配对**：

* 书目条目题名（西里尔 46 处集中于 `john-italos` 15、`mulla-sadra` 13、`lesniewski` 等；谚文 36 处集中于 `korean-buddhism` 20、`buddhism-huayan` 11、`korean-confucianism` 4）；
* 希腊字母与词形残片 12 处（`personalism` 的 `ύ ό`、`simplicius` 的 `ϵ ί`、`wilson` 的 `ά ύ` 等，系页面实体拆分后的碎片）；
* 希伯来文 8 处（`legal-obligation`、`medieval-political`、`meister-eckhart` 的期刊与专著原题）；
* 阿拉伯文 3 处（`arabic-islamic-phil-math` 的《كتاب المدخل الى علم العدد》、`al-din-al-razi` 的 `غیر المعلوم یمتنع الحکم علیه` 及其转写 `Ghayr al-maʿlūm yamtaniʿ al-ḥukm ʿalayhi`、`arabic-islamic-essence` 书目题名里的 `انية [Anniyya]`）、天城体 1 处（`architecture` 正文里的 `Mānasāra (मानसार)`）、平假名 3 处（`への`、`について`、`における`，系日文语法片段）。

其中三处确实构成显式配对（`انية ↔ Anniyya`、`मानसार ↔ Mānasāra`、`غیر المعلوم… ↔ Ghayr al-maʿlūm…`），但三者的键均不在登记册的 265 条缺原文行内（登记册只有 `anniyya faqat`（纯粹存在），与单字 `anniyya` 非同项；另二者未登记），故对本清单无补。

即：SEP 英文原页面通篇使用转写（IAST／DIN 31635／Wylie 等）而不附原生文字，故“只采来源页配对”的口径下，这 265 行**结构性无法回填**，非经办疏忽。

## 结论与选项

维持现状（告警常红）与技术规则冲突；强行回填则必然依赖映射表正推，直接违反 `rules/03` 与 ADR 精神（零信任、可追溯、禁臆造）。可行路径三条：

| 方案 | 内容 | 代价与风险 |
| --- | --- | --- |
| A（建议之一） | 修订 `rules/03`：允许以**权威工具书／辞书**给出的“转写 ↔ 原生文字”配对回填，凭证写入“依据”列（与 ADR-0012 依据档位同构） | 需逐条查证并留凭证，工作量约 265 条；须新 ADR |
| B（建议之一） | 对**人名表**设豁免：来源页未给原生文字者，原文列留 `—`，依据列注明“来源页未给原生文字（specs/008 取证 2026-11-10）”，并把该子集从告警口径移出 | 需改 `check_terms.orig_missing` 判定；术语表 85 条仍走 A |
| C | 维持现状，将 265 条登记为结构性欠账 | 告警失真，长期看会掩盖真实缺口 |

建议 A＋B 组合：术语（85 条）按工具书补齐并留凭证；人名（180 条）豁免并留痕。二者均需用户裁定后另起 ADR，本轮未擅自改规则。

## 附：人名表“籍属／生卒”约 3 008 条

同源问题：该两列要求逐人考订国籍与年代。以同一语料测算可行性（2026-11-10）：

| 判据 | 行数 |
| --- | --- |
| 缺籍属或生卒的行 | 3 008（随并行会话写入浮动，`check_terms` 报 3 006–3 007） |
| 其中出处词条存在、且源页同时出现该姓氏与任一“年份–年份”区间 | 399（13.3%） |
| 收紧到姓氏出现处 120 字邻域内含年份区间 | 76（2.5%） |
| 上述 76 行改用严格判据（两端均四位年份、且首年 ≥1000 且末年 > 首年）后 | **3**，且三条均为时期跨度（`Eagleton` 的 1900-1933 指其著述时段、`Masham` 两行的 1550-1800 指家族世代），非生卒 |

结论修正（2026-11-10 二次复核）：宽松判据命中的 76 行中，绝大多数是 DOI 串（如 `10.1007/s11229-006-0005-1`）、期刊卷页（如 `583-588`）与著作出版年，**无一是“姓名 + 生卒”配对**；严格判据下仅存 3 条时期跨度，亦不可用。故本语料对“生卒”的可自动回填量为 **0**。

处置：该两列只能走外部权威工具书（《世界人名翻译大辞典》等）逐人考订，且须逐条写凭证；本轮不填，避免把不确定写成确定。规则层是否开放该来源，与原文列 A 案同源，待裁定（原文列已由 ADR-0030 开放工具书来源；籍属/生卒列尚未开放）。

## 附：方法与可复现性

取证脚本为本地一次性工具 `script/orig_candidates.py`（`script/` 不入库，ADR-0027）；关键实现为：剥离标签后解码十进制实体（SEP 用 `&#NNNN;` 承载非拉丁字符）、按 Unicode 区块提取原生串、以转写骨架（去变音符与小写化）匹配上下文。全部数值由该脚本在 2026-11-10 的 `en/` 快照上得出，可复跑核对。
