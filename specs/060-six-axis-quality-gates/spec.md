## 2 结论：六类在现行流程中的真实落点

### 2.1 落点表

| 需求 | 现行落点（文件:行） | 独立性判定 |
| ---- | ---- | ---- |
| 标点校对 | `check_style`（S3 硬拦，`rules/pipeline.json:511`）；`check_quotes`（挂 global，`:502`）；`check_pairs` bracket-pair／ellipsis-form（挂 s2.4 体例轴，ADR-0063）；人工在 s3（`rules/04:27`） | **否**。四器挂三节点，与空格、加粗、HTML 残留、表格、SUMMARY 同工位；GB/T 15834 十七种标点只覆盖约六种 |
| 语法校对 | s2“二校（语言）”（`rules/04:26`）；机检仅 `check_prose` 十一条反欧化模式，告警级（`rules/05/tools.md:15`） | **否**。与语体、节奏、破折号、“一个”、AI 腔混装；`check_prose` 是模式统计，不做句法分析；成分残缺、搭配不当、语序、虚词误用零判据；和制汉语全库无条款 |

| 句式逻辑（公理化） | 无。R2“连贯性”只查段落级论证链与指代（`rules/pipeline.json:403-425`） | **否**。完全空白，无判据、无工具、无凭据 |

### 2.2 现行架构自相矛盾

`rules/pipeline.json:7-9` 自述三条原则，其中第一条为“一个节点只对一个对象负责：对象变了就是两个节点，哪怕工序名相同”。现状：

* s2 一个节点同时对“语法合法性”“语域”“修辞节制”三个对象；
* S3 一个节点同时对“标点”“空格”“结构”“交付格式”四个对象；
* 标点判据分散在 `check_style`、`check_quotes`、`check_pairs`、`check_math_zh` 四处，`criteria_owner` 却只登记 S3 一处（`rules/pipeline.json:511`），所有权与实际承载不符。

即：**用户要求的六类独立，不是新增主张，而是把仓库自己写下的原则贯彻到语言与体例层。**

## 3 建议架构：六道工序，q1–q6

### 3.1 位次与命名

状态机 v3 序列（`→` 为推进方向）：

```
pending → cleared → s0_source_checked → drafted
→ s1_checked → s2_checked → s2.4_termchecked → s2.5_checked
→ q1_cite_checked → q2_logic_checked → q3_grammar_checked
→ q4_register_checked → q5_measure_checked → q6_punct_checked
→ s3_checked → r1_reviewed → r2_reviewed → r3_reviewed → done
```

命名用 `q`（quality gate）前缀而不用 `s2.6…s2.11`：`s2.x` 的语义是“二校的子步骤”，与“独立工序”矛盾；`s4…s9` 会与既有的 s0／s3 形成编号与位次倒挂。`q1–q6` 与既有 `s*`、`r*` 家族不冲突，且位次由 `rules/pipeline.json` 的显式 `prev` 字段决定，不依赖字典序。

### 3.2 顺序论证（不可换位的五条依赖）

1. **q1 引文先于 q2 逻辑**：引文是照录对象，其命题不属于译者的表述责任。先锁定引文清单与 hash，q2 起不得改动引文内部文字与标点；否则逻辑比对会把源文引文的命题算到译者头上。
2. **q2 逻辑先于 q3 语法**：逻辑决定“说什么”，语法决定“说得对不对”。逻辑错误不能靠改语法修；反之，语法破碎会使逻辑骨架抽取失真。
3. **q3 语法先于 q4 语域**：语域的前提是句子合法。ISO 5060 明确 Style 是“语法可接受但不合规范”，语法不合格时语域判断无意义。
4. **q5 计量先于 q6 标点**：量值与单位的规范形会牵动数字间连接号、数值与单位间空格、数字分组空格；标点是最后的形式层，须在计量定形后判。
5. **q6 标点先于 s3**：标点从 S3 独立出来后，S3 只保留结构、表格、图片、交付格式；若标点仍在 S3 内判，则 S3 又回到“一节点多对象”。

### 3.3 与既有节点的职责迁移

| 既有对象 | 迁移后归属 | 处理 |
| ---- | ---- | ---- |
| `check_style` 的 curly-quotes／quote-spacing | q6（P-8、P-18） | 规则迁入 `punct_audit`，`check_style` 保留空格／加粗／HTML／AsciiDoc／斜体 |
| `check_quotes` 直角引号总检 | q6（P-8） | 全库总检并入 q6，避免双器同判 |
| `check_pairs` bracket-pair／ellipsis-form | q6（P-9、P-11） | 迁入 q6；`check_pairs` 保留配对类之外的引用一致性与数量对照 |
| `check_style --connector-scan` | q6（P-13）＋q5（M-6） | 形态归 q6，数值范围该用哪一形归 q5；分工写进两条判据 |
| `check_prose` 十一条 | q3（G-9…G-16） | 升级为 `grammar_audit` 的第二层，模式表保留，判据分层显式化 |

## 4 六道工序规格

每道工序统一五件：**对象、判据、机检子集、凭据、裁判与独立性**。判据全文见 `checklists/`。

### 4.1 q1_cite_checked（引文锁定）

| 项 | 内容 |
| ---- | ---- |
| 对象 | 全部引文：引块、行内引号引文、脚注引文、参考文献内的被引条目 |
| 判据 | C-1…C-8，见 `checklists/q1-cite.md`。核心事实：SEP 引文约 99% 为英文转述或英译（成句引文 34458 片段中确定非英文 315，占 0.91%）。因此：英文直引不另造英文；逐条判原著语种（`origin_lang`）与原文可得性（`na`／`present`／`verifiable`／`unavailable`）；`verifiable` 的原文须补齐，`unavailable` 不得代造；间接转述归 s1，术语级归 s2.4；转写按 ISO 24229 登记；引文 hash 在 q3–q6 守恒 |
| 机检子集 | C-1 清单条目数与文中引文标记数比对；C-2 字段完整性；C-5 转写字符域与登记系统白名单；C-6 锚点存在性；C-7 hash 守恒（q3–q6 出口各核一次） |
| 凭据 | `cite-manifest.json`（每条：id、位置、lang、original、english、translator、register_system、anchor、verdict、reviewer） |
| 裁判 | 不得为 draft actor（ISO 17100）；单会话形态须冷置并留痕（ADR-0020） |
| 门禁 | 首期告警，T1 起硬拦 C-1／C-2／C-6／C-7；C-3／C-4 为人审判据，凭据缺签字即视为未完成 |

### 4.2 q2_logic_checked（逻辑一致性）

| 项 | 内容 |
| ---- | ---- |
| 对象 | 每个命题单元（以句为基本单位，复句按分句登记）的谓词-论元骨架与逻辑算子 |
| 判据 | L-1…L-12，见 `checklists/q2-logic.md`。核心：命题数守恒、论元角色不反转、量词辖域、否定辖域、条件方向、模态强度、命题态度、预设与断言、并列同质、指代链、时间体、病句逻辑类（对齐 CY/T 266 表 1 第 1-11 类） |
| 机检子集 | L-3／L-4／L-5／L-6 的算子词配对初筛（all／every／any／no／some／not／if／unless／must／should／may ↔ 所有／任何／没有／有些／如果／除非／必须／应当／可以）；L-1 的句数与分句数粗对齐；其余人审 |
| 凭据 | `logic-skeleton.jsonl`（每句一条：源骨架、译骨架、差异项、判定、依据、reviewer） |
| 裁判 | 人审唯一裁决；LLM 只可产候选句对，不得出现“模型判定一致”作为通过证据 |
| 门禁 | L-1／L-3／L-4／L-5／L-6 可升硬（T2），其余为人审判据 |

**“公理化”的可操作边界（必须写死）**：本库的“公理”指 `rules/axioms.json` 的管线公理 P1–P28；q2 的逻辑形式化是**句级命题骨架登记**，不得占用“公理”一词，以免与管线公理体系混淆。骨架只登记可判项；不可判项标 `unformalized` 并转人审。禁止把逻辑骨架写成可写 oracle。

### 4.3 q3_grammar_checked（语法）

| 项 | 内容 |
| ---- | ---- |
| 对象 | 每个句子（不含引文内部、代码、公式） |
| 判据 | 三层：句法合法性 G-1…G-8；反欧化 G-9…G-16；和制汉语甄别 G-17…G-19。见 `checklists/q3-grammar.md` |
| 机检子集 | G-9…G-16 由升级后的 `grammar_audit`（吸收 `check_prose`）承担；G-1…G-8 只做句长、分句数、关联词配对、介词框架完整性等启发式告警；G-17／G-18 靠 `baseline/ja-loanwords.json` 三分类词表核对 |
| 凭据 | `grammar-report.json`（逐句：rule、span、判定、处置、reviewer） |
| 裁判 | 人审；G-9…G-16 的告警逐条判定或豁免留痕（承 ADR-0020） |
| 门禁 | G-1…G-8 首期告警、T2 起硬拦“句式杂糅／成分残缺／关联词错配”三型（机检可判子集）；其余人审判据 |

**和制汉语口径（用户 2026-11-25 裁定）**：已定型并收入《现代汉语词典》第 7 版的日源词照常使用，不判错；只禁未定型、生造、以词害意的日源词，处置为回源重选并登记 `shu-yu-biao.md`。判据不按“是否日源”一刀切，而按“是否定型”二分。

### 4.4 q4_register_checked（语域）

| 项 | 内容 |
| ---- | ---- |

## 5 全量回炉迁移方案

### 5.1 用户裁定与范围

用户 2026-11-25 选“全量回炉”：凡未经六类完整校验的存量一律回炉重走。范围分三块：

| 存量块 | 现状（2026-11-25 `tasks/` 实测） | 处置 |
| ---- | ---- | ---- |
| pending／cleared | 619／148 | 自然走新链，无需回退 |
| drafted…s2.4_termchecked | 16＋5＋408 | 继续推进至 s2.5，再进 q1–q6，无回退 |
| s2.5_checked 及以后（s3／r1／r2／done） | 需 `tools/progress.py` 精确摸底 | `revert-state <slug> --to s2.5_checked`（ADR-0043 原语），再进 q1–q6 |

### 5.2 迁移矩阵

| 当前状态 | 一条命令 | 目标状态 | 备注 |
| ---- | ---- | ---- | ---- |
| done | `task_ops.py reopen --actor <x> --reason "六轴回炉"` ＋ `revert-state --to s2.5_checked` | s2.5_checked | 不动译文，只重走校验；steps 留史 |
| r1／r2／r3 | `revert-state --to s2.5_checked` | s2.5_checked | r 链全重走 |

| s2.4_termchecked 及以前 | 无 | 原状态 | 推进到 s2.5 后进 q1 |

### 5.3 回退与重入规则

* q 链内发现问题按三层落位（承 ADR-0040）：q 自身可外科式修复者在本工序修；涉及命题内容者退回 q2；涉及重译或术语改动者退回 s2.5 或 draft，`changes:` 登记。
* **q 链重入上限 1**：同一件在同一轮内第二次退回，按 rework 登记 Critical（防止无限循环）。
* q1 引文 hash、q5 量值清单 hash 在 q6 出口各核一次，不守恒即硬失败——这是“六类不得互相侵蚀”的结构防线。

### 5.4 分批与试金石

1. **试金石 3 件**：一件引文密集（多语种引用）、一件逻辑密集（量词与否定多）、一件计量密集（单位与换算多）。三件全过才铺量（ADR-0039 §10）。
2. **按字头 A–Z 分批**，每批内 q1→q6 顺序固定，不并行跨类（避免同一件被两个会话同时判）。
3. **每批收口判据**：该字头 q1–q6 全部 pass，且 `check_all.py` 全绿。
4. **存量清零口径**：每类给出“残余 0 或全部登记豁免”的清单；未清零不得宣布该类完成。

## 9 词条规范化样态（国内＋国际标准对齐）

本节回答“条目本身如何合规”。以下为建议范式，落地时逐条对应判据编号。

| 层 | 规范样态 | 依据 |
| ---- | ---- | ---- |
| 题名 | `# 中文题 英文题 (作者)`，与 `SUMMARY.md` 同步；英文题与 `yuanwen` 同件 H1 一致 | ADR-0024、ADR-0063 |
| 版本事实 | H1 后引块：`> *首次发表于 YYYY 年 M 月 D 日；YYYY 年 M 月 D 日实质修订。*`，日期与 `baseline/entries.json` 一致 | rules/07 |
| 节结构 | 导言→编号节→参考文献→学术工具→其他网络资源→相关词条→脚注→译者注释 | ADR-0063／0065 |
| 术语 | 首现可括注原文，后文一律登记册主形；同概念全库同译 | rules/03、ISO 704 |
| 引文 | 英文直引为主：中译据英文，另记原著语种与原文可得性；`verifiable` 者补原文入脚注，`unavailable` 者保留英文并说明，不代造。非英文直引（少数）：引块原文＋方括号英译＋中文另段；英文按作者阐释／通行译本／本库转译三通道取用并注明。间接转述不按引文处理 | ISO 690:2021、ADR-0011、C-3／C-4 |
| 引文（中国典籍） | 用通行中文原文与篇码（《论语》2.3），不以英译回译 | ADR-0011、C-8 |
| 计量 | 量值＋单位规范形；数值与单位间一个空格；同量全文同单位；换算括注并记依据 | GB 3100／3101、ISO 80000-1 7.2、M-1…M-9 |
| 数字 | 计量用阿拉伯数字，概数与成语用汉字；同场合同形 | GB/T 15835 4.1／4.2／4.3 |
| 标点 | 全角、弯引号、连接号三形分工、省略号六连点、书名号内中英混排加空格 | GB/T 15834、CY/T 154（偏离登记 ADR-0041） |
| 译注 | 文末 `## 译者注释`，圈号锚点连续；不写入引文内部 | ADR-0065、CY/T 121 |
| 参考文献 | 照录＋中国文献条目中文化；要素按 GB/T 7714-2025 防漏核对 | rules/07、ADR-0011 |
| 语域 | 现代汉语学术书面语；引文外禁文言、禁方言与网络语；第二人称用“你” | rules/02、R-1…R-5 |

## 11 待裁事项（需用户逐项定）

1. **语域样章基准**：`baseline/register-baseline.md` 选哪 3–5 段作全书标尺（建议取已 done 且经用户认可的三件：一件分析哲学、一件哲学史、一件逻辑条目）。

3. **换算口径**：源文英制单位是否一律加公制括注，还是仅首次出现加注。
4. **日源词清单规模**：先以《现代汉语词典》第 7 版收录为“定型”唯一判据，还是另建 300–500 词的人工审定表。
5. **q 链重入上限**：确认“同一轮 1 次”是否足够，或按引文／逻辑设 2 次。
6. **是否新立 ADR**：六道工序与状态机 v3 属单向门（rules/08 §14），建议编号 ADR-0079 起。
7. **原文补齐的边界**：`verifiable` 是否只覆盖“有通行编号／定本”的古典与经典著作（亚里士多德 Bekker、柏拉图 Stephanus、康德 Akademie、阿奎那 Leonina 等），现代外文著作一律按 `unavailable` 处理，还是也逐条查初版。前者可执行，后者成本高且版本歧义多。
8. **引文承载形态**：补入的原文与英译统一方括号 `[…]`（建议），还是原文入脚注、正文不出现；决定后同步站点渲染检查。
9. **术语级括注范围**：约 1.27 万片段是一律要求首现括注通行英译，还是只对“首现且可能歧义”的术语括注。前者一致性硬、成本高。
