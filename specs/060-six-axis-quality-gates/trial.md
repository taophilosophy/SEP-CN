# 试金石报告（T0 阶段，三件）

> 执行器：`bin/trial.py`；工单：`results/trial-report.json`（2026-11-25）。
> 纪律：本报告生成清单与拦截分布，**不填写任何 verdict**，不推进任务状态。人工裁定与 r1/r2 签名不在本阶段范围（ADR-0070）。

## 1 选件依据

| 件 | 选择理由 | 清单量（q1/q2/q3/q4/q5/q6） |
| ---- | ---- | ---- |
| `adorno` | 引文最密（137 条直引）＋量值最多（85 条），压测 q1 与 q5 | 137／597／78／1／85／72 |
| `abduction` | 量词、条件、否定密集，压测 q2 算子配对 | 45／394／1／3／7／6 |

`ibn-gabirol`、`measurement-science` 等原本的候选件是桩件（55–81 字节），不具试金石价值，改用已译件。

## 2 结果

| 件 | q2 待裁定（非平凡/全句） | 门禁拦截（条） | 人工估算（下限–上限） |
| ---- | ---- | ---- | ---- |
| `adorno` | 138／597 | 586 | 149–253 小时 |
| `abduction` | 156／394 | 191 | 47–78 小时 |
| `aesthetics-existentialist` | 123／436 | 364 | 88–163 小时 |

三件全部被门禁拦下，拦截原因可分类：

* **q1**：C-6 缺 anchor（每条一条）＋ C-4 未裁定（每条一条），合计 2×直引数。属预期——清单骨架生成后须人审补锚点与裁定。
* **q2**：非平凡句未裁定。属预期。
* **q3**：反欧化与句法三型告警，逐条待处置。
* **q4**：每节 R-a 未定档＋文言/口语候选。
* **q5**：M-2 数值-单位空格为主（`adorno` 单行最多 10 处），M-4 上标形。
* **q6**：P-13 数值范围 ASCII 连字符为主，P-8 引号形态、P-18 邻接空格次之。

**结论**：六器可跑、门禁实拦、凭据落盘；流程能力成立。三件均未穿越门禁，符合“机检为筛、人审为判”——不存在“全绿即合格”的假通过。
