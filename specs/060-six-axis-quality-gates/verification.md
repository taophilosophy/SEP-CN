# 六轴工序公理化证明、完备性与一致性计算

> 验证器：`bin/verify_six_axis.py`（可复算）；凭证：`results/verification.json`（金样本 3 件）、`results/verification-a.json`（a 字头 161 件）。
> 范围声明：本文件证明的是**流程的结构性质与判据覆盖映射**；语义类判据（语法深检、语域好坏、逻辑实质一致）不可机判，其“通过”由人审签字承载（公理 P33、假设 H 组）。不伪造不可判项的证明。

## 3 定理与证明

### T1 全序性与位次正确性

**断言**：G 是单链；q1–q6 连续且满足 pos(q1)=pos(global)+1、pos(q6)+1=pos(S3)；ORDER 与 pipeline 同步；回退目标合法。
**证明**：S-1…S-5 谓词逐一求值。验证器 A 组 19 项检查全过（违例 0），其中链覆盖 22/22、q 链位次按索引比较、三处计数一致。
**凭证**：`results/verification.json` §A_structure。∎

### T2 判据唯一性

**断言**：六判据 `cite_audit…punct_audit` 各恰属一个节点，无双挂，承载体存在且与档位一致。
**证明**：S-2 谓词；六节点 `criteria` 各单项且 `gate_owner=false`（T0 档），`criteria_owner` 反向完备，`tools/<名>.py` 存在（S5 缺省承载）。∎

### T3 覆盖完备性

**断言**：𝔇 中每个缺陷类型至少归属一个节点或豁免；且判定形态三分类穷尽。
**证明**：CY/T 266 全部 29 类映射非空：机检承载 23、人审承载 4（1-1 错字、1-2 多漏字、1-3 颠倒字归 s1；1-9 倾向性归 r1/r2）、豁免 2（2-4 曲谱、3-2 转行），23+4+2=29，缺口 0；MQM 七维全部映射非空（7/7）。六类需求对应判据 73 条（q1=10、q2=12、q3=19、q4=12、q5=10、q6=20）。
**凭证**：`results/verification.json` §B_coverage。∎

### T4 一致性（互斥性与可解释交）

**断言**：六类对象域（D7）两两不交，或其交有预登记分工且处置互补；实证上，多器同位置命中 100% 落入预登记分工对。
**证明**：对象域按内容划分（引文 span 与正文 span 互斥由 protect 豁免保证；命题、语域、量值、标点分属不同分析单位）。实证：金样本 3 件多器同位置 38 处，其中 q3×q6=24、q3×q5=9、q5×q6=8、q3×q4=1，全部命中预登记分工（M-6/P-13、G 层/M-2、G/R 层、引文豁免），待复核 0。分工语义：q5 判“数值范围该用哪种连接号”，q6 判“连接号写法对不对”——同位置、不同问题，处置不冲突（P31）。
**凭证**：`results/verification.json` §C_consistency。∎

### T5 引文守恒（检测完备性）

**断言**：若各工序遵守豁免（引文 span 不改写），则 hash 守恒保持；若违反，q1 的 `--check-hash` 在 q2–q6 各出口必然检出。
**证明**：
(i) 工具层：六器的分析面均排除引文 span——`axis_lib.prose_lines`／`prose_blocks` 跳过引块行（`>`），`protect` 掩码不改变字符位置，q6 的引号配对检查对引文内部原文标点豁免（判据表 §4）。
(ii) 归纳：H₀ 由 q1 登记；设 Iᵢ 成立，qᵢ₊₁ 的机检写回路径不含引文 span（(i)），故 Hᵢ₊₁=Hᵢ。
(iii) 检测：C-7 门禁在每出口比对 hash 集，不守恒即硬失败——**保证的是“必被检出”，不是“必不发生”**；违反豁免的人工改动由 H-1（追责）与 C-7（检测）共同承担。
(iv) 幂等：同文档两次扫描 hash 集相等（金样本 3/3）。
**凭证**：`results/verification.json` §C_consistency.idempotent。∎

### L1 终止性（q 链无死循环）

**断言**：q 链推进在有限步内到达 s3。
**证明**：状态数有限（|S|=19），`advance` 要求单调前进（expected_prev 唯一前驱、禁跳步）；唯一回退原语 `revert-state` 目标态为 s2.4/s2.5，且 P32 限定同一轮 q 链重入上限 1。∎

### T6 顺序必要性的反例（五条依赖不可换位）

| 换位 | 反例 |
| ---- | ---- |
| q1 后置 | 语法工序润色引文内标点（如把引文内的英文引号改弯引号），破坏 C-7 hash，且无法区分译者改动与引文原貌——引文锁定的目的即先冻结该风险面 |
| q2 后置 | 语法改写（拆句、被动改主动）先发生，命题数与论元角色的比对基准被改变，L-1 无法判定漂移来自原文还是来自语法工序 |
| q4 先于 q3 | 对成分残缺句（G-1）判语域档位无意义；ISO 5060 明确 Style 以语法可接受为前提 |
| q6 先于 q5 | 先把“100–150 kg”的连接号定为“～”，计量工序若改换单位（“100～150 kg”→“100～150 千克”）会再次触发标点复核，产生返工 |
| 标点留在 S3 | S3 与 q6 双判标点，违反 S-2（判据唯一），回到“一节点多对象” |

### T7 完备性边界

**断言**：T3 的完备性只对可判域成立；语义域的“实质正确”不在本证明范围内。
**证明**：H-5 给出机检上限的实证依据（FCGEC）；q2 的 `unformalized` 通道、q4 的五档标尺、q3 第一层的处置留痕，均为“不可判项的登记形态”而非自动判定。假设组 H 显式列出全部不可判前提。∎

## 4 一致性计算结果（实证）

| 指标 | 金样本 3 件 | a 字头 161 件 |
| ---- | ---- | ---- |
| 六器条目（实测） | 引文 208、散句 1534、语法 240、语域 8、计量 68、标点 69 | 见 `results/verification-a.json` |
| 多器同位置（行级） | 38（预期互补 38，待复核 0） | 657（预期互补 657，待复核 0） |
| 分工对分布 | q3×q6=24、q3×q5=9、q5×q6=8、q3×q4=1 | q3×q6=435、q5×q6=208、q3×q5=179、q3×q4=18、q4×q6=17、q4×q5=10 |
| 幂等（7 指标×件数） | 21/21 | 1127/1127 |
| 结构违例 | 0 | 0（A 组与样本无关） |

**粒度声明**：交分析以行为单位；“多器同行”是常态（161 件共 657 处），预登记分工的原则是**同句不同 span、不同判据**——R 层只判语域档位（无 span），q5 的单位符号 span 与 q6 的标点 span 不交，q3 的语法 span 与 q6 的标点 span 不交。**span 级双判为零**，因为六器规则性质两两不重叠；行级共现全部落预登记分工对（P31）。新增规则须先补 `EXPECTED_PAIRS` 登记，否则验证器以待复核报告。

## 5 结论

1. **结构性质**（T1、T2、L1）：已由可计算谓词完全验证，违例 0。
2. **覆盖完备性**（T3）：CY/T 266 29/29、MQM 7/7、判据 73 条，缺口 0；机检缺口（错字、多漏字、颠倒字）显式登记为人审承载，不是遗漏。
3. **一致性**（T4）：判据交 100% 可解释，处置互补，无双计（P31）。
4. **守恒**（T5）：工具层不触碰引文，门禁层必检出违反；“绝不发生”不由机检承诺，由追责与检测组合承担。
5. **不可判域**（T7）：由假设 H-1…H-5 显式登记，交由人审与后续战役；本文件不为它们伪造证明。
