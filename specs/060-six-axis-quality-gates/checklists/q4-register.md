# q4 语域判据表（register_audit）

> 工序：`q4_register_checked`，位次在 `q3_grammar_checked` 之后、`q5_measure_checked` 之前。
> 对象：译文的语域档位与语气（不含引文、典籍原文、参考文献照录条目）。
> 裁判：人审；机检只做候选词表告警，不作裁判（承 ADR-0033 口径）。
> 依据：ISO 5060:2024 Style 维度（Language register、Organization style、Third-party style、Inconsistent style；明确定义为“语法可接受但不合规范”）；rules/02 语体与文风；rules/02 AI 腔与套话。

## 1 五档标尺

| 档 | 名称 | 适用对象 | 判例 |
| ---- | ---- | ---- | ---- |
| R-1 | 学术书面语 | 正文主节、导言、论证段 | “这一论证预设了……” |
| R-2 | 学术书面语（说明性） | 举例、术语解释、译注背景 | “例如，当一个人承诺……” |
| R-3 | 中性书面语 | 图注、表注、表格说明 | “图 1：三种模型的对照” |
| R-4 | 口语 | 仅引文内对白、书信引文 | “他说：‘我不知道。’” |
| R-5 | 文言／仿古 | 仅典籍引文、碑铭 | “子曰：‘学而时习之。’” |

**硬规则**：译文自述部分（标题、正文、译注说明、脚注说明）只允许 R-1／R-2／R-3；R-4／R-5 只出现在引文与豁免内容内。

## 2 判据

| 编号 | 判据 | 判定形态 | 级别 | 处置 |
| ---- | ---- | ---- | ---- | ---- |
| R-a | 主体档位判定：逐节判定档位并记录；全文主档必须为 R-1（导言与说明段可 R-2） | 人审 | Critical | 档位缺失即 fail |
| R-b | 档位漂移：同一节内不得从 R-1 跳到 R-4／R-5；出现口语、俚语、网络语即漂移 | 人审＋口语词表告警 | Major | 回源重译该句 |
| R-c | 语气一致：陈述、让步、转折、反讽、调侃按源保留；不得拔高为官样文章，不得抹平反讽 | 人审（逐节） | Major | 回 en 核对后重译 |
| R-d | 文言残留：句末“矣／焉／哉／耳／乎／耶”、“……者，……也”、文言代词（吾／吾人／彼／厥）、文言连词（然则／何则／是以／若夫／至若／盖）、四字骈句堆叠 | 人审（语义判断；候选词表只作提示） | Critical | 不合规即置空重译（ADR-0033） |
| R-e | 口语与方言残留：方言词、网络流行语、俚语、语气词滥用（“嘛”“呗”“搞”“弄”） | 人审＋词表告警 | Major | 改写 |
| R-f | 称谓与敬谦：第二人称用“你”不用“您”；同一对象通篇同称，不在一句内切换“父亲／约翰／史密斯” | 人审 | Minor | 统一称谓 |
| R-g | 样章基准：与 `baseline/register-baseline.md` 的 3–5 段样章比对，判“同一本书”而非“好文笔” | 人审 | Major | 偏离须说明理由 |

## 3 与语法工序的边界（防重叠）

| 现象 | 归属 | 理由 |
| ---- | ---- | ---- |
| “进行地很顺利”（的／地误用） | q3 G-6 | 无可争议的语法错 |
| “这事儿挺有意思”（口语） | q4 R-e | 语法合法，语域不当 |
| “该论证颇具说服力”（文言化） | q4 R-d | 语法合法，语域不当 |
| “由于……导致……”（主语残缺） | q3 G-1 | 语法错 |
| “值得注意的是……”（增译套话） | s1＋q4 R-c | 先按增译删（s1 准确性），再判语域 |
| “作为哲学家，他认为……” | q3 G-16 | 反欧化条款，语法层 |
| “哲学家用一种深刻的方式……”（空洞拔高） | q4 R-c | 语域与文风 |

## 4 凭据与验收

* 凭据：`register-report.md`，含：逐节档位表、漂移点清单、文言／口语处置、样章比对结论、reviewer 签字。
* 全文一句结论必须含：主档判定、是否存在 R-4／R-5 越界、是否存在 AI 腔套话、样章比对是否通过。
* 验收：R-a 必须有结论；R-d 命中零容忍（引文外）；R-b／R-c／R-e／R-f 逐条处置或豁免留痕。
* 不得以 r1“通读签语体结论”替代：r1 判受众适切性（Verity），q4 判语域合规（Register），二者维度不同（ISO 5060）。

## 5 样章基准机制

1. `baseline/register-baseline.md` 由用户裁定 3–5 段（建议：一件分析哲学、一件哲学史、一件逻辑条目），每段附“为什么是标尺”的一句话。
2. 样章只作比对基准，不得作为改写模板（禁止套用句式，防机械同质化）。
3. 样章变更走 ADR，变更后已 done 件不自动回炉，仅在下次回炉时按新基准判。
