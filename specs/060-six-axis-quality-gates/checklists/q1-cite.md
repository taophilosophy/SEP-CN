# q1 引文锁定判据表（cite_audit）

> 工序：`q1_cite_checked`，位次在 `s2.5_checked` 之后、`q2_logic_checked` 之前。
> 对象：译文中**带引号的直引**（引块、行内引号、脚注引文）。间接转述无引号者不属本工序。
> 裁判：人审唯一裁决；机检做完备性、字段完整性、守恒与形态核对。
> 依据：ISO 690:2021（引文数据保持原始语言与文字系统、关联信息 `[translit.: …]`／`[trans.: …]`、转写系统按 ISO 24229 登记）、GB/T 7714-2025 5.1（按信息资源本身语种著录）、ADR-0011、rules/07、SEP《Guidelines and Policies for Entry Content》引用条款。

## 0 事实基线（2026-11-25 全量扫描，`bin/nonlatin_scan.py`）

| 项 | 实测 |
| ---- | ---- |
| `yuanwen` 文件 | 2417 |
| 成句引文片段（≥40 字符且 ≥6 词） | 34458 |
| 其中确定非英文 | 315（0.91%）：拉丁 161、德 80、希腊 34、法 20、汉语 17、意 2、西 1 |
| 非英文小语种片段（变音符术语、阿拉伯／梵／藏转写） | 约 700，人工复核后多数为术语级 |
| 上游明示“my translation”“trans.” | 全库 5 处 |

**结论一：SEP 作者的引文绝大多数是英文转述或英译。**“实际语言原文”在多数情况下并不存在于上游，它不是照录字段，而是中译本对上游的**增补义务**。

**结论二：对英文直引，“作者理解的英文翻译”就是那段英文本身**，不需要我们再造一个英文。真正需要判断的是：这段英文背后是否有非英文原著，原文能否确定版本。

**结论三：上游引用规范与执行有落差。** SEP 指引要求引文可核对、译文须注明来源，实际标注率不足 1%。不能把“上游没标”当作“无需处理”。

## 1 对象与边界

| 类别 | 判据 | 归属 |
| ---- | ---- | ---- |
| A 英文直引（主，约 99%） | 引号内的英文句子或短语，来自英文原著、已刊英译或作者自译 | q1（本工序） |
| B 非英文直引（约 0.9%，300–600 条） | 引号内的希腊、拉丁、德、法、意、西、阿、梵、巴利、藏、汉、日文 | q1 |
| C 术语级片段（约 1.27 万） | 单个或几个词的外语术语、人名、书名转写，多斜体或括注 | 术语轴 s2.4，不入本清单 |
| D 间接转述 | 无引号，作者用自己的英文概括他人观点 | s1 准确性，不入本清单 |
| E 书目条目内的非英文书名 | 参考文献节 | s1＋`check_academic`，不入本清单 |

**边界规则**：判断“直引 vs 转述”以引号为唯一形式标志；上游用 *that* 从句、无引号者一律按转述处理，不得提高为直引。上游把原文放在 `<em>` 而无引号者，按术语级处理。

## 2 主模型：英文直引怎么处理

三步，全部可机检或结构化留痕：

1. **判原著语种**（`origin_lang`）：查书目条目与引文内容。英文原著记 `en`；原著为外文而引文是英译记该语种；无法判定记 `unknown`。
2. **判原文可得性**（`original_status`）：
   * `na`：英文原著，无需原文；
   * `present`：上游已同时给出原文（少数）；
   * `verifiable`：原著语种已定、通行版本可查（古典文本有 Bekker／Stephanus／DK 编号，现代著作有定本），**应当**给出原文；
   * `unavailable`：原著语种或版本无法确定，或原文无法可靠取得。
3. **处置**：
   * `na` → 中译据英文，完成；
   * `present` → 核对原文与英译对应关系，完成；
   * `verifiable` → 加原文（脚注或括注，见 §6），完成；
   * `unavailable` → 保留英文，**不造原文**，译注或脚注说明“原文未能取得，据作者英译转译”。

**不得做**：为凑“原文呈现”而凭记忆补外文、用模型生成原文、把通行英译冒充作者自译。这三条按 C-4b 判 Critical。

## 3 少数模型：非英文直引怎么处理

仅当 `origin_lang≠en` 且引文本身即外文时适用。

| 情形 | 要求 |
| ---- | ---- |
| 上游已给原文＋英译 | 照录两者，核对对应；`original_status=present`、`english_source=sep-inline` |
| 上游只给原文，无英译 | 须补英文；通道见下；原文照录 |
| 上游只给英译，无原文 | 须补原文（`verifiable`）或标 `unavailable`；英文照录并注 `english_source=sep-inline` |

补英文的三通道（**只有此情形才需要**）：

| 通道 | 取值 | 取得 | 证据 |
| ---- | ---- | ---- | ---- |
| 一 | `sep-paraphrase` | 作者紧随引文的英文阐释句即其理解 | 逐字摘录，anchor 指向该句 |
| 二 | `published` | 通行英译本 | 查证到实书：书名、译者、版次、页码 |
| 三 | `editorial` | 本库转译 | 必标 `to_verify`，译注声明“非作者理解”，禁用作者口吻 |

`editorial` 是末位兜底，且只对少数模型开放；英文直引不得使用本通道。

## 4 清单模型（cite-manifest.json）

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| `id` | string | `c-<slug>-<序号>`，全篇连续 |
| `loc` | string | `§2.B16` 或 `note-<key>` |
| `form` | enum | `block`／`inline`／`note` |
| `quote_lang` | string | 引文本身语种，BCP 47（多数为 `en`） |
| `origin_lang` | string | 原著语种：`en`、`grc`、`la`、`de`、`fr`、`ar`、`sa`、`bo`、`ja`、`zh`、`unknown` |
| `original` | string | 原文；`na`／`unavailable` 时填 `—` |
| `original_status` | enum | `na`／`present`／`verifiable`／`unavailable` |
| `english` | string | 英文；英文直引即引文本身，非英文引文填补入的英文 |
| `english_source` | enum | `self`（作者英文即引文）／`sep-inline`／`sep-paraphrase`／`published`／`editorial`／`—` |
| `register_system` | string | `iso-843`／`iso-233`／`iso-9`／`iso-3602`／`iast`／`wylie`／`pinyin-gbt16159`／`—` |
| `anchor` | string | `en/<slug>/index.html#<节>`、`[^key]`、书目键 |
| `hash` | string | 引文原文的 SHA-256 前 16 位 |
| `verdict` | enum | `pass`／`fail`／`waived` |
| `reviewer` | string | 裁判标识；不得等于 draft actor |

## 5 判据

| 编号 | 判据 | 判定形态 | 级别 |
| ---- | ---- | ---- | ---- |
| C-1 | 清单完备：每处直引有且仅有一条记录；清单条数与文中直引标记数一致；间接转述不得混入 | 机检（引号抽取＋计数）＋人审 | Critical |
| C-2 | 字段完整：十二字段齐全，枚举取值合法；`origin_lang=unknown` 须在处置栏说明 | 机检 | Critical |
| C-3 | 原文呈现：`original_status=verifiable` 者须给出原文；`unavailable` 者须有说明；`na` 者不要求 | 机检（字段）＋人审（`verifiable` 判得对不对） | Critical |
| C-4 | 英文呈现：英文直引不另造英文；非英文直引须有英文，`english_source` 按 §3 取值，`editorial` 须 `to_verify` | 机检＋人审 | Critical |
| C-4b | 禁止冒充与代造：不得凭记忆补原文、不得用模型生成原文或英文而不标注、不得把通行译本标成作者自译或作者阐释 | 人审（`editorial`／`sep-paraphrase` 全量复核） | Critical（一票否决） |
| C-4c | 术语级片段：只要求首次出现括注原文与通行英译，同一术语全篇同形 | 机检（首现定位）＋人审 | Minor |
| C-5 | 转写规范：非拉丁文字按登记系统转写，`register_system` 与所用系统一致，不得混用两套 | 机检（字符域＋白名单） | Major |
| C-6 | 出处可回溯：anchor 指向的 en 源位置或书目键存在；页码、年份不得凭记忆补全 | 机检＋人审 | Critical |
| C-7 | 引文守恒：`hash` 在 q2–q6 各出口核对不得变动；引文内部文字与标点不得被后续工序改动 | 机检 | Critical（硬失败） |
| C-8 | 中文／日文原典：中国典籍用通行中文原文与篇码（《论语》2.3）；日文引文用日文原文；不以英译回译 | 人审 | Major |

## 6 承载分档

| 档 | 判据 | 承载 |
| ---- | ---- | ---- |
| A 短语级 | 原文 ≤25 字 | 正文中文＋括注引文（原文或英文）＋必要时方括号另一层 |
| B 整句级 | 1–3 句 | 引块＝引文（英文直引即英文）；英文直引的中文译文另起一段；非英文引文在块末方括号补英文 |
| C 长段级 | >3 句 | 引块＝引文；中文译述在正文；原文或英译入紧邻脚注 |

规范形：英译与补入原文统一用方括号 `[…]`；圆括号留给语法插注与中文行文（与 ISO 690:2021 关联信息写法一致）。`verifiable` 的原文入脚注，正文不叠三层。

## 7 语种与转写

| 语言 | 标签 | 转写 | 备注 |
| ---- | ---- | ---- | ---- |
| 古希腊语 | `grc` | `iso-843` 或学界惯用拉丁转写，全篇统一 | 与 `el` 区分 |
| 拉丁语 | `la` | 原文照录，不转写 | 保留 macron |
| 德语／法语／意大利语／西班牙语 | `de`／`fr`／`it`／`es` | 原文照录 | 保留变音符 |
| 阿拉伯语／波斯语 | `ar`／`fa` | `iso-233`（波斯语变体须注明） | 佛学与伊斯兰哲学高频 |
| 梵语／巴利语 | `sa`／`pi` | `iast` | 与藏语区分 |
| 藏语 | `bo` | `wylie` | — |
| 日语 | `ja` | `iso-3602` 或 Hepburn，二者择一 | 假名原文优先 |
| 汉语 | `zh` | 典籍用汉字原文，不转写；拼音按 GB/T 16159，人名按 GB/T 28039 | — |

## 8 批次与成本

批次不按字头，按原著语种与版本可得性：

| 批 | 对象 | 主要工作 | 量级 |
| ---- | ---- | ---- | ---- |
| B0 | 英文直引中的 `origin_lang` 判定 | 判语种、定 `original_status`，多数为 `na`／`unavailable` | 全库，机检＋抽样人审 |
| B1 | 希腊、拉丁、德、法 | `verifiable` 原文补齐（Bekker／Stephanus／DK／Akademie 页码） | 约 250 条 |
| B2 | 阿拉伯、梵、巴利、藏 | 转写＋原文＋少数英文补入 | 约 100 条，`unavailable` 比例高 |
| B3 | 汉语、日语 | 典籍还原、日文原文 | 约 40 条 |

成本：B0 以机检为主，人审抽样；B1–B3 逐条查证 40–60 分钟，合计约 200–400 人时。**主成本不在“补英文”，而在“判原著语种与定版本”**。

质量指标：`verifiable` 但未给原文的比例应为 0；`unavailable` 单件超过 50% 须复核是否漏查；`editorial` 全库应趋近 0（只对少数模型开放）。

## 9 豁免与误报

| 情形 | 处理 |
| ---- | ---- |
| 英文引文内夹外语词（*das Man*） | 随英文条登记，`quote_lang=en`、`origin_lang` 按原著 |
| 书名、术语斜体（*dharma*、al-Rāzī） | 术语级，C-4c |
| 参考文献照录条目 | 不入清单 |
| 数学公式中的希腊字母 | 不属引文 |
| 章节标题、图表题注中的引号 | 不入清单（非引文） |
| 译注中引述他人译法 | 入清单，`form=inline`，注明出处 |
