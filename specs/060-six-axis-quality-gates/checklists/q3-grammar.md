# q3 语法判据表（grammar_audit）

> 工序：`q3_grammar_checked`，位次在 `q2_logic_checked` 之后、`q4_register_checked` 之前。
> 对象：译文每个句子（不含引文内部、代码、公式、参考文献照录条目）。
> 裁判：人审；机检只做启发式初筛与模式告警。
> 依据：CY/T 266-2023 表 1 第 1-11 类（语法性差错，每处计 2 个差错）；rules/02 反欧化条款；FCGEC 错误类型体系（Incorrect Word Collocation、Component Missing、Component Redundancy、Structure Confusion、Incorrect Word Order、Illogical、Ambiguity）；吕叔湘、朱德熙《语法修辞讲话》“羡余非赘余”判例；《实用现代汉语语法》分句主语隐现判例。

## 1 三层结构

| 层 | 内容 | 机检能力 | 门禁档 |
| ---- | ---- | ---- | ---- |
| 第一层 句法合法性 G-1…G-8 | 成分、搭配、语序、杂糅、虚词、关联词、指代形式 | 弱（启发式告警） | T2 起硬拦三型，其余人审 |
| 第二层 反欧化 G-9…G-16 | 被动、弱动词、定语链、名词化、时态词、连词、类名“们”、直译框架 | 强（模式＋阈值） | 告警逐条判定，T2 升硬 |
| 第三层 和制汉语 G-17…G-19 | 定型／未定型二分 | 词表核对 | 告警，处置须登记 |

## 2 第一层：句法合法性

| 编号 | 判据 | 典型形态 | 判定形态 | 级别 |
| ---- | ---- | ---- | ---- | ---- |
| G-1 | 成分残缺：主语、谓语、宾语缺失；介词框架不完整（“由于……导致……”造成主语残缺） | “由于甲乙两国战火不断，导致两国民众积怨已久” | 启发式（介词开头＋“导致/使”＋无主语）＋人审 | Critical |
| G-2 | 成分赘余：同义反复、结构冗余（“原因是……造成的”“大约……左右”） | “原因是因为”“首先……第一” | 模式＋人审 | Major |
| G-3 | 搭配不当：动宾、主谓、定中、状中不搭 | “提高了……水平”可，“提高了……质量”须看语境 | 人审 | Critical |
| G-4 | 语序不当：多层定语顺序、状语位置、否定词位置 | “一件他买的旧大衣”语序 | 人审 | Major |
| G-5 | 句式杂糅：两种句式拼在一句 | “本着……为原则”“对于……问题上” | 模式＋人审 | Critical |
| G-6 | 虚词误用：的／地／得、把／被／对／对于、因为／由于 | “进行地很顺利”“对于这个问题上” | 模式＋人审 | Major |
| G-7 | 关联词错配：不但…而且／虽然…但是／只有…才／除非…否则 | “不但……反而”“只有……就” | 机检配对表＋人审 | Major |
| G-8 | 指代形式不合法：代词与先行词数、性、人称不一致；“其”悬空 | “它们”指单数概念 | 人审 | Major |

## 3 第二层：反欧化

| 编号 | 判据 | 阈值／判例 | 判定形态 | 级别 |
| ---- | ---- | ---- | ---- | ---- |
| G-9 | “被”字句滥用与语义方向：非必要不用“被”；“被”用于受害、不如意事；单句 ≥2 个“被”须复核 | “被选为部长”→“当选部长”；“被发现”→“见于” | `check_prose` passive-bei | Major |
| G-10 | 弱动词：“进行／作出／加以／予以＋抽象名词”恢复动词本力 | “作出决定”→“决定” | `check_prose` weak-verb | Major |
| G-11 | 定语链：“的”三连或单句 ≥6 个“的”须重排 | “我们对他人的证言的信任”→“我们对他人证言的信任” | `check_prose` de-chain | Major |
| G-12 | 名词化与物称主语：改回人作主语、动词作谓 | “女朋友的失踪让他感到焦急”→“女朋友失踪了，他很着急” | 人审（可加词表候选） | Major |
| G-13 | 时态词冗余：“曾于／已于”非必要不出现 | “曾于 1916 年任校长，并已于 1927 年辞职”→“1916 年任校长，1927 年辞职” | `check_prose` tense-adverb | Minor |
| G-14 | 并列连词接动词／形容词／小句：改“并／且／或”或顿号；“和”只连名词性成分 | “帮助和支持”→“帮助并支持” | `check_prose` conj-he-verb | Major |
| G-15 | 类名“们”：作者们、科学家们→论者、学界，或径去“们” | 人称代词不受限 | `check_prose` plural-men | Minor |
| G-16 | 直译框架：“作为……”“当……的时候”“如果……那么”能简则简 | “作为一个哲学家”→“作为哲学家” | `check_prose` as-one／dang-shihou | Minor |

## 4 第三层：和制汉语甄别（用户 2026-11-25 裁定：只禁未定型者）

| 编号 | 判据 | 处置 | 级别 |
| ---- | ---- | ---- | ---- |
| G-17 | 已定型日源词：《现代汉语词典》第 7 版收录者（哲学、美学、逻辑、实体、主观、客观、感性、理性、范畴、命题等）照常使用，不判错 | 无 | — |
| G-18 | 未定型日源生造词：词典未收、学界未定、以词害意者禁用；回源重选，登记 `shu-yu-biao.md` 并留查证凭证 | 改写＋登记 | Major |
| G-19 | 日源词误用：定型词被用在错误义项上（以词害意的具体个案） | 逐词裁定，入判例表 | Major |

工具依赖：`baseline/ja-loanwords.json` 三分类（`定形`／`未定形`／`禁用候选`），每词记：词形、来源学科、最早书证、词典收录状态、裁定日期、裁定人。词表变更走 ADR，不得由单会话就地增删。

## 5 不得判错的情形（防误判清单，必须写进工具白名单）

| 情形 | 依据 |
| ---- | ---- |
| 分句主语隐现：后分句主语承前分句主语的领属性定语而省略 | 《实用现代汉语语法》分句主语隐现；例“陈局的手臂曾经骨折过……所以对我的伤感同身受”不判缺主语 |
| 羡余而非赘余：“彻底根治”“亲眼目睹”“凯旋归来”“免费赠送”“除夕之夜” | 吕叔湘、朱德熙《语法修辞讲话》；习惯语可接受 |
| “正如……一样” | 《辞海》第 7 版有同类用法，不判赘余 |
| 文言词在引文、典籍、碑铭内 | rules/02 豁免条款 |
| 成语主语相容的历史用法 | rules/02 判例（“付之阙如”） |
| 术语性词汇内部的“的”“被”（目的论、被动） | `check_prose` 现有豁免 |

## 6 凭据与验收

* 凭据：`grammar-report.json`，逐句一条：`id`、`loc`、`rule`、`span`、`severity`、`verdict`（`fixed`／`waived`／`false-positive`）、`reviewer`、`evidence`（修改前后 diff 或豁免理由）。
* 验收：G-1／G-5／G-7 三型机检命中须 100% 处置（修复或豁免留痕）；G-9…G-16 告警逐条判定；G-17…G-19 词表命中逐条裁定。
* 语体结论不得替代本工序：s2 的“语体：现代汉语学术书面语”只证明留痕，不证明语法合格。
