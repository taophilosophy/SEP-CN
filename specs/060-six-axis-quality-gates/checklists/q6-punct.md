# q6 标点判据表（punct_audit）

> 工序：`q6_punct_checked`，位次在 `q5_measure_checked` 之后、`s3_checked` 之前。
> 对象：正文全部标点（不含代码、公式、URL、参考文献照录条目、引文内部原文标点）。
> 裁判：人审；机检覆盖形态、配对、方向、位置、邻接，语义类只出告警。
> 依据：GB/T 15834-2011（现行；2016-12-31 复审“继续有效”；新计划 20240034-T-360 暂缓）；CY/T 154-2017（中西文间空格，偏离登记 ADR-0041）；CY/T 266-2023 表 2 第 2-1 类（标点差错 0.1/处）；rules/02。
> 条款号说明：下列 4.x 编号按 GB/T 15834-2011 第 4 章通行编排；落地前须以标准正文逐条核对，核对结果记入 `tools/data/punct-rules.json` 的 `clause` 字段。

## 1 判据（按十七种标点逐种）

| 编号 | 标点 | 判据 | 机检 | 级别 |
| ---- | ---- | ---- | ---- | ---- |
| P-1 | 句号（4.1） | 陈述句末用“。”；不用句号的情形（标题、表格短句、图注）不得乱加；句号不得与问号、叹号叠用 | 可 | Minor |
| P-2 | 问号（4.2） | 疑问句、反问句、设问句末用“？”；选择问句中问号置于句末；有疑问词但非疑问句（“我不知道他去哪儿。”）不用问号；连续问可各自用问号 | 告警（语义判断） | Major |
| P-3 | 叹号（4.3） | 感叹句、呼语、拟声词后用“！”；叠用不超过三个；学术正文慎用 | 告警 | Minor |
| P-4 | 逗号（4.4） | 主语较长或需强调时主谓间可用逗号；状语在句首时其后用逗号；并列词语间用顿号不用逗号（除非并列成分较长）；复句分句间用逗号 | 可（部分） | Minor |
| P-5 | 顿号（4.5） | 并列词语间用“、”；**概数不用顿号**（“三四个”不写“三、四个”）；**并列引号、并列书名号之间通常不用顿号**，但之间有其他成分（括注、连词）时宜用顿号 | 可（概数、引号书名号邻接） | Major |
| P-6 | 分号（4.6） | 并列复句的分句间用“；”；非并列多重复句第一层用“；”；分号不得与逗号层级混乱 | 告警 | Minor |
| P-7 | 冒号（4.7） | 提示下文、总结上文用“：”；一个句子里不得套用两个冒号；冒号后不用“即”“就是”等重复提示 | 可（套用计数） | Major |
| P-8 | 引号（4.8） | 弯引号“ ”‘ ’；外层双、内层单；引文独立成句时句末标点在引号内，不独立时在引号外；引号内不得再用同形引号；禁直引号、直角引号、日式半角引号 | 可（全面） | Critical |
| P-9 | 括号（4.9） | 圆括号用于注释、补充；方括号用于校勘、增补、外文注；六角括号用于公文年份；括号层级外圆内方；括号内句末标点按独立性处理；括号套用不超过两层 | 可（配对、方向、层级） | Major |
| P-10 | 破折号（4.10） | “——”两字位（U+2014 两个）；承担插入、转折、解释；不得替代冒号、括号、分句；不得与“即”“也就是”重复 | 可（形态）＋人审（功能） | Major |
| P-11 | 省略号（4.11） | 六连点“……”（U+2026 两个）；不与“等等”“之类”并用；引文省略用“[……]”与原文自带“……”区分（CY/T 122 §7）；引文前不用省略号 | 可 | Major |
| P-12 | 着重号（4.12） | 本库以加粗替代着重号（偏离登记 ADR-0041）；加粗语法须有效（星号内侧禁空格） | 可 | Minor |
| P-13 | 连接号（4.13） | 三形分工：短横线“-”用于复合名词、型号、年月日简写；一字线“—”用于时间地域起止；浪纹线“～”用于数值范围；混用即违例；豁免参考文献照录、代码、URL、公式、直接引文 | 可 | Major |
| P-14 | 间隔号（4.14） | 外国人名姓与名之间（让-雅克·卢梭的“·”）、书名与篇名之间、月份与日期简称之间（“一·二八”）用“·”；不得与小数点混用 | 可 | Major |
| P-15 | 书名号（4.15） | 书名、篇名、报刊名、文件名用“《》”；书名号内再用书名号时用单书名号“〈〉”；书名号内中英混排加半角空格（《C 程序设计语言》） | 可 | Major |
| P-16 | 专名号（4.16） | 本库不用专名号（偏离登记 ADR-0041）；出现即报 | 可 | Minor |
| P-17 | 分隔号（4.17） | 诗行分隔、标题层级分隔用“/”；不得与斜杠混用于普通并列 | 可 | Minor |
| P-18 | 标点邻接空格 | 引号、括号与汉字之间不加空格；与西文、数字之间保留半角空格（CY/T 154-2017 偏离项，ADR-0041）；标点前后不得有多余空格 | 可 | Major |
| P-19 | 行首行末禁则 | 点号（，。、；：？！）不出现在行首；前引号、前括号不出现在行末；后引号、后括号不出现在行首 | 渲染层检查（`check_render_artifacts` 扩展） | Minor |
| P-20 | 半角与全角 | 正文标点一律全角；代码、行内代码、公式、URL 内保持原样；不得混用全角空格 | 可 | Major |

## 2 机检规则形态（工具实现提示）

`tools/data/punct-rules.json` 每条：

```json
{"id":"P-5","clause":"GB/T 15834-2011 4.5","kind":"span","regex":"…","exempt":["quote-adjacent","bibliography"],"level":"major"}
```

四类规则：

1. `char`：字符域与形态（P-8、P-11、P-13、P-14、P-20）。
2. `pair`：配对与方向（P-8、P-9、P-15），复用 `check_pairs` 的配对引擎，但所有权归本工序。
3. `context`：上下文邻接（P-5 概数、P-7 冒号套用、P-18 空格）。
4. `semantic`：只出告警（P-2 反问、P-4 并列该用顿号否、P-10 破折号功能、P-6 分号层级）。

## 3 与既有检查器的所有权迁移

| 旧规则 | 旧归属 | 新归属 | 迁移方式 |
| ---- | ---- | ---- | ---- |
| `curly-quotes` | `check_style` | P-8 | 规则体迁入，`check_style` 删除 |
| `quote-spacing` | `check_style` | P-18 | 同上 |
| 直角引号总检 | `check_quotes` | P-8 | 全库总检并入，`check_quotes` 退役或转为 q6 的薄壳 |
| `bracket-pair` | `check_pairs` | P-9 | 配对引擎复用，判据所有权转 q6 |
| `ellipsis-form` | `check_pairs` | P-11 | 同上 |
| `connector-form` | `check_style --connector-scan` | P-13 | 形态归 q6，数值范围选择归 q5 M-6 |
| 公式内标点 | `check_math_zh` | 保留在 check_math_zh | 公式内部不适用 GB/T 15834，不迁 |

迁移后 `check_style` 只剩：`bold-spacing`、`cjk-spacing`、`no-html`、`no-text-fence`、`no-asciiart`、`italic-cjk`——即“非标点的排版形态”，与 q6 彻底分离。

## 4 豁免清单

| 内容 | 理由 |
| ---- | ---- |
| 围栏代码块、行内代码、URL | 技术内容原样 |
| 数学定界符内 | LaTeX 记号，不适用中文标点规则 |
| 参考文献照录的非中文条目 | 照录豁免（rules/02） |
| 引文内部原文标点 | 按原文语言规则；中文译文对引文的说明用中文标点 |
| 占位、桩件、带点补充材料子文档 | 与 s3 现有豁免一致 |

## 5 凭据与验收

* 凭据：`punct-report.json`（逐处：rule、clause、span、verdict、fix），＋按标点种类的命中与处置计数表。
* 验收：P-8／P-9／P-11／P-13／P-15／P-18／P-20 零硬错误；P-2／P-4／P-6／P-10 告警逐条判定或豁免；P-19 以渲染产物扫描为准。
* 计数口径：同一处问题只计一次；标点差错按 CY/T 266 表 2 第 2-1 类 0.1/处计，与 q5 的计量差错不重复计。
