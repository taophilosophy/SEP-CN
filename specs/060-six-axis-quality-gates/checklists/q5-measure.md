# q5 计量判据表（measure_audit）

> 工序：`q5_measure_checked`，位次在 `q4_register_checked` 之后、`q6_punct_checked` 之前。
> 对象：每个量值-单位对、数值范围、百分比、货币、日期时间、修约。
> 裁判：人审；机检做形态、空格、白名单与量纲核对。
> 依据：GB 3100-1993（国际单位制及其应用，现行，2021-11-30 复审结论“修订”）、GB/T 3101-1993（有关量、单位和符号的一般原则）、GB/T 3102 系列、ISO 80000-1:2022（7.1 量的符号斜体、7.2 数字与小数点、7.1.3 运算符两侧细空）、SI Brochure 第 9 版（2026-06 修订 4.01）、GB/T 15835-2011（4.1 计量、4.2 编号、4.3 概数、5.1.3 数值范围）、CY/T 266-2023 表 1 第 1-6 类（计量单位中文名称差错，每处 1 差错）与表 2 第 2-3 类（单位符号差错）。

## 0 清单模型（measure-manifest.json）

| 字段 | 说明 |
| ---- | ---- |
| `id` | `m-<slug>-<序号>` |
| `loc` | 节.段 |
| `src` | 源文原样（如 `5 km`、`25 °C`、`30 miles`） |
| `zh` | 译文原样 |
| `value` | 数值 |
| `unit` | 单位（规范符号，如 `km`、`°C`、`mile`） |
| `quantity` | 量（长度、温度、质量、时间……），用于同量一致性比对 |
| `canonical` | 规范形（如 `5 km`、`25 °C`） |
| `conversion` | 换算（如 `30 miles ≈ 48.3 km`），记公式与来源 |
| `verdict` | `pass`／`fixed`／`waived` |
| `reviewer` | 裁判标识 |

## 1 判据

| 编号 | 判据 | 判定形态 | 依据 | 级别 |
| ---- | ---- | ---- | ---- | ---- |
| M-1 | 单位符号合规：法定单位符号大小写正确（`km` 非 `KM`、`kg` 非 `KG`、`mL` 非 `ml`）、正体、不加复数 s、不加句点；`kg` 不加倍词头 | 机检（符号白名单＋正则） | GB 3100、ISO 80000-1 7.1 | Critical |
| M-2 | 数值与单位符号之间一个空格（`5 km`、`25 °C`）；例外：`°`、`′`、`″` 紧跟数值（`30°`）；`%` 紧跟数值（`25%`） | 机检 | ISO 80000-1 7.2、SI Brochure | Major |
| M-3 | 单位中文名称合规：科技语境用法定名称（米、千克、秒、开尔文、摩尔、安培、坎德拉）；“公里”为俗称，正式语境用“千米”；中文名称不混用符号（“5 千米”或“5 km”，不写“5 km 千米”） | 人审＋词表 | GB 3100／3101／3102、CY/T 266 表 1 第 1-6 类 | Critical |
| M-4 | 单位符号非规范形：`km.`、`m2`（应为 `m²`）、`sq m`、`摄氏度`与`°C`混排 | 机检 | GB 3100、ISO 80000-1 | Major |
| M-5 | 同量全文一致：同一量在同一文本内只用一种单位（英里／公里混用、摄氏／华氏混用须有换算或说明）；源内不一致须登记并按统一规则处理 | 人审＋清单分组 | rules/02 数字与计量、GB/T 19682-2005 5.3 | Major |
| M-6 | 数值范围连接号：用浪纹线“～”或一字线“—”，全文同形；前后单位相同时可省后一单位（`100～150 kg`）；省略会造成歧义则不得省略（`15%～30%` 不写 `15～30%`） | 机检（形态）＋人审（省略歧义） | GB/T 15835-2011 5.1.3 | Major |
| M-7 | 数字形态一致：计量、编号、现代生活事件用阿拉伯数字；概数、成语、非公历纪年用汉字；同场合同形（“今年的产值五亿多，比上年增加了 1.24 亿元”须统一为“5 亿多……1.24 亿元”） | 人审＋模式告警 | GB/T 15835-2011 4.1／4.2／4.3 | Major |
| M-8 | 修约一致：同一量的数值修约数位一致；修约规则符合 GB/T 8170（现行版本以标准现行性核对为准） | 人审 | CY/T 170 表身条款延伸 | Minor |
| M-9 | 换算可复核：源文英制或历史单位加公制括注者，换算值与公式可复核（`30 miles ≈ 48.3 km`，注明 1 mile = 1.609 344 km）；禁止凭记忆换算 | 人审 | GB/T 19682-2005 5.3、rules/07 禁幻觉 | Critical |
| M-10 | 货币与日期时间：货币符号与代码全文统一（`US$` 与 `USD` 择一）；日期时间按 GB/T 7408.1（等同 ISO 8601）或中文惯用形，全文统一 | 机检（形态）＋人审 | GB/T 7408.1、rules/README 标准清单 | Minor |

## 2 “照录源”与“格式一致”冲突的处理

现行 `rules/02:61` 为“单位与量值照录源（GB 3100 豁免）”，只能继承源内不一致。本工序改为：

1. **源内一致**：照录，manifest 记 `pass`。
2. **源内不一致**（同一量不同单位、同一单位不同写法）：在 manifest 标记 `src_inconsistent`，按“主形统一＋首次括注”处理，并在 q5 凭据登记。**不构成对 en 源的修改**（en 冻结，ADR-0062）。
3. **源用非 SI 单位**：照录并加公制括注（M-9）；是否一律加注按待裁事项 3 定。
4. **译文自产数字**（译注、图注、表注）：按 GB/T 15835 与 GB 3100 全套执行，不适用“照录源”豁免。

## 3 机检规则要点（工具实现提示）

* 单位白名单：`tools/data/units.json`，每条含符号、中文名、量、是否 SI、允许词头、正体/斜体。
* 数值-单位切分正则：`(-?\d+(?:[.,]\d+)?)\s*([°℃%‰]|[A-Za-zµμΩ°][A-Za-z0-9/·^²³⁻¹]*)`，注意排除 `5G`、`3D`、`COVID-19` 等非量值。
* 同量分组：按 `quantity` 字段聚合同篇条目，单位集合 >1 即出候选。
* 量纲表只做提示，不做换算裁判；换算须人审确认。

## 4 凭据与验收

* 凭据：`measure-manifest.json`＋一段汇总（各量单位集合、源内不一致清单、换算清单）。
* 验收：M-1／M-2／M-3／M-9 零硬错误；M-5 每篇单位集合 ≤1（有说明者除外）；M-6 全文同形。
* 与 q6 分工：M-6 判“该用哪种连接号”，q6 P-13 判“连接号写法对不对”；同一处问题只在一处计错，避免双重计分。
