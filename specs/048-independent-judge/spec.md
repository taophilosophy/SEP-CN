# 048 — 独立模型族辅助判官：GEMBA-MQM 落地（供人审，不替代）

**版本** v1.0 ｜ **状态** 方案（待实施）｜ **日期** 2026-11-18 ｜ **权威** 用户“全部批准”（ADR-0072 决策 3）｜ **承接** ADR-0070、ADR-0071 S01/S03、`开源翻译.md` §4

## 0. 方向声明

- **目标**：s3/r3 引入与翻译模型**不同族**的 LLM，按 MQM 输出错误清单（类型 + 严重度）供人审，提升人审靶向性。
- **非目标**：不替代人审（ADR-0070 硬约束）、不全库跑、不产译文、不自动改稿。

## 1. 两条硬边界（不可松）

1. **不替代人审**：判官输出是“错误清单”而非“终审结论”；人审覆盖 ADR-0070 盲区清单 9 条。
2. **异模型族**：评估模型与翻译模型必须不同族（自偏好偏差，GPT-4 仅抓到 42.5% 自身坏译）。

## 2. MQM 判据（GEMBA-MQM v2 口径）

| 严重度 | 权重 | 含义 |
|---|---|---|
| Critical | 25 | 阻断理解 |
| Major | 5 | 破坏流畅、意思可勉强恢复 |
| Minor | 1 | 别扭但可懂 |
| Punctuation | 0.1 | 标点（minor 子集） |

错误维度：Accuracy（增/漏/误译/未译）、Fluency（语法/拼写/语域/标点）、Style、Terminology、Non-translation。归一化 NPT = MQM×1000/源词数。单次判断噪声大，**多次独立判断聚合**。

## 3. 方案

1. 输入：源（en 文字）+ 译（中文）+ 术语册摘录。
2. 判官：与翻译模型不同族的 LLM，prompt 按 MQM 标注错误 span。
3. 聚合：同一译文多次判断，取一致错误。
4. 输出：错误清单（维度/严重度/位置/建议），交 s3/r3 人审消费。

## 4. 落点

- `specs/048-independent-judge/spec.md`（本文件）＋ `bin/judge.py`（待实施）。
- 测试词条（1–5）验证清单质量，确认后再议是否扩面（仍不全库翻译）。

## 5. 边界

- LLM 处理仅限测试词条（1–5），符合“不进行全量翻译”。
- 判官不写任何文件、不改稿，只产清单。
