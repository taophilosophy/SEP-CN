# Stanford Encyclopedia of Philosophy — English source text

This directory holds the English original of every entry in this project, one Markdown file per
entry, path-for-path parallel to the Chinese translation:

    <letter>/<slug>.md           Chinese translation
    yuanwen/<letter>/<slug>.md   English source text

Every file is a snapshot of an entry as published by the Stanford Encyclopedia of Philosophy; the
authoritative version is always the one currently online at <https://plato.stanford.edu/>.

* Upstream encyclopedia: <https://plato.stanford.edu/>
* Chinese edition (this project): <https://github.com/taophilosophy/SEP-CN>
* Entry list: `SUMMARY.md` in this directory mirrors the Chinese edition's table of contents.

Entry text remains the property of the Encyclopedia and of the individual authors. This mirror
exists for translation review and for reading side by side with the Chinese text; it is not a new
edition of the entries.
