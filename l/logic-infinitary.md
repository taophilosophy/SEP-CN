# 无穷逻辑 Infinitary Logic (John L. Bell)

*首次发表于 2000 年 1 月 23 日；2023 年 9 月 6 日实质修订。*

传统上，形式系统里的表达式被看作有穷的墨迹，原则上总能以原始记号实际写出来。但（一阶）公式可以经“哥德尔编码”与自然数、从而与有穷 **集合** 等同，于是不必再把公式当成墨迹，还可以设想构造某些“语言”，其中有些公式天然就是 **无穷集合**。这类“语言”叫 **无穷语言**：本文讨论的那些，可以直截了当地从一阶语言得到——只要允许合取、析取乃至量词序列有无限长。下文会看到，这类语言的表达力远超其有穷（一阶）对应物，但其中很少有谁具备后者的“诱人”特征（如紧致性、完全性）。因此，真正具备这些特征的无穷语言，值得单独关注。

第 1 节规定无穷语言的基本语法与语义，再用例子展示其表达力。第 2 节讨论只允许有穷量词序列的无穷语言，它们相对温顺。第 3 节讨论无穷语言的 **紧致性问题**，以及它与“大”基数这类纯集合论问题的联系。第 4 节勾画一个论证：多数“无穷量词”语言带 **二阶** 性质，因而 **本身** 就高度不完全。第 5 节简述无穷语言的一类特殊子语言，对它们能证明紧致性定理的一个满意推广；这一节还含一小节讲可容许集的定义。历史与文献评论见第 6 节。

## 1 无穷语言的定义与基本性质

给定一对无穷基数 κ、λ，且 λ ≤ κ，我们定义一类无穷语言：其中可以构造基数 < κ 的公式集的合取与析取，也可以对长度 < λ 的变元序列作量化。

设 L（有穷的 **基础语言**）是任意固定的、带任意多非逻辑符号的一阶语言。无穷语言 L(κ,λ) 的 **基本符号** 如下：

- L 的所有符号
- 个体变元集合 Var，其基数（记作 |Var|）为 κ
- 一个逻辑算子 ∧（**无穷合取**）

L(κ,λ) 的 **前公式** 类递归定义如下：

- L 的每个公式都是前公式；
- 若 φ 与 ψ 是前公式，则 φ∧ψ 与 ¬φ 也是；
- 若 Φ 是前公式的集合且 |Φ| < κ，则 ∧Φ 是前公式；
- 若 φ 是前公式且 *X* ⊆ Var 满足 |*X*| < λ，则 ∃*X*φ 是前公式；
- 所有前公式都由上述子句定义。

若 Φ 是由集合 *I* 索引的前公式集，比如 Φ = {φ_{*i*} : *i* ∈ *I*}，我们约定把 ∧Φ 写作：

> ∧_{*i*∈*I*} φ

或者，若 *I* 是自然数集，则把 ∧Φ 写作：

> φ₀ ∧ φ₁ ∧ …

若 *X* 是由序数 α 索引的个体变元集，比如 *X* = {*x*_{ξ} : ξ < α}，我们约定把 ∃*X*φ 写作 (∃*x*_{ξ})_{ξ<α}φ。

逻辑算子 ∨、→、↔ 按通常方式定义。此外引入算子 ∨（**无穷析取**）与 ∀（**全称量化**）：

> ∨Φ =*_{df}* ¬∧{ ¬φ : φ ∈ Φ}
>
> ∀Xφ =*_{df}* ¬∃X¬φ,

对 ∧、∃ 也采用类似约定。

所以，L(κ,λ) 就是在 L 上允许长度 < κ 的合取、析取以及长度 < λ 的量化[^note-1]得到的无穷语言。L(κ,ω) 叫 **有穷量词** 语言，其余叫 **无穷量词** 语言。注意 L(ω,ω) 就是 L 本身。

有个 **反常现象** 只在无穷语言里出现，有穷语言里没有。语言 L(ω₁,ω) 允许可数无穷合取，却只允许有穷量化；其中有些前公式自由变元太多，加量词也“封闭”不成 L(ω₁,ω) 句子。比如下面这个 L(ω₁,ω)-前公式：

> *x*₀ < *x*₁  ∧  *x*₁ < *x*₂  ∧  …  ∧  *xₙ* < *x*_{*n*+1} …,

其中 L 含二元关系符号 <。因此作如下定义：

> 定义。L(κ,λ) 的 **公式** 是含 < λ 个自由变元的前公式。L(κ,λ) 的全体公式记作 Form(L(κ,λ)) 或 Form(κ,λ)，全体句子记作 Sent(L(κ,λ)) 或 Sent(κ,λ)。

与此相关，一般说考虑 λ > κ 的“语言”L(κ,λ) 并无收获。比如在“语言”L(ω,ω₁) 里，公式只有有穷个自由变元，却有一大堆“无用”量词，能约束无穷多个自由变元。[^note-2]

语法定了，接着勾画 **语义**。L(κ,λ) 的非逻辑符号就是 L 的符号，而正是它们决定给定一阶语言所解释的结构形式，所以不妨把 L(κ,λ)-结构直接定义为 L-结构。L(κ,λ) 公式在 L-结构 *A* 中（由 *A* 的域中元素组成的序列）被 **满足**，其定义方式与 L 公式相同，只需为 ∧Φ 与 ∃Xφ 补两条子句：

> ∧Φ 在 *A* 中（由给定序列）被满足  ⇔  对所有 φ ∈ Φ，φ 在 *A* 中（由该序列）被满足；
>
> ∃*X*φ 在 *A* 中被满足  ⇔  存在一个与 *X* 双射对应的、由 *A* 的域中元素组成的序列，它在 *A* 中满足 φ。

这些非形式定义在严格展开时还得收紧，但意思应当清楚。于是，L(κ,λ) 公式与句子的通常 **真、有效、可满足** 与 **模型** 概念都能用了。特别地，若 *A* 是 L-结构、σ ∈ Sent(κ,λ)，写 *A* ⊨ σ 表示 *A* 是 σ 的模型，写 ⊨ σ 表示 σ **有效**，即对一切 *A* 都有 *A* ⊨ σ。若 Δ ⊆ Sent(κ,λ)，写 Δ ⊨ σ 表示 σ **是 Δ 的逻辑后承**，即 Δ 的每个模型都是 σ 的模型。

下面举例展示 κ ≥ ω₁ 的无穷语言 L(κ,λ) 有多大表达力。每一例中的概念，众所周知都无法在任何一阶语言里表达。

在 L(ω₁,ω) 中刻画算术的标准模型。**算术的标准模型** 是结构 N = ⟨*N*, +, ·, *s*, 0⟩，其中 *N* 为自然数集，+、·、0 取通常意义，*s* 为后继运算。设 L 是适用于 N 的一阶语言，那么与 N 同构的 L-结构类，正好是下列 L(ω₁,ω) 句子之合取的模型类（其中 0 是 0 的名称）：

> ∧_{*m*∈ω} ∧_{*n*∈ω} *s*^{*m*}0 + *s*^{*n*}0 = *s*^{*m*+*n*}0
>
> ∧_{*m*∈ω} ∧_{*n*∈ω} *s*^{*m*}0 · *s*^{*n*}0 = *s*^{*m*·*n*}0
>
> ∧_{*m*∈ω} ∧_{*n*∈ω−{*m*}} *s*^{*m*}0 ≠ *s*^{*n*}0
>
> ∀*x*∨_{*m*∈ω} *x* = *s*^{*m*}0

项 *sⁿx* 递归定义如下：

> | *s*⁰*x* | = | *x* |
> | --- | --- | --- |
> | *s*^{*n*+1}*x* | = | *s*(*sⁿx*) |

在 L(ω₁,ω) 中刻画全体有穷集合。这里基础语言没有非逻辑符号，于是全体有穷集合恰是下面这个 L(ω₁,ω)-句子的模型类：

> ∨_{*n*∈ω} ∃*v*₀ … ∃*vₙ*∀*x*(*x* = *v*₀ ∨ … ∨ *x* = *vₙ*).

在 L(ω₁,ω) 中为可数基础语言 L 定义真。设 L 是可数一阶语言（如算术或集合论的语言），对每个自然数 *n* 都有名称 *n*，并把其句子枚举为 σ₀, σ₁, …。那么 L(ω₁,ω)-公式

> Tr(*x*)  =*_{df}*  ∨_{*n*∈ω} (x = n ∧ σ*ₙ*)

就是 L 的 **真谓词**，因为句子

> Tr(*n*) ↔ σ*ₙ*

对每个 *n* 都有效。

在 L(ω₁,ω₁) 中刻画良序。这里基础语言 L 含二元谓词符号 ≤。设 σ₁ 是刻画线性序的通常 L-句子，那么“≤ 的解释为良序”的 L-结构类，正是 L(ω₁,ω₁) 句子 σ = σ₁ ∧ σ₂ 的模型类，其中

> σ₂ =*_{df}* (∀*vₙ*)_{*n*∈ω} ∃*x* [∨_{*n*∈ω} (*x = vₙ*) ∧ ∧_{*n*∈ω} (*x* ≤ *vₙ*)].

注意 σ₂ 含 **无穷量词**：它表达的是本质上 **二阶** 的断言——每个可数子集都有最小元。事实上可以证明，这个无穷量词不可省：良序结构类无法在任何有穷量词语言中刻画。这个例子说明，L(ω₁,ω₁) 这类无穷量词语言很像二阶语言；下文会看到，它们既有后者的缺陷（不完全），也有后者的一些长处（表达力强）。

许多一阶语言的扩张可以 **翻译** 成无穷语言。例如广义量词语言 L(*Q*₀)：在 L 上加新量词符号 *Q*₀，把 *Q*₀*x*φ(*x*) 解释为 **存在无穷多个 x 使** φ(*x*)。容易看出，*Q*₀*x*φ(*x*) 与下面这个 L(ω₁,ω)-句子同模型：

> ¬∨_{*n*∈ω} ∃*v*₀…∃*vₙ*∀*x*[φ(*x*) → (*x = v*₀ ∨ … ∨ *x* = *vₙ*)].

所以，L(*Q*₀) 在自然意义上可翻译成 L(ω₁,ω)。另一种能这样翻译的语言是 **弱二阶语言**：在 L 上加可数多个一元谓词变元，解释为取遍个体的全体 **有穷** 集合。

也能引入合取、析取乃至量化任意长的语言。对固定无穷基数 λ，语言 L(∞,λ) 的公式类 Form(∞,λ) 定义为所有 κ ≥ λ 的 Form(κ,λ) 之并。因此 L(∞,λ) 允许任意长的合取与析取：只要 Φ 是 Form(∞,λ) 的任意子集，∧Φ 与 ∨Φ 就都在 Form(∞,λ) 中。但 L(∞,λ) 只允许长度 < λ 的量化：其公式都有 < λ 个自由变元。语言 L(∞,∞) 的公式类 Form(∞,∞) 则定义为所有无穷基数 λ 的 Form(∞,λ) 之并，因而除任意长合取、析取外，还允许任意长量化。注意，按哥德尔–贝尔奈斯集合论，Form(∞,λ) 与 Form(∞,∞) 都是真类。L(∞,λ) 与 L(∞,∞) 公式在结构中的满足，按 L(κ,λ) 相应概念作明显推广即可定义。

## 2 有穷量词语言

前面说过，L(ω₁,ω₁) 这类无穷量词语言像二阶语言，因为它们允许对个体的无穷集合量化。有穷量词语言不允许这样做，这提示它们在某些方面也许比乍看更接近一阶语言。下文会看到，确实如此，尤其是 L(ω₁,ω)。

L(ω₁,ω) 在无穷语言里地位特殊：和一阶语言一样，它有一个有效的 **演绎装置**。具体说，在通常一阶公理与推理规则之外，加一条公理模式

> ∧Φ → φ

其中 Φ ⊆ Form(ω₁,ω) 可数、φ ∈ Φ；再加新的推理规则

> | φ₀, φ₁, …, φ*ₙ*, … |
> | --- |
> | ∧_{*n*∈ω} φ_{*n*} |

并允许演绎有可数长度。把这种意义上的可推演性记作 ⊢*，于是有

> L(ω₁,ω)-完全性定理。对任何 σ ∈ Sent(ω₁,ω)，⊨ σ  ⇔  ⊢*σ

立得：这个演绎装置 **足以处理 L(ω₁,ω) 中从可数前提集出发的演绎**。也就是说，按记号的明显扩展，对任何 **可数** 集 Δ ⊆ Sent(ω₁,ω)，有

> (2.1) Δ ⊨ σ  ⇔  Δ⊢*σ

这个完全性定理，可以修改一阶逻辑通常的 Henkin 完全性证明来证，也可以用布尔代数方法证。把类似论证用于适当扩充后的公理与推理规则，还能为许多其他有穷量词语言得到类似的完全性定理。

若只允许可数长的演绎，就无法为 L(ω₁,ω) 建立足以从 **任意** 前提集出发作演绎的装置——也就是让 (2.1) 对每个 Δ ⊆ Sent(ω₁,ω) 都成立，**不管其基数**。这从一个简单观察即可推出：存在一阶语言 L 与不可数的 L(ω₁,ω)-句子集 Γ，使 Γ **没有模型，但其每个可数子集都有模型**。取 L 为算术语言加上 ω₁ 个新常项 {c_{ξ} : ξ < ω₁}，取 Γ 为 L(ω₁,ω)-句子集 {σ} ∪ {*c*_{ξ} ≠ c_{η} : ξ ≠ η}，其中 σ 是刻画算术标准模型的 L(ω₁,ω)-句子。这个例子同时表明，**紧致性定理** 对 L(ω₁,ω) 失效，因而对任何 κ ≥ ω₁ 的 L(κ,λ) 也失效。

另一个在一阶情形成立、但在 κ ≥ ω₁ 的 L(κ,ω) 上失效的结果，是 **前束范式定理**（对 L(ω₁,ω₁) 也失效，只是更难证）。句子若量词全在句首，就叫 **前束** 的；下面给出一个 L(ω₁,ω)-句子，它不等价于任何前束句子的合取。设 L 为无非逻辑符号的一阶语言，σ 是刻画有穷集合类的 L(ω₁,ω)-句子。假设 σ 等价于一组合取

> ∧_{*i*∈*I*} σ*ᵢ*

其中每个 σ*ᵢ* 都是前束 L(ω₁,ω)-句子。于是每个 σ*ᵢ* 形如

> *Q*₁*x*₁ … *Q*ₙ*xₙ* φ*ᵢ*(*x*₁*,…, xₙ*),

其中每个 *Qₖ* 是 ∀ 或 ∃，φ*ᵢ* 是形如 *xₖ* = *xₗ* 或 *xₖ* ≠ *xₗ* 的公式的（可能无穷）合取或析取。每个 σ*ᵢ* 既是句子，每个 φ*ᵢ* 里就只有有穷多个变元，容易看出 φ*ᵢ* 等价于一阶公式，因而 σ*ᵢ* 可当作一阶句子。既然 σ 假定等价于这些 σ*ᵢ* 的合取，σ 与 Δ = {σ*ᵢ* : *i* ∈ *I*} 就同模型。可显然 σ（从而 Δ）有所有有穷基数的模型；由一阶句子集的紧致性定理，Δ（从而 σ）有无穷模型——这与 σ 的定义矛盾。

再看 **Löwenheim–Skolem 定理**：其 **向下** 版本对 L(ω₁,ω)（其实对所有无穷语言）都有适当推广。用与一阶句子集大体相同的方法可以证明：若 Δ ⊆ Sent(ω₁,ω) 有基数 ≥ |Δ| 的无穷模型，它就有基数为 ℵ₀ 与 |Δ| 中较大者的模型。特别地，任何有无穷模型的 L(ω₁,ω)-句子都有可数模型。

另一方面，通常形式的 **向上** Löwenheim–Skolem 定理对所有无穷语言都 **失效**。比如刻画算术标准模型的 L(ω₁,ω)-句子，只有基数 ℵ₀ 的模型，别的基数一概没有。不过，正如后文所示，也不是全无办法。

语言 L 的 **Hanf 数** h(L)，定义为最小的基数 κ：只要某个 L-句子有基数 κ 的模型，它就有任意大基数的模型。h(L) 的存在性很容易确立。对每个没有任意大基数模型的 L-句子 σ，令 κ(σ) 为使 σ 没有基数 κ 模型的最小基数 κ；取 λ 为所有 κ(σ) 的上确界，那么 L 的句子若有基数 λ 的模型，就有任意大基数的模型。

递归定义基数 μ(α)：

> | μ(0) | = | ℵ₀ |
> | --- | --- | --- |
> | μ(α+1) | = | 2^{μ(α)} |
> | μ(λ) | = | ∑_{α<λ} μ(α), for limit λ. |

于是可以证明

> h(L(ω₁,ω)) = μ(ω₁),

其他有穷量词语言也有类似结果。L(ω₁,ω₁) 这类无穷量词语言的 Hanf 数取值，取决于大基数是否存在，但无论如何都远大于 L(ω₁,ω) 的 Hanf 数。

有个结果对 L 成立、可推广到 L(ω₁,ω)，却推不到其他任何无穷语言：

> Craig 插值定理：若 σ,τ ∈ Sent(ω₁,ω) 满足 ⊨ σ → τ，则存在 θ ∈ Sent(ω₁,ω)，使 ⊨ σ → θ、⊨ θ → τ，且 θ 中出现的每个非逻辑符号都在 σ 与 τ 中出现。

证明是一阶情形的合理直接推广。

最后再提一个能漂亮地推广到 L(ω₁,ω)、却推不到其他任何无穷语言的结果。众所周知，若 *A* 是只有有穷多个关系的有穷 L-结构，就存在 L-句子 σ 在同构意义上刻画 *A*。对 L(ω₁,ω) 有下述推广，称为

> Scott 同构定理。若 *A* 是只有可数多个关系的可数 L-结构，则存在 L(ω₁,ω)-句子，其可数模型类恰好是与 *A* 同构的 L-结构类。

限制在 **可数** 结构上是本质性的：可数性一般无法用 L(ω₁,ω)-句子表达。

语言 L(∞,ω) 也可算有穷量词语言。相对于它的结构等价概念格外重要：若两个（相似）结构 *A*、*B* 中成立的 L(∞,ω) 句子完全相同，就称它们 **(∞,ω)-等价**，记作 *A* ≡_{∞ω} *B*。这个关系首先可用部分同构来刻画。*A* 与 *B* 间的 **部分同构**，是一个非空映射族 *P*，满足：

- 对每个 *p* ∈ *P*，dom(*p*) 是 *A* 的子结构，ran(*p*) 是 B 的子结构，且 *p* 是其定义域到值域的同构；
- 若 *p* ∈ *P*，*a* ∈ *A*，*b* ∈ *B*，则存在都扩张 *p* 的 *r*, *s* ∈ *P*，使 *a* ∈ dom(*r*)、*b* ∈ ran(*s*)（“来回”性质）。

若 *A* 与 *B* 间存在部分同构，就说它们部分同构，记作 *A* ≅_{*p*} B。于是有

> Karp 部分同构定理。对任何相似结构 *A*, *B*，*A* ≡_{∞ω} *B* ⇔ *A* ≅_{*p*} *B*。

L(∞,ω) 也有 Scott 同构定理的一个版本：

> (2.2) 给定任何结构 *A*，存在 L(∞,ω)-句子 σ，使得对所有结构 *B*，*A* ≅_{*p*} *B* ⇔ *B* ⊨ σ。

部分同构与 (∞,ω)-等价还同 **布尔同构** 有关。为此要引入集合论的布尔值模型。给定完全布尔代数 *B*，*B*-值集合的 **全域** *V*^{(*B*)}（也叫 **集合全域 V 的 B-扩张**）这样构造：先按 α 递归定义

> *V*_{α}^{(*B*)} = {*x*: *x* is a function ∧ range(*x*) ⊆ *B* ∧ ∃ξ<α[domain(*x*) ⊆ *V*_{ξ}^{(*B*)}]}

然后令

> *V*^{(*B*)} = {*x*: ∃α(*x* ∈ *V*_{α}^{(*B*)})}.

*V*^{(*B*)} 的成员叫 *B*-值集合。现在容易看出，*B*-值集合恰好是定义域为 *B*-值集合之集的 *B*-值函数。设 L 是集合论的一阶语言，L^{(*B*)} 是在 L 上为 *V*^{(*B*)} 的每个元素加一个名称所得的语言（元素与其名称用同一符号）。于是可构造 L^{(*B*)}（句子）到 *B* 的映射 [·]^{(*B*)}：对 L^{(*B*)} 的每个句子 σ，*B* 中元素 [σ]^{(*B*)} 就是 σ 在 *V*^{(*B*)} 中的“布尔真值”。这个映射把策梅洛–弗兰克尔集合论的一切定理都送到 *B* 的顶元 1，即“真”；因此 *V*^{(*B*)} 可看作集合论的 **布尔值模型**。一般地，若 [σ]^{(*B*)} = 1，就说 σ 在 *V*^{(*B*)} 中 **有效**，记作 *V*^{(*B*)} ⊨ σ。

现在每个 *x* ∈ *V* 在 *V*^{(*B*)} 中都有典范代表 *x*，满足

> *x* = *y* iff *V*^{(*B*)} ⊨ *x* = *y* *x* ∈ *y* iff *V*^{(*B*)} ⊨ *x* ∈ *y*

称两个相似结构 *A*、*B* 布尔同构，记作 *A* ≅_{*b*} B，如果对某个完全布尔代数 *B* 有 *V*^{(*B*)} ⊨ *A* ≅ *B*——也就是说，集合全域的某个布尔扩张里，*A* 与 *B* 的典范代表以布尔值 1 同构。于是可以证明：

> (2.3) *A* ≡_{∞ω} *B* ⇔ *A* ≅_{*b*} *B*。

这个结果可以借范畴论表述而得到加强。为此需要（初等）**拓扑斯** 概念。先从熟知的集合与映射范畴 Set 说起，Set 有以下关键性质：

1. 有“终端”对象 1：对任何对象 *X*，存在唯一映射 *X* → 1（1 可取任一单元素集，特别是 {0}）。
2. 任何一对对象 *X*,Y 都有笛卡尔积 *X* × *Y*。
3. 对任何一对对象，可构造所有从 *X* → *Y* 的映射组成的“指数”对象 *Y*^{*X*}。
4. 有“真值”对象 Ω：对每个对象 *X*，*X* 的子对象（子集）与映射 *X* → Ω 之间自然对应。（Ω 可取集合 2 = {0,1}；此时映射 *X* → Ω 就是 *X* 上的 **特征函数**。）

这四个条件都能用范畴论语言表述；满足它们的范畴叫 **拓扑斯**。Set 是拓扑斯；下面这些也是：(i) 任何布尔扩张 *V*^{(*B*)} 中布尔值集合与映射的范畴 Set^{(*B*)}；(ii) 拓扑空间上的集合层范畴；(iii) 所有集合映射图

> *X*₀ → *X*₁ → *X*₂ → …

的范畴。这些范畴的对象都可看作以某种方式 **变化** 的集合：情形 (i) 在 **布尔代数** 上变化；情形 (ii) 在拓扑 **空间** 上变化；情形 (iii) 在（离散）时间上变化。于是拓扑斯可以设想为“可变”集合的全域；熟知的 Set 是它的特殊极限情形——对象“变化”降为零。

和集合论里一样，任何拓扑斯的真值对象上都能定义“逻辑算子”：映射 ¬: Ω → Ω；∧, ∨, ⇒: Ω × Ω → Ω，分别对应否定、合取、析取、蕴涵。有了这些运算，Ω 成为 Heyting 代数，一般体现的不是经典逻辑规律，而是直觉主义逻辑规律。在这个意义上，直觉主义逻辑被“内化”进拓扑斯：直觉主义逻辑就是可变集合的逻辑。（当然，经典逻辑也在某些拓扑斯里被内化，例如 Set，以及任何完全布尔代数 *B* 的 Set^{(*B*)}。）

任何拓扑斯都可设想为可能的“论域”，数学断言能在其中解释，数学构造能在其中进行。数学断言在拓扑斯 E 中，借其 **内部语言**（通常集合论语言的类型论版本）表达而获得解释。仿照布尔值有效性，可以引入内部语言句子 σ 在 E 中有效的适当概念；同样写 E ⊨ σ 表示“σ 在 E 中有效”。

拓扑斯 E 叫 **满的**，如果对任何集合 *I*，其终端对象的 *I*-重余积[^note-3] ∐_{*I*}1 在 E 中存在。∐_{*I*}1 可看作集合 *I* 在 E 中的典范代表，所以直接写作 *I*。（在 *V*^{(*B*)} 中，这与先前定义的 *I* 一致。）上面提到的拓扑斯都是满的。

设 E 是满拓扑斯。若 *A* = (*A*, *R*, …) 是结构，就写作 *A* 表示 (*A*, *R*, …)。两个结构 *A*、*B* 叫 **拓扑斯同构**，记作 *A* ≅_{*t*} B，如果对某个定义在集合范畴上的拓扑斯 E 有 E ⊨ *A* ≅ *B*。换句话说，两个结构拓扑斯同构，是指它们的典范代表在某个拓扑斯的内部语言里同构。于是可以证明

> (2.4) *A* ≡_{∞ω} *B* ⇔ *A* ≅_{*t*} *B*。

因此，(∞,ω)-等价可以看作“可变”集合全域这一极其一般的语境中的同构。在这个意义上，(∞,ω)-等价是一种“不变”的同构概念。

## 3 紧致性

如前所述，通常形式的紧致性定理对所有无穷语言都失效。不过，无穷语言是否满足该定理的某个适当修改版，仍值得一问。这个 **紧致性问题** 恰好与涉及“大”基数的纯集合论问题有自然联系。

定义如下。设 κ 为无穷基数。语言 L 叫 **κ-紧致的**（相应地 **弱** **κ-紧致的**），如果只要 Δ 是 L-句子集（相应：基数 ≤ κ 的 L-句子集）且 Δ 的每个基数 < κ 的子集都有模型，Δ 就有模型。注意 L 的通常紧致性定理，正是说 L 是 ω-紧致的。给 κ-紧致性一个意义，理由如下。称 L 为 **κ-完全的**（相应：**弱** **κ-完全的**），如果存在 L 的演绎系统 *P*，演绎长度 < κ，使得：若 Δ 是 *P*-一致[^note-4]的 L-句子集（相应：且 |Δ| ≤ κ），则 Δ 有模型。这样的 *P* 足以按第 2 节的意义从任意（基数 ≤ κ 的）前提集作演绎。容易看出，L 若 κ-完全或弱 κ-完全，就 κ-紧致或弱 κ-紧致。所以，若能证明某语言 **不是**（弱）κ-紧致的，就不可能有演绎长度 < κ、足以从任意（基数 ≤ κ 的）前提集出发作演绎的演绎系统。

事实上，多数语言 L(κ,λ) 连弱 κ-紧致都不是；而那些是的，κ 必须是极大的 **大** 基数。先给几个定义。

无穷基数 κ 叫 **弱不可达的**，如果

> (a) λ < κ → λ⁺ < κ（其中 λ⁺ 表示 λ 的基数后继），并且
>
> (b) | *I* | < κ 且 λ*ᵢ* < κ（对所有 *i* ∈ *I*） ⇒ ∑_{*i*∈*I*} λ_{*i*} < κ。

若再满足

> (c) λ < κ ⇒ 2^{λ} < κ,

则称 κ 为（**强**）**不可达的**。ℵ₀ 本身不可达，所以通常只关注超过 ℵ₀ 的不可达或弱不可达基数；因此，不可达或弱不可达基数总被当作 **不可数的**。显然，这类基数若存在，必定极大；而且哥德尔不完全性定理确实蕴涵：连弱不可达基数的存在，都不能从集合论通常公理证明。

称基数 κ **紧致**（相应：**弱紧致**），如果语言 L(κ,κ) 是 κ-紧致（相应：弱 κ-紧致）的。于是有：

> (3.1) ℵ₀ **是紧致的**。当然，这只是表达一阶语言紧致性定理的简洁方式。
>
> (3.2) κ **弱紧致** ⇒ L(κ,ω) **弱** **κ-紧致** ⇒ κ **弱不可达**。因此（与集合论通常公理一道）可以一致地假定：没有 κ ≥ ω₁ 的语言 L(κ,ω) 是弱 κ-紧致的，更不用说弱 κ-完全。
>
> (3.3) 设 κ 不可达。则 κ **弱紧致**  ⇔  L(κ,ω) **弱** **κ-紧致**。并且，κ 弱紧致 ⇒ **在** κ **之前存在一集** κ **个不可达基数**。于是，弱紧致的不可达基数极大；特别是，它不可能是第一个、第二个、…、第 *n* 个、… 不可达基数。
>
> (3.4) κ **紧致** ⇒ κ **不可达**。（但由上述结果，逆命题不成立。）

设 Constr 代表哥德尔的可构成性公理；记得它与集合论通常公理一致。

> (3.5) **若** Constr **成立，则不存在紧致基数**。
>
> (3.6) **假定** Constr **并设** κ **不可达。则** κ **弱紧致** ⇔ L(ω₁,ω) **对所有 L 都是弱 κ-紧致的**。
>
> (3.7) **若** Constr **成立，则不存在基数** κ **使** L(ω₁,ω) **紧致**。因此，与集合论通常公理一致地，可以设想没有基数 κ 使所有语言 L(ω₁,ω) 都 κ-完全。这与下述事实恰成对照：**所有** 一阶语言都是 ω-完全的。

这些结果说明：对多数 κ ≥ ω₁ 的语言 L(κ,λ)，紧致性定理败得很惨。

这里该作点历史说明。1930 年代，数学家研究过所谓 **测度问题** 的若干版本，它与 Lebesgue 在连续统上的测度论有关。特别是提出了下面这个很简单的测度概念。若 *X* 是集合，*X* 上的（可数可加、二值、非平凡）**测度** 是幂集 P*X* 到 {0, 1} 的映射 μ，满足：

> (a) μ(*X*) = 1,
>
> (b) μ({*x*}) = μ(∅) = 0，对所有 *x* ∈*X*，并且
>
> (c) 若 *A* 是 *X* 的任意可数族两两不交子集，则 μ(∪*A*) = ∑{μ(*Y*) : *Y* ∈ *A*}。

显然，一个集合是否支持这样的测度，只取决于它的基数。于是自然把基数 κ 叫 **可测的**，如果所有基数为 κ 的集合都支持这种测度。人们很快认识到，可测基数必定不可达；但直到 1960 年代，Tarski 证明可测基数弱紧致、其学生 Hanf 证明第一、第二等不可达基数不弱紧致（参看 (3.3)），“逆命题为假”才被确立。如今通常不必绕道弱紧致性与无穷语言就能证明“可测基数极大”，但事实仍是：这些想法最初正是用来确立该结果的。

## 4 无穷量词语言的不完全性

一阶语言最重要的结果，大概是 **哥德尔完全性定理**：任何一阶语言 L 的所有有效公式，都能由一小组公理、经几条直截了当的推理规则生成。它有个主要推论：若 L 的公式以某种构造性方式编码成自然数，则（有效句子的编码）集 **递归可枚举**。也就是说，一阶语言的完全性蕴涵：其有效句子之集以特别简单的方式 **可定义**。于是，给定 **任意** 语言 L，不妨把这个蕴涵倒过来：若有效 L-句子之集不能用某种简单方式定义，就不能为 L 建立任何有意义的完全性结果——或者如我们所说，L 是 **不完全的**。本节就用这个思路，勾画一个证明：多数 **无穷量词** 语言都这样不完全。

先引入 **可定义性** 的形式概念。设 L 是语言，*A* 是 L-结构，*X* 是 *A* 的域 *A* 的子集。称 *X* 在 *A* 中由 L 的公式 φ(*x, y*₁,…,*yₙ*) **可定义**，如果存在 *A* 中元素序列 *a*₁,…,*aₙ*，使 *X* 恰由所有满足“φ(*x, a*₁,…,*aₙ*) 在 *A* 中成立”的 *x* ∈ *A* 组成。

把 L 的所有 **有效** 句子之集记作 *Val*(L)。要给“*Val*(L) 可定义”这句话赋予意义，必须先指定

1. 一个结构 *C*(L)——L 的 **编码结构**；
2. 一个特定的一一映射——**编码映射**——从 L 的公式集到 *C*(L) 的域。

于是，若把 *Val*(L) 与它在编码映射下于 *C*(L) 中的像等同，“*Val*(L) 可定义”就解释为：“*Val*(L) 作为 *C*(L) 的域的子集，在 *C*(L) 中由 L 的公式可定义。”

例如，当 L 是算术的一阶语言时，哥德尔最初拿算术标准模型 ℕ 当编码结构，拿由自然数素因子分解定理得到的著名函数当编码映射。于是 *Val*(L) 递归可枚举，只意味着：*Val*(L) 成员的编码（“哥德尔数”）之集，在 ℕ 中能由形如 ∃*y*φ(*x, y*) 的 L-公式定义，其中 φ(*x, y*) 是递归公式。

算术一阶语言的另一种等价编码结构，是 **遗传有穷集合** 的结构[^note-5] ⟨*H*(ω), ∈ ⨡ *H*(ω)⟩；集合 *x* 叫 **遗传有穷的**，如果 *x*、其成员、其成员的成员……都是有穷的。这种编码结构照顾到一点：一阶公式天然被看作有穷集合。

现在转到 L 是无穷语言 L(κ,λ) 的情形：合适的编码结构是什么？开头说过，无穷语言源于“把公式当作集合论对象”的想法。那就想想无穷公式该是哪种集合论对象。既然对每个 φ∈Form(κ,λ)，φ 及其子公式、子子公式……长度都 < κ[^note-6]，稍想便知：L(κ,λ) 的公式“对应”于 **遗传基数** < κ 的集合 *x*——即 *x*、其成员、其成员的成员……基数都 < κ。这类集合的总体记作 *H*(κ)。*H*(ω) 就是前面说的 **遗传有穷** 集合总体，*H*(ω₁) 则是全体 **遗传可数** 集合。

为简单起见，设基础语言 L 的唯一非逻辑符号是二元谓词符号 ∈（讨论很容易推广到含额外非逻辑符号的情形）。循上述思路，取下面这个结构作为 L(κ,λ) 的编码结构：

> H(κ) =*_{df}* ⟨*H*(κ), ∈ ⨡ *H*(κ)⟩.

现在可以定义 Form(κ,λ) 到 H(κ) 的编码映射。首先给 L(κ,λ) 的每个基本符号 *s* 指定编码对象 ^{⌈}*s*^{⌉} ∈ *H*(κ) 如下。设 {*v*_{ξ}: ξ < κ} 枚举 L(κ,λ) 的个体变元。

> | 符号 | 编码对象 | 记号 |
> | --- | --- | --- |
> | ¬ | 1 | ^{⌈}¬^{⌉} |
> | ∧ | 2 | ^{⌈}∧^{⌉} |
> | ∧ | 3 | ^{⌈}∧^{⌉} |
> | ∃ | 4 | ^{⌈}∃^{⌉} |
> | ∈ | 5 | ^{⌈} ∈ ^{⌉} |
> | = | 6 | ^{⌈}=^{⌉} |
> | *v*_{ξ} | ⟨0,ξ⟩ | ^{⌈}*v*_{ξ}^{⌉} |

然后递归地给每个 φ ∈ Form(κ,λ) 指定编码对象 ^{⌈}φ^{⌉}：

> ^{⌈}*v*_{ξ} = *v*_{η}^{⌉}  =*_{df}*  ⟨^{⌈}*v*_{ξ}^{⌉}, ^{⌈}=^{⌉}, ^{⌈}*v*_{η}^{⌉}⟩,
>
> ^{⌈}*v*_{ξ} ∈ *v*_{η}^{⌉}  =*_{df}*  ⟨^{⌈}*v*_{ξ}^{⌉}, ^{⌈}∈^{⌉}, ^{⌈}*v*_{η}^{⌉}⟩;

对 φ, ψ ∈ Form(κ,λ)：

> ^{⌈}φ ∧ ψ^{⌉}  =*_{df}*  ⟨^{⌈}φ^{⌉}, ^{⌈}∧^{⌉}, ^{⌈}ψ^{⌉}⟩
>
> ^{⌈}¬φ^{⌉}  =*_{df}*  ⟨^{⌈}¬^{⌉}, ^{⌈}φ^{⌉}⟩
>
> ^{⌈}∃*X*φ^{⌉}  =*_{df}*  ⟨^{⌈}∃^{⌉}, {^{⌈}*x*^{⌉}: *x* ∈ *X*}, ^{⌈}φ^{⌉}⟩;

最后，若 Φ ⊆ Form(κ,λ) 且 |Φ| < κ，则

> ^{⌈}∧Φ^{⌉}  =*_{df}*  ⟨^{⌈}∧^{⌉}, {^{⌈}φ^{⌉}: φ ∈ Φ}⟩.

映射 φ ↦ ^{⌈}φ^{⌉} 从 Form(κ,λ) 到 *H*(κ)，容易看出是一一的，正是所需编码映射。因此约定：把 *Val*(L(κ,λ)) 与它在该编码映射下于 *H*(κ) 中的像等同。

*Val*(L(κ,λ)) 何时是 H(κ) 的 **可定义** 子集？要回答，需先给定义。

L-公式叫 **Δ₀-公式**，如果它等价于一个量词全为 ∀*x*∈*y* 或 ∃*x*∈*y* 形式的公式（即 ∀*x*(*x*∈*y* → …) 或 ∃*x*(*x*∈*y* ∧ …)）。L-公式叫 **Σ₁-公式**，如果它等价于一个只由原子公式及其否定、仅用逻辑算子 ∧, ∨, ∀*x*∈*y*, ∃*x* 构造的公式。集合 *A* 的子集 *X* 叫在 *A* 上 Δ₀（相应 Σ₁）的，如果它在结构 ⟨*A*, ∈ ⨡ *A*⟩ 中由 L 的 Δ₀-（相应 Σ₁-）公式可定义。

例如，按通常方式把自然数集与遗传有穷集合 *H*(ω) 等同，则对每个 *X* ⊆ *H*(ω) 有：

> *X* 在 *H*(ω) 上 Δ₀ ⇔ *X* 递归
>
> *X* 在 *H*(ω) 上 Σ₁ ⇔ *X* 递归可枚举。

因此，Δ₀-集与 Σ₁-集概念可分别看作 **递归** 集与 **递归可枚举** 集概念的推广。

L 的完全性定理蕴涵：*Val*(L)（看作 *H*(ω) 的子集）递归可枚举，从而是 *H*(ω) 上 Σ₁ 的。类似地，L(ω₁,ω) 的完全性定理（见第 2 节）蕴涵：*Val*(L(ω₁,ω))（看作 *H*(ω₁) 的子集）是 *H*(ω₁) 上 Σ₁ 的。可一到 L(ω₁,ω₁)，这幅好景就彻底崩了。因为可以证明

> Scott 关于 L(ω₁,ω₁) 的不可定义性定理。*Val*(L(ω₁,ω₁)) **在** H(ω₁) **中即使由 L(ω₁,ω₁)-公式也不可定义**；**因此更不用说** *Val*(L(ω₁,ω₁)) **不是** *H*(ω₁) **上 Σ₁ 的**。

这个定理的证法，与下面这个著名结果大体相同：算术二阶语言 L² 的有效句子（编码）集，在其编码结构 ℕ 中不是二阶可定义的。要得后一结果，先注意 ℕ 由单个 L²-句子刻画；再说明：若结果不成立，L²-句子的“在 ℕ 中为真”便由 L²-公式可定义，从而违反 Tarski 的真不可定义定理。

所以，沿这条路线证 Scott 不可定义性定理，需要先确立：

> (4.1) **编码结构** H(ω₁) **在** L(ω₁,ω₁) **中的可刻画性**：存在 L(ω₁,ω₁)-句子 τ₀，使得对所有 L-结构 *A*，*A* ⊨ τ₀  ⇔  *A* ≅ H(ω₁)。
>
> (4.2) **L(ω₁,ω₁)-句子在编码结构中的真不可定义性**：不存在 L(ω₁,ω₁)-公式 φ(*v*₀)，使得对所有 L(ω₁, ω₁)-句子 σ，H(ω₁) ⊨ σ↔φ(^{⌈}σ^{⌉})。
>
> (4.3) **存在** L(ω₁,ω₁) **的项** *t*(*v*₀, *v*₁)，**使得对每对** L(ω₁,ω₁) **句子** σ, τ，H(ω₁)  ⊨  [*t*(^{⌈}σ^{⌉},^{⌈}τ^{⌉}) = ^{⌈}σ → τ^{⌉}]。

(4.1) 靠分析 H(ω₁) 的集合论定义、说明它能在 L(ω₁,ω₁) 中“内部”表述来证。(4.2) 的建立方式，与 Tarski 关于一阶或二阶语言真不可定义的定理大体相同。(4.3) 则把编码映射 σ ↦ ^{⌈}σ^{⌉} 的定义在 L(ω₁,ω₁) 中形式化。

有了这些，就能这样得到 Scott 不可定义性定理。假设它不成立，则存在 L(ω₁,ω₁)-公式 θ(*v*₀)，使得对所有 L(ω₁,ω₁)-句子 σ，

> (4.4) H(ω₁) ⊨ θ(^{⌈}σ^{⌉})  iff  σ ∈ *Val*(L(ω₁,ω₁)).

设 τ₀ 为 (4.1) 给出的句子。则对所有 L(ω₁,ω₁)-句子 σ，有

> H(ω₁) ⊨ σ   iff   (τ₀ → σ) ∈ *Val*(L(ω₁,ω₁)),

于是由 (4.4) 得

> H(ω₁) ⊨ σ   iff   H(ω₁) ⊨ θ(^{⌈}τ₀ → σ^{⌉}).

若 *t* 是 (4.3) 给出的项，就可推出

> H(ω₁) ⊨ σ↔θ(*t*(^{⌈}τ₀^{⌉}, ^{⌈}σ^{⌉})).

现在把 θ(*t*(^{⌈}τ₀^{⌉}, ^{⌈}σ^{⌉})) 记作 L(ω₁,ω₁)-公式 φ(*v*₀)。于是

> H(ω₁) ⊨ σ↔φ(^{⌈}σ^{⌉}),

这与 (4.2) 矛盾，证明完毕。

所以，*Val*(L(ω₁,ω₁)) **即使由 L(ω₁,ω₁)-公式** 也不可定义，更不用说 L(ω₁,ω₁) 不完全了。类似论证表明，把 ω₁ 换成任何后继基数 κ⁺，Scott 不可定义性定理照样成立；因此语言 L(κ⁺,κ⁺) 全都不完全。[^note-7]

## 5 L(ω₁,ω) 的子语言与 Barwise 紧致性定理

照我们如今对无穷语言的了解，L(ω₁,ω) 似乎是唯一还算规矩的。可紧致性定理无法以任何有用方式推广到 L(ω₁,ω)，这对应用来说是个严重缺陷。下面细看一下这个失败。

回忆第 4 节：一阶语言 L 的公式可以编码成遗传有穷集合，即 *H*(ω) 的成员。这样，每个有穷的 L-句子（编码）集也在 *H*(ω) 中，于是 L 的紧致性定理可写成：

> (5.1) 若 Δ ⊆ Sent(L) 使得每个子集 Δ₀ ⊆ Δ、Δ₀ ∈ *H*(ω) 都有模型，则 Δ 也有模型。

众所周知，(5.1) 是 L 的 **广义完全性定理** 的直接推论；该定理按类似 (5.1) 的形式表述，就是：

> (5.2) 若 Δ ⊆ Sent(L) 与 σ ∈ Sent(L) 满足 Δ ⊨ σ，则存在 σ 从 Δ 的演绎 *D*，使 *D* ∈ *H*(ω)。[^note-8]

第 2 节说过，L(ω₁,ω) 的紧致性定理败得很惨；事实上我们构造了 Γ ⊆ Sent(ω₁,ω)，使

> (5.3) Γ 的每个可数子集都有模型，但 Γ 没有。

还记得我们在 L(ω₁,ω) 中引入了 **演绎** 概念；这种演绎长度可数，由 (5.3) 立得

> (5.4) 存在句子[^note-9]σ ∈ Sent(ω₁,ω)，使 Γ ⊨ σ，但不存在 σ 在 L(ω₁,ω) 中从 Γ 的演绎。

现在，L(ω₁, ω) 的公式可编码为 H(ω₁) 的成员，而 H(ω₁) 显然对可数子集与序列的构造封闭。于是 (5.3) 与 (5.4) 可写成：

> (5.3 *bis*) 每个满足 Γ₀ ∈ H(ω₁) 的 Γ₀ ⊆ Γ 都有模型，但 Γ 没有；
>
> (5.4 *bis*) 存在句子 σ ∈ Sent(ω₁,ω)，使 Γ ⊨ σ，但不存在 σ 从 Γ 的演绎 *D* ∈ *H*(ω₁)。

所以，把“L”换成“L(ω₁,ω)”、把“H(ω)”换成“H(ω₁)”之后，(5.1) 与 (5.2) 就失效。而且可以证明，(5.3 *bis*) 与 (5.4 *bis*) 里的 Γ ⊆ Sent(ω₁,ω) 可以取成 *H*(ω₁) 上 Σ₁ 的。因此，即便对 L(ω₁, ω)-句子的 Σ₁-集，紧致性定理与广义完全性定理也失效。

由 (5.4 *bis*) 可见，广义完全性定理对 L(ω₁,ω) 中的 Σ₁-集失效，原因大致是：*H*(ω₁) 对“从 *H*(ω₁) 中句子的 Σ₁-集构造演绎”并不“封闭”。要补救，自然该把 *H*(ω₁) 换成某种意义下对这种演绎构造封闭的集合 *A*，然后只考虑编码落在 *A* 里的公式。

下面勾画怎么做。

首先，照第 4 节的做法，把 L(ω₁,ω) 的符号与公式同其在 *H*(ω₁) 中的编码等同。对每个可数传递[^note-10]集 *A*，令

> L_{*A*} = Form(L(ω₁,ω)) ∩ *A*.

称 L*_{A}* 为 L(ω₁,ω) 的 **子语言**，如果满足下列条件：

1. L ⊆ L*_{A}*
2. 若 φ, ψ ∈ L*_{A}*，则 φ ∧ ψ ∈ L*_{A}* 且 ¬φ ∈ L*_{A}*
3. 若 φ ∈ L*_{A}* 且 *x* ∈ *A*，则 ∃*x*φ ∈ L*_{A}*
4. 若 φ(*x*) ∈ L*_{A}* 且 *y* ∈ *A*，则 φ(*y*) ∈ L*_{A}*
5. 若 φ ∈ L*_{A}*，则 φ 的每个子公式都在 L*_{A}* 中
6. 若 Φ ⊆ L*_{A}* 且 Φ ∈ *A*，则 ∧Φ ∈ L*_{A}*。

L*_{A}* 中的演绎按通常方式定义：若 Δ 是 L*_{A}* 的句子集、φ ∈ L*_{A}*，则 φ 从 Δ 在 L*_{A}* 中的 **演绎**，就是 φ 从 Δ 在 L(ω₁, ω) 中的演绎，且每个公式都在 L*_{A}* 里。若存在这样的演绎 *D*，就说 φ 在 L*_{A}* 中从 Δ **可推演**，记作 Δ ⊢*_{A}* φ。一般地 *D* 不在 *A* 中；要保证演绎能落到 *A* 里，还得给 *A* 加条件。

设 *A* 是可数传递集，L*_{A}* 是 L(ω₁, ω) 的子语言，Δ 是 L*_{A}* 的句子集。称 *A*（或滥用术语，称 L*_{A}*）为 **Δ-封闭的**，如果对 L*_{A}* 的任何公式 φ，只要 Δ ⊢*_{A}* φ，就存在 φ 从 Δ 的演绎 *D* 且 *D* ∈ *A*。可以证明，对 **任意** Δ 都 Δ-封闭的可数语言，只有一阶语言 L，即 *A* = *H*(ω) 的情形。但 J. Barwise 发现，存在可数集 *A* ⊆ *H*(ω₁)，其对应语言 L*_{A}* 不同于 L，却对 **所有** **Σ₁-句子集** Δ 都 Δ-封闭。这种 *A* 叫 **可容许集**；粗略说，它们是遗传有穷集合的扩张，其中递归论——从而证明论——仍然行得通（完整定义见下文 5.1 节）。

由 Barwise 的结果立得

> Barwise 紧致性定理。**设** A **是可数可容许集，** Δ **是** L_{*A*} **的句子集，且在** A **上 Σ₁。若每个满足** Δ′ ∈ A **的** Δ′ ⊆ Δ **都有模型，则** Δ **也有模型。**

这里出现“Σ₁”，说明这个定理是 **递归可枚举** 句子集紧致性定理的推广。

Barwise 紧致性定理另有一个版本，对构造集合论模型很有用。设 ZFC 为策梅洛–弗兰克尔集合论的通常公理集，含选择公理。于是有：

> 5.5 定理。设 A 是可数传递集，使 A = ⟨*A*, ∈ ⨡ *A*⟩ 是 ZFC 的模型。**若** Δ **是** L*_{A}* **的句子集，在** A **中由集合论语言的公式可定义，并且每个满足** Δ′ ∈ **A 的** Δ′ ⊆ Δ **都有模型，则** Δ **也有模型。**

最后给出一个简单应用。设 *A* = ⟨*A*, ∈ ⨡ *A*⟩ 是 ZFC 的模型。ZFC 的模型 *B* = ⟨*B, E*⟩ 叫 *A* 的 **真端扩张**，如果 (i) *A* ⊆ *B*；(ii) *A* ≠ *B*；(iii) *a* ∈ *A, b* ∈ *B*，*bEa* ⇒ *b*∈*A*。也就是说，ZFC 模型的真端扩张是一种真扩张，其中没有“新”元素跑到任何“旧”元素“前面”。作为 5.5 的应用，我们证明

> 5.6 定理。每个可数传递 ZFC 模型都有真端扩张。
>
> 证明。设 *A* = ⟨*A*, ∈ ⨡ *A*⟩ 是 ZFC 的传递模型，L 是集合论的一阶语言，为每个 *a* ∈ *A* 加名称 a，再加额外常项 c。设 Δ 由下列 L*_{A}*-句子组成：
>
> - ZFC 的所有公理；
> - c ≠ a，对每个 *a* ∈ *A*；
> - ∀*x*(*x* ∈ a → ∨_{*b*∈*a*} *x* = b)，对每个 *a* ∈ *A*；
> - a ∈ b，对每个 *a* ∈ *b* ∈ *A*。
>
> 容易证明，Δ 是 *A* 的子集，且在 *A* 中由集合论语言的公式可定义。而且，每个满足 Δ′ ∈ *A* 的 Δ′ ⊆ Δ 都有模型：使 a 出现在 Δ′ 中的所有 *a* ∈ *A* 构成集合 *C*，既然 Δ′ ∈ *A*，就有 *C* ∈ *A*；于是把 c 解释为（必然非空的）*A − C* 的任一成员，*A* 就是 Δ′ 的模型。因此 (5.5) 蕴涵 Δ 有模型 ⟨*B, E*⟩。把每个常项 a 解释为元素 *a* ∈ *A*，⟨*B, E*⟩ 就是 *A* 的真端扩张。证毕。

读者很快会看出，一阶紧致性定理得不出这个结果。

### 5.1 可容许集概念的定义

非空传递集 *A* 叫 **可容许的**，如果满足下列条件：

1. 若 *a, b* ∈ *A*，则 {*a, b*} ∈ *A* 且 ∪*A* ∈ *A*；
2. 若 *a* ∈ *A* 且 *X* ⊆ *A* 在 *A* 上 Δ₀，则 *X* ∩ *a* ∈ *A*；
3. 若 *a* ∈ *A*，*X* ⊆ *A* 在 *A* 上 Δ₀，且 ∀*x*∈*a*∃*y*(<*x*,*y*> ∈ *X*)，则存在 *b* ∈ *A*，使 ∀*x*∈*a*∃*y*∈*b*(<*x*,*y*> ∈ *X*)。

条件 (ii)——**Δ₀-分离模式**——是策梅洛分离公理的限制版。条件 (iii)——替换公理的类似弱化版——可叫 **Δ₀-替换模式**。

很容易看出：若 *A* 是传递集，且 ⟨*A*, ∈ | *A*⟩ 是 ZFC 的模型，则 *A* 可容许。更一般地，从 ZFC 删去幂集公理，结论仍成立，所以 *H*(ω) 与 *H*(ω₁) 都可容许。只是后者不可数，Barwise 紧致性定理用不上。

## 6 历史与文献评论

第 1、2 节。无穷命题语言与谓词语言，似乎最早明确见于 Scott 与 Tarski [1958]、Tarski [1958] 的论文。L(ω₁,ω) 及其他无穷语言的完全性定理由 Karp [1964] 证明；L(ω₁,ω) 的 Hanf 数计算最早由 Morley [1965] 做出；有穷量词语言中良序不可定义，由 Karp [1965] 与 Lopez-Escobar [1966] 证明；L(ω₁,ω) 的插值定理由 Lopez-Escobar [1965] 证明，其 Scott 同构定理由 Scott [1965] 证明。Negri [2021] 把源于拓扑斯理论的几何逻辑思想推广到 L(ω₁,ω)。

Karp 的部分同构定理最早在 Karp [1965] 中证明，另见 Barwise [1973]。结果 (2.2) 见 Chang [1968]，(2.3) 见 Ellentuck [1976]，(2.4) 见 Bell [1981]。

第 3 节。结果 (3.2)、(3.3) 归功于 Hanf [1964]，Lopez-Escobar [1966] 与 Dickmann [1975] 有所改进；(3.4) 由 Tarski 证明；(3.5) 归功于 Scott [1961]，(3.6) 归功于 Bell [1970]、[1972]，(3.7) 归功于 Bell [1974]。可测基数最早由 Ulam [1930] 与 Tarski [1939] 考虑；可测基数弱紧致这一事实，见 Tarski [1962]。

第 4 节。关于 L(ω₁,ω₁) 的不可定义性定理。Carol Karp 说（1964, 166）：“1960 年斯坦福大学国际逻辑、方法论与科学哲学大会上，Dana Scott 散发了一份证明纲要，证明除等号外再加单个二元谓词符号的 (γ+, γ+) 语言，不可能有完全可定义的形式系统。”Scott 从未发表该结果，完整详细的证明最早见于 Karp [1964]。本文处理该定理的路线，依据 Dickmann [1975] 的论述。

第 5 节。本节结果的原初动机来自 Kreisel：他在 [1965] 指出，仅凭“长度”挑无穷公式没有过硬理由，提议改用可定义性或“封闭性”判据。Barwise [1967] 极为成功地接过了这个建议，其紧致性定理就在那里证明。可容许集概念归功于 Platek [1966]；定理 (5.6) 取自 Keisler [1974]。

无穷语言的进一步阅读，见 Aczel [1973]、Dickmann [1975]、Karp [1964]、Keisler [1974]、Makkai [1977]；无穷语言与大基数之间联系的有用论述，见 Drake [1974] 第 10 章。
