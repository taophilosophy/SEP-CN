# 进化认识论 evolutionary (Michael Bradie and William Harms)

*首次发表于 2001 年 1 月 11 日；2020 年 1 月 21 日实质修订。*

进化认识论是一种自然主义的认识论进路，它强调自然选择在两个首要角色上的重要性。在第一个角色中，选择是我们的感官与认知机制之可靠性的产生者与维持者，也是这些机制与世界之间“契合”的产生者与维持者。在第二个角色中，试错学习与科学理论的进化被理解为选择过程。

## 1 历史、问题与议题

传统认识论植根于柏拉图与古代怀疑论者。一条线索出自柏拉图对区分知识与真信念这一问题的兴趣。他的解决方案是提出：知识有别于真信念，在于知识得到了辩护。古代怀疑论者抱怨说，提供任何这类辩护的一切尝试都存在无可救药的缺陷。另一条线索出自对人类知识的一种重构尝试，即展示人类知识的各个部分如何在一种相互支持的结构中彼此契合。这一事业在现代打上了笛卡尔的印记，既有经验主义版本也有理性主义版本，二者又都可以采取基础主义或融贯主义的取向。两条线索由一个共同主题编织在一起：把人类知识的重构维系在一起的，是那些使我们能够区分知识与真信念的辩护关系与证据关系。

传统进路以下述假定为前提：认识论问题必须在不预设任何特定知识的方式下得到回答。其论证是：任何这类诉诸都显然是在乞题。这类进路可以恰当地标记为“先验的”。

19 世纪的达尔文革命提示了另一种进路，由杜威与实用主义者率先探索。人类作为进化发展的产物，是自然存在者。他们知识与信念的能力同样是自然进化的产物。就此而言，有理由怀疑：认识作为一种自然活动，可以且应当沿着与其身份相容的路线来处理与分析，即用自然科学的方法。按这一观点，科学与认识论之间不存在截然分明的分工。特别是，进化生物学与心理学等特定科学的成果，并不被先天地排除在认识论问题的解决之外。这类进路一般称为自然主义认识论，无论其是否直接受进化考量的驱动。那些直接受进化考量驱动、并主张知识之增长遵循生物学进化模式的进路，称为“进化认识论”。

进化认识论是从进化的观点出发处理知识理论问题的尝试。进化认识论部分地在于运用取自进化生物学的模型与隐喻，以刻画并解决认识论与概念变迁中产生的问题。随着学科共同进化，模型被来回借用。因此，进化认识论也包括通过我们关于概念变迁与理论发展的理解所得的模型来解释生物进化如何进行的尝试。“进化认识论”一词由唐纳德·坎贝尔（1974a）创造。

### 1.1 认识机制之进化（EEM）与理论的进化认识论（EET）

有两个相互关联但彼此不同的纲领都以“进化认识论”为名。一个聚焦于动物与人类认知机制的发展。这涉及把生物进化理论直接扩展到动物的这样一些方面或特质——它们是认知活动的生物学基质，例如大脑、感觉系统、运动系统等。另一纲领试图用取自进化生物学的模型与隐喻，来说明观念、科学理论、认识规范乃至文化的一般进化。两个纲领都植根于 19 世纪的生物学与社会哲学，即达尔文、斯宾塞、詹姆斯等人的工作。此后多年间已有许多尝试对这两个纲领作细致发展（见 Campbell 1974a, Bradie 1986, Cziko 1995）[^bradie-1986][^campbell-1974a][^cziko-1995]。当代进化认识论的许多工作源自康拉德·洛伦茨（1977）、唐纳德·坎贝尔（1974a 等）、卡尔·波普尔（1972, 1984）与斯蒂芬·图尔敏（1967, 1972）的工作。

这两个纲领被标记为 EEM 与 EET（Bradie 1986）。EEM 是那个试图为认知结构的发展提供进化说明的纲领的标签。EET 是那个试图通过诉诸相关生物学考量来分析人类知识与认识规范之发展的纲领的标签。其中一些尝试以选择主义的模型与隐喻来分析人类知识的增长（如 Popper 1972, Toulmin 1972, Hull 1988；对这类努力的批评见 Renzi and Napolitano 2011）[^hull-1988][^popper-1972][^renzi-2011][^toulmin-1972]。另一些则主张认识规范与方法论的生物学奠基，但回避把人类知识之增长本身作 **选择主义** 的建模（如 Ruse 1986, Rescher 1990）[^rescher-1990][^ruse-1986]。

EEM 与 EET 纲领相互关联但彼此不同。一个关于认知脑结构之发展的成功的 EEM 选择主义说明，本身并不为把此类模型外推到理解人类知识系统的发展提供任何保证。同样，支持一个关于人类知识系统如何增长的 EET 选择主义说明，本身也不保证得出结论说：涉及认知的特定或一般的脑结构，是旨在增强认知能力的自然选择的结果。两个纲领虽然在设计上相似、并使用相同的模型与隐喻，却并不共存亡。

### 1.2 个体发生与系统发生

生物发展既涉及个体发生也涉及系统发生的考量。因此，特定特质的发展——例如人类可对握的拇指——既可以从该特质在个体生物体中的发展（个体发生）来考察，也可以从该特质在人类谱系中的发展（系统发生）来考察。知识与认识机制的发展呈现出一个平行的区分。我们可以考察个体的知识储备与认识规范或个体大脑的增长（个体发生），也可以考察人类知识跨世代的增长、认识规范的建立或人类谱系中大脑的发展（系统发生）。EEM/EET 的区分横跨这一区分，因为我们关涉的既可能是脑的个体发生或系统发生，也可能是规范与知识储备的个体发生或系统发生。人们也许会预期：既然当代正统观点认为个体发生的生物学过程不同于系统发生的选择过程，各进化认识论也会反映这一差异。然而颇为奇怪的是，它们大体上并不如此。例如，Edelman（1987）与 Changeux（1985）提出的“神经达尔文主义”理论，对大脑神经结构的个体发生发展给出了一种选择主义说明。卡尔·波普尔关于人类知识发展的猜想与反驳模型，是选择主义说明的一个著名例子，它既被应用于个体知识的个体发生增长，也被应用于科学知识的跨世代（系统发生）进化。B. F. 斯金纳的操作性条件反射理论处理个体行为的个体发生，明确以达尔文的选择主义模型为基础（Skinner 1981）[^skinner-1981]。

### 1.3 描述性进路与规范性进路

第三个区分关涉认识论与人类知识增长的描述性进路与规范性进路。传统上，认识论被理解为一项规范性事业，其目标是澄清并辩护关于知识、基础、证据担保与正当性的诸种构想。许多人论证，EEM 纲领与 EET 纲领都与严格（即传统）意义上的认识论毫无关系。这一主张的根据是：严格理解的认识论是一门规范性学科，而 EEM 与 EET 纲领关涉的是为认知能力或知识系统的进化建构因果的与发生学的（即描述性的）模型。据称，任何这样的模型都不能对规范性认识论作出重要贡献（如 Kim 1988）[^kim-1988]。这一抱怨的力度，取决于人们如何理解进化认识论与该传统的关系。

描述性认识论与传统认识论的关系有三种可能的构型。(1) 可以把描述性认识论理解为传统规范认识论的竞争者。按这一观点，二者试图处理同样的关切并提供相互竞争的解答。Riedl（1984）为这一立场辩护。对这类进路的一个标准反驳是：描述性的说明不足以公正对待规范方法论中的规范性要素。一种进化进路对传统认识论与哲学问题之解决的贡献大小，取决于人们采纳哪一种进路（参 Dretske 1971, Bradie 1986, Ruse 1986, Radnitsky and Bartley 1987, Kim 1988）[^bradie-1986][^dretske-1971][^kim-1988][^ruse-1986]。(2) 可以把描述性认识论看作传统认识论的后继学科。按这一读法，描述性认识论不处理传统认识论的问题，因为它认为这些问题不相干、无法回答或乏味。许多自然化认识论的辩护者属于这一阵营（如 Munz 1993）[^munz-1993]。(3) 可以把描述性认识论看作与传统认识论互补。这似乎是坎贝尔的观点。按这一分析，进化进路的功能是提供关于认识机制的描述性说明，而把认识论的规范性方面留给更传统的进路。往好处说，进化分析的作用是排除那些不合理性的、或与人类理解的进化起源不一致的规范性进路。

### 1.4 未来前景

EEM 纲领背负着系统发生重建所特有的种种不确定性：这个或那个器官或结构是否是一种适应？若是，为了什么？此外，还有因大脑与感觉器官发展的化石记录必然稀少而产生的不确定性。EET 纲领的问题更多。虽然“进化在我们的思维器官上留下的印记影响我们所想的内容与方式”这一想法足够合理，但这一影响是否直接、是否显著、是否可探测，却全然不清楚。那些把“试错”方法论当作理解科学变迁之恰当模型的选择主义认识论，并不是“大脑及其他辅助器官是主要在自然选择影响下进化而来的适应”这一接受的分析后承。这类选择主义模型的可行性是一个经验问题，依赖于充分模型的发展。Hull（1988）的模型——如他本人所承认——只是朝那个方向迈出的第一步。Cziko（1995）是一份敦促发展这类模型的宣言（另见 Harms 1997 的进化博弈论建模进路）[^harms-1997]。要支撑这条研究路线，还需要大量艰苦的经验工作。沿着 Ruse（1986）路线的非选择主义进化认识论面临另一系列困难。仍有待表明：任何生物学考量都足够有约束力，能以任何有意义的方式收窄潜在方法论的范围。Barham（1990）提出了一种基于“庞加莱动力学”的非选择主义进化认识论进路。另一种进路利用有机体与其环境经由二者之间的辩证互动而共同进化这一事实，导向了“非适应主义”进化认识论的发展（Gontier et al. 2006）[^gontier-2006]。关于进化认识论自然主义转向所面临问题的批判性综述，见 Callebaut and Stotz (1998)。

尽管如此，20 世纪最后二十五年间兴起的、为人类理解提供进化说明的认真努力，具有潜在的激进后果。例如，把选择主义模型应用于人类知识的发展，会立刻产生一种张力。关于科学知识之出现与增长的标准传统说明，把科学看作一项进步的事业：在理性而自由的探究的适当条件下，它产生出一批逐步收敛于真的知识。而生物进化的选择主义模型一般被理解为非进步的，或至多是局部进步的。生物进化产生的不是收敛而是多样性。波普尔的进化认识论试图二者兼顾，却兼顾得颇为勉强。库恩的“科学革命”说明试探性地借用达尔文模型，但在受到批评后即行退却（参 Kuhn 1962 第 172 页以下，与 Lakatos and Musgrave 1970 第 264 页）[^kuhn-1962][^lakatos-1970]。图尔敏（1972）是值得一提的例外。按他的说明，理性概念纯粹是“局部的”，其自身也处于进化之中。这转而似乎蕴含着必须放弃科学探究中任何“目标指向”的观念。这是一个很少有人接受的激进后果。走认识论的进化进路，会引出关于知识、真理、实在论、正当性与理性这些概念的根本问题。

### 1.5 扩展圈子

虽然坎贝尔与波普尔都指出了人类知识的进化与非人类有机体知识的进化之间的连续性，进化认识论的早期工作大多聚焦于人类境况。然而，心理学家、认知动物行为学家、认知神经科学家与动物行为学家的晚近经验研究表明：无论灵长类还是非灵长类，动物的认知能力都远比先前猜测的复杂（Panksepp 1998, Heyes and Huber 2000, Rogers and Kaplan 2004, Lurz 2011, van Schaik 2010）[^heyes-2000][^lurz-2011][^panksepp-1998][^rogers-2004][^schaik-2010]。从进化视角看，鉴于一切动物共有进化遗产，这并不奇怪。认真对待达尔文，意味着依据我们对其他物种成员认知能力日益增长的了解，重新考虑与重估人类知识的本性。此外，一旦关于动物认知能力之范围与限度的稳固经验基础得以确立，我们将能够重估我们对动物心灵生活以及它们的认识地位与道德地位的哲学评价。进一步的野外研究有望彻底变革我们对“人类是动物之一”这一说法的理解。

康拉德·洛伦茨研究所的 KLI Theory Lab 出版一份专门讨论进化认识论议题以及生物学理论其他应用的期刊，[*Biological Theory: Integrating Development, Evolution and Cognition*](http://www.kli.ac.at/journal/)。

## 2 形式模型

每一项科学事业都需要形式与半形式的模型，以便对其研究对象作定量刻画。把哲学的知识研究改造成一门把知识当作生物学现象来处理的科学学科，这一尝试也不例外。进化认识论的许多文献关涉如何把知识构想为一种自然现象、这会如何改变我们对自己在世界中位置的理解，以及如何回应针对这项事业的种种异议。此外，还有一些更技术性的方案，试图为自然主义认识论提供必要的理论工具。

### 2.1 静态优化模型

在最简单的模型中，一个生物体须应付具有两种状态 $S_1$ 与 $S_2$ 的环境，并有两种可能的反应 $R_1$ 与 $R_2$。我们假定生物体在各状态下的所作所为会影响其适合度。适合度通常用矩阵 $W$ 来刻画。

矩阵的各元素 $W_{ij}$ 是反应 $i$ 在状态 $j$ 下的适合度后果。例如，$W_{21}$ 表示 $R_2$ 在 $S_1$ 中的适合度后果。若令 $W_{11}$ 与 $W_{22}$ 等于 1、$W_{12}$ 与 $W_{21}$ 等于 0，则在 $S_1$ 中执行 $R_1$、在 $S_2$ 中执行 $R_2$ 就有明显的进化优势。

然而，生物体必须首先探测环境的状态，而探测器一般并不完全可靠。如果生物体自动对探测器作出反应，我们可以用“给定状态时反应的概率”来刻画探测器的可靠性。把给定 $S_1$ 时 $R_1$ 的概率写作 $\Pr(R_1 \mid S_1)$。据此可以算出：只要下列不等式成立，对探测器作反应就比总是选择 $R_1$ 或 $R_2$ 更有优势（参 Godfrey-Smith 1996）[^godfrey-smith-1996]：

$$ \frac{\Pr(R_2 \mid S_2)}{1-\Pr(R_1 \mid S_1)} \gt \frac{\Pr(S_1)(W_{11}-W_{21})}{(1-\Pr(S_1))(W_{22}-W_{12})} $$

这个简单的模型表明，灵活反应是否适应，取决于这些反应所造成的适合度差异的具体特征、环境各状态的概率，以及探测器的可靠性。这一具体结果是在假定探测环境状态与灵活反应系统在进化上没有成本的条件下计算的。更完整的分析会把这些因素的成本计入。

像上面勾画的静态优化模型可以通过多种方式扩展。最明显的做法是增加环境状态与生物体反应的数目，但还有其他更有意思的修改。例如，信号检测理论以更细致的方式为探测器与线索建模。在一个例子中，一种“海苔藓”经由化学线索探测掠食性海蛞蝓的存在，并以长出尖刺作回应，而长刺是有代价的。这里的线索——水传播的化学物质——有各种浓度，指示不同程度的危险。信号检测理论使我们能够算出探测器长刺的最佳阈值。

静态模型以适合度的代价与收益来描绘进化过程。它们之所以是静态的，在于它们并不为任何实际过程建模，而只是计算不同情形下变化的方向。适合度高，某类型就增加；低则减少。当适合度相等时，种群比例保持稳定平衡。动态模型通常运用静态模型所涉及的那类计算，来描绘种群比例随时间的实际变化。动态模型不是计算变化是否发生、朝什么方向发生，而是追踪变化。

### 2.2 种群动力学

种群动力学，有时称“复制者动力学”，提供了一条可行的途径来为种群在各种选择压力下随时间的演化建模，这些选择压力可以由静态优化模型来刻画。这常常是必要的，因为这类种群的动态往往难以纯凭收益差异的静态考量来预测。所谓“复制者动力学”由 Taylor and Jonker（1978）命名，由 Schuster and Sigmund（1983）与 Hofbauer and Sigmund（1988）加以推广。其源头可追溯到 R.A. 费希尔在 1920 与 1930 年代的开创性工作。这一推广涵盖了种群遗传学、进化博弈论、生态学以及前生物进化研究中所用的进化模型。这些模型既可以在数学上实现，也可以在计算上实现，并且可以为分步（离散）的或连续的进化变化建模。

种群动力学为种群演化建模。种群是个体的集合，个体按类型分类。在遗传学中，类型是基因；在进化博弈论中，类型是策略。认识论模型中关涉的类型，是认知装置的类型或认知策略——回应环境线索的方式、操控表征的方式等等。粗略地说，EEM 模型聚焦于遗传的，EET 模型聚焦于习得的。种群的进化由种群内各类型相对频率的变化构成。选择——以差别的繁殖成功为典型——表述如下。每个类型有一个增长率或“适合度”，记作 $w$，还有一个频率，记作 $p$。类型 $i$ 在下一代的频率 $p'_i$，就是旧频率乘以其适合度、再除以种群的平均适合度“$\overline{w}$”。

$$p'_i = p_i \cdot w_i \frasl \overline{w} $$

除以 $\overline{w}$ 起到“归一化”频率的作用，使每个频率乘以其适合度后加起来仍等于 1。它也清楚地表明：只要某类型的适合度高于当前种群平均值，其频率就会上升。

#### 适合度

适合度——应被理解为驱动大种群动态的各种可能增长因素的聚合——可能取决于多种因素。适合度要素不同于变异要素之处在于：它们按与种群频率成比例的方式影响频率，也就是说，以相乘的方式起作用。生物进化中的适合度要素包括死亡率和繁殖率。在文化进化中，它们包括传递概率与拒斥概率。无论在哪一类模型中，要紧的都是适合度如何随模型内其他变化因素而变化。在最简单的情形中，适合度是固定的，适合度最高的类型必然支配种群。在更复杂的情形中，适合度可能取决于可变因素，例如与谁博弈，或可变环境的状态。最常见的做法是用上面那样的收益矩阵来计算可变适合度。一般而言，要计算某类型的期望适合度，就把该类型在每种情形下的适合度乘以种群中个体遭遇该情形的可能性，再把所得的乘积相加。

$$ w_i = S_A \Pr(A)\cdot W_{iA} $$

其中 $W_{iA}$ 是类型 $i$ 在情形 $A$ 中的适合度。这类计算假定各种情形的效应是可加的。当然可以为更复杂的情形建模，但可加矩阵是标准做法。不过应当注意，由矩阵驱动的进化可以表现出相当复杂的行为。例如，仅四个策略就可能出现混沌行为（Skyrms 1992）[^skyrms-1992]。

有些关系可以不用矩阵来表示。例如，Boyd and Richerson（1985）关注文化中一种特殊的频率依赖的传递偏倚：常见本身带来优势，因为模仿者“入乡随俗”。在这种情形下，类型的有效适合度就是按通常因素算出的适合度，再作为该类型频率的函数加以修正。

#### 连续性与计算

复制者动力学的概念基础相当直白。要得到结果，通常需要两种进路之一。要证明超出初等水平的数学结果，通常需要导出动力学的连续版本，其基本形式是

$$ dp_i /dt = p(w_i - \overline{w}) $$

其中适合度照常计算。数学进路已相当多产，尽管大部分理论结果主要适用于种群遗传学。这些结果的汇编以及进化过程数学研究的合理研究生级导论，见 Hofbauer and Sigmund（1988）。

第二种进路是计算性的。随着个人计算机性能的提升，进化模型的计算实现变得日益有吸引力。它们只需要初级的编程技能，而且在所需假定方面通常灵活得多。一般策略是创建一个存放种群频率与适合度的数组，然后编写一系列过程（或方法或函数），它们：

1. 计算适合度；
2. 用新的适合度更新频率；
3. 处理接口细节，例如把种群的新状态输出到文件或屏幕。

然后一个循环反复依次运行这些例程。大多数建模者乐于把源代码放在互联网上，那多半也是寻找源代码的最佳去处。

#### 文化进化的建模

把认知行为理解为进化的产物之所以困难，部分在于其中至少涉及三种很不一样的进化过程。第一，是经由遗传继承的认知与知觉机制的生物进化。第二，是语言与概念的文化进化。第三，是个体一生中发生的试错学习过程。此外，我们有理由同意唐纳德·坎贝尔的观点：要完整地理解人类知识，需要理解这些过程之间的互动。这就要求我们能够为生物进化与文化进化两种过程建模。生物进化已有许多成熟的模型。文化进化则更新颖。

理解文化进化的最流行的尝试，也许是理查德·道金斯（1976）发明的“模因”。道金斯观察到，生物进化的核心在于差别的繁殖。于是，一般的进化就是自我复制实体的各条谱系的竞争动态。按这一观点，文化若要进化，就必须有文化的“复制者”，即其在文化中的差别复制构成文化进化过程的那些实体。道金斯把这些实体称为“模因”，并把它们刻画为感染我们大脑的信息实体，经由我们通常所谓的模仿“从一个头脑跳到另一个头脑”。常见的例子包括传染性的曲调与宗教意识形态。这一进路的主要困难在于如何为基本实体提供界定。基因的同一性条件在理论上可以由染色体上的碱基对序列给出；文化传递的诸项似乎不存在这样一套基本的“字母表”。因此，“模因学”作为进化认识论的候选基础这一事业被搁置，有待对其基本本体论的充分理解。在线期刊 [*Journal of Memetics*](https://web.archive.org/web/20160303201613/http://cfpm.org/jom-emit/) 收有一些关于模因学的早期论文。该刊虽已停刊，既有论文仍可在线获取。对模因式文化进化模型可行性的保留意见，见 Atran (2001) 与 Sperber (2001)。对这一进路的近期辩护，见 Dennett (2017)。

种群模型已被有效地用于为文化传递过程建模。进化博弈论模型经常被主张同时涵盖策略被遗传的过程与策略被模仿的过程。这一应用之所以可能，是因为无须具体规定策略的底层性质，例如策略是应被设想为被复制的“东西”，还是策略所属个体的属性或状态。这有时被称为“流行病学进路”，不过与传染病的类比源于分析所用的定量工具，而非源于关于文化传递底层本体论的任何预设（Sperber 1996, Sperber and Hirschfield 2004）[^sperber-1996][^sperber-2004]。

一些晚近的工作聚焦于生物体修改其环境、从而改变其所面对的选择压力的能力。在有机体—环境互动的经典模型中，生物体通过“嵌入”既有的生态位来适应环境。理查德·列万廷的有机体—环境互动辩证模型强调：生物体在多大程度上“建构”生态位，而不只是迁就环境中已有的那些（Lewontin 1982）[^lewontin-1982]。如今关于生态位建构已有大量文献（尤其见 Laland et al. 2000 与 Odling-Smee et al. 2003）[^laland-2000][^odling-smee-2003]。把这一观念应用于进化认识论问题，采取诉诸文化生态位与认知生态位的形式。文化生态位由生物体——一般而言，在能把拥有文化归于它们的范围内；尤其是人类——相互学习并学习其环境中被建构的文化性改造的能力所创造。对人类而言，这类建构的形式包括语言、教育机构、通信系统以及其他形式的信息操控与传递。认知生态位则由建构环境心理模型的能力所创造，这种能力反过来使生物体——尤其是人类——能够在一生中系统而高效地开发其环境的资源（Pinker 2003, 2010; Whiten and Erdal 2012, Whiten and van Schaik 2007, Laland and O'Brien 2011）[^laland-2011][^pinker-2003][^whiten-2012][^whiten-2007]

### 2.3 多层级进化

进化认识论所涉及的层级，与进化生物学“选择的层级”之争中更常讨论的那种选择的层级颇为不同。在进化生物学中，所讨论的选择“层级”是尺度层级。争论关涉的是：基因是否始终是选择的“单位”或“目标”，或者选择能否发生在更高的层级上，如生物体、群体与物种。而进化认识论所涉及的层级，是行为控制中调节层级的层级。它们包括认知与知觉硬件的遗传基础、概念、语言、技术、信念、偏好等等。注意，在进化认识论的情形中，“层级”与“层级结构”这些词可能是印象式的；往往根本不存在任何清晰的层级排列。

为多层级进化建模，至少已有两种不同的进路。

1. 双重传递模型：Boyd and Richerson（1985）改编遗传学模型，为一个既受遗传进化又受文化进化影响的性状（合作）建模。他们首先表明，在一个迁徙种群中，一种由基因决定的文化传递偏倚可以被选择出来。这一偏倚使习得地方习俗变得更容易，把模仿的可能性提高到超出由行为的频率与可感知价值所决定的水平。一旦这一偏倚到位，其效应就强大到足以压过合作行为所涉及的可感知成本。该模型产生了两个重要结果。第一，它提供了一个新颖的机制，据此合作行为可以在迁徙种群中稳定下来。但更重要的是，它表明文化进化不能纯凭遗传适合度来预测。
2. 多种群模型：Harms（1997）为熊蜂的学习建构了一个多层级的动态种群模型。一方面是传感器类型分布、外显觅食行为与内部觅食偏好的分布，另一方面是环境状态，二者之间的互信息被评估，并与种群状态的平均适合度相比较。结果表明：外显行为中含有的信息可能未被充分利用，而把传感器机制延展适应用于偏好形成，可以促成对该信息的利用。

### 2.4 意义

对真理与正当性的完整描述性说明都需要一种意义理论。一个记号在具有意义之前，谈不上真或假。而且，确定辩护性主张的意义，可能提供一种描述性的正当性理论。可以假定，使一个辩护主张为真的东西，就是该辩护的根据。如果意义是约定性的，那么意义的进化就成为约定进化的一个实例。

约定进化的模型在一个情形中被扩展应用于意义约定。Skyrms（1996，第 5 章）对大卫·刘易斯（1969）关于意义约定的理性选择模型给出了进化论解释。Skyrms 能够表明：在包含全套协调的、反向协调的与不协调的策略的混合种群中，“信号系统”的形成受到强烈的选择。值得注意的是，该模型的结构以及意义约定由此出现并稳定化的选择过程，与露丝·米利肯（1984）给出的意义进化说明大体平行。

在最简单的版本中，模型构造如下：设想有两种事态 $T$、两种行动 $A$ 与两种信号 $M$。各玩家以同等概率处于发送者或接收者的位置。接收者必须纯凭发送者所告诉的来决定怎么做。在这个纯合作版本中，若状态为 $T_1$ 而接收者执行 $A_1$、或状态为 $T_2$ 而接收者执行 $A_2$，则每个玩家得一分。

由于玩家既会当发送者也会当接收者，他们必须对每种情形都有策略。这样的策略共有十六个；我们假定它们或由生物学父母遗传（或习得），或基于以得分衡量的可感知成功而被模仿。策略 $I_1$ 与 $I_2$ 是信号系统：若两个玩家都采用这两个策略中的同一个，他们总能得到收益。$I_3$ 与 $I_4$ 是反信号策略，导致持续的不协调，尽管它们相互对抗时表现良好。所有其他策略都涉及 $S_3, S_4, R_3$ 或 $R_4$，即无论外部状态如何都执行同一行动。

| | **发送者策略** |
| :---: | :-------------------------------: |
| $S_1$ | 若 $T_1$ 发送 $M_1$；若 $T_2$ 发送 $M_2$ |
| $S_2$ | 若 $T_1$ 发送 $M_2$；若 $T_2$ 发送 $M_1$ |
| $S_3$ | 若 $T_1$ 或 $T_2$ 发送 $M_1$ |
| $S_4$ | 若 $T_1$ 或 $T_2$ 发送 $M_2$ |

| | **接收者策略** |
| :---: | :-------------------------------: |
| $R_1$ | 若 $M_1$ 执行 $A_1$；若 $M_2$ 执行 $A_2$ |
| $R_2$ | 若 $M_1$ 执行 $A_2$；若 $M_2$ 执行 $A_1$ |
| $R_3$ | 对 $M_1$ 或 $M_2$ 执行 $A_1$ |
| $R_4$ | 对 $M_1$ 或 $M_2$ 执行 $A_2$ |

| **完整策略** | | | | |
| :------: | :-------: | :---: | :-------: | :-------: |
| $I_1$: | $S_1,R_1$ | | $I_9$: | $S_3,R_1$ |
| $I_2$: | $S_2,R_2$ | | $I_{10}$: | $S_3,R_2$ |
| $I_3$: | $S_1,R_2$ | | $I_{11}$: | $S_3,R_3$ |
| $I_4$: | $S_2,R_1$ | | $I_{12}$: | $S_3,R_4$ |
| $I_5$: | $S_1,R_3$ | | $I_{13}$: | $S_4,R_1$ |
| $I_6$: | $S_2,R_3$ | | $I_{14}$: | $S_4,R_2$ |
| $I_7$: | $S_1,R_4$ | | $I_{15}$: | $S_4,R_3$ |
| $I_8$: | $S_2,R_4$ | | $I_{16}$: | $S_4,R_4$ |

模拟结果表明，几乎所有初始种群分布都会被两个信号系统策略中的一个所支配。当引入更现实的收益时——例如发送者承担成本而非自动分享接收者因对环境作出正确行为而得到的收益——情形会变得更复杂。但即便在此类情形中，最可能的进化进程仍是被某个信号系统所支配。
