# 早期现代印度的分析哲学 Early Modern India, analytic philosophy in (Jonardon Ganeri)

*首次发表于 2009 年 3 月 10 日；2023 年 11 月 5 日实质修订。*

早期正理派（Nyāya）与胜论派（Vaiśeṣika）是两个并行的古老印度哲学传统：前者奠基于乔答摩·足目（Gautama Akṣapāda）约公元 100 年的《逻辑经》（*Nyāya-sūtra*），主要关注逻辑、知识论与论辩理论；后者奠基于迦那陀（Kaṇāda）约公元前 100 年的《胜论经》（*Vaiśeṣika-sūtra*），主要关注存在论。两条传统并流而下，至 11、12 世纪的某个时刻终于合流为一门新学派——“新正理”（Navya-Nyāya），即新的正理派、“新理由”学派（Ganeri 2011）[^ganeri-2011]。名为“新”正理，它实兼收并蓄：既承续古典胜论的形而上学，也承续古典正理的知识论，并将二者推向前进。新正理诸家还锻造出一套精确的技术语言；借这套语言之力，许多传统哲学问题得以澄清和解决。其方法之灵便，连诗学、语言学、法理论等中世纪印度思想的其他领域也乐于取用。学派的奠基之作，是甘格沙（Gaṅgeśa）那部才华横溢、锐意创新的《真理思择摩尼》（*Tattvacintāmaṇi*）。此后学派又发展了约四个世纪，至罗怙那陀（Raghunātha）、贾迦迪沙（Jagadīśa）与迦达陀罗（Gadādhara）的著作而臻于极盛（Ganeri 2014）。然而技术词汇用得越精微，学派就越是难以接近；于是 17、18 世纪出现数部手册与纲要，用浅易语言讲解其基本义理。本文即以其中最成功的一部——阿南跋塔（Annambhaṭṭa）的《理性手册》（*Tarkasaṃgraha*；下称 TS）——连同其自注《明灯疏》（*Dīpikā*；下称 TSD）为据，撮述新正理的哲学原则。此书别号《童蒙迦达陀罗》（*Bāla-gādādharī*），堪称一部“迦达陀罗入门”。它不仅陈述胜论的句义理论（融物理理论、形而上学与心理哲学于一炉），传授新正理体系的知识论、方法论与逻辑技巧，还穿插大量饶有兴味的哲学讨论，读来既令人愉悦又获益良多，是晚期印度分析哲学的一部理想导论（英译本见 G. Bhattacharya 1983；关于该文本的讨论另见 Athalye 1930、Atreya 1948、C. Bhattacharya 1966、Foucher 1949、Shastri 1961）[^athalye-1930][^atreya-1948][^bhattacharya-1966][^foucher-1949][^shastri-1961]。

## 1. 胜论的句义体系

### 1.1 方法论与定义理论

多数正理—胜论文本取两种编排之一：或依传统胜论模式，按次第讨论诸句义及其子类；或依佛教逻辑家陈那（Diṅnāga）所立、甘格沙所承袭的模式，逐一论列各知识来源。《理性手册》独取筏磋衍那（Vātsyāyana，《逻辑经》首位注释者）的分析路数。筏磋衍那有言：

> 此［正理］体系遵循三步程序：列举（*uddeśa*）、定义（*lakṣaṇa*）、考察（*parīkṣā*）。所谓“列举”，是以名指称［所欲分析的］每一对象；所谓“定义”，是举出所名对象区别于其余一切对象的特征；所谓“考察”，则是借助诸量（*pramāṇas*）查明该区别性特征于被定义对象是否恰当（《疏》（*Bhāṣya*），NS 1.1.3 之前）。

这一方法的核心在于定义的运用：定义即被定义者的区别性标记。《理性手册》（TSD 3d）对这一观念作了精炼：它将一类的“定义”界定为与该类共外延的任何特征。以“牛”类为例，其定义性特征是“有垂肉”这一性质。请注意，这并未告诉我们该类的 **本质** 为何——它只是给出一种可供识别的综合症或 **性状**。不妨说，正理论者对定义取“诊断式”而非“本质主义”的理解。“考察”的用意由此显豁：检验所谓定义性性状是否真与待定义之类共外延，抑或有所欠缺——或“过遍”（*ativyāpti*，蔓及被定义项之外的事物），或“不遍”（*avyāpti*，未覆盖被定义项之内的一切事物），或二者兼有。借现代术语说，一个合格的定义性特征必须既是被定义者的必要性质，又是其充分性质。列举—定义—考察这一模式，在《理性手册》一类新正理文本中反复出现，俯拾皆是。

### 1.2 何为胜论的句义体系？

胜论的“句义”（*padārtha*）体系，是要以系统方式为一切存在者的各种类型分类。新正理列出七种对象“句义”：实体（*dravya*）、性质（*guṇa*）、运动（*karma*）、普遍（*sāmānya*）、别异（*viśeṣa*）、和合（*samavāya*）与非存在（*abhāva*）。前六项构成古典句义清单，早在《胜论经》即已具雏形；第七项（非存在）则是后期学派的独特增益。诸类型大多还可细分：实体九种，性质二十四种，诸如此类。

关于这份句义清单，一大问题是：清单背后是否有一条深层结构或组织原则可循。这与另一重要问题相关：句义究竟为何物？《理性手册》以词源分析回答后一问题：“*padārtha*”（句义）一词，即“*pada*”（词）之“*artha*”（义）。其主张是：胜论句义在某种意义上乃是语言结构的形而上学对应物。要使这一主张更精确，一条途径是指明胜论体系与梵语语法之间存在惊人相似（尤其参见 Faddegon 1918）[^faddegon-1918]；另一途径是观察一种独特的论证样式——某类实体、性质等存在的假说，其支持理由是它解释了我们语言实践的某种特征（例如：空间存在，因为它解释了我们对方位词的使用）。

另一条进路是为清单寻找某种纯粹 **先验**（*apriori*）的理据。Athalye（1930: 75）提出过这样一份重构：

> 一个观念或肯定或否定，故观念的外部对象可为“存在”（*bhāva*）或“非存在”（*abhāva*）。“存在”之物又分两类：性质，与性质所居的共同基底。后者即“实体”（*dravya*）。诸性质中，有的共居于多个对象，有的独居于个别事物。前者为“普遍”（*sāmānya*）；后者又可再分：一为恒驻之性质，一为倏逝之性质，即“性质”（*guṇa*）与“运动”（*karma*）。余下两句义——“和合”（*samavāya*）与“别异”（*viśeṣa*）——则是为解释胜论者诸特殊学说而立。

这一对胜论体系的重构并不尽如人意：它倚重“静止性质/倏逝性质”之分，而此分既未获解释，或许还难免循环论证之嫌；且有两个句义全然未获交代。Potter（1977）另给出一个（同样有缺陷的）重构。而细看《理性手册》自己对诸句义的定义，其思路似正是这一进路。《理性手册》的定义如下：

**实体**

（i）分有“实体性”（substance-hood）这一普遍者；

**(ii)**

分有性质者（TSD 3）

**性质**

（i）分有普遍者，而既非实体亦非运动者；

**(ii)**

分有“性质性”（quality-hood）这一普遍者（TSD 4）

**运动**

（i）造成（实体间）连合者；

**(ii)**

分有“运动性”（motion-hood）这一普遍者（TSD 5）

**普遍**

永恒、单一而内居于众多事物者（TS 82）

**别异**

居于永恒实体之中、为之施行别异者（TS 83）

**和合**

既是永恒者、又是一种关系者（TS 84）

**非存在**

［未给出一般定义］

若将这一系列定义读作对句义的 **先验** 重构，则会遇到若干问题：尤其是，“实体”与“性质”的定义似乎互相循环——除非预设实体性之类的普遍者已然在先，而如此一来定义便近乎空洞。我将另行给出一个重构，大体步趋正理—胜论大家优陀耶那（Udayana）（参见 Tachikawa 1981）[^tachikawa-1981]。

## 1.3 清单的深层结构

先把一切事物一分为二：存在者与非存在者，后者对应“非存在”一句义。再取和合为初始的基本关系。给定这一关系，以下三分即可穷尽：

1. 不内居他物，而受他物内居者，
2. 既内居他物，亦受他物内居者，
3. 内居他物，却无任何东西内居于其中者。

我们想让（a）组对应“实体”一句义。可惜胜论者主张整体别于其部分且内居于部分；如此一来，唯一不内居于任何东西的实体便只剩原子实体（胜论者视之与永恒实体相当）。（c）组对应“普遍”：普遍内居于事物（实体、性质、运动）之中，自身却不承载任何内居者。（b）组则收非原子实体、性质与运动。再分此组为二：一类只受普遍内居，一类还受其他东西内居。前者对应“性质”与“运动”——因为实体不但被普遍内居，也被性质、运动乃至其他实体内居。最后还得设法把这一组再切成性质与运动。较传统的正理论者以如下方式守住这一区分：唯运动（性质则否）使其所内居的实体彼此接触（或彼此分离）。然而这诉诸“接触”观念，而接触本身无法用初始关系“和合”来定义。一部分激进的正理论者（尤其是跋萨婆若）干脆主张运动就是一种性质，因为二者属性过于相似。余下的最后一个句义是“别异”（*viśeṣa*）：其成员栖居于永恒实体即极微之中，并使之个体化。要害或在于：其余万物皆由内居于其中的普遍与整体而个体化，而同一实体的两个极微却在一切方面相同。但若对象凭内居者而个体化，则每个极微之内必有什么内居其间、使之彼此有别——即一个“别异”（见 §10.2）。

以上是一个粗略的概略，略去诸多技术细节，意在显示胜论哲学家如何尝试把句义体系立在逻辑原则之上（技术细节的实例见 TSD 3(c)。《理性手册》指出：按胜论学说，实体在受造那一刻不具任何性质，故实体不能定义为性质之基底。）

## 2. 物理实体

### 2.1 五大物理实体

胜论于公认九实之中分出一个五者的子类——地、水、火、风与虚空（*ākāśa*）——名之曰“*bhūta*”（“物理实体”）。*bhūta* 的定义是：分有某一特定可感性质（气味、味、色、触、声）的实体。

最初的想法或许是：五种物理实体与五种可感性质一一对应，每种性质独居一实——气味唯在土，味唯在水，诸如此类（筏磋衍那于 NS 3.1.65–6 处即载有此说）。这或有助理解“五种物理实体”理论的缘起，但人们很快发现：若坚持土不可见，或其颜色永远来自与火的掺杂，则殊难取信（Bhaduri 1947: 133）[^bhaduri-1947]。在《胜论经》及后世文本中，物理实体与可感性质的对应关系要复杂得多，如下表所示：

|   | 气味 | 味 | 色 | 触 | 声 |
| --- | --- | --- | --- | --- | --- |
| 地 | x | x | x | x |   |
| 水 |   | x | x | x |   |
| 火 |   |   | x | x |   |
| 风 |   |   |   | x |   |
| 虚空（*ākāśa*） |   |   |   |   | x |

正统胜论的看法是：每种物理实体的特征，在于分有某一特定类型的可感性质而缺少其他若干性质。于是土即有气味之实，水有味而无气味，火有色而无味亦无气味，如此等等。这类定义有一短处：由检得某一可感性质，并不能推出在场的是哪类实体。故后期胜论转而寻求一套诊断式定义——为每种实体找出一种特定可感性质，其出现即足以指示该实体。《理性手册》（TS 10–14）：

> 地（特有）气味；水（特有）冷触；火（特有）热触；风（特有）无色之触；虚空（*ākāśa*）（特有）声。

如此一来，土、水、火虽皆有触，据说却唯水有冷触。风这一项，看来《理性手册》找不出正面的区别性状，只好退回旧式定义。

十七世纪竟还有人辩护“五大元素”理论，这或许令人诧异。一些现代作者试图把这些实体读作物质诸“状态”的隐喻——固体（地）、液体（水）、气体（风）与温度（火）。然而此说难通：从没有哪处说某一实体能由地转成水再转成风。或许根本不该把这一理论当作物理学；考虑到诸实体皆以其可感性质来定义，我们不如把它看作一项逻辑分析的操演：对诸感官模态所呈现的资料作逻辑分析，以立一个（形而上学的）世界理论。例如，这样的理论会通过设定必有既可见又可触之物类，来解释所见与所触何以相关。同理，触觉感受出现而无相应视觉感受，便引导我们设定有可触而不可见的实体（风）；其余实体，依此类推。说到底，正是不同感官模态之间的这类相关性，奠定了一个客观的世界概念（仅由单一感官通达的现象，更易被认为出于主观）。

### 2.2 胜论原子论

《理性手册》（TS 10–14）复述胜论通行学说：前四实（地、水、风、火）各分两类——原子类与复合类。极微（*paramāṇu*）不可毁（*anitya*）、不可分（即非复合），且具有一种特殊维度，名为“小”（*aṇu*）。胜论者力主原子论的标准论证如下：凡被知觉者皆复合，此乃经验确立之事。故而连最小可见之物——阳光里的一粒浮尘——也有部分，而此部分遂不可见。胜论者称最小可见之物为“三微”（*tryaṇuka*），并谓其含三个部分，每一部分称“二微”（*dyaṇuka*）。那么二微自身可有部分？可有——因为另一条经验真理是：可见之物其部分仍有部分（如布之部分为线，而线亦为复合物）。胜论者遂言：二微含两部分，每一部分即一极微。

这一论证确立了世上有小到不可见的对象，却没有证明其中有些是非复合的。细分何以不能无限进行？《理性手册》的答复颇为耐人寻味：若可无限细分，则须弥山与一粒芥子将一般大小——因为二者将拥有同样（无限多）的构成部分！这里隐含一条前提（其他胜论者曾明确道出）：整体的尺寸是其部分的尺寸、数目与空间排布的函数。

这一论证难免窃取论题之嫌：隐含前提唯有在原子论已获接受时才成立。非原子论者会说，对象的尺寸并非由其构成物决定，而是由构成它的“质料”的空间边界决定。

### 2.3 数目的形而上学（*saṃkhyā*）

新正理的数的学说，就内容与精巧程度而言，堪比弗雷格，也确实引人入胜。《理性手册》只说：数是性质（*guṇa*），数是数目判断的根据，数的范围从 1 直至一个称为 *parārdha* 的极大之数（1014。此处再次见出对无穷观念的疑虑）。“数是性质”一说实出自古胜论，后来被证明与胜论存在论体系的结构不可调和。我们既可说田中有三匹马，也可说胜论体系中有 24 种性质；然而按定义，性质不能居于另一性质之中——故数不能是性质。这一困难促使新正理论者另立一套数的学说，其基础是一种名为 *paryāpti*（“圆足”）的新关系。

下面概述其理论。先看一对句子：

1. 这张桌子有木头的腿
2. 这张桌子有四条腿。

（1）与（2）的相似令人把数词当作一般形容词看待：即给所修饰的对象赋予某种性质。按正理派，在（1）中，“木质”这一性质经由和合关系居于桌腿。那么（2）能否同样分析——视为陈述“四性”这一普遍性质内居于诸腿？新正理（尤其罗怙那陀与贾迦迪沙）答曰不然。试看，（1）蕴涵

1. 每条腿皆是木质的。

但（2）却不蕴涵

1. 每条腿是四。

出路是设定一种新关系——“圆足”（完成）：它 **联合地** 把“四性”关联于四条腿，而非逐条关联于每条腿。罗怙那陀评论道：“‘圆足’关系——其存在由‘这是一只壶’‘这是两个’之类的构造所昭示——是一种特殊的自联结关系。”其注家贾迦迪沙补充道：

> 有人或以为“圆足”关系不过是和合……为此罗怙那陀明言“圆足”是另一种关系……在“这两只是壶”一句中，“圆足”把“二性”关联起来，且把它限定为居于两壶之上的性质。不然便会推出：“这是两个”与“每一只都具二性”并无分别。

依此方案，数性质经由“圆足”这一多对一关系联合地关联于对象。我想可以稍作简化而不失其基本结构。在“火星是行星”一句中，我们不再说“行星性”借和合关系居于火星，而改说谓词“……是行星”对火星为真——相当于把和合关系（或系词）内建于谓词之中。依同理，也可把圆足关系内建于数谓词：数目若为 *n*，该谓词便是一个 *n* 位关系。于是“金星与火星是两个”这句话，是断言金星与火星共同处于某个二位关系之中——这个关系正是数 2。正理派的想法因而是：数形容词乃 *n* 位关系谓词，数则是 *n* 个不同对象之间联合成立的 *n* 位关系。由“关系 2 在金星与火星之间成立”绝推不出“它仅对金星成立”，正如由“*X* 在 *Y* 左边”推不出“*X* 在左边”便完事一样。照正理派的方案，那个麻烦的推理之所以被封堵，是因为其结论根本不合式：“金星是两个”跟“*X* 在左边”一样，是个残缺的、未饱和的表达式。

如前所见，正理派区分和合与圆足两种关系。其动机——用今天的话说——是要说明集体性质与分配性质之别。认识到“这两只是壶”推不出“每只壶是二”，即是认识到谓词“二”并不分配于复数主词。正理派的方案是：把“……是两个”一类集体谓词分析为 *n* 位关系谓词——对 *n* 个对象联合为真——而非聚合体或集合的一元谓词。不过这类关系谓词仍以对象为主词，可见承认分配/集体谓词之分并不迫使我们放弃形容词观点。集体性质，正理派确有专名：谓之 *vyāsajya-vṛtti-dharma*，“联合出现的性质”。

## 3. 空间、时间与运动

### 3.1 空间（*dik*）

《理性手册》论空间与时间之本性，粗略已极，须借其他胜论与正理作者之说补其细节。纵然如此，正理—胜论文本中的时空理论也素少研究，我们眼下只能勾勒一幅粗糙而欠备的图景。《理性手册》关于空间概念的论述如下：

1. 空间是一实体（TS3）
2. 空间是诸如“此在彼之东”一类陈述的“根据”（TS 16）
3. 空间唯一、遍在而永恒（TS16）。
4. 空间是任一结果的工具因（TSD16）。
5. “近”（*aparatva*）与“远”（*paratva*）乃对象的空间性质。

空间被设想为这样一种实体：惟凭它，那些赋以距离与方向的陈述——“*A* 在 *B* 之东”（或“*A* 近于 *B*”、“*A* 距 *B* 较距 *C* 为近”等）——才客观地或真或假。空间因而是一个解释性假设：为解释对象彼此处于空间关系这一事实，必须设定一个新的（空间）实体。难点在于如何理解这一主张。Bhaduri（1947: 216–7）如此处理（下为对其论述的转述）：

> 设想一列对象 *A*、*B*、*C*、*D*、…、*F*，两两相邻相触，排成一行。*A* 在 *B* 之左，*B* 在 *C* 之左；既然“在……之左”是传递关系，则 *A* 在 *C* 之左，余可类推。然而 *A* 与 *B* 相触、*B* 与 *C* 相触，*A* 与 *C* 却未必相触——接触并不传递。故空间地关联对象者，非接触。那是什么？“依胜论，使［*A* 与 *C*］发生关系的是空间：二者皆与空间连合，遂经其中介而彼此连合。空间，就是那把连合关系转化为传递关系的东西”（Bhaduri）。

这一解释有一难处：它假设任意两物之间皆有一串相触的物质对象。但既取此假设，则无须再设定一个万物与之相触的新实体来把接触造成传递关系。因为“在……之左”可以这样定义：*x* 在 *y* 之左，当且仅当有互异的对象 *p*、*q*、*r*、…*t*，使 *x* 与 *p* 相触，*p* 与 *q* 相触，……，*t* 与 *y* 相触。

Potter（1977: 92）将论证再加锤炼。我们说 *A* 距 *D* 较距 *F* 为近，因为 *A* 与 *F* 之间的居间对象多于 *A* 与 *D* 之间者。然而设若 *D* 与 *F* 之间并无物质对象之链，我们何以仍能说“*A* 距 *D* 较距 *F* 为近”？Potter 的回答是：“要为这一比较判断提供解释材料，必须设定一个居间的实体序列，且这些实体必须是空间性的。”请注意：这解释的并非“在……之左”一类方向关系的传递性，而是“近于”一类距离关系的量级——“近于”并非传递关系。它接受“两物之距以居间实体之数来量”这一基本前提，并在物质实体缺席处设定一系列“空间实体”。

此说亦有一难：空间本应是一个单一实体。或许应改口说：两物与空间的某个“片段”相触，而空间片段自有大小。

最妥当的理解或许是：这一论证给出的是对空间分隔的解释，且 **无须** 设定一串中介物体。于是，若 *A* 距 *D* 较距 *F* 为近，而 *A* 与 *D* 之间、*A* 与 *F* 之间皆空无一物，则最佳解释是：*D* 所触的空间部分比 *F* 所触者更近。

《理性手册》称空间“遍在”（*vibhu*），并定义为“与地、风、火、水（及‘意’）的每一份样品相触”（TS14）。于是生一问：空间之维究竟无限，抑与宇宙同大？若空间以物理对象间关系来定义，则似应与宇宙同大。然而胜论自有论证空间无限者。胜论者说：大多数物体之维，或“长”（*dīrgha*）或“短”（*hrasva*）（TS25，Bhaduri 1947: 118）[^bhaduri-1947]；而一物之维若非有作为边界的周边部分，则其“长”“短”不可理解。空间却无部分，故无边界。于是一些胜论者断言空间没有有限之维（即无限）；另一些则谓其有一种名为“*paramadīrgha*”（“极大长度”）的特殊之维。

### 3.2 时间（*kāla*）

《理性手册》论时间：时间乃过去、现在、未来诸陈述之根据；它唯一、永恒而遍在；它是一切之容器，亦是每一结果的工具因（TS15+D）。时间概念映照空间概念：“甲早于乙”一类陈述，惟凭时间而客观地或真或假。据说时间在如下之点上有别于空间、因而不与之同一：空间之远近因人而异，时间之远近则人人相同（参见 Bhaduri 1947、Mohanty 1992）[^bhaduri-1947][^mohanty-1992]。但我们的注意力为何要仅限于现下存在的人？

《逻辑经》中，乔答摩提及一个否定“现时”可能性的论证，与龙树反运动诸论证惊人地相似（或者竟源自后者）。NS 2.1.39（意译）：并无“现时”其物——物坠向地面时，其下落轨迹上的每一点，或属已过之段，或属未至之段；故轨迹上无一点可归诸现时。现时不过是过去与未来之间想象中的分界点。乔答摩如此作答（NS 2.1.40–42）：（i）“过去”“未来”诸概念相对于“现在”概念，而非彼此相对；（ii）否认现在则生出荒谬后果——知觉既在现在中运作，便将一无所知。（i）的要旨或许在于：现在纵然只是一条边界，也并不因此即属想象。

### 3.3 胜论动力学理论：运动的本质与原因

自普拉夏斯塔帕达（公元 6 世纪）以降，早期胜论诸家对抛射体与其他运动物体之行为，显出理性而科学的兴味。其理论堪与菲洛波努斯的“冲力”说对读——后者曾引发西方科学思想的一场范式转移。《理性手册》所论与普拉夏斯塔帕达已有之说大体相合，而后者部分可溯至《胜论经》本身。相关诗节的内容可撮要如下：

> 运动乃连合与分离之非内居因。运动有五：四者属意志（上抛、下掷、收缩、扩张），其五则统摄一切非意志运动（下落、旋转、流动等）（TS 5, 81）。
>
> 重性（*gurutva*）乃物体初始下落运动之非内居因（TS 30）。
>
> 液性（*dravatya*）乃（初始？）流动之非内居因（TS 31）。

“冲力”（*vega*）是一种倾向属性（*saṃskāra*），“弹性”（*sthitisthāpaka*）亦然（TS 80）。“冲力”是物体第二次及其后诸次下落运动的非内居因（TS 30）。弹性者，物受扭曲后使之复归原状者。

兹将此论撮要如下。运动物体在每一时刻都具有一种特定的“运动”，此“运动”须想作物体瞬时性的、类似性质的性质。运动被定义为连合或分离之因。与（静止）物体之连合，由空间位移带来。故物体之运动，或即其两个时刻之间的空间位移本身，或为该位移之因。运动不能由另一运动致动（否则将陷于永恒运动）。物体之起动，由于其分有“重性”“液性”一类性质；其持行，则由于分有一种倾向属性——“冲力”或“弹性”——它是其后诸运动的持续之因；其止息，则由于与他物相触。

“冲力”在此说中的地位尤其耐人寻味。以两例明之：（i）自树上坠落之果实；（ii）斜掷向上之标枪。

1. 设时刻 *t*₀ 果实静止于位置 *s*₀，其重量与果柄之接触相抵。至 *t*₁，果柄折断，重量使其移至点 *s*₁；与此同时，果实中生出一种倾向性的“冲力”。至 *t*₂，果实中的冲力引发第二次运动，自 *s*₁ 至 *s*₂；其后诸时刻，依此类推。请注意：果实的“重量”是其初始运动之因，然随即失效；此后一切运动之因，是最初运动注入果实的“冲力”。正因这一观念——果实之续行非外力所致，而系内注之 *vega*——我们才有资格称胜论之说为冲力说。
2. 标枪掷出之际，最初的意志性推动将一份初始运动与一份冲力注入枪身。向上之冲力抗其重量，引发向上运动；此冲力因与空气接触而耗尽，重量遂注入一份向下之冲力，标枪乃坠。其水平运动由水平冲力所致，而此冲力亦因与空气接触而递减。标枪最初所得冲力之量，与所施意志推动成正比。仍是同一要点：标枪之持续飞行，系于其持有冲力，而非外力之作用。

胜论者将此模型推广以解释另一些运动。（1）据称，水流之初始因出自一种名为“液性”之力（而非水之重量）；其后续流动，则是水所获冲力之果。（2）耐人寻味者：直线运动物体之冲力，被认为在本体论上与弯棍之弹性同属一类——此足见冲力被想作一种内力，而非惯性。（3）胜论者另举诸种运动：铁针趋向磁石、火焰上腾、空气流动，以及创造之始极微的初始运动。按上述模型，诸运动之初必有一“力”引发之；然迄今所分离出的“力”（重性/重力、液性、弹性）皆不足以当之。故胜论者另立一力——“*adṛṣṭa*”（“不可见”之力）——据称可解释此类运动。

## 4. 自我：人与神

胜论九实之第八为“自我”（*ātman*），定义为相信、认知等心灵状态的基底。（第九实为“意”（*manas*），乃心灵存在论中一独特要素。）自我分两类——命我（*jīva*）与最高我（*paramātman；īśvara*）。《理性手册》为两类自我的存在都给出了论证（皆可上溯至更早的作者）。

### 4.1 神存在的一个因果论证

一个合式的正理论证含三个成分：宗、因（*hetu*）与喻例（*dṛṣṭānta*）。宗又含两分：推理的“处所”（*pakṣa*），与一所立性质（*sādhya*）——有待推断其现于处所者。故每一正理论证皆呈同一格式：*p* 有 *S*，因其有 *H*；例如 *d*。（例：“山（= *p*）有火（= *S*），因其有烟（= *H*）；例如厨（= *d*）”。详 §8）。合理论证至少须满足三条：（i）因性质须无可争议地现于处所；（ii）因性质与所立性质须适当关联——大略即因所在处，所立必在；（iii）喻例须是一处因、所立二性皆在而无争议之地。

心怀此则，且看《理性手册》论神存在之证：

> 地等二微有作者，以其为果故；例如壶（TSD 17b）。

此处推理的处所是二微——最小的复合实体。因是“果性”（*kāryatva*），所立是“有作者性”（*kartṛ-janyatva*）。《理性手册》细释“作者”之义：所谓作者，乃非推断地觉知待造之物之和合因或质料因、怀造之之欲、且依之而行者。在此意义上，唯陶工——而非陶轮、陶土或任何其他因果相关者——是壶之作者：唯陶工见陶土（= 壶之质料因），怀造壶之欲，并操轮持棍而行。

评注：（1）《理性手册》何以取二微为推理处所？此实为妙着。显然，处所不可取神（如“神存在，因为……”）——否则合理论证第一条即不满足：无论因性质为何，皆不可能无可争议地现于一个存在本身有争议的处所。处所亦不可取“世界中的一切”——其中许多并非果（如极微、空间），《理性手册》所求之因又将不能明确无疑地现于处所。故必须择一特定之物。人造物则不宜取——如此即使推理健全，也确立不了关于神的任何东西。于非人造物一类中，取二微为佳：（a）二微乃极微所成之最基本者，余物皆由之而成；（b）《理性手册》若能证二微有作者，则（据作者定义与上述（a））即可推出作者觉知一切。神之全知，遂为其存在证明之系论。

（2）此论证取“陶工—壶”例的因果图景，并将其推广以涵盖一切自然现象。神之职分，是以既定而非受造的原材料（极微，比之于陶土）造物，而原材料即产物之质料因。Matilal 因此称正理派持一种关于神的“陶工模型”，以别于“蜘蛛模型”——彼处神以自身本质纺出世界——亦别于“魔术师模型”——彼处世界是神变出的幻象。然而此论证立基于一种拟人的、行动者式的因果观。佛教法称即以此相讥：壶可比于蚁丘（同为陶土所成）；我们可否说，此公认繁复精巧的构造乃理智行动者之产物？纵使可说，世界为何不能如蚁丘一般为集体行动之产物，而非出于单一行动者之手？

（3）此论证亦可视为一种归纳论证：自人造物一类推及自然产物一类。然则何者授权这一归纳——自曾见其有作者之物，推及未曾如此见过之物？法称（参见 Vattanky 1984: 56–8）[^vattanky-1984]言：唯当吾人见过同类型之他物被造，方有资格推断此物有作者。故可推断金字塔有作者——非因吾人能见其作者，而因金字塔属某类型（建筑），其同类实例吾人曾见其被造。正理论者所立归纳主张更大胆：二物同属一“类型”——在此意义上——若其皆为果。

### 4.2 人我存在的一个论证

胜论定义人我为“相信”等心理性质之基底，亦为快乐及其他情感——神所不具者——之基底。此处同样暗暗诉诸“陶工”因果模型：如“陶工造壶”一句中“……造壶”之性居于陶工，“我相信 *p*”一句中“……相信 *p*”之性亦居于我。自我既被定义为一人诸心理性质所居之实体——不论其为何——则问题便是：此实体能否认作物理实体，如人之身体或诸感官；抑或必须设定某种新型实体。胜论证自我为一种新实体之存在，所用者乃排除二竞争候选者之法。

（1）信念等之基底为人之身体。《理性手册》如此立论：若吾言“我冷”“我在跑”，谓词所施于者，吾身也。故吾言“我相信 *p*”时，主语亦当为吾身。《理性手册》的回应是：若果真如此，则

> 便有此难：手、足等毁，则身毁；随之将推出自我亦毁。

显然，人可失去身体之一部分而仍持其信念与认知。然失身之一部分，不等于失其全身。故此证不立。《逻辑经》中另有一证较佳：“我的身体”一语本身即示吾人与吾身并非同一。然此证亦不灵：吾人亦可言“我的灵魂”！此处并无反对物理主义的明确论证。

（2）信念等之基底为感官官能［试忆：每一物理实体曾分三类——属身体者、属感官者与（无生命）对象者］。此说颇为奇特，或可涵盖佛教徒之观点：人可还原为一串刹那心识事件，感觉材料等亦在其列。《理性手册》反对此种观点的论证（乃《逻辑经》中已有论证之重述）颇为有力：

> 若果真如此，则再认统觉（*anusandhāna*）将不复可能——如“我，曾见彼壶者，今正触之”——盖一人所能认取者，必其自所领受，不能认取他人之所领受。

此处要旨：再认经验之所以可能，预设了一个统一而持存之自我。实为两证合于此处。其一：我无法 **忆起** 一物，除非早先见过——你所见者我无从忆起（比照洛克以记忆经验之连续论人格同一）。其二较曲折：阿毗达磨佛教徒主张人只是经验之聚合，或视觉或触觉等等。正理论者就此诘难：跨模态判断实有可能——以一感官之所得与他者相较。设 *V*(*o*₁) 为对对象 *o*₁ 之视觉经验，*T*(*o*₂) 为对对象 *o*₂ 之触觉经验；则“*o*₁ = *o*₂”之判断可能，而此判断不属任何单一感官之辖域。故必另有一实体为其安放之处。自我于此被想作那个校核、整理并比较诸感官所得者。扩展讨论见 Ganeri 2012 第 11、15、16 章。

于此正宜引入九实之最后一实：“意”（*manas*）。《理性手册》（TS18）定义为第六种感官官能——人借以“知觉”其内在心灵对象（信念、乐受等）者。换言之，即内省之官能。当然，还须论证此官能为何不可归属于自我；正理派通行之说为：自我乃认知之行动者，意乃认知之工具，一如伐木之行动者（执斧者）与砍伐之工具（斧）必须分清。正理派又谓意另有一职：于诸感官官能之间“切换”——其预设为：吾人虽同时受诸官能之感官印象，一次却只注意其一。

《理性手册》（TS 79）：胜论诸性质中有八种唯居于自我，不居他实：认知、忆、乐（*sukha*）、苦（*duḥkha*）、欲（*icchā*）、瞋（*dveṣa*）、功德（*dharma*）与非功德（*adharma*）（TS 73–78）。前二者后文另论（§§ 5.2–3）。至于乐与不乐，Matilal（1986: 301）撮述胜论之说：乐之为乐，其本质特征“在于被体验为有利于我、与我相合——即与吾身、吾心或吾人生存境况相合（*anukūla*）”，故别于认知、知觉或领受某物；又为一种“内在倾向，外间世界因之而宜人可欲”。欲者，渴求某物之状态。功德者，有善德之行为（*karma*）所生者。详见 Ganeri 2012 第 13、14 章。

## 5. 哲学心理学

### 5.1 哲学心理学概观

认知（*buddhi, jñāna, upalabdhi*）之本性、内容与原因的研究，正是正理哲学方法的枢纽。知识论所问者：如何分辨真认知与假认知？真认知缘何而起？逻辑理论所问者：在何种得到恰当阐明的意义上，一认知“跟随”另一认知？语言哲学的预设则是：句法映照认知结构，故探究句义须经由分析句子所“表达”的认知。此题分量之重，于《理性手册》可见一斑：按胜论图式，“认知”在技术上不过二十四种性质之一，其分析却占全书近半（TS 34–74）。

“认知”一词，正理论者用以指称任何意向性的（*sa-viṣayaka*；指向对象）心灵状态：知觉、推断、怀疑、猜测、忆念等皆在其列，欲求、希望、受苦等则除外（参见 Matilal 1968: 7–8）[^matilal-1968]。因吾人说主语“有”此等状态，它们遂被视作灵魂的“性质”（按胜论技术义）。《理性手册》称认知为“一切语言实践之根据”（TS 34），正见其语言观：语言首要是说者向听者传递真思想之工具。

自知识论观之，认知一类中至要之分，在真者与其余者。然而《理性手册》所复述的正理派标准认知分类却始于另一分：忆之认知（*smṛti*）与其余（*anubhava*，非忆性认知）。其完整分类如下：

| 认知 |   |   |   |   |
| --- | --- | --- | --- | --- |
|   |   |   |   |   |
| 非忆性（*anubhava*） |   | 忆（*smṛti）* |   |   |
|   |   |   |   |   |
| 真者（*pramā*） 知觉的 推断的 譬喻的 证言的 | 非真者（*apramā*） 颠倒（*viparyaya*；4 种） 疑（*saṃśaya*） *tarka* |   | “如实”（*yathārtha*） | “不如实”（*ayathārtha*） |

正理知识论实质上是一套关于真的非忆性认知的理论：依产生它们的诸种得到认可的认知凭据（*pramāṇa-s*）分为四类。（碰巧为真的认知——如侥幸猜中——又如何？将其纳入上述图式，向有讨论充分之难题。）显然，无论认知方法总体多么可靠，失误仍可能偶发假认知（知觉错觉、因转述之误而生的信念等）。《理性手册》的例（TS 72）是见牡蛎壳而生的假拟知觉判断“这是一块银子”。知觉、推断与证言的知识论将分别在 §§ 7、8、9 讨论。此处则详察三种认知：忆、“疑”与 *tarka*——它们在正理框架中地位重要，却居于其知识论的辅助位置。（梦置于图式何处？TS 70 谓其属“假”认知一类。此说却颇为奇怪：梦并非四 *pramāṇa* 任一失误之产物，亦非忆或疑。按普拉夏斯塔帕达，梦是“意”未与外感官相连时的自由运动所致，其间受 *adṛṣṭa*（“不可见”之力）影响。）

### 5.2 记忆

西方传统视记忆为个人为其过去信念作辩护的重要凭借。故而，正理派一开局便把忆之状态与生知之信念分开，并否认前者具有知识身份，便格外惹眼。《理性手册》论记忆如下：

> 忆之状态，唯由“心习”（*bhāvanā*）而生（TS 35）。
>
> “心习”乃灵魂之一种性质：由非忆性认知所生，复生忆之认知（TS 80）。
>
> 忆之“真”“假”，一随其源起认知之真假（TS 74）。

一般理论如此：一个初始认知（如对某对象之知觉经验）生成一种倾向性心灵状态；当其他某些因果要素在场时，该状态有能力触发对此对象之主动回忆。（全程可喻如习泳之人：既会游泳，便怀倾向能力，遇特定场合而用之。）由此而生的忆之状态，其内容与源起知觉经验相同；其“真”“假”则是派生的，一视原初知觉是否如实。照此说，记忆被表现为一项绝无差错的官能：所谓“虚假记忆”（无源起经验而有记忆）与“失真记忆”（记忆内容与源起经验不尽吻合）的可能性，全未提及。

依此说，记忆不过是往昔认知经验之重现，故在某种意义上，记忆自身或不算知识——恰如毕加索之精确摹本不复为毕加索。正理论者谓记忆缺乏“独立性”。其意或如此：吾人通常以考察一经验之致成方式来确立其真实性（我于桌之知觉所以如实，因视力佳、光线足等等）；然于记忆，则须经由源起经验。记忆被想作原初经验之单纯替身，其真实性“依赖”于原初者。然而我们或可想：记忆所做其实不止于复现原初经验——它可将所经验之事件表象为过去发生之事，从而别有内容。

### 5.3 疑（*saṃśaya*）

疑之概念于正理派有重要理论地位：据称，疑之状态乃一切哲学探究之必要前提。疑为《逻辑经》1.1.1 所列十六谛之一，此十六谛实定全书内容之大端。尤须注意：疑乃合式推理之第一步——山上可有火？有，以彼处有烟故。《理性手册》予疑以极精确之定义（TS 71）：于同一所别中认取两个不相容之能别，如“这（个隐约所见或远处之物）是人还是树桩？”于是图式化而言，疑即内容形如“*x* 是 *F* 还是 非-*F*？”之认知。

有两点值得一记。（i）疑虽归入非真（*apramā*）认知，却并不假：假认知者，其内容为“*x* 是 *F*”而 *x* 实非 *F*。（ii）疑之所以别于他种认知，在于其内容特殊，而不在于其为一种特殊的命题态度。正理派于此并未说：吾人可对同一命题取诸种态度——信、不信、疑等等。然而若疑之独异仅在其内容取 TS 71 之形，则“*x* 是 *F*”之疑与“*x* 既是 *F* 又非 *F*”之信念，其别安在？跋达摩那之答：分判“实有一个矛盾信念”与“仅相信自己有一个矛盾信念”。前者据称不可能：彼号称矛盾之信念——*x* 既是 *F* 又非 *F*——实为“我有一个信念，其所别为 *x*，其能别为 *F* 与 非-*F*”之信念。既无真正矛盾之信念，亦无与疑同内容之信念。

### 5.4 *Tarka*：“假设性思择”

“*tarka*”一词常泛用作假设推理或归谬推理之义；《理性手册》则予之以远为精确、远为技术性的含义：

> *Tarka* 者，由赋予“所遍充”（*vyāpya*）而赋予“能遍充”（*vyāpaka*）之谓（*āropa*）。例如：“若无火，则无烟”（TS 73）。

此定义诸名目须予疏释。“赋予”（*āropa*）之技术义为“反事实或假设性认知”（*āhāryāropa*）：其能别为一性质，而其对立面已知居于所别。换言之，即一反事实假定。“能遍充”“所遍充”乃正理推理理论之名。凡言“有烟处皆有火”，可重述为：火遍充烟——即“有烟之物”一性之外延，窄于“有火之物”一性之外延。故此处火为能遍充，烟为所遍充。于是 *tarka* 即：在“火缺席”这一反事实假定下，对烟之缺席的认知。它乃对一个条件句的认知——“若 *p* 则 *q*”，或“若 *p* 为真则 *q* 为真”——而假定“*p*”为假。

*tarka* 之主要功能，据称在除疑。设吾有疑“*x* 是 *F* 乎？”，则可判曰“若 *x* 非 *F*，则 *x* 非 *G*”；若又知 *x* 为 *G*，则可推得 *x* 为 *F*。正理论者承认此功能，却仍不认 *tarka* 为一认知凭据（*pramāṇa*）。其理由似在：为论题举正面经验证据，与仅凭先验方法排除反面可能，二者有别。此事或亦见于下情：基于 *tarka* 之论证从不举例以佐其推断。《理性手册》似更进一步，否认反事实条件句为真认知；而反事实条件句既亦非假，便意味着它们没有真值。

优陀耶那谓 *tarka* 有五种：自依（*ātmāśraya*）、互依（*anyonyāśraya*）、循环（*cakraka*）、无穷倒退（*anavasthā*）、有不欲之后果（*aniṣṭāprasaṅga*），即归谬。此五者大意自明——其五“*prasaṅga*”一式，龙树与诸中观论师用之最见功效。他家所列略异（详见 S. Bagchi 1953）[^bagchi-1953]。

## 6. 因果性与知识的因果理论

### 6.1 因果性概观

因果性之研究，印度哲学思想之要目也。其故有二。一在早期对宇宙论思辨之兴趣：“应记印度哲学活动出于《吠陀》与《奥义书》之宇宙发生论思辨；哲学之头等大事，是为复杂宇宙之起源寻一简单而单一之原因”（Matilal 1985: 287）[^matilal-1985]。二在印度语言学（尤以波你尼“作业格”（*kārakas*）体系——动名关系之学——深刻影响正理、弥曼差与佛家诸师）立于一个潜在因果模型：句中动词标示一事，而名词所指之对象各当一特定因果之职，以成此事。同一模型浸润并影响了印度知识论，遂有“量”（*pramāṇas*）之论——通向一个知识论认可之觉知事件（*pramā*）的因果手段或过程。正理传统立四量：知觉（*pratyakṣa*）、推断（*anumāna*）、譬喻量（*upamāna*，“类比同一”或“比较”）与声量（*śabda*，证言）。四者之说皆用极端因果主义之语言，典型问题如：“何者致知觉经验？”“真假知觉经验之区别性因果要素为何？”“于何条件下，论证前提之知识致成结论之知识？”等等。

例之取舍，实左右因果理论之形态。正理论者说因果，几乎不离三例：（i）陶工—壶例：果为成壶；其因有壶之两半（陶工合两半以成壶）、陶工、其轮与棍、两半相触以及半与棍相触等等。（ii）线—布例：果为一布；其因有织成之线、织者、梭、机、诸般接触等等。（iii）斧—树例：果即树之被伐，由斧、斧与树之接触、伐者等所致。于此可问者：一切因果实例皆可纳入此三例所示之通式乎（如：必有一“行动者”乎）？正理论者对此三例自身，可有充分之因果说明乎（即能否分辨何者为果之因、何者非是）？对象与事件皆可为因乎？因果之关系为一事之关系，抑基于可重复之规则性？正理学派演进之中，此类问题之求解，遂使因果之说日趋精微。

### 6.2 三种原因

正理—胜论传统主张：在导向一事的因果要素总集（*sāmagrī*）之中，原因可分三类：和合因（*samavayi-kāraṇa*，依处因）、非和合因（*a-samavayi-kāraṇa*）与工具因（*nimitta-kāraṇa*）。《理性手册》复述此分类（TS 43）。和合因者，果所内居之实体也。壶之和合因为壶之两半，布之和合因为线。盖正理派谓整体内居于部分；果（如壶）若是整体，则其所内居之部分即其和合因。果若是对象获得一新性质（如树之被伐），和合因即该对象（树）。请注意：和合因虽与亚里士多德“质料因”有几分相似，实非一物：（i）对象之部分不必同于构成它的质料；（ii）非物质之实体亦可作和合因——如灵魂，即认知事件之和合因。

其余因果要素，非属非和合因，即属工具因。非和合因者，内居于和合因中之要素也；其虽非依处，却与依处紧相维系。线之连合，据称即一布之非和合因。又一常引之例：布色之非和合因为线色——线色内居于线，而果（布色）又内居于线。其余因果要素皆称工具因，如织者之梭或织者其人。正理论者何以区分非和合因与其余？或意在分判：何者为果之存续所必需，何者则否。线若失色，布亦失色；线若散乱，布即不存。然织者织毕而亡，或梭旋即被毁，则于果之存续并无影响。

由上述定义并不能推出：凡内居于依处者即非和合因，凡不然者即工具因。换言之，“何谓为因”仍待定义。而正理派先又分出两种因果要素：特殊工具因（*karaṇa*）与作用条件（*vyāpāra*）。吾人常言一事之 **那个** 原因——即自因果总集之中挑出某一要素，视之为促成此果之尤为显著或紧要者。直观而言：纵有和合因（壶之两半）、非和合因（两半之接触）乃至某些工具因（陶工等），若陶工不行动、不“操作”以成之，则果（壶）终不可得。故在某种意义上，壶之 **那个** 因，正是陶工实际操棍这件事。正理论者欲如此把握此意：诸工具因中有其一，乃果之“特殊”（*asādhāraṇa*）因，名之曰“*karaṇa*”。此概念于正理知识论尤为紧要（见下）。此因之“特殊”性何在？新正理（参见 TS 54）答曰：先立“作用条件”（*vyāpāra*）——紧接于果之前之因。壶之作用条件，即壶两半之连合；伐树之作用条件，即树倒之前斧与树之最后一触。“特殊”因则定义为“促成”此作用条件之要素——换言之，其运作直接带来果。在诸例中，即斧或陶工之棍。于正理派，此等对象方为果借以成之之真工具。

### 6.3 何谓原因？

正理论者由此立一因果模型：诸因果要素各当不同之因果角色。此模型反映（或映现于）印度语法对因果陈述之分析——如“陶工以棍掷壶”“伐者以斧伐树”——其中除标示事件之动词外，尚分出作业者（*kartṛ*）、所作业（*karman*）、工具（*karaṇa*）等等。然而原因与非原因如何分判，吾人尚无所知。《理性手册》（TS 41）给出新正理之答。设有二实体 *c* 与 *e*：

*c* 为 *e* 之一因果要素，当且仅当

1. *c* 先于 *e* 而存在，
2. *c* 与 *e* “恒常伴随”（*niyata*），且
3. *c* 之于 *e* “不由他立”（*ananyathāsiddha*）。

第一条防自因。第二条之旨：与 *c* 相似之实体必恒与与 *e* 相似之实体并存——*c* 类实体与 *e* 类实体之间，须有不变或恒常之连合。此即排除“恰巧在场”之对象——如正理论者之例：陶工将欲作业，恰有一驴踱过陶坊。此说之特色——坚持因果关系例示规则性——似于休谟式因果说。然正理论者亦识“偶然”非因果规则性之可能：如昼恒先于夜，又如（《理性手册》之例）线色恒先于布。布之出现虽恒先有线，亦恒有线色在场，吾人却不愿谓线色为布之因。第三条即彼等排除此类偶然规则性之尝试；同条亦被期望能阻止原因之原因（如陶工之父母）成为原因。然其义不甚明晰。按字面，谓因须“不由他立”。Kalidas Bhattacharya 云：“不变之先行者，若对其之知识并非任何预期果起之知识所需，即为不相干”（见 Potter 1977: 67）[^potter-1977]。Matilal 云：先行者不相干，若“可为它的出现找到合理之解释”（1985: 290）。《理性手册》云：先行者不相干，若其先行性唯连同另一实体而确立。吾人知线色先于布，仅因知线色与线俱现（而知线先于布）；故线色在此义上不相干。此显两规则性间之不对称：线色—布与线—布。后者可由观察线布之相关而直接确立；前者则由观察线色与线之相关而确立。据称前者依赖后者，反之不然。然此依赖是否亦反向而行，并不清楚。无论如何，正理论者以此判准阻断传递性，其所致力者似非因果性本身（多数人视为传递关系），而是“因果解释”或“因果显著性”这一知识论概念。

### 6.4 因果性与知识

非忆之认知分两类：真与假。若能觅得恒先于 **真** 认知之要素，则知识之因果理论已具发端。吾人将可说：一认知为一知识事件，当且仅当其（i）为真，且（ii）先有一恒先于真认知之因果要素（即其真非出偶然）。正理派（TS 39）称觅得四条且仅四条不变之关联：知觉、推断、譬喻与证言。四者皆套用上述因果模型；尤其于每一情形中分离出一个“特殊”工具因（*karaṇa*），名之曰“*pramāṇa*”（量）。知觉之例，即诸感官。请注意：依上文定义之不变关联，并不蕴涵前者在场则后者亦在——陶工恒与壶相关，然唯其“操作”之时方成壶。同理，*pramāṇa*（如眼）唯实际运作时方成真认知。换言之，*pramāṇa* 为真认知之必要因而非充分因。欲得充分因，正理派（TSD 69 iii）云：

> 于真认知为“特殊”之因果条件，名曰“*guṇa*”［认识论善德］；于假认知为“特殊”之因果条件，名曰“*doṣa*”［认识论过失］。知觉之例：真认知“*x* 是 *F*”之 *guṇa*，即与具有性质 [*F*] 之对象 [*x*] 之感官连接等等。

此即真知觉认知之作用条件。于是，诸通常要素（和合因、非和合因、一般工具因等）之俱现，加上一种认识论善德（*guṇa*），便是真认知出现之充要因果条件（另见 Philips and Tatacharya 2003）。

## 7. 知觉、概念与感官—对象关系

见屋角蜷曲之物，我知觉其为一段绳。望窗外，见天色之蓝，或亦见天之蓝性；亦见空气之冷，街上无人。凡此诸经验，共同点何在，使其皆为知觉之行？《理性手册》（TS 46）予古典正理之答：

> **原则 1**：每一知觉经验，其特殊工具因乃一“连接”（*sannikarṣa*）：所知对象与知觉者感官官能间之连接。

一切“看见”皆感官连接（类型待指明）之产物。此基本想法须两路充实，方可立为合式之知觉理论：（i）须说明上引诸例中知觉内容皆有语义结构（如：屋角之物是一段绳）；否则知觉经验不能为真，遂无资格充任知识事件；（ii）须说明此处所涉“连接”之类型。如此方能评骘正理理论之得失。

### 7.1 “有分别知觉”与概念的角色

有结构之知觉——知觉对象 a 之具有某性 *f*（如见屋角之物为一段绳）——正理论者名之曰“有分别”（*savikalpaka = saprakāraka*）：知觉一所别（*viśeṣya*）之具有某一特征，即“能别”（*prakāra*；*viseṣaṇa*）（参见 TS 47）。正理论者主张：凡知觉 **知识** 必具此形；且吾人自称仅“看见”一对象之多数情形（如“我看见那辆车”），实皆“将某物看作一辆车”之情形。于“有分别”知觉，与知觉者作感官连接者为所别。然则能别何以入局？正理派主张：

> **原则 2**：每一知觉之中，能别皆为先前所知觉之实体（实体、性质、运动或普遍）：知觉者忆取之，“叠加”于所别之上。

直观言之：限定之特征即一概念，知觉者经验得之，今以之范畴化所知对象。欲见过往之动物为马，必先有“马”之概念——由先前对该类之熟识而来。（此处言“概念”，并不意味诸特征有任何主观之义——于正理派，它们是客观实体，或由客观实体构成之构造。）正理派遂以其记忆理论（初始经验致倾向痕迹，倾向痕迹致记忆事件）充作概念拥有之理论。

原则 2 生数条后果：

1. 若每次将对象 *a* 看作 *f* 皆先有对 *f* 之先行知觉，而该先行知觉又是对 *f* 为某能别 *g* 所限定之知觉，则无穷倒退随之而来。故正理派（参见 TS 47）立言：有分别知觉之外，尚有“无分别”（*nirvikalpaka = niṣprakāraka*）知觉经验——此种经验中，对象与其能别同时被看见，却不见作被能别所限定者。
2. 试以此说解一例：设我初见一花瓶，其蓝色调为我生平未见。理论曰：在将花瓶看作“为该色调所限定”之前，我先见花瓶连该色调（而不见作被其限定），继而忆起该色调，加诸花瓶之上。
3. 错觉、幻觉等等，皆被解作自记忆（或概念库）误忆特征之情形。设我将屋角蜷曲物误知觉为蛇：正理派谓我忆取并叠加“蛇性”，其所据，大概是它与真特征“绳性”之紧密相似。又如我幻觉一匕首：则我在把往昔所见某匕首之记忆叠加于目前之空间区域（按原则 1，必有一所别）。此即知觉错误之“错置他相”（*anyathākhyāti*）说。须知：若一切错误皆能别错置所致，则于知觉者作感官连接之所别，错误不可能发生。又须知：正理派解释幻觉，并不诉诸“意象”“观念”或任何主观内容——此乃错误之外在主义说明。所谓错觉论证——由如实与非如实知觉现象上不可分辨，推出二者共享某种主观内容——遂为虚假。然是否总能觅得合式之所别（幻觉中果真知觉到空间区域么？）或合式之能别（如棍半没于水中而被视作弯，“如此弯曲”一性从何而来？——正理派实主张它乃知觉行为因果地产生之客观特征！），并不明朗。
4. 借此理论，正理派得以主张：“我（视觉地）见空气冷”“我见芒果甜”一类说法——其中能别可感而非可见性质——乃真正之知觉情形，归入一种“超常”知觉，名曰 *jñāna-lakṣaṇā-pratyāsatti*。（其他时有承认之超常知觉：一为“*sāmānyalakṣaṇa*”——由知觉一性质而知觉其一切承载者；一为瑜伽知觉。）
5. 正理派立言：经验成为知识事件，当且仅当其为真——即能别实限定所别。《理性手册》（TS 69 iii）谓，知觉知识之 *guṇa* 或特殊因果要素为：知觉者加于感官连接之所别之上的能别，实际存在于该所别之中。然此定义，盖梯尔式反例或仍有容身之地。

### 7.2 感官—对象关系的类型

《理性手册》（TS 48）载正理标准之说（出自乌底耶多迦罗）：为知觉经验奠基之感官—对象关系，恰有六种：

1. 接触或连合（*saṃyoga*）。通常知觉，如见一壶。若“接触”解作某种因果关系，则正理派可说持一因果知觉理论；然彼等亦可意指：眼于更字面之义上与对象相触。
2. 连合者中之和合（*saṃyukta-samavāya*）。前已指出：无分别知觉中，对象与其特征并见。特征与知觉者之间为间接关系——特征内居于对象，知觉者与对象相触。
3. 连合者中内居者中之和合（*saṃyukta-samaveta-samavāya*）。若（2）之特征为一性质（*guṇa*），如某种特定蓝色调，则内居于其中者为一普遍——蓝性——而蓝性自身显然亦可被知觉。
4. 和合（*samavāya*）。正理—胜论有一说颇为奇特：每种感官官能皆由与其特别相系之实体类所成。听觉官能由虚空所成，而声内居于虚空，故听者与声之关系为和合。
5. 内居者中之和合（*samaveta-samavāya*）。经此间接关系，听者系于内居于声中之“声性”一类性质。
6. 能别—所别关系（*viśeṣaṇa-viśeṣya-bhāva*）。此为要项。正理派信非存在乃“实在”对象——如今日屋中无象之非存在——且可被知觉。据称非存在限定其基底，知觉者见基底，遂间接知觉非存在。佛教法称则论之曰：此实为出于未觉（*anupalabdhi-hetu*）之推断——“吾见屋之四壁；若有象，吾必见之，而吾知觉官能运作如常；故无象。”

### 7.3 甘格沙的批评与新定义

甘格沙就三点批评原则 1：（a）每一觉知皆经“内”感官官能即 *manas* 之作用而生，依原则 1 便皆成知觉；（b）神之知觉不涉感官连接，原则 1 遂失之涵盖；（c）感官连接并无单一类型，而六类型之 ad hoc 清单亦无显而易见之共通点。故甘格沙另立新定义：

> **原则 3**：知觉经验者，一无其他非忆性认知为其“特殊”工具因（*karaṇa*）之认知。

此定义遭两难诘，皆获回应。诘一：有分别认知皆由能别之先行觉知所生，则定义外延失窄。答曰：不然。能别之觉知仅是辅助因果要素；其“特殊”工具因乃感官—对象之接触。诘二：再认（知觉之一类）实以能别之先行觉知为其“特殊”工具因，则定义外延失窄。答曰：不然。“特殊”因果要素乃先行觉知所生倾向痕迹所触发之能别记忆，非先行觉知自身。

甘格沙定义之长，在于把握了知觉经验较他种经验更“直接”之义，且于人神知觉皆可适用。限缩于人之知觉，则还原为先前之定义（甘格沙谓“内”感官终究不得视为知觉性）。

## 8. 逻辑理论与甘格沙对推断凭据（*vyāpti*）的分析

### 8.1 逻辑理论概观

甘格沙《真理思择摩尼》析为四部，正理学派所认四知识来源（四量）各当一部。甘格沙以后诸家日趋专精于第二部——论推断——于书中较小一段反复作注，愈注愈细：即甘格沙考察推断标记与所立性质间关系之处，此关系名曰 *vyāpti*，“遍充”或“推断凭据”关系（Ingalls 1951、Goekoop 1977、Wada 2007）[^goekoop-1977][^ingalls-1951][^wada-2007]。直至今日，传统印度教育中，研读甘格沙 *vyāpti* 节诸子节之疏注，仍为课程之大端。

正理合式推论之通格有三：宗、因（*hetu*）、喻例（*dṛṣṭānta*）。宗又含两分：推论之“处所”（*pakṣa*），与一所立性质（*sādhya*）——待推其现于处所者。故每一正理论证皆循同一格式：*p* 有 *S*，因其有 *H*；例如 *d*。例如：“山（= *p*）有火（= *S*），因其有烟（= *H*）；例如厨（= *d*）”。合理论证至少须满足三条：（i）因性质须无可争议地现于处所；（ii）因与所立须适当关联——大略即因所在处，所立必在；（iii）喻例须为因、所立俱在而无争议之地。

关于上述格构，《理性手册》与其他新正理文本处理了若干题目：推论得以进行之条件，及其结果成为知识事件之条件（TS 49, 54）；推断凭据关系之正解——推断标记与所立性质间之关系，名曰“遍充”或“*vyāpti*”（TS 50）；为己推理与为他推理之分（TS 52, 53）；推论类型之三分：全同转（*kevalānvayin*，全称肯定）、全异转（*kevala-vyatirekin*，全称否定）与同异合转（*anvaya-vyatirekin*）（TS 55）；推断谬误（*hetvābhāsa*，似因）之类型（TS 57–64）。

以下主要论“遍充”关系之定义。惟先略说知识因果模型如何施于推断。据称，推断认知之“特殊”工具因（*karaṇa*）乃推断者于相关遍充关系之知识。“作用条件”（*vyāpāra*）则为一觉知：推论处所（*p*）所具之推断标记（*h*）为所立性质（*s*）所遍充。此实为结论导出前夕合并论证两前提之觉知，名曰“*parāmarśa*”，即“省察”。推断认知之“*guṇa*”或“致真之因果要素”，即此“省察”为真之条件——处所实有被所立遍充之此标记。又一辅助因果要素：推断者或尚未知结论，或须有推断之特殊意愿（意谓：既有前提之知识，推断通常机械发生；若结论已如知觉般先知，则推断者须有以推断重立之之特殊意愿）。此条件名曰“*pakṣaṭā*”（宗未决性），勿与“*pakṣadharmatā*”（宗法性）相混——后者即上文条件（i）之名。

### 8.2 遍充（*vyāpti*）关系的诸定义

*Vyāpti*（遍充）者，推断标记（*hetu*）与所立性质（*sādhya*）之间使推断合法之关系也。通常以“凡有烟处皆有火”“凡存在者皆无常”一类句子表之。按正理派，此关系之知识乃推断过程之工具因——惟有此关系之知识，辅以对推断标记之观察，吾人方能成健全而生知之推断。故甘格沙于此关系之精确定义用力极深。他录定义多至二十一个，皆以种种理由拒之；继而另出七种表述，自认可接受。所拒定义之前五者，后世称“*vyāpti-pañcaka*”（遍充五定义），于梵语注家与其现代诠释者两界皆激起浩繁文献。此五定义可上溯早期佛教与正理文献。另两被拒者称“狮与虎”定义，显出自甘格沙之新正理前辈（Wada 2007，第 5 章）[^wada-2007]。甘格沙最终所取之定义，称其“*siddhānta-lakṣaṇa*”（宗义相）。

### 8.3 “无反例”定义

甘格沙“*vyāpti-pañcaka*”之五定义，皆为吾人可名之曰遍充关系“无反例”定义之变体。其言曰：所立性质 *S* 遍充因性质 *H*，当且仅当无一处所/实体，*H* 在其中而 *S* 缺席。形式化之：

**V₁**

Pervades (*S*, *H*) iff ¬(∃*x*)(*Hx* & *S*′*x*).

式中 *S*′ 表 *S* 之补。此定义一可溯早期正理“偏离”似因之观念——即见于可立性质 *S* 缺席处之似因；二可溯陈那推断标记“三相”说——其三相者，H 不得出现于任何“异品”（*vipakṣa*），即 *S* 缺席之处。二途之直觉皆同：“有烟处即有火”所表之关系成立，当且仅当无火缺席而烟在场之场所——即无反例。甘格沙所考第一定义正取此形：*S* 遍充 *H*，当且仅当 *H*“于 *S* 之阙无处不转”（*sādhyābhāvavad-avṛttitvam*），即 V₁。

此一貌似可信之遍充概念诠释，新正理何以拒之？有二故：

**部分位于属性之问题**。“无反例”定义之第一难，系于新正理“局部遍转”（*avyāpya-vṛtti*）之概念。一性若遍在对象之每一部分，则谓其整全出现于该对象。如“是金”之性整全出现于（纯）金一块；对象为该性所“饱和”（*abhivyāpya），犹芝麻油之浸润芝麻。然亦有性质只现于对象之一部分而不现于其余——是为“部分位于”。如“是熔融”一性，现于地心而不现于地壳。须知同一性质可于此处所整全定位、于彼处所局部定位——如红性整全现于红宝石，局部现于红色斯诺克球。此分所涉者，乃性质拥有之两种样态，非性质之两种类型。要义在于：一性若局部位于一物，其否定亦然。正理论者部分位于性质之标准例——“与猴连合”（*kapi-samyoga*）——恰明此理。猴若坐于树枝，则下二陈述可能皆真：

1. 树于时刻 *t* 与猴相连合，且
2. 树于时刻 *t* 不与猴连合，

（2）之所以真，因树有其部分，猴不与之相触。正理派以“出现”概念之相对化，避却矛盾律之危。（1）遂被分析为：“与猴连合”一性在树中之出现，*为（avacchinna）树枝所限界*。（2）中所示限界者不同，故二陈述并行不悖。

纳部分位于性质于体系之中，其显要后果为：性质 *P* 与其补 *P*′ 未必互斥，二者今可相交。若所立性质局部位于，则“同品”（*sapakṣas*，所立在场之处所）与“异品”（*vipakṣas*，所立缺席之处所）两类遂相重叠，不复判然分立。换言之，性质 *P* 宜想作既有“在场域”（*P*+）复有“缺席域”（*P*−），二者可交。试取标准推断“山有火，以其有烟”。设吾得一处所，烟在场而火既缺席亦在场，如厨房。此足证推断有失乎？按 V₁，然也：厨房将成反例——烟在场而火缺席之处。然此非也：火既亦在场，则于“有烟处即有火”之规则，此非真反例。故结论为：吾人所须考察者，乃因性质与所立性质之“在场域”，非其“缺席域”。规则之真反例，乃是处于因性质在场域而不处于所立性质在场域之情形。

甘格沙之第二定义正为此难而设：*H*“于异乎 *S* 处所之 *S* 缺席处所不转”。换言之，一 *S* 缺席之处所，若亦非 *S* 之处所，则不当为 *H* 之处所：

**V₂**

Pervades (*S*, *H*) iff ¬(∃*x*)(*Hx* & *S*′*x* & ¬*Sx*).

新条款之效，正在以更严格之反例判准，排除部分位于性质之难。

**全同转推断之问题**。正理派主张：合法推断亦有如是模式——所立性质以外延为整个论域。此等推断谓之“*kevalānvayin*”或“全同转”（参见 TS 55）。正理之标准例：“此是可命名者，以其是可知者”；可命名性被视为万物之性。又一例：“此是存在者，以其是被产生者”。此类推断若健全，则其因性与所立性必例示遍充关系。按上定义，谓可命名性遍充可知性，即谓凡“不可命名性”之处所皆非可知性之处所。难在：可命名性既为普遍性质，“不可命名性”遂为无实例（*aprasiddha*）之性质，而正理派谓此类性质于本体论上有可疑。换言之，“凡不可命名性之处所皆非可知性之处所”一语，内含一无所指之表达式——“不可命名性之处所”或“不可命名之物”——遂不可作真值评价。然此难并非遍及一切无实例性质：有若干性质——如“是空华”“是方圆”——可证为自更简单之有实例性质所构造。故“方圆是圆的”一语，可不解作内含无所指表达式，而解作意谓“圆既是方的又是圆的”。然“不可命名（之物）”不得如此分解为两个不同性质。

甘格沙所考“无反例”定义之诸诠释，无一种能解全同转推断之难；彼遂尽数拒之。其自出之定义以一诀窍绕过此难。

### 8.4 甘格沙的定义：“*siddhānta-lakṣaṇa*”（宗义相）

《理性手册》稍事简化，转述甘格沙新定义：*S* 与 *H* 由遍充关系所系，当且仅当 *H* 与 *S* 同所依，且 *S* 非如是性质——其缺席与 *H* 同所依（*hetusamānādhikaraṇātyantābhāvāpratiyogi-sādhyasāmānādhikaraṇyam vyāptiḥ;* TS 50）。几乎同一之表述见于其他新正理文本，如《宗义摩尼鬘》。此定义据称即便所立性质 *S* 为“全同转”亦可适用。大意谓：若 *S* 遍充 *H*，则凡其缺席与 *H* 同所依之性质，皆不得等同于 *S*。吾人若能觅得一处所，烟在于彼而某性——如冷性——之缺席亦在于彼，则冷性不得即火性。即：

Pervades (*S*, *H*) only if (∃*x*)(*Hx* & *P*′*x*) → (*P* ≠ *S*).

（此处对 *P* 有一隐含量化）。此条件所言者：无一处所使 *H* 与 *S* 之缺席同所依；而其表达并未实际使用那个可能无所指的短语“S 之缺席”，遂避却全同转性质之难。然此条件于遍充虽为必要，却不充分——盖其与 *H*（或 *S*）无实例者相容。故甘格沙并坚持 *H* 与 *S* 必须同所依：

Pervades (*S*, *H*) iff i. ∃*x* (*Hx* & *P*′*x*) → (*P* ≠ *S*), and

**ii.**

∃*x* (*Hx* & *Sx*).

甘格沙之诀窍，暗用定理“*A* → *B* ≡ ¬ (*A* & ¬ *B*)”。故条款（i）实质等值于 V₁。由此亦可见：吾人尚无定义能处理部分位于性质；为此须更近于 V₂ 者。故甘格沙终局之定义为：

**V₃**

Pervades (S, H) iff i. ∃*x* (*Hx* & *P*′*x* & ¬*Px*) → (*P* ≠ *S*), and

**ii.**

∃*x* (*Hx* & *Sx*).

此遍充定义，既可处理全同转性质，亦可处理以所立性质面貌出现的部分位于性质。

或问：遍充关系既有“凡 *H* 皆 *S*”之形，正理论者何以不径用全称量化于其定义？答案或为：彼等所事者，正为此概念下定义，且仅以若干彼所视为初始之概念为之——尤以同所依与缺席为要。若此解不诬，则吾人须示明：如何重构此定义而不用其对性质 *P* 之隐含量化（参见 Goekoop 1967）。

## 9. 意义、理解与证言

### 9.1 语言处理机制

在 *pramāṇa* 体系中，知觉与推断被描述为生知之官能；语言亦然。由此，正理派构造出一套机制描述：胜任之语言使用者如何解码噪音话语、导出基于语言之知识。《理性手册》对这一“语言处理机制”之描述如下（TS 67, 68）。过程之输入，是听者对口语话语——就其为未经解释之噪音而言——之听觉知觉；此即被认定为“特殊”工具因（*karaṇa*）者。例如，听到噪音串

[*]

“The” “cat” “is” “on” “the” “mat”.

“作用条件”（*vyāpāra*）者，听者对话语中各词之义（*śakti-jñāna*）之（默会）知识也。理解该语言者与不理解者（后者虽亦能闻其言，却无解释之能力），正以此为分。例如，知道

**[M1]**

“the cat” 意谓 the cat，

**[M2]**

“the mat” 意谓 the mat，且

**[M3]**

“is on” 意谓 基底—覆层关系。

过程之输出——诸因果要素合致之效——乃听者形成一信念，如相信

**[P]**

The cat is on the mat.

知觉之例尚有诸辅助因果要素——照明足、知觉者感官完好、知觉者留意等等；此处亦然。正理派特举四者：所说诸词之时空“亲邻”（*sannidhi*）；说者意向（*tātparya*）；“待余”（*ākāṅkṣā*，句法期待）；“义适”（*yogyatā*）（参见 TS 67）。其一自明：话语诸词若历时良久逐一而出，或混入他话语之词，则无从对话语成合式之听觉知觉。其二“说者意向”，用于句有歧义词之时——消歧之法，在审说者所欲达之义。《理性手册》定义“待余”为“一词无他词则不能生对二者间关系之觉知”，并举“horse man elephant”一语为无此期待之话语例。其意显然至少是：话语须语法正确。尚不止此，似更有言：惟凭句法规则，词间未获表达之语义关系方得以表达。理解“the cat is on the mat”者何以把握一个统一命题，而非仅得一份清单［the cat、on-关系、the mat］？其意或谓：句法规则（之知识）生成对此诸条目间连接关系之觉知。

“义适”（*yogyatā*）一名，殊为耐人寻味。《理性手册》定义之为“诸词所指之间无不相容”，并以“以水洒田”对“以火洒田”两语明之。其意：洒洒之事“相容于”（即唯可施于）水这般液体，不相容于火这般实体。若曰“猫性在垫上”，或乔姆斯基所谓“无色之绿念狂然酣睡”，即此之类：语法虽通，义则不通。故此因果要素谓：所表命题惟在一个预设本体论体系——如胜论句义体系——观照之下于本体论上可能，话语方为可解。然亦有正理论者加一更苛之求：欲“义适”，话语须真——“适”即“真”而非仅“可能”——话语唯有真方为可解！实即于语言处理机制中，彼等把“义适”等同于“*guṇa*”或“致真之因果要素”。此争稍后再论。

### 9.2 语义能力与语义性质的还原

《理性手册》之词定义，声名卓著，征引甚多。其言（TS 66）：词者，有语义能力者是也（*śaktaṃ padam*）。句（*vākya*）定义为词之集合。故此定义与今之界说相合：词者，有语义意义之句成分也。语义能力者，一旦知之，胜任之听者即能解词；于正理论者，其义在词之指代一对象。故解“cat”一词者，知有<“cat” 意谓 cat>之形之事，“means”乃词与某类对象间之关系。《理性手册》就此关系设三问：（i）此关系是否为新出而不可还原之类型——即不能还原为任何既已承认之关系（TSD 66a）？（ii）关系项为何——词在语义上与何类实体相关（TSD 66b, k）？（iii）词义如何习得（TSD 66c, d）？

（i）弥曼差论者与语法家持意义“本质主义”：梵语乃自然实体，独立于人间约定与用法，其词自具指物之语义能力，如火自具燃物之能。正理论者传统上与此相抗，谓语言乃约定之产物，词之语义能力可由支配其用之约定说明。其主张为：意义关系可定义（从而可分析）如下：

> *x* 意谓 *y*，当且仅当有一条形如“令 *x* 之话语生出关于 *y* 之认知”之敕/约（*saṅketa*）。

规定或敕令，据称即在于规定者怀有一特定心灵状态——所规定形式之“欲”（*icchā*）。故意义关系按心灵状态及其内容而分析，非作为一种新关系类型。规定者谁欤？《理性手册》谓是神；然多数后期正理论者分判二类：“无尽”属于语言之词（神所引入）与明确之人约定所引入之词（如波你尼语法中之技术术语）。

（ii）如“cow”一类泛指名词表达式，其意义关系项为何？此处《理性手册》又以正理之观对勘弥曼差。弥曼差一支派（跋吒派）主张：“cow”之义即牛性之普遍——盖“（这）牛是动物”一类句子，或“毋踢牛”一类律令，所言者乃全牛之类，非任何一特定个体。于是：

**(Bh)**

“cow” 意谓 牛性。

对一显而易见之诘——如“牛在园中”一类句子所指乃某一特定牛——跋吒派诉诸一说：句子可于字面义之外另携“牵带”（*ākṣepa*）。故“牛在园中”一句，字面谓牛性与“在园中之出现”同所依（即园中有牛），而牵带之义则为某一特定牛在园中。此间原理：能别（*viśeṣaṇa*）之先行觉知，引出所限定者（*viśeṣya*）之牵带觉知（TSD 66b）。正理派对此论证之回应，在拒斥所引原理：盖谓能别或普遍之觉知，惟经由对所限定者之觉知方可能。

《理性手册》立现代正理之观：“cow”一词一次发出之话语，其义为一特定个体——由牛性所限定者（*jāti-viśiṣṭa-vyakti*）：

**(Ny)**

“cow” 意谓 为牛性所限定之牛。

其意如下。凡解“（这）牛在园中”一话语者，其解法有二：（a）认定某对象为“cow”一词之所指；（b）把握该个体由“在园中之出现”一性所限定。然认定一对象，必待将其与他者分别开来，此须用一分别之特征。故该个体在觉知中被把握为“由牛性一特征所分别/限定”者。词之义，按定义，即其对“闻此话语所生最终信念”之贡献；故“cow”之义即“为牛性所限定之一个体”。注意：依此说，“cow”之诸话语符号（token）所指个体各别，然每一话语符号皆共享一语义性质——“……—为牛性所限定”。正理论者遂区分类型义与符号义（或如或人所言：意义与指称之分）。

弥曼差另一支派（钵罗跋迦罗派）主张：闻一句而吾人所得者乃统一之命题，非徒实体之清单；为解此事实，“cow”一类词之义关系项当为“连他之物”（*itarānvita*）。意义关系项是一牛，连同将其与其他意义关系项勾连之“钩”。更确切言之，该词之义当类似于

**(Pr)**

“cow” 意谓 一牛个体，它是……

故“牛在园中”一句，非仅意谓清单<牛、在园中>——若每词各指一物，其义当如是——而意谓相连之命题<在园中之牛>。此意实谓：一切意义关系项，以弗雷格之术语言之，皆“未饱和”。对此巧思，《理性手册》答（TSD 66k）曰：此说过剩——“［意义关系项间之］关系既可被把握为句子［整体］所意谓者，则无须就此关系另设语义能力”。换言之，《理性手册》主张：句子之一般（想必是句法之）特征，足以连结诸意义关系项；无须主张关系项自相勾连。

（iii）正理论者于语言习得有如下说明（TSD 66c）。童子对成人之语言行为作系列观察：闻 A 发某噪音，如“牵牛来”，又见 B 行某事——牵牛来；复闻 A 发“牵马来”之噪音，见 B 牵马来；闻“喂牛”，见牛受喂。于是经一双管齐下之归纳：（a）“同有”（*anvaya*）与“同无”（*vyatireka*）——即察 A 之出言与否与 B 之行事与否间之相关；（b）“集取”（*āvāpa*）与“摒除”（*udvāpa*）——即察“cow”之声与牛之诸事、“bring”之声与牵来之诸事等等间之规则——童子遂解得：“cow”一词与属于牛类之对象相连结，等等。

此乃经验主义之语言学习说，令吾人忆及维特根斯坦归于奥古斯丁之说——维氏对之驳斥甚厉。姑置归诸童子之超人推断力不论，维特根斯坦所突出问题为：观察无论如何繁多，皆不足以示明——例如——相关者究竟在“cow”与牛个体之间，抑在“cow”与 B 之就牛行事、牛性之普遍、牝犊而非牛等等之间（参见 TSD 66d）。

### 9.3 证言

《理性手册》谓陈述有二：吠陀的与世俗的。又谓：闻吠陀陈述即是 *pramāṇa*——知其所言之手段——以吠陀陈述最初为神所发故。（弥曼差论者于此有争：彼等不信神，转谓吠陀陈述之为认知手段，恰以其无个人来源；证言之误，恒出于来源中人之误！）闻世俗陈述而为认知手段，唯当说者为“可信者”（*āpta*）。可信者定义为依实言者（*yathārthavaktā*）。此处有一歧义：可信者乃就特定话语而依实言者，抑一般诚实者？又一问：闻者须知说者在此义上为权威与否，是否必要？

更添混淆者，《理性手册》谓闻者信念之真所系之“*guṇa*”，乃“*yathārtha-yogyatā-jñāna*”——或解作（i）对义适之如实认知，或（ii）对如实义适之认知。无论何解，“*guṇa*”似皆与说者资历无涉。然（ii）必误：闻者已知所言为真，断不得为证言之条件。（i）亦不足保听者最终信念为真——除非《理性手册》此处“适切”取一强义：意义关系项彼此“相适”，当且仅当其实际相连——即话语表达一真理。此解固为他派正理论者理解 *yogyatā* 之法，却与《理性手册》自家定义不合。

请试下一解。语言处理机制，上文描述为令闻者信其所闻之机制。故闻者信念之真，系于说者是否依实而言；此处之“*guṇa*”当指此。然吾人未必尽信所闻——尤其当有理由料想说者未必依实之时。于是可有之事：语言处理机制之输出，非径信 **所言何事**，而仅信 **其言已发**。此类情形约有两端：（1）闻者断定说者欺诈、不可信，或于话题一无所知；（2）闻者据独立根据——或为关于断言可合理性之 **先验** 根据——知说者所言为假（此与说者自信而诚证相容）。稍假诠释之便，可认此二条件对应于《理性手册》加于证言之二条件：说者须为“权威”（*āpta*），句子须“义适”（*yogya*）。

## 10. 胜论的普遍、和合与基本别异概念

### 10.1 普遍

《理性手册》载正理—胜论关于普遍（*sāmānya, jāti*）之标准定义：

> 普遍者：（i）永恒，（ii）单一，（iii）居于众多事物（实体、性质或运动）之中。（TS 82）

普遍遂被想作无结构之客观性质，必然居于个体。胜论图式中设定此类实体，自有解释之功：用以说明“自然”分类与“约定”分类之分。直观言之：牛类、马类之组，反映自然之划（“顺自然之关节而切”）；内阁部长、濒危物种之组，反映以人为中心之关切——此即其分。正理论者标记此分之法：自然性质谓之“普遍”（*jāti*），以人为中心之性质谓之“假立”或“名义”性质（*upādhi*）。语义上相应有“自然种类词”（*naimittikī*）——其适用之据为一普遍——与“假立种类词”——其适用之据为一以人为中心之性质——之分。优陀耶那欲使其分更精，遂立一清单：性质须满足何种判准方算自然。考察其清单——谓之“*jāti-bādhakas*”（类障，分辨自然性质之障碍）——将更示正理派关于自然性质之本性。

六类障曰：（1）“非复多”——真普遍须受复多实例化；（2）“等同”（*tulyatva*）——共外延之二性质不得皆为真普遍；（3）“交叠”（*saṃkara*）——真普遍之二，不得部分交叠；（4）“倒退”——普遍性一类性质不得自身为普遍，否则无穷倒退（普遍性之性，等等）；（5）别异性一类性质不得为真普遍——盖按定义，诸基本别异不共享任何共同普遍性质；（6）和合性一类性质不得为普遍——盖其不内居于其处所。六者之中，末三条基本为护胜论体系之内部一致，首条则径为普遍定义之推论。首条把仅有一例之性质（如空间性）逐出真正自然种类之列；其动机或在此想：普遍之本性，正在于为“*x* 与 *y* 同类”型之判断奠基，而此型判断预设至少有二实体。

其二、其三两条判准至为紧要，可较正式地表之如下。设 *P*、*Q* 为两个不同性质，则（等同，*tulyatva*）：

> [*P*] = [*Q*] → either *P* or *Q* (or both) is not a universal,

其中“[*P*]”表 *P* 之外延。其逆否形为：

> *P* and *Q* are universals → [*P*] ≠ [*Q*].

请注意：此条并不蕴含——如或人所持——普遍性质按外延个体化、或等价于类。其所示者唯是：对应每类，至多有一普遍。纵在诸普遍之域内，普遍为其外延所唯一确定；然普遍与共外延之假立性质（如壶性与螺壳状颈性）之分，仍是内涵之分。

至第三类障（*sāṃkarya*），若 *P*、*Q* 为互异性质，则

> [*P*] partially overlaps [*Q*] → either *P* or *Q* (or both) is not a universal.

其逆否形为：

> *P* and *Q* are universals → [*P*] ⊂ [*Q*] or [*P*] ⊃ [*Q*] or [*P*] ∩ [*Q*] = ∅.

（包含取严格义，以“等同”约束故。）换言之，真普遍排成层级：任取二普遍，或如属种相系——其一之实例尽为另一之实例；或全然相离，无一共例（如牛性—动物性、牛性—树性）。正理派谓：一普遍如此为另一所统摄，则前者“下位”（*apara*），后者“上位”（*para*）（参见 TS 6）。诸普遍之至高者为“存在性”（*sattā*）：实体、性质、运动，尽落其外延。普遍须层级地组织——此一要求显示：正理派以生物物种为范式，物种固有此等结构。而“普遍”一词——“*jāti*”——亦即“种姓”。Matilal（1971: 76）遂揣想

> 于正理派之类性质学说中，或可觅得婆罗门社会—宗教观念之远绪。移译为生物学语言，“不交叠”之……原则即转为反对杂交之原则。故有若干迹象可见：正理派偏爱实在类性质，部分受婆罗门教理想社会秩序概念之熏染——彼种秩序中，诸阶层不容混杂。

正理论者中有人——尤以跋萨婆若与罗怙那陀——拒“交叠”一障：以之施于非生物之自然种类，困难立见（红与绿交叠，壶性与金性亦然）。罗怙那陀更进一解：此原则若一以贯之，存在论中之普遍将几乎荡然无存。故优陀耶那“自然”之判准，既不必要，亦不充分：其诸类障无一能示明，何以“蓝—绿”较古德曼之“grue—bleen”更为自然（x 为 grue，当且仅当 x 为绿且于时刻 t 前受检，否则为蓝；bleen 反是）。

普遍于某种意义上“位于”殊相——此一想生两独特之难。陈那即乘空间隐喻而攻：正理普遍概念不融贯。盖普遍若“单一”，则至多位于一所——遂非“复多实例化”；反之若同时位于多处，则必因有部分，各据一所——遂非“单一”。此论证乘“被位于”之歧义，佯作牛性位于个别之牛，与牛位于田中同义同型。然此攻亦迫正理派于普遍—殊相关系之说明更自谨慎。如《理性手册》所注（TS 84）：普遍栖于其诸实例，所凭乃“和合”（*samavāya*）关系；和合定义为“不离”（*ayutasiddhi*）关系。设有二实体 *x* 与 *y*，

> *x* 不离于 *y*，当且仅当：无 *y* 则 *x* 不能存。

其意：牛之能存，必待牛性之存；牛性之“位于”牛，其义即在此。（同一关系亦被谓见于不可重复之“性质”（*guṇa*）与实体之间、整体与部分之间、基本别异与极微之间。）至若空间之定位，则凭截然另一关系：接触（*saṃyoga*）。“定位”一词之歧义遂解。

另一难则古已有之：普遍之实例尽毁，普遍将何如？普遍可不实例化而在乎？和合关系之定义许之：所求者乃“无牛性则牛不存”，非反是。牛之存在，可谓随附于普遍牛性之存在。然谓（譬如）车之部分不能存，除非整体（车）存——此说是否同样成立，便不甚了然。

### 10.2 基本别异（*viśeṣa*）

胜论传统上独把“基本别异”（*viśeṣa*）一项纳入其存在论——或谓其派名即由此得。《理性手册》定义之曰（TS 83）：“居于永恒实体［即极微］之中、为其施行别异者，谓之 *viśeṣa*”。其意：牛与马因性质有别而为两物；同一实体之二极微——如土——亦必至少于一性质上有别。故每一极微各具一独有之“别异”，藉之与同类之任何他极微相区别。于是其设为：任何两个不同一之项目，皆因性质有别而得区别。此即莱布尼茨“不可分辨者同一”律之逆否形： (∀*P*)(*Px* ≡ *Py*) → (*x* = *y*)，“*P*”遍历诸性质。若不约束所量化性质之范围，此原则将陷于平庸。如“…… = *y*”一性若获允许，原则便空洞地言“同一者同一”。胜论者隐含地限此原则于对象之内在非关系性质——“处于某时空位置”之类，不得充作区分两个本同对象之性质。于是其主张似为：任何两个对象——极微亦在其列——不能内在地同一。莱布尼茨自解其律，似亦如此：“除时间地点之异外，恒须有内在之区别原则……故时间地点虽可助区分事物，吾人却难单凭其区分”；又谓“绝无彼此不可分辨之二个体。两滴水或两滴奶，置显微镜下，即见彼此可辨”。

此原则之强，无可讳言。维特根斯坦（*Tractatus* 5.5302）指出：由此律可推，容有二相同球体之宇宙逻辑上不可能；威金斯则指出：甚而单个球体（或任何对称物）亦逻辑上不可能——盖此律蕴含二半球同一（循此以至几何点而后止）。更要害者——胜论者隐含已识：由此律可推，同一实体之多于一极微（具定速、定旋等）逻辑上不可能。然彼等不拒此律，反引入新之内在一性质——基本别异——以此避却难堪之后果。

## 11. 非存在（*abhāva*）的存在论与否定陈述的语义学

### 11.1 动机

后期正理论者立一非存在理论，殊为可观。彼等谓：对象或特征于某特定时空位置之 **缺席**，与该对象或特征之 **在场** 同其客观，皆事态也。故于迦那陀六句义（*padārtha*）之原列，添以第七句义：“非存在”（*abhāva*）。此存在论学说之根基，一在现象学，二在语义学。

（i）现象学之要点：否定之觉知——如“某人不在此室”——在现象面目上迥异于任何关于室中之有之觉知。认知“无”，自有其自主之现象学（此义以萨特所阐为最著）。所依原理遂为：

**P₁**

非存在之经验，现象面目上别于存在者之经验，且不可还原于后者。

此义见诸正理知识论：彼等谓非存在可被知觉，而此知觉乃 **自成一类** 之知觉经验，不可还原为通常知觉与推断之复合（参见乌底耶多迦罗清单之第六种感官连接）。

（ii）语义学之要点：正理派奉真理符合论之一型——真句对应事实。据谓，真之否定句（如“壶不在地上”）对应“否定事实”。然于正理派，事实悉具同一基本关系形式‘bRa’（谓其有所别—关系—能别之构；即皆存在实体之复合）。何谓事实，其限可由下述语义原理表出：

**P₂**

句子所对应之事实，由简单或复杂实体构造而成（如‘a’、‘a 之缺席’、‘a-且-b’、‘a-或-b’等实体）。

此原则所蕴：真值函项联结词不得用以构造事实，惟其等价于词项逻辑联结词者除外。（例：“罗摩与悉多皆正直”等价于“罗摩正直且悉多正直”；然“罗摩与悉多成婚”中之词项联结词，不得如法消去而代以真值函项合取“罗摩成婚且悉多成婚”。）要义：如“壶不在地上”一类句子，不能对应‘¬bRa’形式之事实（按 P₂ 无此事实），必须对应‘bRā’形式之事实。否定实体遂引入存在论之中。

### 11.2 时间与空间上定位的缺席

《理性手册》（TS 85–88）载正理通行之说：非存在有四——先无（*prāgabhāva*）、后无或“灭无”（*dhvaṃsa*）、“究竟无”（*atyantābhāva*）、互无（*anyonyābhāva*）。前二者关乎一无常对象之可能时间状态。设以如下一线表一人 *A* 之生存绵延（设其生卒在 1650 与 1750 之间）：

| *t*₁ | 1650 | *t*₂ | 1750 | *t*₃ |   |
| --- | --- | --- | --- | --- | --- |
|   |   |   |   |   |   |

凡 1650 前之时刻 *t*₁，*A* 尚未存在；凡 1750 后之时刻 *t*₃，*A* 不复存在。循上述原理，正理派将此等否定存在主张重述为关于否定实体之肯定存在陈述：“*A* 之先无”，记作“<*A*”；“*A* 之后无”，记作“*A*>”。于是第一条读作：

<*A* 现存于 *t*₁，

或依正理惯语，对象不惟位于空间，亦位于时间——

1. <*A* 定位于 *t*₁。

同理，

1. *A*> 定位于 *t*₃。

于 *t*₂ 一类时刻，何事发生？此等时刻，*A* 存在而在场（被定位）。且请留意：*t*₂ 时，<*A* 有一后无（*A* 之先无，随 *A* 之出现而灭），记作‘(<*A*)>’。*A*> 亦有一先无（*A* 之后无，彼时尚未存在），即‘<(*A*>)’。《理性手册》（TSD 89E）录早期正理论者之主张：此等双重缺席必与原初实体同一，否则无穷倒退。于是：

(<*A*)> = <(*A*>) = *A*.

后期正理论者显然不认此自然同一（其对应经典逻辑之双重否定律），其理由：双重否定之构造内含否定之概念，故逻辑上更为繁复。

第三类非存在——“究竟无”（*atyantābhāva*，恒常或绝对之缺席）——以“壶不在地上”一类构造为式例。《理性手册》谓（TS 87）：此类缺席之特质，在其位于三时——过去、现在、未来。此说似怪：壶或于此时在地上、于彼时不在。要点或在于：此处缺席之处所乃空间实体，非时间实体。如“热不在冰中”一式，即例示此类缺席。或更进一层：此否定之力，谓壶 **从不** 位于地上——故不得言壶之先无或后无（此二概念按壶在场之时刻定义）。（如优陀耶那定义实体为“不具有性质之究竟无”者。）

第四类非存在——互无（*anyonyābhāva*）——式例如“壶非（彼）布”。此语当读作一非同一之陈述。

正理论者遂谓：一切否定句皆形如“*aRb*”之句之否定；且分判 *R* 为同一关系之情形与非同一关系之情形。对象 *a* 谓之缺席之处所；对象 *b* 谓之缺席之“所遮”（*pratiyogin*）——即其于处所之在场被否认者。此足显明：缺席被想作一种性质、一种“可定位者”，而非一种“定位”（至少当关系非同一时）。例如 *A* 之缺席，同时位于多处；并非 *A* 缺席之每一处各有一相异之 *A* 缺席。正理派解析否定句而不用句否定之法，于今可见。取“壶不是蓝的”一句：其一阶转写为“并非壶是蓝的”（¬*Fa*）。正理之策略：先谓任一性质——如蓝性——既有外延 *F*（其所在之场所）复有补外延 *F*′（其缺席所在之场所）；然后将句转写为：壶具有蓝之缺席。请注意：部分可定位之性质，即外延与补外延交叠者——特征可与自身之缺席同所依。

### 11.3 否定的逻辑

《理性手册》（TS 89）于缺席或否定之逻辑性质，有数则极具启发性之观察。

**指称对描述**。据谓有“别有所无”（*viśiṣṭābhāva*）与“唯无”（*kevalābhāva*）之分。请看下列一对句子：

1. 阿南跋塔不在室中，且
2. 《理性手册》之作者不在室中。

其意：（3）中所位于室者，乃阿南跋塔之“单纯”缺席；（4）中所位于室者，乃一别有所无——阿南跋塔之缺席，由作者身份所限定。（3）与（4）果有不同的逻辑形式乎？于此或可见一悟：如“《理性手册》之作者”一类名词表达式，实有二逻辑职能——**指称** 一个体，与 **经其性质** 而 **描述** 之。（4）故可读作与（3）同一之断言——阿南跋塔不在室中；亦可读作谓：《理性手册》之作者，无论其人为谁，不在室中——即“为《理性手册》之作者”与“在室中”二性不同所依。若（4）之涉别有所无取此义，则（3）与（4）逻辑形式果异。

**全称量化**。《理性手册》另立一极重要之分：特定非存在（*viśeṣābhāva*）与通类非存在（*sāmānyābhāva*）。式例如下：

1. （这）壶不在室中，且
2. （任何）壶皆不在室中

（按：梵语中二者将由同一句表达，括号以此。）谓室中有壶之特定非存在，谓某特定壶不在室中；谓室中有壶之通类非存在，谓任何壶皆不在室中（即室中无壶）。此分遂与全称量化构造之表述相系。诚然，正理逻辑理论中，通类非存在用以表述遍充（*vyāpti*）关系：“有烟处即有火”换质位得“无火处即无烟”，而后者表作：凡火有通类缺席之处所，烟有通类缺席（参见 Ingalls 1951: 54–5）[^ingalls-1951]。（5）与（6）逻辑形式确异，明矣。正理技术语言中，此分如此道出：限定缺席之所遮性之性质（即 *pratiyogitāvacchedaka*），于（5）为“此壶性”，于（6）为“壶性”。

**逻辑联结词与德摩根律**。《理性手册》兼及合取缺席与析取缺席之义——即（*A* 且 *B*）之缺席（*ubhayābhāva*）与（*A* 或 *B*）之缺席（*anyatarābhāva*）。其观察为：知二壶皆缺席，与知一壶在场（另一缺席）相容。实则如 Ingalls 所示（1951: 63–67），正理派认两条普遍等式之效：

> （*A* 且 *B*）之缺席 ＝（*A* 之缺席）或（*B* 之缺席），且
>
> （*A* 或 *B*）之缺席 ＝（*A* 之缺席）且（*B* 之缺席）。

此二式显为德摩根律之变形：¬(*A* & *B*) ≡ ¬*A* ∨ ¬*B*，与 ¬(*A*∨*B*) ≡ ¬*A* & ¬*B*。试举第二律之例：摩偷罗那陀有言（1951: 66），（特定）缺席之“堆”（*abhāva-kūṭa*）等价于通类缺席。火有通类缺席之处所，即每个特定火皆缺席之处所；反之，诸特定火皆缺席，则火通类缺席。故火之特定缺席之“堆”（合取），等价于任何火之缺席（诸特定火之析取）。
