# 早期现代印度的分析哲学 Early Modern India, analytic philosophy in (Jonardon Ganeri)

*首次发表于 2009 年 3 月 10 日；2023 年 11 月 5 日实质修订。*

两个更古老的印度哲学传统并行发展，直到 11 或 12 世纪的某个节点合流为一门新学派。其一是早期正理派：以乔答摩·足目约公元 100 年的《逻辑经》为根基，主要处理逻辑、知识论与论辩理论。其二是胜论派：以迦那陀约公元前 100 年的《胜论经》为根基，主要处理存在论。合流之后的新学派叫“新正理”（Navya-Nyāya），也就是新的正理派，或称“新理由”学派（Ganeri 2011）[^ganeri-2011]。名虽如此，新正理却兼收并蓄：古典胜论的形而上学、古典正理的知识论，都被它吸收进来，并推进了它们。新正理的作者还锻造出一套精确的技术语言；有了这套语言，许多传统哲学问题得以澄清、得以解决。其方法之灵便，超出了哲学的范围，诗学、语言学、法理论以及中世纪印度思想的其他领域也都拿来使用。学派的奠基之作，是甘格沙那部才华横溢、锐意创新的《真理思择摩尼》（*Tattvacintāmaṇi*）。此后学派又发展了约四个世纪，至罗怙那陀、贾迦迪沙与迦达陀罗的著作而臻于极盛（Ganeri 2014）。技术词汇用得越精微，学派就越是难以进入；于是 17、18 世纪出现了数部手册与纲要，用浅近的语言讲解其基本义理。本文依其中最成功的一部，撮述新正理的哲学原则。那便是阿南跋塔的《理性手册》（*Tarkasaṃgraha*，下称 TS）及其自注《明灯疏》（*Dīpikā*，下称 TSD）。此书别号《童蒙迦达陀罗》（*Bāla-gādādharī*），堪称一部“迦达陀罗入门”。《理性手册》一面陈述胜论的句义理论（其中物理理论、形而上学与心理哲学融为一体），一面传授新正理体系的知识论、方法论与逻辑技巧；此外还穿插了大量饶有兴味的哲学讨论，读来既有趣又长见识，是晚期印度分析哲学的一部理想导论（英译本见 G. Bhattacharya 1983；关于该文本的讨论，另见 Athalye 1930、Atreya 1948、C. Bhattacharya 1966、Foucher 1949、Shastri 1961）[^athalye-1930][^atreya-1948][^bhattacharya-1966][^foucher-1949][^shastri-1961]。

## 1. 胜论的句义体系

### 1.1 方法论与定义理论

正理派与胜论派的典籍大体取两种结构之一：要么沿用胜论旧例，把诸句义连同其子类依次讲完；要么仿效佛教论师陈那开出的路数——甘格沙正是照此办理——把诸知识来源逐一处理。《理性手册》走的却是另一条路：它采用了筏磋衍那（《逻辑经》首位注家）的分析体例。筏磋衍那写道：

> 此［正理］体系将依三重程序展开：列举（*uddeśa*）、定义（*lakṣaṇa*）与考察（*parīkṣā*）。所谓“列举”，是用名目把［待分析的］对象逐一点出；所谓“定义”，是举出该对象有别于其余一切对象的一项特征；所谓“考察”，是借助诸量（*pramāṇa*）查验这项区别性特征对该对象来说是否切当（《逻辑经疏》，NS 1.1.3 之前）。

这套方法的枢纽，在于运用“定义”：所谓定义，就是被定义者的区别性标记。《理性手册》（TSD 3d）把这一想法再收紧一步：某类事物的“定义”，就是与该类外延重合的任意一项特征。比方说，“有垂肉”就是“牛”这个类的定义特征。请注意，这并没有告诉我们该类的本质是什么——它只是提供一种可供识别的综合症候或性状。就此而言，正理论师的定义观属于“诊断式”，而非“本质主义”。“考察”的用意也随之明朗。它要检验：所谓定义特征是否真的与待定义之类同其外延，抑或出了毛病。毛病有两种：要么“过遍”（参考 *ativyāpti*，把它套到了被定义项之外的东西上），要么“不遍”（参考 *avyāpti*，没能覆盖被定义项之内的一切），要么两者兼犯。用现代术语讲，合格的定义特征，必须既是待定义者的必要属性，又是充分属性。在《理性手册》一类新正理文本里，“列举—定义—考察”这一套被反复地重演。

### 1.2 胜论的句义体系是什么？

胜论的“句义”（*padārtha*）体系，试图把一切存在者的不同类型作系统归类。新正理开出七种对象“句义”：实体（*dravya*）、性质（*guṇa*）、运动（*karma*）、普遍（*sāmānya*）、异（*viśeṣa*）、和合（*samavāya*）与非存在（*abhāva*）。前六项是古典句义清单，早在《胜论经》中已经具备；第七项“非存在”则是后期学派的独家增补。这些类型多半还可以继续细分为子类：比如实体有九种、性质有二十四种，诸如此类。

就这份句义清单而言，头一个主要问题是：能否从中辨认出某种底层结构或组织原则。这又牵连着另一个重要问题：句义到底是什么？对后一问，《理性手册》用词源分析作答：“句义”（*padārtha*）就是词（*pada*）的义（*artha*）。言下之意是：胜论的诸句义在某种意义上正是语言结构的形而上学对应物。要把这层主张说得更精确，可以从两个方向入手：一是指出胜论体系与梵语语法之间存在引人注目的相似（尤其参见 Faddegon 1918）[^faddegon-1918]；二是留意一种别具一格的论证样式——“某类实体、性质等存在”这一假设，靠的是它能解释我们语言实践的某个特征（比如：空间存在，因为它解释了我们为何使用方位词）。

还有一种进路，是为这份清单寻找纯粹先验的理据。Athalye（1930: 75）给出过一例：

> 一个观念非肯定即否定，故观念的外部对象要么是“存在”（*bhāva*），要么是“非存在”（*abhāva*）。“存在”的东西又分两类：性质，以及性质共同寓居的基底；后者就是“实体”（*dravya*）。性质之中，有的同时寓于多个对象，有的各自只寓于个别事物。前者是“普遍”（*sāmānya*）；后者再分为恒驻者与易逝者，即“性质”（*guṇa*）与“运动”（*karma*）。至于余下的“和合”（*samavāya*）与“异”（*viśeṣa*）两个句义，则是为解释胜论各家的特殊学说而设。

这套对胜论体系的重构并不十分令人满意：其一，它依赖“恒驻”与“易逝”两种性质之间未经解释的区分，这个区分本身或许有预设结论之嫌；其二，它对其中两个句义完全没有交代。Potter（1977）另给出一种重构（同样有缺陷）。再看《理性手册》自己给各句义下的定义，它似乎也在走这条路。其定义如下：

**实体**

（i）具有实体性这一普遍者；

**（ii）**

具有诸性质者（TSD 3）

**性质**

（i）具有诸普遍、并且不是实体或运动者；

**（ii）**

具有性质性这一普遍者（TSD 4）

**运动**

（i）造成（诸实体之间的）连合者；

**（ii）**

具有运动性这一普遍者（TSD 5）

**普遍**

恒常、单一，并且和合于多个事物之中者（TS 82）

**异**

存在于恒常实体之中，并充当其区分者的东西（TS 83）

**和合**

恒常的、并且是关系的东西（TS 84）

**非存在**

［未给出一般定义］

把这串定义当作对句义的先验重构来读，问题不小。最扎眼的是循环问题：“实体”与“性质”两个定义合起来看，相互循环；要打破循环，就得把实体性这类普遍当作已经给定的前提，可这样一来，定义本身又显得空洞无物。下面我给出另一种重构，它大体沿袭正理胜论传统的大家优陀耶那的思路（参考 Tachikawa 1981）[^tachikawa-1981]。

## 1.3 句义清单的底层结构

第一步，把一切事物分为存在者与非存在者，非存在者对应“非存在”句义。第二步，把和合当作初始的、基本的关系。有了这种关系，以下三分法便是穷尽的：

1. 不和合于他物、反而被他物所和合者；
2. 既和合于他物、又被他物所和合者；
3. 和合于他物、却没有任何东西和合于其上者。

我们希望（a）组恰好对应“实体”句义。麻烦在于，胜论派主张整体不同于其部分、并且和合于其部分之上；于是唯一不和合于任何东西的实体就只剩原子性实体（在胜论派那里，这正对应恒常实体）。（c）组对应“普遍”句义：普遍据说和合于事物（实体、性质、运动）之上，而没有任何东西和合于普遍之上。（b）组则包括非原子实体、性质与运动。接着把这组再一分为二：只受普遍和合者，以及此外还受其他东西和合者。前者对应“性质”与“运动”两个句义，因为实体不仅受普遍和合，还受性质、运动以及其他实体和合。最后，还得设法把前者拆成性质与运动两类。较传统的正理论师是这样保住这个区分的：运动（而非性质）会使其所和合的实体彼此连合或分离。不过这诉诸“连合”这个观念，而连合本身没法用我们那个初始关系“和合”来定义。一些激进的正理论师（尤其是跋沙罗婆吉那）干脆主张运动就是一种性质，因为二者的属性实在太过相似。至此只剩最后一个句义——“异”（*viśeṣa*）：它的成员居于恒常实体即原子之中，把这些原子彼此个体化。这里的关键或许在于：其他一切事物都由和合于其上的普遍与整体来个体化，可同一实体的两个原子在一切方面都毫无差别。而如果对象是靠和合于其上的东西来个体化的，那么每个原子内部就必须有某种使它区别于其他原子的东西——一个“异”（见 §10.2）。

以上只是对胜论哲学家如何在逻辑原则上搭建句义体系的一个粗略轮廓，许多技术细节被略去了（这类细节的一个例子见 TSD 3(c)。《理性手册》还指出：实体不能定义为“性质的基底”，因为按胜论学说，实体在刚刚被创造出来的那一刻并不具有任何性质）。

## 2. 物理实体

### 2.1 五种主要的大种

胜论在公认的九种实体之中，划出一个五类子集——地、水、火、风与虚空——并称之为“大种”（*bhūta*，即“物理实体”）。大种的定义是：具有某种特定可感性质的实体，这些性质即气味、味、颜色、触与声。

或许在最初，人们以为五种大种与五种可感性质一一对应：每种性质只寓居在唯一一种实体里，气味只在土，味只在水，如此等等（《逻辑经疏》在 NS 3.1.65–6 下记载了这种看法）。这也许能多少透露“五大种”理论的来历，可是人们很快就发现，硬说土不可见、或说土的颜色总是混入火的产物，实在站不住脚（Bhaduri 1947: 133）[^bhaduri-1947]。在《胜论经》及后来的文本里，大种与可感性质之间的对应关系要复杂得多，见下表：

|   | 气味 | 味 | 颜色 | 触 | 声 |
| --- | --- | --- | --- | --- | --- |
| 地 | x | x | x | x |   |
| 水 |   | x | x | x |   |
| 火 |   |   | x | x |   |
| 风 |   |   |   | x |   |
| 虚空（*ākāśa*） |   |   |   |   | x |

正统胜论主张，每种大种都靠“具备某一类可感性质、同时缺少另一些性质”来刻画。照此，土是带气味的实体，水有味而无气味，火有色而无味、无气味，依此类推。这样的定义有个短处：即便察觉到某种可感性质，也推不出在场的是哪一类实体。后期胜论于是改求一套“诊断式”定义，为每种实体指定一种可感性质，只要它出现，就指示该实体在场。《理性手册》（TS 10–14）：

> 土（特有地）具气味。水（特有地）具冷触。火（特有地）具热触。风（特有地）具无色之触。虚空（特有地）具声。

这样一来，土、水、火虽都可知触，据说却只有水具冷触。看来《理性手册》没能替风找出正面的区别特征，只好退回到旧式定义。

到了十七世纪还有人为“五元素”说辩护，这大概会让人意外。有些现代作者想把这些实体解读为物质不同“状态”的隐喻——固体（地）、液体（水）、气体（风）以及温度（火）。这个说法恐怕站不住：文本里从未说过某一种实体可以从土变成水、再变成风。也许，把它硬塞进物理学本身就是一个错误；不如记住这些实体原是依可感性质来定义的，从而把它看成一项逻辑分析：对诸感官所提供的数据作分析，据以构造一种（形而上学）的世界理论。比方说，这类理论会这样解释“所见”与“所触”之间的对应——它设定必有某几类事物，既可看见，也可触到。同理，当触觉出现而没有任何相应的视觉感受时，我们便被引去设定存在可触而不可见的实体（风）；其余实体依此类推。说到底，正是不同感官之间这类对应关系的存在，才为客观的世界图景奠定了基础（只能由单一感官通达的现象，总更容易被当成主观的产物）。

### 2.2 胜论的原子论

《理性手册》（TS 10–14）照搬了胜论的传统说法：前四种实体（地、水、风、火）各分两类，原子式与复合式。原子（*paramāṇu*）不可毁灭（*anitya*），不可再分（也就是非复合），并具有一种特殊维度，叫做“小”（*aṇu*）。胜论替原子论给出的标准论证大致如此：经验早已确立，凡可感知者都是复合的；于是连最微小的可感知物——阳光里的一粒尘埃——也有部分，只是这些部分看不见罢了。胜论把最小的可感知物称作“三微”（*tryaṇuka*），说它有三个部分，每一部分叫“二微”（*dyaṇuka*）。那么每个部分自己还有部分吗？有。这同样是经验确立的事实：可见之物的部分自身仍有部分（例如一块布，它的部分是线，线又是复合的）。胜论说，二微有两个部分，每个部分就是一个原子。

这个论证只能说明存在小到看不见的对象，却说明不了其中有些是不可再分的。为什么分割不能无限进行下去？《理性手册》的回答很有意思：如果真能无限分割，须弥山和一粒芥子就会一般大小，因为两者的组成部分数目相同，都是无限多！这里藏着一条未明说的前提（其他胜论师曾把它讲出来）：整体的尺寸取决于其各部分的尺寸、数目和空间排列。

这个论证恐怕是在预设结论：那条隐含前提，唯有先接受原子论才站得住。非原子论者会说，对象尺寸不由其构成物决定，而由“材料”占据的空间边界决定。

### 2.3 数的形而上学（*saṃkhyā*）

新正理对数的处理，在内容与精巧程度上常被拿来与弗雷格相比，确实很有意思。《理性手册》只说了三点：数是性质（*guṇa*）；数是数判断的根据；数的范围从 1 一直到一个叫做 *parārdha* 的极大数（10^14；这里又一次显出对“无限”的不安）。数即性质之说本属早期胜论，后来却发现与胜论存在论体系的结构无法相容。我们固然可以说田里有三匹马，也可以说胜论体系中有二十四德；但按定义，性质不能寓居于另一性质之中——所以数不可能是性质。难题逼着新正理论师另起炉灶，用一类新关系来说明数，这类关系叫“圆足”（*paryāpti*），即“完成”关系。

他们的理论可以概述如下。先看这样一对句子：

1. 这张桌子的腿是木头的。
2. 这张桌子有四条腿。

（1）与（2）看上去结构相仿，这提示我们把数词当作形容词一类的东西：它们给所修饰的对象加上某种属性。正理论认为，在（1）里，“木质”这一属性借和合关系寓于桌子的各条腿中。那么（2）能否照此分析，说“四性”这个普遍和合于各条腿？新正理（尤其是罗怙那陀与贾迦迪沙）说不可以。请注意，（1）蕴涵

1. 每条腿都是木质的。

可是（2）并不蕴涵：

1. 每条腿都是“四”。

他们提出的办法是增设一种新关系——“完成”关系：它把“四性”这一属性与四条腿整体地关联起来，而不是分别关联到每一条腿。罗怙那陀说：“‘完成’关系是一种特殊的自连关系；‘这是一个罐’、‘这些是两个’这类说法，便指示出它的存在。”其注家贾迦迪沙接着讲：

> 有人可能觉得，“完成”关系无非就是和合……正因如此，罗怙那陀才说“完成”是另一种关系……拿“这些是两个罐”这句话来说，“完成”把“二性”关联起来，并把这一属性限定为“同时寓于两个罐之中”的属性。不然的话，“这些是两个”和“每一个都具有二性”便毫无分别了。

照这一提议，数属性是通过“完成”这个多对一关系与若干对象联合关联的。我觉得，稍作简化也无损其基本结构。拿“火星是一颗行星”来说，旧说法是“行星性”借和合关系寓于火星；我们不妨改说谓词“……是一颗行星”对火星为真，等于把和合关系（或系词）做进了谓词里。同样道理，也可以把完成关系做进数谓词；这样一来，若数是 *n*，该谓词便是一个 *n* 元关系。“金星与火星是两个”于是断言：金星与火星之间成立某种二元关系，这个关系就是数 2。新正理的主张因而是：数形容词是 *n* 元关系谓词，数是 *n* 个不同对象联合承负的 *n* 元关系。既然“关系 2 成立于金星与火星之间”，就绝推不出它单独成立于金星；这正像从“*X* 在 *Y* 左边”推不出“*X* 在左边”便算了事。按新正理方案，那个捣乱的推论被堵住了——它的结论压根不合式：“金星是二”和“*X* 在左边”一样，都是不完整、未饱和的表达式。

前面已经看到，正理区分两种关系：和合与完成。用现在的话说，他们关心集合属性与分配属性有何不同。承认“这些是两个罐”推不出“每个罐都是二”，无非就是承认谓词“二”不会分配到复数主词的每一个上。正理的思路是：像“……是两个”这样的集合谓词，不当作关于聚合体或集合的一元谓词，而当作 *n* 元关系谓词——它对 *n* 个对象联合成立。可这类关系谓词毕竟仍以对象为主词，这恰恰说明：看清分配谓词与集合谓词之别，并不逼我们放弃形容词式的看法。正理还给集合属性起了专门名称：*vyāsajya-vṛtti-dharma*，即“共转属性”。

## 3. 空间、时间与运动

### 3.1 方（*dik*）

对于空间与时间究竟是什么，《理性手册》讲得极其简略。要弄清，就得从其他胜论与正理作者的著作里补足细节。可即便补了，正理胜论文献中的时空理论仍很少有人研究，眼下我们也只能勾出一个粗糙而不完整的轮廓。《理性手册》论空间，要点如下：

1. 空间是实体（TS3）。
2. 空间是“这在那个的东边”一类陈述的“根据”（TS 16）。
3. 空间唯一、遍在而恒常（TS16）。
4. 空间是一切结果的工具因（TSD16）。
5. “近性”（*aparatva*）与“远性”（*paratva*）是事物的空间性质。

所谓空间，就是那样一种实体：有了它，“*A* 在 *B* 的东边”（以及“*A* 离 *B* 近”、“*A* 离 *B* 比离 *C* 近”等）这类表示距离和方向的陈述才有客观的真假。可见空间是一个解释性的设定：据论证，为了说明事物之间何以有空间关系，我们必须承认存在一种新的、空间性的实体。麻烦在于这句话该怎么理解。Bhaduri（1947: 216–7）作了如下说明（以下是他的说法的转述）：

> 设想有一串对象 *A*、*B*、*C*、*D*……*F*，一个挨一个排成一线，彼此相触。这样，*A* 在 *B* 左边，*B* 在 *C* 左边；既然“在……左边”是传递的，*A* 也就在 *C* 左边，依此类推。然而，*A* 虽触着 *B*，*B* 虽触着 *C*，*A* 却并不因此触着 *C*——“触”不是传递关系。所以，“触”没法充当对象之间空间关联的根据。那到底是什么呢？“按胜论的说法，把［*A* 与 *C*］关联起来的正是空间。两者都与空间连合，于是经由空间的中介而彼此相关。空间所起的作用，就是把连合关系变成传递关系”（Bhaduri）。

这个说明有个漏洞：它假定任意两个物体之间都夹着一串彼此相触的质料对象。可一旦有了这个假定，我们根本不需要再设一种万物都与之相触的新实体。要把“触”变成传递关系，只消这样定义“在……左边”即可：*x* 在 *y* 左边，当且仅当存在一串不同的对象 *p*、*q*、*r*……*t*，其中 *x* 触着 *p*，*p* 触着 *q*，……，*t* 触着 *y*。

Potter（1977: 92）把这个论证打磨了一番。我们说 *A* 离 *D* 比离 *F* 近，是因为 *A* 到 *F* 之间隔着的东西比 *A* 到 *D* 之间多。可是，假如 *D* 与 *F* 之间根本没有质料对象连成一线，我们又凭什么说“*A* 离 *D* 比离 *F* 近”？Potter 的回答是：“要为这一比较判断提供解释材料，我们就得设定一串居间的实体，而且这些实体必须是空间性的。”注意，这里解释的不是“在……左边”这类方向关系的传递性，而是“靠近”这类距离关系的大小。“靠近”并非传递关系。这个说法接受了一条基本前提：两个对象之间的距离，以居间实体的数目来计量；若没有质料实体充数，就设定一串“空间实体”。

这个说明也有麻烦：空间据说只是一个单一实体。也许应当改口说，两个对象分别触着空间的某个“片段”，而空间片段是有大小的。

也许最好的读法是：这个论证无非是想在不假设一串居间物体的情况下说明空间上的间隔。这样一来，若 *A* 离 *D* 比离 *F* 近，而 *A* 与 *D* 之间、*A* 与 *F* 之间又都空无一物，那么最好的解释就是：*D* 触着空间较近的一段，*F* 则否。

《理性手册》说空间“遍在”（*vibhu*），并把遍在定义为“与土、风、火、水的每一个样品（以及‘意’）相触”（TS14）。问题随之而来：空间的维度是无限的，还是与宇宙一样大？若按物理对象之间的关系来定义空间，它似乎应与宇宙同大。但胜论另有一套论证，说它是无限的。胜论师指出，大多数物体在维度上非“长”（*dīrgha*）即“短”（*hrasva*）（TS25，Bhaduri 1947: 118）[^bhaduri-1947]；然而，一个物体若没有界定范围的周边部分，说它“长”或“短”便无从谈起。空间恰恰没有部分，也就没有边界。一些胜论师因此断定：空间没有有限维度（也就是无限）；另一些则说，它有一种特殊维度，叫“极大长度”（*paramadīrgha*）。

### 3.2 时（*kāla*）

《理性手册》这样讲时间：时间是关于过去、现在、未来之陈述的根据；它唯一、恒常、遍在；它包容万物，也是一切结果的工具因（TS15+D）。时间的构想与空间如出一辙：靠着它，“A 早于 B”一类陈述才有客观真假。据说时间与空间有一处不同，因而并不等同于空间：空间上的远近因人而异，时间上的远近则对所有人都一样（参考 Bhaduri 1947、Mohanty 1992）[^bhaduri-1947][^mohanty-1992]。可是，为什么只盯着现在活着的人呢？

《逻辑经》里，乔答摩记载了一个否定“现在时间”的论证，它与龙树破运动的论证像得出奇（甚至可能就是从那里来的）。NS 2.1.39（转述）：并无所谓现在时间。物体坠地时，轨迹上每一点要么落在已经过之处，要么落在尚未到达之处；于是轨迹上没有任何一点可以归给现在。现在时间只是过去与未来之间一条想象出来的分界线。乔答摩的答复见 NS 2.1.40–42：(i)“过去”与“未来”两个概念是相对于“现在”才成立的，二者彼此之间并不相对；(ii)若否认现在，就会推出一个荒谬的结论——没有任何东西能靠知觉被认识，因为知觉恰恰发生在现在。(i) 的意思或许是：现在即便只是一条界线，也未必就是虚构的。

### 3.3 胜论的动力学理论：运动的性质与原因

从普拉夏斯塔帕达（公元 6 世纪）开始，早期胜论作者对抛射体以及其他运动物体的行为，产生了一种理性而科学的兴趣。他们的理论可以拿来与菲洛波诺斯的“冲力”说相比——后者在西方科学思想史上引发过一次范式转换。《理性手册》的叙述与普拉夏斯塔帕达的说法大体相同，而后者有一部分可以追溯到《胜论经》本身。相关诗节的内容可概述如下：

> 运动是连合与分离的非和合因。运动分五类：四类出于意愿（上抛、下掷、收缩、扩张），第五类则囊括一切非意愿的运动（下落、旋转、流动等）（TS 5, 81）。
>
> 重性（*gurutva*）是物体最初下落运动的非和合因（TS 30）。
>
> 液性（*dravatya*）是（最初的？）流动的非和合因（TS 31）。

“冲力”（*vega*）是一种倾向属性（*saṃskāra*），“弹性”（*sthitisthāpaka*）也是（TS 80）。“冲力”是物体第二轮以及此后各轮下落运动的非和合因（TS 30）；弹性则是使变形之物恢复原状的东西。

这套理论可以简述如下。一个运动中的物体，在每一时刻都带有某种特定的“运动”；这种运动应当看成物体身上瞬时的、近乎性质的东西。运动被定义为连合或分离之因。物体与另一（静止）物体的连合，由空间位移造成。于是，物体的运动要么等同于、要么导致了它在两个时刻之间于空间中的位移。运动不能由另一个运动产生（否则就会永动不息）。物体之所以开始运动，是因为它具有“重性”或“液性”之类的性质；之所以持续运动，是因为它带有一种倾向属性——“冲力”或“弹性”，后者是后续运动的持续原因；之所以停下来，是因为与其他物体相触。

“冲力”在这里扮演的角色特别有意思。可以用两个例子说明：(i) 果实从树上落下；(ii) 标枪斜着向上掷出。

1. 时刻 *t*₀，果实静止在位置 *s*₀，其重性由与果柄的接触而平衡。到 *t*₁，果柄折断，重性使果实移向点 *s*₁；也就在这时，果实内部产生了倾向性的“冲力”。到 *t*₂，果实中的冲力促成第二次运动，由 *s*₁ 到 *s*₂；此后每一时刻皆如此。请注意：果实的“重性”只造成最初那次运动，随后便不再起作用；此后一切运动之因，都是最初那次运动印入果实内部的“冲力”。正因为后续运动源于内部印入的 *vega*，而非外部力量，我们才把胜论的这套说法称为冲力说。
2. 标枪掷出时，最初那一推出于意愿，给标枪带来初始运动和冲力。向上的冲力抵消标枪的重性，使它向上飞；待冲力因与空气接触而耗尽，标枪的重性又给出向下的冲力，标枪便坠落。标枪的水平运动也来自它所带的水平冲力，而这个冲力同样因空气接触而递减。标枪起初获得的冲力大小，与那一推的力度成正比。这里再一次看到：标枪持续穿行空中，靠的是它自身带有冲力，而不是某种外力在推它。

胜论师把这个模型推而广之，用来解释另外几类运动。(1) 水最初之所以流动，据说原因是一种叫“液性”的力（而不是水的重性）；此后的流动，则靠水获得的冲力。(2) 还有一点很有意思：直线运动物体的冲力，在本体论上与弯曲木棍的弹性同属一类。可见冲力是内部力量，不是惯性。(3) 胜论师还举出别的运动：铁针趋向磁石、火焰上腾、空气流动，以及创世之初原子的启动。按上述模型，每种运动起初都得有某种“力”来发动，可已经找出的那些“力”（重性／重力、液性、弹性）都不敷用。于是胜论师又提出一种新力——“不可见力”（*adṛṣṭa*），据说它可以解释这类运动。

## 4. 自我：人的与神的

在胜论九种实体中，第八种是“自我”（*ātman*），其定义是相信、知道等心理状态的基底。（第九种是“意”（*manas*），它是心理现象的存在论中的一个独立要素。）自我分两类：人的自我（*jīva*）与神的自我（*paramātman*；*īśvara*）。《理性手册》为这两类自我的存在各提供了论证，而这些论证都可以追溯到更早的作者。

### 4.1 关于上帝存在的因果论证

一个表述合式的正理论证包含三部分：宗、因（*hetu*）与喻（*dṛṣṭānta*）。其中“宗”又分两截：一是推理的“处所”（*pakṣa*，所别），二是要在该处所中推出其存在的属性（*sādhya*，所立）。所以凡正理论证都套同一个模子：*p* 有 *S*，因为它有 *H*；例如 *d*。（举例：“山（= *p*）有火（= *S*），因为它有烟（= *H*）；例如厨房（= *d*）”。详见 §8。）一个站得住的论证至少得满足三条：(i) 因属性在处所中必须无争议地存在；(ii) 因属性与所立属性之间必须有恰当的关联，粗略地说，凡有因之处即有其所立；(iii) 喻必须是双方都承认、且因与所立同时具备的场合。

有了这些准备，再来看《理性手册》论证上帝存在的那一段：

> 地等的二微有作者，因为它是果；例如罐（TSD 17b）。

此处推理的处所是二微，即最小的复合体。因是“果性”（*kāryatva*），所立是“有作者性”（*kartṛ-janyatva*）。《理性手册》对“作者”有细致的界定：所谓作者，就是能非推理地觉知到所造之物的和合因或质料因、生起制造它的欲望、并照此行动的东西。按这个意思，罐的作者是陶匠，而不是陶轮、陶土或其他任何因果环节，因为看见陶土（即罐的质料因）、起意做罐、并且动手使用轮与棍的，正是陶匠。

评注：(1) 《理性手册》为什么拿二微当推理的处所？这其实是一着妙棋。当然不能拿上帝当处所（比如说“上帝存在，因为……”），否则可靠推理的第一条标准立刻落空：处所本身的存在尚有争议，因属性再怎么样也不可能在它里面无争议地成立。也不能拿“世上万物”当处所，因为其中不少东西并不是果（原子、空间即是），于是想要的那个因又不会在处所中毫无歧义地存在。所以只能挑某个具体的东西。人工制品最好别挑：那样的话，推理即便可靠，也证明不了上帝什么。在非人工制品里，挑二微很合适：(a) 二微是由原子做成的最基本之物，其他一切又都由二微做成；(b) 只要《理性手册》能证明二微有作者，按作者的定义并结合 (a)，就能推出这位作者觉知一切。于是，上帝的遍知反倒成了其存在证明的附带结论。

(2) 这个论证把“陶匠—罐”一例中的因果图景，推广去覆盖一切自然现象。上帝所做的，是拿给定而未被造的原料（原子，好比陶土）造出万物；这些原料是产品的质料因。Matilal 因此说，正理的上帝是“陶匠模型”，有别于“蜘蛛模型”（上帝从自己的本质中纺出世界）和“魔术师模型”（世界是上帝变出的幻象）。可是，这个论证背后是一种拟人化的、行动者式的因果观。佛教徒法称就拿它开涮：罐不过是用土做成的东西，跟蚁丘一样；难道能说蚁丘这号公认复杂精巧的建筑，是智能行动者的作品？退一步说，就算是，世界为什么不能像蚁丘那样出于集体行动，而必得由单一行动者造出？

(3) 这个论证也可以理解为一种归纳：从人工制品一类，归纳到自然产品一类。那么，凭什么从“见过有作者的东西”，推到“没见过有作者的东西”？法称（参考 Vattanky 1984: 56–8）[^vattanky-1984] 的答复是：只有当我们见过同类中的其他对象被造出来时，才有权推断某个对象有作者。所以，我们能推断金字塔有作者，不是因为看见了那位作者，而是因为金字塔属于“建筑物”一类，而这一类的其他实例我们见过是怎么造起来的。正理论师则把归纳的胆子放大：两个对象只要同为结果，就算在这个意义上属于同一“类”。

### 4.2 关于人的自我存在的论证

胜论对人的自我所下的定义是：它是相信等心理性质的基底，也是快乐及其他情感的基底——这些情感上帝并没有。这里同样暗中借用了因果的“陶匠”模型：就像“陶匠造罐”一句中“造罐”这一属性寓于陶匠，“我相信 *p*”中“相信 *p*”这一属性也寓于我。自我既然被定义为心理性质所寓居的那种实体（不管它究竟是什么），问题便是：这种实体能否认作某种物理实体，比如人的身体或感官？还是说，必须另立一类新实体？胜论的答案是后者，办法则是排除两个竞争者。

(1) 相信等的基底就是人的身体。《理性手册》替这一方这样申说：我说“我冷”“我在跑”时，谓词落在我的身体上；那么我说“我相信 *p*”时，主词也该是我的身体。《理性手册》反驳道：若真是这样，那么

> 麻烦就来了：手、脚之类一经毁坏，身体也就毁坏；照此推下去，自我也会跟着毁坏。

显然，我少了一部分身体，仍旧可以相信、可以知道；而失去身体的一部分，不等于整个身体都没了。所以这条论证不成立。《逻辑经》里另有一个更高明的论证：“我的身体”这个说法本身，就说明我并不等同于我的身体。可这一招也不灵——我照样可以说“我的灵魂”！可见这里并没有一条明确驳倒物理主义的论证。

(2) 相信等的基底是人的诸感官［别忘了，每种物理实体都分三方面：属于身体、属于感官、属于（无生命的）对象］。这个说法有些古怪，或许可以把佛教的观点也包进来：人不过是一串刹那生灭的心理事件，感官材料也在其中。《理性手册》驳斥这种看法所用的论证相当有力（它其实已见于《逻辑经》）：

> 若真是这样，再认统觉（*anusandhāna*）就不会有了，例如“先前看见那个罐的是我，此刻摸到它的也是我”；因为一个东西不可能再认另一个东西所领受到的内容。

这番意思无非是说：要有再认的经验，就得先有一个单一而持存的自我。这里其实挤着两个论证。第一个：我不可能记得某物，除非此前见过它；你见过的东西，我记不得（可参洛克用记忆经验的连续性来讲人格同一性）。第二个更绕。阿毗达磨佛教说，人只是经验堆积而成，其中有的是视觉的、有的是触觉的，如此等等。正理论师反问：跨感官判断分明可能——人会把这一感官所给的东西，同另一感官所给的东西拿来比较。设 *V*(*o*₁) 是对 *o*₁ 的视觉经验，*T*(*o*₂) 是对 *o*₂ 的触觉经验；我们可以判断“*o*₁ = *o*₂”，可这个判断不属于任何一个感官的辖区。于是它只能落在别的实体里。这里，自我被设想为那样的东西：它把各个感官的所与汇集起来、组织起来、加以比较。详细讨论见 Ganeri 2012 第 11、15、16 章。

趁便介绍九种实体里的最后一种——“意”（*manas*）。《理性手册》（TS18）把它定为第六种感官，人靠它“感知”自己内心的心理对象（信念、快乐感受等）；换句话说，它是一种内省官能。那么，凭什么说它不属于自我、而自成一物？正理惯常这样回答：自我是认知的作业者，意是认知的工具——好比砍树时，挥斧者才是作业者，斧头只是工具，两者要分开。正理还说意另有一桩职能：在各感官之间“切换”。其假设是，来自不同感官的印象可以同时加于我们，而我们一次只关注一个。

《理性手册》（TS 79）说，胜论诸性质中有八种只寓于自我，不寓于其他任何实体：认知、记忆、乐（*sukha*）、苦（*duḥkha*）、欲（*icchā*）、瞋（*dveṣa*）、功德（*dharma*）与非功德（*adharma*）（TS 73–78）。前两种留到后文（§§ 5.2–3）再谈。至于乐与苦，Matilal（1986: 301）的概括可以代表胜论的说法：“乐或幸福的本质特征，在于它被体验为对我们有利、与我们相合，也就是与我们的身体、心灵或整个生存处境相合（*anukūla*）。”正因如此，它不同于认知、知觉或领受某物；它也是“一种内在的配置，有了它，外部世界才显得适意、可欲”。欲是对某物的渴求；功德则由有功业（*karma*）产生。详见 Ganeri 2012 第 13、14 章。

## 5. 哲学心理学

### 5.1 哲学心理学概观

正理哲学方法的核心，是对认知（*buddhi*、*jñāna*、*upalabdhi*）的本性、内容和原因的研究。知识论问的是：真认知与假认知如何区分？真认知在什么条件下发生？逻辑理论问的是：在某种恰当界定的意义上，一个认知何时“跟随”另一个认知？语言哲学则假定，句子结构映照着认知结构，所以要研究句子意义，就得分析句子所“表达”的认知。《理性手册》足以说明这一主题的分量：在胜论图式里，“认知”严格说来只是二十四种性质之一，可对它的分析却占了全书近一半（TS 34–74）。

正理论师所谓“认知”，指的是任何意向性的（*sa-viṣayaka*，即指向对象的）心理状态，知觉、推理、怀疑、猜测、记忆等都在其内；欲望、希望、受苦之类则不算（参考 Matilal 1968: 7–8）[^matilal-1968]。既然我们说主体具有这类状态，它们便被看作灵魂的“性质”（取胜论的术语义）。《理性手册》说认知是“一切语言实践的根据”（TS 34）——这透露出正理的看法：语言首先是说话者把真思想传给听者的工具。

从知识论着眼，认知之中最要紧的划分，是真认知与其余认知之别。不过，正理对认知种类的标准分类（《理性手册》照搬了这一分类）却从另一刀切起：先把记忆认知（*smṛti*）与其他认知（*anubhava*，非回忆性认知）分开。完整分类如下：

| 认知 |   |   |   |   |
| --- | --- | --- | --- | --- |
|   |   |   |   |   |
| 非回忆性（*anubhava*） |   | 记忆（*smṛti*） |   |   |
|   |   |   |   |   |
| 真（*pramā*）：知觉的、推理的、比较的、证言的 | 非真（*apramā*）：假（*viparyaya*，四类）、疑（*saṃśaya*）、*tarka* |   | “真”（*yathārtha*） | “非真”（*ayathārtha*） |

正理的知识论，实际上就是关于“真的非回忆性认知”的一套理论。按产生它们的四种被认可的知识手段（*pramāṇa*），这类认知又分四类。（偶然为真的认知呢？比如瞎猜猜中了——要把它们塞进上述图式，麻烦不少，讨论也很多。）显而易见，知识方法再可靠，也免不了偶尔失手，产出假认知（知觉幻象、因转述出错而形成的信念，等等）。《理性手册》（TS 72）举的例子是：看见一枚牡蛎壳，却作出“这是一块银”的假知觉判断。知觉、推理与证言的知识论，分别留到 §§7、8、9 讨论。这里先细看三类认知：记忆、“疑”与 *tarka*。它们在正理框架中地位重要，却都从属于知识论。（那么梦算什么？TS 70 把梦归入“假”认知。这有些奇怪：梦不是四种 *pramāṇa* 中任何一种失手的结果，也不是记忆或疑。按普拉夏斯塔帕达的说法，梦是“意”脱离外部感官时自由活动的结果，并受“不可见力”（*adṛṣṭa*）的驱使。）

### 5.2 记忆

西方传统一向把记忆看作个人证成自己关于过去的信念的重要手段。相形之下，正理从一开始就把记忆状态与能带来知识的信念分开，不承认记忆有知识的资格，这一点颇值得注意。《理性手册》关于记忆的说法是：

> 记忆状态，就是仅仅由“心习”（*bhāvanā*）所生的状态（TS 35）。
>
> “心习”是灵魂的一项性质：它由非回忆性认知引起，又引起记忆认知（TS 80）。
>
> 记忆或“真”或“假”，取决于其源初认知的真假（TS 74）。

这套理论大体是说：最初的认知（比如对某物的知觉经验）会留下一种倾向性的心理状态；一旦其他因果条件具备，它就能唤起对该物的现时记忆。（整个机制有点像学会游泳的人：他有了游泳的倾向能力，遇到合适场合便下水。）由此生成的记忆状态与源初知觉经验内容相同；它只是在派生意义上才谈得上“真”或“假”，端看最初那次知觉是否如实。照这样说，记忆成了一种完全不会出错的官能：文本压根没提“虚假记忆”（没有任何源初经验却有记忆），也没提“错误记忆”（记忆内容与源初经验对不上）。

照这套说法，记忆不过是在复现过去那次认知经验；这么说来，记忆本身也许算不上知识——正如一幅毕加索的精确复制品算不上毕加索。正理论师说，记忆缺少“独立性”。其意或许是：通常我们靠检查经验如何被引起来判断它是否真实（我看见桌子，这知觉是如实的，因为视力好、光线足，等等）；可记忆不同，必须绕道源初经验。记忆被看成原初经验的替身，其真实性“依赖”于原初经验。不过我们也可以反过来说：记忆所做的，恐怕不止是复现原初经验——它还能把所经验之事表现成“发生在过去”，内容因而并不相同。

### 5.3 疑（*saṃśaya*）

“疑”在正理中扮演着重要的理论角色：正理主张，任何哲学探究都以疑的状态为先决条件。疑是《逻辑经》1.1.1 所列举的十六个论题之一，而这些论题框定了全书的范围。尤其是，疑乃是一个规范推理的头一步：山上有没有火？——有，因为那里有烟。《理性手册》对疑的定义极为精确（TS 71）：在同一所别中对两个不相容能别的认知，例如“这（模糊看到或远处的）东西是人还是树桩？”这样一种认知。用图式的话说，疑的内容形如“*x* 是 *F*，抑或不是 *F*？”。

两点值得一说。(i) 疑虽归入非真认知（*apramā*），却不是假认知。假认知是：实际上 *x* 不是 *F*，可内容偏偏是“*x* 是 *F*”。(ii) 疑之有别于其他认知，是因为它的内容类型特殊，而不是因为它属于某种特殊的命题态度。正理在这里并没有说，人对同一命题可以采取相信、不信、怀疑等一整套态度中的某一种。可要是疑的唯一标记就是 TS 71 规定的那种内容，那么“*x* 是 *F*”的疑与“*x* 既是 *F* 又不是 *F*”的信，又差在哪里？跋达摩那的办法，是把“真地持有一个矛盾信念”与“只是相信自己持有矛盾信念”分开。前者按理不可能；那个貌似矛盾的信念“*x* 既是 *F* 又不是 *F*”，实际上是一个信念：我相信我有一个信念，其所以别为 *x*，能别为 *F* 与非 *F*。既然根本没有真正的矛盾信念，也就不会有与疑同内容的信念。

### 5.4 *tarka*（假想性思维）

“*tarka*”一词常被随随便便地用来指假设性推理或归谬推理；《理性手册》却赋予它一个远为精确、也远为技术化的含义：

> *tarka*，就是通过赋予“所遍充”（*vyāpya*）而赋予“能遍充”（*vyāpaka*）。例如“若无火，则无烟”（TS 73）。

定义里的几个词得解释一下。“赋予”（*āropa*）的专门含义是“反事实认知”或“假设性认知”（*āhāryāropa*）：这种认知的能别，是一个已知其反面居于所别之中的属性。说白了，就是一种反事实的假定。“能遍充”和“所遍充”则借自正理的推理理论。我们说“凡有烟处必有火”，可以改说成“火遍充烟”，也就是“有烟之物”的外延比“有火之物”窄。这里，火是能遍充，烟是所遍充。于是 *tarka* 便是：在反事实地假定火不存在之后，认知到烟也不存在。它是对条件句“若 *p* 则 *q*”（或“倘若 *p* 为真，则 *q* 为真”）的认知，前提是假定“*p*”为假。

*tarka* 的一大功能，据说是消解疑。假定有人怀疑“*x* 是 *F* 吗？”，他也许判断“若 *x* 不是 *F*，则 *x* 不是 *G*”；要是他又知道 *x* 是 *G*，就可以推出 *x* 是 *F*。正理论师承认这功能，却仍旧不认 *tarka* 为知识来源（*pramāṇa*）。理由似乎是：为某个论题举出正面的经验证据，跟只靠先验方法排除相反的可能，是两回事。这一点也许就体现在：凡以 *tarka* 为据的论证，都不举喻例来支撑推论。《理性手册》似乎还走得更远，连反事实条件句也否认是真认知；既然它们也不假，那就等于说反事实条件句没有真值。

优陀耶那说 *tarka* 分五类：“自依”（*ātmāśraya*）、“互依”（*anyonyāśraya*）、“循环”（*cakraka*）、“无穷倒退”（*anavasthā*），以及“有不欲之后果”，也就是归谬（*aniṣṭāprasaṅga*）。这五类大体上望文可解；其中第五类 *prasaṅga*，正是龙树和其他中观佛教徒用得出神入化的那一招。别的作者开列的清单略有出入（详见 S. Bagchi 1953）[^bagchi-1953]。

## 6. 因果与知识的因果理论

### 6.1 因果概观

在印度哲学思想里，因果研究分量很重。一个原因是早期就热衷于宇宙论思辨：“别忘了，印度的哲学活动是从《吠陀》与《奥义书》的宇宙起源思辨里长出来的；哲学的头等大事，就是为这个复杂宇宙的起源找出某个简单而单一的因”（Matilal 1985: 287）[^matilal-1985]。另一个原因是印度语言学——尤其是波你尼的“作业格”体系（动词与名词之间的关系学说，对正理、弥曼差和佛教思想家影响深远）——本身就建立在一个底层因果模型之上：句子里的动词标示一个事件，而被名词标示的对象，各自在这个事件的产生中扮演特定的因果角色。同一模型又塑造并影响了印度知识论，催生了“量”（*pramāṇa*）的理论：量就是引向知识论上合格的认识事件（*pramā*）的因果手段或过程。正理传统承认四种量：知觉（*pratyakṣa*）、推理（*anumāna*）、“类比认定”或“比较”（*upamāna*），以及证言（*śabda*）。对每一种量，说明都用十足因果主义腔调，典型问题如：“什么引起了知觉经验？”“真知觉与假知觉的区别性因果因素是什么？”“在什么条件下，对前提的知识会引起对结论的知识？”等等。

用什么例子，无疑会反过来影响一个人的因果理论。正理论师几乎总是用下面三个例子之一展开讨论：(i) 陶匠—罐例。果是做成的罐；它的因包括两半罐坯（陶匠把它们接合成罐）、陶匠、轮与棍、两半坯之间的连合、坯与棍之间的连合等等。(ii) 线—布例。果是一块布；它的因包括织成它的线、织工、梭、织机，以及各种连合等等。(iii) 斧—树例。果是树被砍倒；它的因有斧、斧与树的接触、伐木者等等。我们想问的问题有：所有因果事例都能装进这些例子所展示的一般模式吗（比如：总得有个“作业者”吗）？就算就这三个例子而言，正理论师的因果说明够用吗（换句话说，他们分得清哪些因素是果的因、哪些不是吗）？对象和事件都能充当因吗？因果关系是逐一的，还是建立在可重复的规律性之上？随着正理学派的发展，对这些问题的回答把因果说明打磨得越来越细。

### 6.2 三种因

按正理胜论的传统说法，在导致一个事件的因果因素总集（*sāmagrī*，因缘总集）之内，可分出三种因：“依处因”（即“和合因”，*samavayi-kāraṇa*）、“非依处因”（即“非和合因”，*a-samavayi-kāraṇa*），以及“工具因”（*nimitta-kāraṇa*）。《理性手册》（TS 43）照抄了这一分类。所谓依处因，就是果所和合于其中的实体。罐的依处因是两半罐坯，布的依处因是线。道理在于，正理主张整体和合于其部分；于是若果（比如罐）是整体，它的依处因就是它所和合其中的那些部分。若果是“对象获得某个新性质”（比如树被砍倒），依处因就是那个对象（树）。要注意，虽然相似，依处因这个概念并不等于亚里士多德所谓“质料”因：其一，对象的部分未必等同于组成它的材料；其二，非物质实体也可以是依处因——比如灵魂，它就是认识事件的依处因。

其他一切因果因素，要么是“非依处因”，要么是“工具因”。所谓非依处因，是和合于依处因之中的因素——它虽不是依处本身，却与依处紧密相连。人们说，线的连合是一块布的非依处因。常引的另一例：布的颜色，其非依处因是线的颜色（线色和合于线，而线又和合着果——布色）。其余一切因果因素都叫工具因，比如织工的梭，或织工本人。为什么要分出非依处因与其余？也许是要区分“果要存在、它就必须继续存在”的因，与“果不必靠它维持”的因。线失了颜色，布就跟着失色；线一散，布就不复存在。可织工织完布后再死、梭随后被毁，都动不了果的分毫。

这些定义推不出“凡和合于依处的都是非依处因”，也推不出“其余的都是工具因”。换句话说，“成为一个因”还得另行定义。不过在此之前，正理又分出两类因果因素：“特殊”工具因（*karaṇa*）与“作用条件”（*vyāpāra*）。我们平常爱说某果的“那个”因，也就是从因果因素的总集里挑出格外突出、格外要紧的那一个。直观的图画是：依处因（两半罐坯）有了，非依处因（两半的连合）有了，甚至部分工具因（陶匠等）也有了，可陶匠要是不“动手”，果（罐）还是出不来。于是在某种意义上，陶匠当真用棍这件事，才是罐的“那个”因。正理论师试图抓住这个直觉：工具因当中，有一个是结果的“特殊”（*asādhāraṇa*）因，他们称之为 *karaṇa*。这个概念在正理知识论里特别要紧（见下文）。那么这个因“特殊”在哪里？新正理（参考 TS 54）这样回答。他们先引入“作用条件”（*vyāpāra*）：直接先于果的那个因。罐的作用条件是两半罐坯的连合；砍树的作用条件，是树倒下之前斧与树的最后一下接触。“特殊”因则定义为“造出”这一作用条件的因素——换句话说，它的运作直接带来了果。在例子里，就是斧，或陶匠的棍。对正理来说，这些对象才是产生果的真正工具。

### 6.3 什么是因？

正理论师就这样搭起一个因果模型：不同的因果因素各司其职。这个模型呼应（或被呼应于）印度语法对因果句子的分析——“陶匠用棍掷出罐”“伐木人用斧砍倒树”——除标示事件的动词外，还分出作业者（*kartṛ*）、所作业（*karman*）、工具（*karaṇa*）等等。可是，因与非因怎么区分？这个悬而未决的问题由《理性手册》（TS 41）给出新正理的答案。给定两个实体 *c* 与 *e*：

*c* 是 *e* 的因果因素，当且仅当

1. *c* 先于 *e* 而存在；
2. *c* 与 *e* “恒常”（*niyata*）相伴而存；
3. *c* 相对于 *e* 是“相关”的（*ananyathāsiddha*，不由他立）。

第一条防止自因。第二条是说：*c* 一类实体，总与 *e* 一类实体恒常并存。*c* 类与 *e* 类之间必须有不变的恒常连合。这排掉了纯属碰巧在场的对象——正理论师自己的例子：陶匠刚开工，一头驴恰好踱过陶坊。这一说明的要点——坚持因果关系例示一种规律性——颇有休谟味道。不过正理论师也承认“偶然的”非因果规律性是可能的：白昼总在黑夜之前；又如《理性手册》的例子，线色总在布之前。布出现时固然总先有线，也总有线色，可我们不会说线色是布的因。第三条就是他们用来清掉这类偶然规律性的办法。同一条也用来把“因之因”（如陶匠的父母）挡在因之外。但它的意思不太清楚。按字面，因必须“不由他立”。Kalidas Bhattacharya 说：“一个不变的前件，若对它的知识并非预见果之产生所必需，便是不相关的”（见 Potter 1977: 67）[^potter-1977]。Matilal 则说，前件不相关，是指“可以为它的出现找到合理的解释”（1985: 290）。《理性手册》的说法是：一个前件若只是与某个其他实体一起才确立了先行性，那它就不相关。我们知道线色先于布，只因为知道它随线出现（而我们知道线先于布）；所以说线色在这个意义上不相关。这就暴露出两种规律性并不对称：线色—布是一种，线—布又是一种。后一条可以直接靠观察线与布的关联确立；前一条却要靠观察线色与线的关联才能确立。据说前者依赖后者，反之不然。可这种依赖是否也会反过来走，并不清楚。总之，正理论师用这一标准挡传递性时，他们要定义的似乎不是因果性本身（多数人认为因果性是传递关系），而是一个知识论概念：“因果解释”或“因果显著性”。

### 6.4 因果与知识

非记忆的认知分真假两类。只要找到恒常先于真认知的因素，知识的因果理论就有了眉目。我们就能说：一个认知是知识事件，当且仅当 (i) 它为真，且 (ii) 先于它的是一个恒常先于真认知的因果因素（这样，它为真就不是碰巧）。正理（TS 39）声称恰好找到四种不变关联：知觉、推理、比较与证言；对每一种都套用上述因果模型。尤其是，他们从每一种里分离出一个“特殊”工具因（*karaṇa*），命名为 *pramāṇa*（量）。就知觉而言，这就是感官。注意，按上文定义的两实体间不变关联，并不蕴含“第一者在场，第二者就在场”——陶匠与罐恒常相连，可只有他实际“操作”时才造出罐。同理，一个 *pramāṇa*（比如眼睛）只有在实际运作时才产生真认知。换句话说，*pramāṇa* 是真认知的必要因，而非充分因。要凑足充分因，正理（TSD 69 iii）说：

> 与真认知相对而言“特殊”的那个因果条件，称作 *guṇa*［认识善德］；与假认知相对而言“特殊”的那个因果条件，称作 *doṣa*［认识过失］。就知觉而言，［真认知“*x* 是 *F*”的］*guṇa*，就是与具有属性［*F*］的对象［*x*］的感官连接，等等。

这其实就是真知觉认知的作用条件。于是，所有常规因素（依处因、非依处因、一般工具因等）加上一项认识善德（*guṇa*）齐备，就是真认知发生的充分且必要的因果条件（另见 Philips and Tatacharya 2003）。

## 7. 知觉、概念与感官—对象关系

注意到屋角里蜷着一团东西，我把它看成一段绳子；朝窗外看，我看见天是蓝的，也许还看见天的蓝；我也看见空气是冷的，看见街上空无一人。这些经验凭什么都算知觉行为？《理性手册》（TS 46）给出正理的经典答案：

> **原则 1**：凡知觉经验，其特殊工具因都是所知觉对象与知觉者感官之间的一种“连接”（*sannikarṣa*，感官连接）。

一切“看见”，都是与所见之物发生某种（待说明的）感官连接的产物。这个基本想法要补上两件事，才算得上像样的知觉理论。其一，得说明上文所举各例中知觉内容为什么有语义结构（比如“角落里的东西是一段绳子”），不然知觉经验就不可能为真，也就没资格当知识事件。其二，得说明这里涉及的“连接”有哪几类。到那时，我们才有资格评判正理理论的高低。

### 7.1 “有分别知觉”与概念的作用

把对象 *a* 看作具有某属性 *f* 的有结构知觉（比如把角落里的东西看成一段绳子），正理论师称之为“有分别”（*savikalpaka* = *saprakāraka*）：这是把一个对象——所别（*viśeṣya*）——知觉为带有某个特征或“能别”（*prakāra*；*viśeṣaṇa*）（参考 TS 47）。正理论师主张，一切知觉知识都必须是这种形式；他们还说，我们自以为“只是看见一个对象”的大多数情形（“我看见那辆车”），实际上是把某物看成一辆车。在“有分别”知觉里，与知觉者发生感官连接的是所别。那么，能别又是怎么进来的？正理的回答是：

> **原则 2**：凡知觉，其能别都是先前被知觉过的实体（实体、性质、运动或普遍）；知觉者把它回忆起来，“叠加”到所别之上。

直观的图画是：那个起限定作用的特征是一个概念，由知觉者从经验中学得，如今用来给所见对象归类。要把跑过去的动物看成马，必须先通过以往的接触拥有“马”这个概念。（这里用“概念”一词，并不是说这些特征是主观的——在正理看来，它们是客观实体，或由客观实体构造出来。）于是，正理把他们的记忆理论（最初经验→倾向痕迹→记忆事件）当作了“概念拥有”的理论。

原则 2 引出一串推论：

1. 若每次把对象 *a* 看成 *f*，都得先有对 *f* 的先前知觉，而那次知觉又是把 *f* 看成被某能别 *g* 限定的，那就没完没了了——无穷倒退。所以正理（参考 TS 47）主张，除有分别知觉之外，还有“无分别”（*nirvikalpaka* = *niṣprakāraka*）的知觉经验：这种经验里，对象与其能别同时呈现，却不把它看成“受该能别限定”。
2. 拿一个例子说明总理论。设我头一次见到一只蓝瓶，那种蓝我从未见过。理论说：在把瓶子看成“带那种蓝”之前，我先看见瓶子连同那种蓝（但不是“带那种蓝”的样子），随后回忆起那种蓝，把它叠加到瓶子上。
3. 知觉幻象、幻觉之类，都能解释成“从记忆（或概念库）里召回了一个错误特征”。设我把屋角蜷着的东西看成蛇。按正理的说法，我召回并叠加了“蛇性”，大概因为它与真正的“绳性”长得太像。同样，若我幻觉出一柄匕首，这个说明就意味着：我把从前见过的某柄匕首的记忆，叠加到了眼前的空间区域上（按原则 1，总得有个所别）。这就是知觉错误的“错置”（*anyathākhyāti*）理论。注意：若一切错误都出于能别错置，那么对正与感官连接着的那个所别而言，就不会出错。还要注意，正理解释幻象从不诉诸“意象”“观念”或任何其他主观内容——这是关于错误的外在主义说明。由此可见，所谓“幻象论证”（从如实与不如实知觉在现象上无法分辨，推出二者共有主观内容）是站不住的。可是，合适的所别是否总能找到（幻觉里当真知觉到一个空间区域了吗？）、合适的能别是否总有（比如把半浸水中的棍看成弯的，“如此这般地弯”这个特征打哪儿来？——正理居然主张：它是知觉行为因果地产生的客观特征！），并不清楚。
4. 这个理论让正理可以说：“我（用视觉）看见空气是冷的”“我看见芒果是甜的”这类说法，虽然其能别可被知觉却不是可见性质，但仍是正经的知觉。他们把这类情形归为一种“非常”知觉，叫 *jñāna-lakṣaṇā-pratyāsatti*（识相连接）。（有时还被承认的“非常”知觉另有两种：一是“总相连接”（*sāmānyalakṣaṇa*），借知觉某属性而知觉到该属性的一切承载者；二是瑜伽知觉。）
5. 正理主张：经验当且仅当为真时才够得上知识事件，也就是当能别真的限定着所别之时。《理性手册》（TS 69 iii）说，知觉知识的 *guṇa*（特殊因果因素）在于：知觉者叠加到有感官连接的所别上的那个能别，确实就在该所别之中。不过，这个定义也许仍躲不开盖梯尔式的反例。

### 7.2 感官—对象关系的类型

《理性手册》（TS 48）转述了出自乌底耶多迦罗（Uddyotakara）的正理标准观点：恰好有六类感官—对象关系为知觉经验奠基：

1. 接触或连合（*saṃyoga*）。普通的知觉，比如看见一只罐。若“接触”指的是某种因果关系，那就可以说正理有一套知觉的因果理论；不过他们也可能是在更字面的意义上说：眼睛就贴着那个对象。
2. 连合者中的和合（*saṃyukta-samavāya*）。前面说过，“无分别”知觉里，对象与其特征是一起被看见的。特征与知觉者之间的关系是间接的：特征和合于对象，而知觉者正接触着这个对象。
3. 连合者中和合者中的和合（*saṃyukta-samaveta-samavāya*）。若 (2) 里的特征是一项性质（*guṇa*），比如某种特别的蓝，那么和合于它的是一个普遍——蓝色；而蓝色本身显然也能被知觉。
4. 和合（*samavāya*）。正理胜论有一套相当怪异的学说：每种感官都由与它特别相配的那类实体做成。听觉官能由虚空做成；声和合于虚空，于是听者与声之间是和合关系。
5. 和合者中的和合（*samaveta-samavāya*）。借这条间接关系，听者关联到和合在声中的属性，比如“声性”。
6. 能别—所别关系（*viśeṣaṇa-viśeṣya-bhāva*）。这条关系很重要。正理相信，非存在是“实在的”对象——比如此刻房间里没有大象这回事——而且非存在是可以被知觉的。据说非存在限定着自己的基底，并经由知觉者看见基底而被间接知觉。佛教徒法称则论证：这其实是一个“未觉”（*anupalabdhi-hetu*）推理：“我知觉到了房间的墙壁；若真有大象，我会看不见它；而我的知觉官能运作正常；所以，没有大象。”

### 7.3 甘格沙的批评与新定义

甘格沙从三处批评原则 1：(a) 它会推出“一切意识都是知觉”——因为一切意识都经由“内在”感官即意这一工具产生；(b) 它装不下神圣知觉，后者不靠任何感官连接；(c) 感官连接并没有一个统一的类型，那份六种类型的应景清单也没有什么显而易见的共同点。于是甘格沙给出一个新定义：

> **原则 3**：所谓知觉经验，就是这样一种认知：没有任何别的非记忆性认知充当它的“特殊”工具因（*karaṇa*）。

这个定义招来两条反驳，都被逐一化解。反驳一：每个有分别认知都由对能别的先前意识产生，定义的外延就太窄了。答：不。对能别的意识只是辅助性的因果因素；“特殊”工具因是感官—对象的接触。反驳二：再认是一种知觉，它偏偏就是拿“对能别的先前意识”当“特殊”工具因，定义的外延还是太窄。答：不。这里起“特殊”作用的是：先前意识留下倾向痕迹，痕迹再触发对能别的记忆，而非先前意识本身。

甘格沙的定义有个好处：它抓住了知觉经验较之其他经验更为“直接”的那一层意思，而且人的知觉与神圣知觉都适用。若只限人的知觉，它就退化为先前那个定义（甘格沙说，“内在”感官毕竟不能算知觉性的）。

## 8. 逻辑理论与甘格沙对推理保证（*vyāpti*）的分析

### 8.1 逻辑理论概观

甘格沙的《真理思择摩尼》分四部分，一部分对应正理承认的一种知识来源（量，*pramāṇa*）。甘格沙以后的学者越来越只盯着第二部分——讲推理的那部分——而且注疏越写越细，却集中在全书极小的一段上：甘格沙考察推理标记与所推属性之间关系的那一段。这个关系叫 *vyāpti*，即“遍充”关系，也叫“推理保证”关系（Ingalls 1951，Goekoop 1977，Wada 2007）[^goekoop-1977][^ingalls-1951][^wada-2007]。直到今天，传统印度教育里，研读这些针对遍充节各小节的子注疏，仍是课程中少不了的一环。

一个合式的正理论证，由宗、因（*hetu*）、喻（*dṛṣṭānta*）三部分组成。宗又含两截：推理的“处所”（*pakṣa*，所别），以及要在该处所里推出其存在的属性（*sādhya*，所立）。于是正理论证总是同一个格式：*p* 有 *S*，因为它有 *H*；例如 *d*。举例：“山（= *p*）有火（= *S*），因为它有烟（= *H*）；例如厨房（= *d*）”。站得住的论证至少满足三条：(i) 因属性在处所中无争议地存在；(ii) 因属性与所推属性之间有恰当关联，粗略说，凡有因处即有所立；(iii) 喻是双方都承认、因与所立兼具的场合。

《理性手册》和其他新正理文本讨论过与此相关的若干问题：推理在什么条件下进行、在什么条件下其结果是知识事件（TS 49、54）；推理标记与所推属性之间那条推理保证关系——即“遍充”或 *vyāpti*——该怎么说明（TS 50）；推理与为他人论证之别（*svārtha* 推理与 *parārtha* 推理）（TS 52、53）；推理的三分：全同转（*kevalānvayin*）、全异转（*kevala-vyatirekin*）、同有同无（*anvaya-vyatirekin*）（TS 55）；以及推理谬误（*hetvābhāsa*）的诸类型（TS 57–64）。

下面主要谈“遍充”关系的定义。先简短交代知识的因果模型如何用在推理上。推理认知的“特殊”工具因（*karaṇa*），据说是推理者掌握相关遍充关系的那份知识；“作用条件”（*vyāpāra*），则是对“推理处所（*p*）具有某种推理标记（*h*），而该标记为所推属性（*s*）所遍充”的意识。这其实就是在结论出台前一刻，把论证的两个前提合到一起的意识，名为“省察”（*parāmarśa*）。推理认知的 *guṇa*（即“负责其真”的因果因素），在于这项“省察”为真：处所确实带有那种被所推属性所遍充的标记。另有一项辅助因果因素：推理者要么还没知道结论，要么必须有一种要推理的特定意愿（也就是说，前提知识在手，推理通常会机械地发生；可若结论已由知觉等途径得知，推理者就得特意愿意用推理把它重新确立一遍）。这项条件叫 *pakṣaṭā*（宗未决性），不可与 *pakṣadharmatā*（宗法性）相混——后者是上面条件 (i) 的名字。

### 8.2 遍充（*vyāpti*）关系的定义

*Vyāpti*（遍充）是推理标记（*hetu*）与所推属性（*sādhya*）之间那个使推理得以成立的关系。它通常用这样的句子表达：“凡有烟处即有火”，或“凡存在者皆无常”。按正理，关于这一关系的知识就是推理过程中的工具因：有了它，再结合对推理标记的观察，我们才能形成可靠、能产生知识的推理。正因如此，甘格沙才极其看重这个关系的精确定义。他一口气列出二十一种定义，各以某种理由否掉；然后又给出七种表述，认为都可接受。被否掉的前五种，后来称作“遍充五定义”（*vyāpti-pañcaka*），梵语注家和现代研究者围绕它写出了大量文献。这些定义可以追溯到更早的佛教与正理文献。另外两种被否掉的定义叫“狮子与老虎”定义，显然出自甘格沙之前的新正理学者（Wada 2007，第 5 章）[^wada-2007]。甘格沙最终接受的那个定义，称作他的“宗义相”（*siddhānta-lakṣaṇa*）。

### 8.3 “无同喻例”定义

甘格沙“遍充五定义”里的五个定义，都属于我们不妨称为“无同喻例”式的遍充定义。它的意思是：所推属性 *S* 遍充因属性 *H*，当且仅当没有任何处所或实体是 *H* 在而 *S* 不在的。形式地写：

**V₁**

Pervades (*S*, *H*) iff ¬(∃*x*)(*Hx* & *S*′*x*).

这里 *S*′ 表示 *S* 的补。这个定义有两个来历：一是早期正理关于“偏离”伪因的说法（伪因出现在所推属性 *S* 不在的某个地方）；二是陈那的推理标记“三条件”说，其第三条要求 *H* 不得落在任何“相异品”（*vipakṣa*）即 *S* 缺席之处。两个来历都指向同一个直觉：“凡有烟处即有火”成立，当且仅当没有“火不在而烟在”的地方，也就是没有反例。甘格沙考虑的第一个定义正是这个形式：*S* 遍充 *H*，当且仅当 *H* 具有“于所立之无处不转”（*sādhyābhāvavad-avṛttitvam*），也就是 V₁。

这个看起来挺合理的遍充解释，新正理为什么要否掉？理由有两条：

部分可定位属性带来的麻烦。“无同喻例”定义遇到的第一个问题，与新正理的“局部遍转”（*avyāpya-vṛtti*）观念有关。一个属性若在对象的每一部分都发生，就说它在该对象中完整地发生。比如“金色”在一块（纯）金里就是完整发生的；对象被这个属性“浸透”（*abhivyāpya*），好比芝麻油浸透芝麻。可有些属性只在对象的某些部分发生，别处没有——这叫“部分可定位”。比如“熔化”在地心发生，在地表就不发生。注意，同一个属性可以在这里完整定位、在那里部分定位：红色在红宝石里是完整的，在一颗红台球上却是部分的。这个区分讲的是属性的两种拥有方式，不是两类属性。要紧的是：一个属性若部分定位于某物，它的否定也一样。正理论师举的标准例子“……与猴相触”（*kapi-samyoga*）恰好说明这一点。猴子坐在树枝上时，下面两句话可以同时为真：

1. 树在时刻 *t* 与猴相触；
2. 树在时刻 *t* 不与猴相触。

(2) 为真，是因为树上有些部分猴子没碰到。正理把“发生”观念相对化，从而避开了违反矛盾律的指控。(1) 于是分析为：“与猴相触这一属性在树中的发生，以枝条为限界（*avacchinna*）。”既然 (2) 里的限界者不同，两句话就不冲突。

承认部分可定位属性进入体系，主要后果是：属性 *P* 与其补 *P*′ 不再互不相交，它们可能交叉。若所推属性是部分可定位的，“同品”（*sapakṣa*，所推属性在场之处）与“异品”（*vipakṣa*，所推属性缺席之处）这两类就会重叠，而不是彼此分开。换个说法，属性 *P* 应看作既有“在场范围”（*P*+），又有“缺席范围”（*P*−），两者可以交叠。现在看标准推理“山上有火，因为有烟”。假定我们找到一处地方，烟在场，火既缺席又在场——比如厨房。这能说明推理有毛病吗？按 V₁，能，因为厨房成了反例：烟在场，火不在场。可这是错的：火在那里明明也在场，厨房并不构成“凡有烟处即有火”的真反例。由此可见，我们该考察的是因属性与所推属性的“在场范围”，不是“缺席范围”。一条规则的真反例，是落在因属性在场范围之内、却不落在所推属性在场范围之内的情形。

甘格沙的第二个定义就是冲着这个问题来的：*H*“于异于 *S* 所在处的 *S* 缺席之处不转”。换句话说，一个地方若既是 *S* 的缺席之处、又不是 *S* 的所在之处，那它就不该是 *H* 的所在之处：

**V₂**

Pervades (*S*, *H*) iff ¬(∃*x*)(*Hx* & *S*′*x* & ¬*Sx*).

新增的这一子句，作用正是更严格地限定“什么算反例”，从而把部分可定位属性带来的麻烦挡在门外。

全同转推理的麻烦。正理说，有些合法推理模式，其所推属性的外延铺满整个论域。这类推理叫“全同转”（*kevalānvayin*），即“普遍肯定式”（参考 TS 55）。正理的标准例子是“这是可名的，因为它是可知的”。可名性被当作万物共有的属性。另一例是“这是存在的，因为它是被产生的”。这类推理若可靠，其因属性与所推属性之间就得成立遍充关系。按上面的定义，说可名性遍充可知性，等于说：“不可名性缺席”这个属性的任何所在处，都不是可知性的所在处。麻烦在于：可名性是普遍属性，所以“不可名性”是个没有实例的（*aprasiddha*）属性，而正理认为这类属性在存在论上可疑。换句话说，“不可名性缺席的任何所在处都不是可知性的所在处”这句话里塞着一个没有指称的表达式——“不可名性缺席之处”或“不可名之物”——因此根本谈不上真假。这个问题并不对一切无实例属性都发生。有些（比如“天空莲花”“方的圆”）可以表明由更简单、有实例的属性构造而成。“方的圆是圆的”便可理解为“这个圆既是方的又是圆的”，其中没有空指称。可“不可名之物”没法这样拆成两个不同的属性。

甘格沙考虑过的“无同喻例”定义诸解释，没有一个能摆平全同转推理，于是他全部否掉。他自己的定义耍了个花招，绕过了这道坎。

### 8.4 甘格沙的定义：“宗义相”

《理性手册》略加简化，复述了甘格沙的新定义：*S* 与 *H* 由遍充关系相连，当且仅当 *H* 与 *S* 同所依，并且 *S* 不是那种“其缺席与 *H* 同所依”的属性（*hetusamānādhikaraṇātyantābhāvāpratiyogi-sādhyasāmānādhikaraṇyam vyāptiḥ*；TS 50）。《宗义摩尼鬘》等其他新正理文本里，几乎同样的表述也出现过。这个定义据说连“全同转”的所推属性 *S* 也能应付。大意是：若 *S* 遍充 *H*，那么凡是“其缺席与 *H* 同所依”的属性，都不可能正是 *S*。比方说，我们若是找到烟的某处所在，它同时又是某属性（就说冷性吧）缺席的所在，那么冷性就不可能是火性。也就是：

Pervades (*S*, *H*) only if (∃*x*)(*Hx* & *P*′*x*) → (*P* ≠ *S*).

（这里对 *P* 隐含着一个全称量化。）这句话的意思是：没有哪个地方是 *H* 与“*S* 之缺席”同所依的；但它自始至终没有动用那个可能空指的短语“*S* 之缺席”，于是绕开了全同转属性的难题。不过，这个条件对遍充只是必要的，还不充分——它与“*H*（或 *S*）根本没有实例”并不冲突。因此甘格沙又强调：*H* 与 *S* 必须同所依：

Pervades (*S*, *H*) iff i. ∃*x* (*Hx* & *P*′*x*) → (*P* ≠ *S*), and

**ii.**

∃*x* (*Hx* & *Sx*).

甘格沙这一手，暗地里用上了定理“*A* → *B* ≡ ¬(*A* & ¬*B*)”。于是子句 (i) 实质上等于 V₁。这也说明，眼下这个定义仍处理不了部分可定位属性——那需要更像 V₂ 的东西。所以甘格沙的最终定义是：

**V₃**

Pervades (S, H) iff i. ∃*x* (*Hx* & *P*′*x* & ¬*Px*) → (*P* ≠ *S*), and

**ii.**

∃*x* (*Hx* & *Sx*).

这个遍充定义，既能应付全同转属性，也能应付以所推属性身份出现的部分可定位属性。

有人可能纳闷：遍充关系的形式不就是“凡 *H* 皆 *S*”吗，正理论师干吗不干脆在定义里用全称量化？答案也许是：他们恰恰是在定义全称量化本身，而且只想用几个被当作初始的观念来定义，尤其是“同所依”和“缺席”。若果真如此，那我们就得交代清楚：如何在不偷偷对属性 *P* 作量化的前提下，把这一定义重建出来（参考 Goekoop 1967）。

## 9. 意义、理解与证言

### 9.1 语言处理机制

在量（*pramāṇa*）体系里，知觉和推理都被说成能产生知识的官能；语言也不例外。于是正理着手描述一套机制：一个胜任的语言使用者，如何把一串“噪声”似的话语解码，从而获得基于语言的知识。《理性手册》对这套“语言处理机制”的说明如下（TS 67、68）。过程的输入，是听者把一段口头话语当作未经解释的噪声来听，这就是“特殊”工具因（*karaṇa*）。比如听到这一串声音：

[*]

“The” “cat” “is” “on” “the” “mat”。

“作用条件”（*vyāpāra*），是听者对话语中每个词之义（*śakti-jñāna*）的（默会）知识。懂这门语言的人与不懂的人，分别就在这里——后者照样听见那些词，却没有解释它们的能力。例如，知道：

**[M1]**

“the cat”意指猫，

**[M2]**

“the mat”意指席子；以及

**[M3]**

“is on”意指基底与上层的关系。

过程的输出——诸因果因素合起来的效果——是听者形成了一个信念，例如相信：

**[P]**

猫在席子上。

知觉那里有一堆辅助因果因素——光线够亮、感官状态良好、知觉者在留意，等等——语言这里也一样。正理挑出四项格外关注：所说话词在时空上的“亲邻”（*sannidhi*）；说话者的意图（*tātparya*）；“句法期待”（*ākāṅkṣā*）；“语义适切”（*yogyatā*）（参考 TS 67）。头一项不用多解释：词若是在老长时间里一个一个往外蹦，或者跟另一句话的词搅在一起，听者就形不成对这句话的像样听觉知觉。第二项“说话者意图”，在句中有歧义词时派上用场——靠揣摩说话者想表达什么来消歧。《理性手册》把“句法期待”定义为“一个词若没有另一个词相伴，便不能产生对二者关系的意识”，并以“马 人 象”这句话为例，说明什么叫缺乏句法期待。这至少是说，话语得合乎语法。不止于此，它还暗示：词与词之间那些没说出口的语义关系，正是靠句法规则表达出来的。凭什么说，听懂“猫在席子上”的人把握到的是一个统一命题，而不只是一份清单［猫、在……上关系、席子］？此处的想法也许是：（关于）句法规则的（知识）生起了对各项之间连接关系的意识。

“语义适切”（*yogyatā*）这概念很有意思。《理性手册》的定义是“词所表者之间没有不相容”，并用“他用水浇田”与“他用火浇田”的对照来示例。意思是：浇这个动作与像水这样的液体“相容”（也只能拿液体来浇），与火这样的东西却不相容。这就好比说“猫性在席子上”，或者乔姆斯基那句“无色的绿观念愤怒地睡眠”。这类句子语法没毛病，就是讲不通。所以这项因果因素是说：一句话要可理解，它所表达的命题，按某种预先设定的本体论体系（比如胜论句义体系）来看，必须在存在论上说得通。不过，有些正理论师把门槛抬得更高：要“语义适切”，话语还必须为真——“适切”不光是“可能”，而是“真”；于是，话只有为真才可理解！实际上，他们等于在语言处理机制里把“语义适切”当成了 *guṇa*，即“引向真的因果因素”。这场争论稍后再谈。

### 9.2 语义能力与语义属性的还原

《理性手册》给“词”下的定义鼎鼎有名，常被引用。它说（TS 66）：词就是有语义能力者（*śaktaṃ padam*）；句子（*vākya*）则是词的集合。这倒与现代定义合拍——词是句子中有语义意义的构成成分。所谓语义能力，就是关于它的知识让胜任的听者能够解释这个词；在正理论师看来，这一能力就在于词指称某个对象。所以，懂“猫”这个词的人，知道某种形如〈“猫”意指猫〉的东西，其中“意指”是词与某类对象之间的关系。《理性手册》围绕这个关系提了三个问题：(i) 它是一种新的、不可还原的关系吗，也就是说，不能化归为已经承认的任何关系吗（TSD 66a）？(ii) 关系项是什么——词在语义上与哪一类实体相关（TSD 66b, k）？(iii) 我们是怎么学会词义的（TSD 66c, d）？

(i) 弥曼差派和文法家是意义问题上的“本质主义者”。他们说，梵语是自然形成的实体，不依赖人的约定或习惯；词本身就带有指称对象的语义能力，正如火本身就带有燃烧的能力。正理一向反对这种看法，认为语言是约定俗成的产物；一个词的语义能力，可以用规范其用法的约定来交代。他们主张，意义关系可以这样定义（因而可以分析）：

> *x* 意指 *y*，当且仅当存在一条约定或规定（*saṅketa*），其形式为“让 *x* 的话语产生关于 *y* 的认知”。

那么，规定或约定又是什么？据说它在于规定者具有某种心理状态，也就是带着规定所要求的形式的“欲”或“意志”（*icchā*）。这样一来，意义关系就用心理状态及其内容来分析，不必再设一类新关系。规定者是谁？《理性手册》说是上帝；不过后来多数正理论师把两类词分开：一类“无始以来”就在语言里（由上帝引入），另一类由人明确约定引入（比如波你尼语法里的术语）。

(ii) 像“牛”这样的类名，它的意义关系项是什么？《理性手册》又把正理与弥曼差派摆在一起对照。弥曼差的一个支派（跋吒派）主张，“牛”的意义就是“牛性”这个普遍。理由是：“牛是动物”这样的句子，或者“切勿踢牛”这样的训令，讲的是整个牛类，不是某一头牛。所以：

**(Bh)**

“牛”意指牛性。

明显的反驳是：在“牛在园中”等许多句子里，明明指的是某一头牛。这些弥曼差师的应对，是搬出“牵带”（*ākṣepa*）这一观念：句子除了字面意义，还能带出言外之意。于是“牛在园中”字面上也许表示“牛性与在园中发生同所依”（也就是园里有牛），但同时还牵带出“某一头特定的牛在园中”。他们的原则是：先有对能别（*viśeṣaṇa*）的意识，才谈得上对所别（*viśeṣya*）的牵带意识（TSD 66b）。正理的反驳则直接否掉这条原则：他们说，对能别或普遍的觉知，本身就只能通过对所别之物的觉知才可能。

《理性手册》摆出现代正理的主张：说出“牛”这个词时，其意义是一个被牛性所限定的个别个体（*jāti-viśiṣṭa-vyakti*）：

**(Ny)**

“牛”意为一头被牛性所限定的牛。

道理是这样：听懂“牛在园中”的人，做的是两件事——(a) 把某个对象认作“牛”这个词的所指；(b) 把握到这个个体被“在园中发生”这一属性所限定。可人要认定一个对象，就得把它与别的对象区分开，而这离不开某项区别性特征。于是，个体在意识里总是呈现为“受牛性所区分／限定”的东西。既然按定义，一个词的意义就是它对“听到含该词之句后所生最终信念”的贡献，那么“牛”的意义便是一个被牛性所限定的个体。注意，按这套理论，“牛”的每一次具体说出，所指的个体各不相同；但每次说出都共享同一个语义属性——“……被牛性所限定”。正理论师就这样分开了类型意义与话语意义（也有人说是意义与指称）。

弥曼差的另一支派（钵罗跋迦罗派）则说：我们听到一句话，把握到的是一个统一命题，不是一堆实体；要解释这一点，就得承认“牛”这类词的意义关系项是“与另一物相连的对象”（*itarānvita*）。也就是说，意义关系项是一头牛，还带着一个钩子，把它同别的意义关系项挂在一起。说得更细些，词的意义大致是：

**(Pr)**

“牛”意为一头牛个体，它……

照此，“牛在园中”这句话的意思就不只是一份清单〈牛、在园中〉——倘若每个词只管指称一个对象，得到的就是那份清单——而是一个连接起来的命题〈在园中的牛〉。这想法实际上等于说：用弗雷格的术语，一切意义关系项都是“未饱和的”。对这条巧妙的建议，《理性手册》的回答（TSD 66k）是：多余。因为“既然［意义关系项之间的］关系可以作为整句所表的东西被把握，就不必再针对这一关系设定语义能力”。换句话说，《理性手册》认为，句子的一般特征（大概是句法特征）已经足以把各意义关系项连起来，用不着说这些关系项本身在干连接的活。

(iii) 关于人怎样学会语言，正理论师的说法是这样（TSD 66c）。孩子观察大人的言语行为：听见大人 A 发出某个声音，比如“把牛牵来”，又看见大人 B 做出相应动作，把牛牵来；再听见 A 说“把马牵来”，看见 B 把马牵来；听见“喂牛”，看见牛被喂。经过一整套双重的归纳——(a) “同有”（*anvaya*）与“同无”（*vyatireka*），即留意 A 说与不说某句话、B 做与不做某个动作之间的相关；(b) “集取”（*āvāpa*）与“摒除”（*udvāpa*），即留意“牛”这个词同关于牛的事件、“牵”这个词同牵的动作之间的规律——孩子终于明白：“牛”这个词，是与牛类中的对象连在一起的，如此等等。

这是一套经验主义的语言学习说，让人想起维特根斯坦归到奥古斯丁名下、又狠狠批过的那种说法。且不说它塞给孩子超人的推理能力；维特根斯坦指出的毛病是：观察再多，也看不出相关的关联究竟在什么地方。它是在“牛”与牛个体之间，还是在“牛”与 B 那些冲着牛去的动作之间、与牛性这个普遍之间、与小母牛而不是牛之间？（参考 TSD 66d）

### 9.3 证言

《理性手册》说，陈述分两类：吠陀的与世俗的。它又说：（听）一个吠陀陈述是一种量，是认识所陈述之事的途径，因为吠陀陈述最初是上帝说的。（弥曼差派不买账。他们不信上帝，反过来说：吠陀陈述之所以能成为认识途径，恰恰因为它是无源的；而证言出错，从来都是源头的人为错误！）听世俗陈述，则只有当说话者是“可信者”（*āpta*）时才算认识途径。可信者的定义是说真话者（*yathārthavaktā*）。这里有歧义：所谓可信者，是对眼前这句话说真话的人，还是一贯说真话的人？还有个问题：受言者必须知道说话者在这个意义上是可信的吗？

更添乱的是，《理性手册》说，负责受言者信念之真的 *guṇa* 是 *yathārtha-yogyatā-jñāna*。这个复合词可以两解：(i) 对语义适切的如实认知；或 (ii) 对“如实的语义适切”的认知。无论哪种，*guṇa* 似乎都跟说话者的资质不沾边。但 (ii) 必错：总不能把“听者事先已经知道所说为真”当成证言的条件。(i) 又保证不了听者的最终信念为真——除非《理性手册》这里的“适切”是个强得多的概念：意义关系项彼此“适切”，当且仅当它们在事实上相连，也就是这句话表达了一个真理。某些正理论师确实这样理解 *yogyatā*，但这与《理性手册》自己的定义对不上。

我的解决办法如下。上文把语言处理机制说成：它使受言者相信言说者所说的事。那么，受言者信念的真假，就取决于言说者是否说了真话——这才该叫这里的 *guṇa*。不过，我们并不总是听到什么就信什么，尤其是在有理由觉得说话者未必说真话的时候。这样一来，语言处理机制的输出，可能不是“相信所说的内容”，而只是“相信它被说过”。大致有两种情形：(1) 受言者判断言说者在骗人、不可靠，或者对这话题根本不懂；(2) 受言者凭独立根据知道言说者所说为假（这不妨碍言说者本人相信它并真诚作证），这根据也许是对该断言可信与否的先验判断。稍微放宽一点解释，我们可以说，这两种情形恰好对应《理性手册》为证言设的两个条件：说话者须是“可信者”（*āpta*），句子须“语义适切”（*yogya*）。

## 10. 胜论的普遍、和合与基本别异概念

### 10.1 普遍

《理性手册》转述了正理胜论给普遍（*sāmānya*、*jāti*）下的标准定义：

> 所谓普遍，就是 (i) 恒常、(ii) 单一、(iii) 寓于多数事物（实体、性质或运动）之中的东西。（TS 82）

这样看来，普遍就是无结构的客观属性，必然寓于个体之中。在胜论图式里设定这类东西是有解释力的：它能说明“自然”分类与“约定”分类的差别。按直觉，这就是牛类、马类这样的分组（反映自然本身的分界，“顺着自然的关节下刀”）与内阁部长类、濒危物种类这样的分组（反映以人为中心）之间的不同。正理论师用名称标出这一区分：自然属性叫“普遍”（*jāti*），以人为中心的属性叫“假立”或“名义”属性（*upādhi*）。语义上也相应分开：“自然种类词”（*naimittikī*）指应用根据为普遍的词；“假立种类词”则指应用根据为人类中心属性的词。优陀耶那想把这个区分弄得更精确，便开出了一份“什么算自然属性”的判准清单。看看这份清单（称作 *jāti-bādhaka*，即“类障”，区分自然属性的障碍），能进一步看出正理心中自然属性的面貌。

六种障碍如下：(1)“非多数性”——真正的普遍必须有多于一例的实例；(2)“等同”（*tulyatva*）——两个外延完全相同的属性，不能都是真正的普遍；(3)“交叠”（*saṃkara*）——两个真正的普遍不得部分重叠；(4)“倒退”——“普遍性”这样的属性本身不能是普遍，否则会无穷倒退（普遍性的普遍性……）；(5)“别异性”这样的属性不能是真正的普遍，因为按定义，基本别异之间不共有任何普遍属性；(6)“和合性”这样的属性不能是普遍，因为它并不和合于自己的所在处。六条里头，后三条主要是为了保住胜论体系的内部一致；第一条则是普遍定义的直接推论——它把“虚空性”这种只有一例的属性挡在真正自然种类之外。其背后的想法也许是：普遍之所以为普遍，就在于为“*x* 与 *y* 同类”这类判断奠基，而这种判断起码得有两个实体才谈得上。

第二、第三条最要紧，可以写得更形式一些。设 *P* 与 *Q* 为不同属性，则（等同，*tulyatva*）：

> [*P*] = [*Q*] → *P* 或 *Q*（或两者）不是普遍；

其中“[*P*]”指 *P* 的外延。取逆否式，就是：

> *P* 与 *Q* 都是普遍 → [*P*] ≠ [*Q*]。

注意，这并不推出普遍属性是按外延来个体化的，也不推出它们等同于类——虽然有人这么主张。它只说明：每一个类，至多对应一个普遍。在普遍的范围之内，一个普遍固然由其外延唯一确定；但普遍与外延相同的假立属性（比如“罐性”与“螺壳状颈性”）之间，仍是内涵上的区别。

至于第三项障碍（*sāṃkarya*，交叠），设 *P* 与 *Q* 为不同属性，则

> [*P*] 与 [*Q*] 部分重叠 → *P* 或 *Q*（或两者）不是普遍。

逆否式是：

> *P* 与 *Q* 是普遍 → [*P*] ⊂ [*Q*]，或 [*P*] ⊃ [*Q*]，或 [*P*] ∩ [*Q*] = ∅。

（包含是严格的，因为要受“等同”约束。）换句话说，真正的普遍排成一个层级：给两个普遍，它们要么是属种关系，一个的一切实例都是另一个的实例；要么完全不相交，没有一个共同实例（比如牛性与动物性、牛性与树性）。正理说，一个普遍若这样被另一个包含，就是“较低”（*apara*），后者则“较高”（*para*）（参考 TS 6）。最高的普遍是“存在性”（*sattā*），一切实体、性质、运动都落在它的外延里。普遍必须按层级组织，这说明正理拿生物物种当了样板，因为生物物种往往就是这种结构。别忘了，“普遍”一词即 *jāti*，同时也是“种姓”一词，Matilal（1971: 76）因此推测：

> 也许，从正理的类属性学说里，能看出婆罗门社会—宗教观念的遥远影响。若译成生物学的语言，那条……“不重叠”原则，就成了一条禁止杂交的原则。因此有理由相信，正理偏爱真实的类属性，部分是被婆罗门式理想社会秩序观感染的——在那种秩序里，种姓之间的混杂不被容许。

有些正理论师——尤其是跋沙罗婆吉那和罗怙那陀——不接受“交叠”这条障碍。他们指出，拿它去套非生物的自然种类就麻烦了（红性与绿性重叠，罐性与金性也重叠）。罗怙那陀甚至说，若把这条原则贯彻到底，存在论里几乎剩不下什么普遍。如此看来，优陀耶那那条“自然属性”的判准，既不必要，也不充分。他的障碍没有一条能说明，为什么“蓝—绿”这一对就比古德曼的“绿蓝—蓝绿”更自然。（*x* 是绿蓝，当且仅当 *x* 是绿且在时刻 *t* 之前被检查过，否则是蓝；蓝绿反之。）

普遍在某种意义上“位于”个别之中——这个说法招来两个别具一格的反驳。陈那借空间隐喻发难：若普遍是“单一”的，它最多只能在一处，那就不成其为“多实例”；反过来，若它同时位于多处，那只能是因为它有部分、各部分在不同处，于是它又不“单一”了。这个论证玩弄“位于”一词的歧义，硬说牛性位于各头牛之中，跟一头牛位于田里是一回事。不过，它逼着正理把普遍与个别的关系讲得更小心。正如《理性手册》（TS 84）所记，普遍据说借“和合”（*samavāya*）关系寓于其诸实例之中，而和合被定义为一种“不离”（*ayutasiddhi*）关系。设有两个实体 *x* 与 *y*：

> *x* 与 *y* 不离，当且仅当除非 *y* 存在，*x* 便不能存在。

意思是：牛要存在，就得先有“牛性”这个普遍存在；牛性位于牛中，正是在这个意义上说的。（据说同样的关系还出现在不可重复的“性质”（*guṇa*）与实体之间、整体与部分之间、基本别异与原子之间。）而空间位置涉及的是另一种关系，即接触（*saṃyoga*）。这样一来，“位置”一词的两义就分清了。

另一个是老问题：一个普遍的所有实例都毁掉了，这个普遍会怎样？没有实例，普遍还能存在吗？按和合关系的定义，可以——它只要求“没有牛性就没有牛”，不要求反过来。或许可以说，牛的存在随附于牛性这个普遍的存在。可要说（比如汽车的）部件离开整体（汽车）就不能存在，就没那么清楚了。

### 10.2 基本别异（*viśeṣa*）

胜论传统独有地把一类项目收进存在论，称为“基本别异”（*viśeṣa*）；有人说，“胜论”之名就是从它来的。《理性手册》的定义是（TS 83）：“那些居于恒常实体［即原子］之中、充当其区分者的实体，叫做 *viśeṣa*。”意思是：牛与马属性不同，所以是两个东西；同理，连同一物质（比如土）的两个原子，也至少得在某一属性上有别。于是每个原子都带有一个只属于自己的“别异者”，用来把自己与同类的其他任何原子分开。这里的假定是：凡是两个不相同的项目，都靠属性不同而彼此有别。这其实是莱布尼茨“不可分辨者同一”律的逆否式：(∀*P*)(*Px* ≡ *Py*) → (*x* = *y*)，其中“*P*”取遍属性。可若不限定属性的范围，这条原则就没意义了：比如允许“……＝*y*”这样的属性，它无非空洞地说“同一者同一”。胜论师暗中把原则限在对象内在的、非关系的属性上，把“处于某空间或时间位置”之类排除在外——这类属性不能用来区分两个其他方面完全一样的对象。所以，他们的主张似乎是：任何两个对象，包括原子，都不可能在内在方面完全一样。莱布尼茨本人似乎也这样理解自己的定律。他说：“除了时间地点之别，总还得有内在的区分原则……所以，时间地点虽然有助于区分事物，我们却不容易单靠它们把事物区分开。”又说：“绝不存在两个彼此不可分辨的个体。两滴水，或者说两滴奶，放到显微镜下看，也会显出分别。”

这条原则确实够强。维特根斯坦（《逻辑哲学论》5.5302）指出：若它成立，一个装着两个全同球体的宇宙在逻辑上就不可能。威金斯补充说：连一个球体（或任何对称物体）都不可能，因为原则会推出两个半球同一，一路推下去直到一个几何点。更要命的是，胜论师自己也隐约看出了：原则会推出，给定物质（具有某速度、自旋等）的原子不能多于一个。可他们没有抛弃原则，而是添了一批新的内在属性——基本别异——把这个难以下咽的结论绕了过去。

## 11. 非存在（*abhāva*）的存在论与否定语句的语义

### 11.1 动机

后期正理论师琢磨出一套相当惊人的非存在理论。在他们看来，一个对象或特征在某个空间或时间位置上缺席，跟它在那里在场一样，都是客观事实。于是，他们在迦那陀原有的六种句义（即存在者类型）清单之外，又添了第七种——“非存在”（*abhāva*）。这套存在论主张，底下有 (i) 现象学和 (ii) 语义两重考虑撑着。

(i) 现象学上的理由是：否定性的意识——比如“某人不在屋里”——在现象上与任何关于“屋里有什么”的意识都不一样。对“不在者”的认知，自有其独立的现象学（这一层，萨特讲得格外清楚）。所以他们援引的原则是：

**P₁**

关于非存在的经验，在现象上不同于关于存在者的经验，并且不能还原为后者。

这个想法在正理知识论里表现为两个主张：非存在可以被知觉；而且这种知觉是自成一类（*sui generis*）的知觉经验，不能化归为普通知觉与推理的拼合（参考乌底耶多迦罗所列的第六种感官连接）。

(ii) 语义上的理由是：正理主张一种真理符合论——真句子与事实对应。据说，真的否定句（比如“罐不在地上”）对应的是“否定性事实”。可是在正理看来，一切事实都是同一种基本关系形式，即“bRa”（据说事实具有所别—关系—能别结构，也就是由存在实体构成的复合体）。什么能算事实，受这条限制管着，可用下面这条语义原则说出来：

**P₂**

句子对应于由简单或复杂实体构造而成的事实（这些实体如“*a*”“*a* 的非存在”“*a*-且-*b*”“*a*-或-*b*”）。

这条原则意味着：真值函项联结词不能用来造事实，除非它们恰好等价于词项逻辑联结词。（比如说，“罗摩与悉多都正直”等于“罗摩正直且悉多正直”；可“罗摩与悉多结婚了”里的词项联结词，就没法这样拆成真值合取“罗摩结婚了且悉多结婚了”。）关键点是：“罐不在地上”这类句子，不能对应“¬bRa”形式的事实（按 P₂，根本没有这种事实），而只能对应“bRā”形式的事实。于是，否定性实体就被请进了存在论。

### 11.2 时间与空间中的非存在

《理性手册》（TS 85–88）转述正理的一般说法：非存在分四类：先无（*prāgabhāva*）；后无，即“灭无”（*dhvaṃsa*）；“恒常”或“究竟”无（*atyantābhāva*）；以及别异（*anyonyābhāva*）。前两类说的是一个暂存对象在时间上可能出现的情形。设某人 *A* 的一生可以用下面这条线表示（假定他生于 1650、卒于 1750）：

| *t*₁ | 1650 | *t*₂ | 1750 | *t*₃ |   |
| --- | --- | --- | --- | --- | --- |
|   |   |   |   |   |   |

在 1650 之前的任一时刻 *t*₁，*A* 还没存在；在 1750 之后的任一时刻 *t*₃，*A* 已经不存在。依照上述原则，正理把这些否定性的存在命题，改写成关于否定性实体的肯定命题——“*A* 的先无”（记作“<*A*”）与“*A* 的后无”（记作“*A*>”）。于是，前一句读作：

<*A* 存在于 *t*₁，

或者说——按正理的讲法，对象既位于时间中，也位于空间中——

1. <*A* 位于 *t*₁。

同理，

1. *A*> 位于 *t*₃。

那么 *t*₂ 这样的时刻又怎样？这是 *A* 存在、在场的时刻。还要注意，在 *t*₂ 有“<*A* 的后无”（因为 *A* 一产生，*A* 的先无就灭了），我们记作“(<*A*)>”；同时还有“*A*> 的先无”（因为 *A* 的后无尚未出现），即“<(*A*>)”。《理性手册》（TSD 89E）记下了早期正理论师的主张：这些双重非存在必须与原初实体同一，否则就会无穷倒退。于是：

(<*A*)> = <(*A*>) = *A*。

后期正理论师似乎不认这条自然的同一（它相当于经典逻辑的双重否定律），理由是：双重否定结构里含否定概念，逻辑上更复杂。

第三类非存在叫“恒常”或“究竟”无（*atyantābhāva*），例子是“罐不在地上”。《理性手册》（TS 87）说，这类非存在的特点在于：它位于三时之中——过去、现在、未来。这话听着有些奇怪，因为罐可能有时在地上、有时不在。也许要点是：这里非存在的所在处是个空间实体，不是时间实体。再如“热不在冰中”，也示例这类非存在。另外，这个否定的力度也许是说：罐从来就不在地上——因此谈不上罐的先无或后无（这两个概念是按罐在场的时间来定义的）。（比如优陀耶那把实体定义为“不具有诸性质的恒常非存在者”。）

第四类非存在叫“别异”（*anyonyābhāva*），例子是“罐不是布”。这句话应读作一个“不同一”的陈述。

于是正理论师说：每个否定句，都是对一个“*aRb*”形式句子的否定；他们又分出两种情形：*R* 是同一关系，以及 *R* 不是同一关系。对象 *a* 叫非存在的所在处，对象 *b* 叫非存在的“所遮”或“否定项”（*pratiyogin*），也就是“它在该处所的在场正被否定”的那个对象。这透出一个事实：非存在被当作一种属性或“可定位者”，而不是一种“位置”（至少当关系不是同一时）。比方说，*A* 的非存在同时位于许多地方；但正理不会说，*A* 缺席的每一处各有一个不同的“*A* 之非存在”。现在我们能看出，正理怎样不靠句子层面的否定词来解析否定句。拿“罐不是蓝的”来说。一阶逻辑转述为：罐是蓝的，这并不成立（¬*Fa*）。正理的策略则是：先说每个属性（比如蓝色）都有外延 *F*（它所在之处）与反外延 *F*′（其非存在所在之处），再把句子转述为“罐具有蓝之非存在”。注意，所谓部分可定位属性，就是外延与反外延重叠的属性——一个特征可以和自己的非存在同处。

### 11.3 否定的逻辑

《理性手册》（TS 89）对非存在（否定）的逻辑性质，提出了几点很有意思的观察。

**指称与描述之别**。据说，有定限的非存在（*viśiṣṭābhāva*）与纯非存在（*kevalābhāva*）不是一回事。看下面这对句子：

1. 阿南跋塔不在屋里；
2. 《理性手册》的作者不在屋里。

意思是：在 (3) 里，位于屋里的是阿南跋塔的“纯”非存在；在 (4) 里，位于屋里的则是一个有限定的非存在（阿南跋塔作为“被作者身份所限定者”的非存在）。(3) 和 (4) 真有不同逻辑形式吗？也许这里透出一种认识：“《理性手册》的作者”这类名词短语有两种逻辑功能——指称某个个体，以及借其属性来描述某个个体。所以 (4) 可以读成与 (3) 相同的断言：阿南跋塔不在屋里；也可以读成：《理性手册》的作者，不管此人是谁，不在屋里，也就是“是《理性手册》的作者”与“在屋里”这两个属性不同所依。若 (4) 中的限定非存在是这个意思，那么 (3) 与 (4) 的逻辑形式确实不同。

**全称量化**。《理性手册》又分出很重要的一对：特定非存在（*viśeṣābhāva*）与通类非存在（*sāmānyābhāva*）。例子如下：

1.（这）只罐不在屋里；
2.（任何）罐都不在屋里。

（注意：在梵语里这两句用同一句话表达，所以加了括号。）说屋里存在罐的特定非存在，意思是某一只特定的罐不在屋里；说屋里存在罐的通类非存在，意思是任何罐都不在屋里（也就是屋里没有罐）。因此，这个区分与全称量化结构的表述挂上了钩。事实上，在正理逻辑理论里，通类非存在正是用来表述遍充（*vyāpti*）关系的：“凡有烟处即有火”换质位，得到“凡无火处即无烟”；而这句话被表述为：在通类火之非存在所在之处，有通类烟之非存在（参考 Ingalls 1951: 54–5）[^ingalls-1951]。显然，(5) 与 (6) 的逻辑形式不同。在正理的技术语言里，这个区分是这样交代的：限定该非存在之所遮性（*pratiyogitāvacchedaka*）的属性，在 (5) 里是“这罐性”，在 (6) 里是“罐性”。

**逻辑联结词与德摩根律**。《理性手册》还谈到合取式与析取式非存在的含义，即“（*A* 与 *B*）二者皆无”（*ubhayābhāva*）与“（*A* 或 *B*）任一皆无”（*anyatarābhāva*）。它指出：意识到两只罐都不在，与意识到一只在（另一只不在），并不冲突。事实上，正如 Ingalls 所表明的（1951: 63–67），正理承认下面两个一般等式成立：

> “*A* 与 *B* 二者”之非存在 =（*A* 之非存在）或（*B* 之非存在）；
>
> “*A* 或 *B* 任一”之非存在 =（*A* 之非存在）与（*B* 之非存在）。

这两个等式一看就是德摩根律的翻版：¬(*A* & *B*) ≡ ¬*A* ∨ ¬*B*，以及 ¬(*A* ∨ *B*) ≡ ¬*A* & ¬*B*。作为后一律的一例，可看 Mathuranātha 的说法（1951: 66）：一堆（特定）非存在（*abhāva-kūṭa*）等价于一个通类非存在。一个地方若为火的通类非存在之所在，那里就是每一种特定的火都不在；反过来，若每一种特定的火都不在，火就是通类地不在。于是，火的诸特定非存在之“堆”（合取），等价于“根本没有任何火”（即诸特定火之析取）。
