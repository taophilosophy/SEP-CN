# 术语治理

本规则展开宪法第 III 条（单一事实源）与第 VI 条（体例即契约）中的术语部分。

## 两个文件，两种职责（ADR-0036，2026-11-13 发布词汇表并网删除）

| 文件 | 职责 | 性质 |
| ---- | ---- | ---- |
| `shu-yu-biao.md`（仓库根目录；ADR-0036 改名，原 `yi-zhe-shuo-ming.md`） | **术语登记册**：术语（含希腊文等原词）与书名／作品译法的决策记录（书名行依据列注记“文献译名”，ADR-0011） | 术语译法的单一事实源 |
| `ren-ming-biao.md`（仓库根目录，ADR-0012 拆分） | **人名登记册**：人名译法的决策记录 | 人名译法的单一事实源 |

译法有争议或需要说明依据时，以登记册为准。原发布词汇表 `qian-yan/ci-hui-biao.md`（术语+人名+书名合刊的三列速查视图）已于 2026-11-13 并网删除：同键行以登记册为准校对废弃，主译冲突以术语在线审定名词库为准仲裁，未命中行逐行分类取证后分流两册（口径与决策账见 `specs/008-terminology-campaign/results/`）。

## 译名依据优先级（ADR-0012，2026-10-28）

登记“依据”列时按以下档位取一并附查询日期：

1. **知网系权威源**：CNKI 翻译助手（dict.cnki.net）、术语在线 termonline.cn（全国科学技术名词审定委员会审定名词）。
2. **权威译本与学术出版通行译法**：正式出版学术著作、核心期刊通行译名。
3. **学界惯例**：如古典学千年通行译名。

**禁止**以维基百科（中/英文）及任何大众百科译名作为依据；存量发现为维基来源的行，按译法变更流程换源重裁定，不删除旧行。查无可查时保留英文原名并登记，不得臆造译名。

### 伊斯兰阿拉伯人名与术语（ADR-0013）

* 拉丁通行名与阿拉伯本名指同一人物时，登记册一行归并（`Ibn Sīnā / Avicenna` → 伊本·西那（阿维森纳））；罗马化变体（al-Farabi / Al-Fârâbî）按变音符折叠归并，展示保留首见形。
* 汉译以学界通行与权威工具书（《世界人名翻译大辞典》、《中国大百科全书》、权威哲学史译本）为准；音译连接号用“·”；ibn 译“伊本”，abu 从通行，定冠词 al- 不单独音译。
* 阿拉伯术语（kalām、ijmāʿ 等）译名优先取中国伊斯兰研究界与哲学史通行译法，原文列括注罗马化原词。

## 登记流程

1. 新术语/人名先查对应登记册；查无，确定译法后 **先登记、后使用**。登记前先确认术语的指称范围、使用语境与依据档位；不确定时先问不猜，不臆造译名（[08](08-intent-first.md)）。
2. 登记格式（两登记册各表列数不同，2026-11-07 起）：

   ```
   术语表 shu-yu-biao.md（六列）
   | 原文 | 翻译 | ... |
   人名表 ren-ming-biao.md（八列）
   | 人名 | 原文 | 译法 | 籍属 | 生卒/鼎盛年 | 出处 | 依据 | 日期 |
   ```

   * “原文”列：该术语/人名在**源语言中的书写形式**；英语条目填 `—`。非英语条目按**两级来源**取证并留凭证：① 来源页面（`en/<slug>/index.html`）显式给出的“转写 ↔ 原生文字”配对（首选）；② **权威工具书／辞书**显式给出的同项配对——书名、条目与查证日期写入依据列（见 [ADR-0030](adr/0030-原文列取证来源扩展与人名表豁免.md)）。**禁止**用 IAST／DIN 31635／Wylie 等映射表正推或逆推（`specs/012-orig-column/`）。**人名表豁免**：来源页与工具书均未给出者留 `—`，不再计入“非英语术语缺原文”告警；术语表仍逐条告警施压。
   * 人名表“籍属”“生卒/鼎盛年”两列：**每一行人物条目必填**——籍属取国籍／地区／民族／语言共同体中最能界定身份者；年代写作 `生年–卒年`，仅知鼎盛期者写 `fl.`，不确定者加 `c.`；非历史人物（神祇、菩萨、经中人物）写“非历史人物（…）”与“不适用”（见 `specs/013-person-attribution/`）。

3. “依据”必填，按”译名依据优先级”取档并附查询日期；缺列由 `tools/check_terms.py` 告警施压补齐。
4. 译法变更时 **不删除旧行**，另起一行并在译法处注明“已废弃，见新行”，保留决策轨迹（可追溯原则）；换源（如去维基化）同样留痕。
5. 三校（体例）步骤须校验正文用词与登记册一致。

## 译法总则

* **人名以登记册 `ren-ming-biao.md` 为准**（ADR-0012；体例经 [ADR-0022](adr/0022-现代学者人名体例澄清.md) 澄清，以**有无通行汉名**为准，不以古今二分）：有通行汉名者（古典与 modern 均同）用汉译并首次括注原文（柏拉图（Plato）、威廉姆森（Timothy Williamson））；无通行汉名或学界无惯译的学者保留英文（Vlastos、Zhmud、Fish），首次出现如需说明身份，用同位语补充；伊斯兰阿拉伯人名按 [ADR-0013](adr/0013-阿拉伯伊斯兰人名与术语体例.md) 取通行译名（伊本·西那（阿维森纳））。
* 产品名、软件名、命令名保持英文：UNIX、BSD、System V、shell、uucp、vi 等。
* 有通行中译的著名公司采用中译（微软、惠普、苹果、施乐、英特尔等，完整清单以登记册为准）；无通行译名者保持英文（IBM、AT&T、DEC 等）。芯片/机器型号中的品牌一律英文（Intel 80386、Motorola 68000）。
* 固定译法（登记册为准）：shell 不译“壳”；daemon → 守护进程；kernel → 内核；source(s) → 源码；public-domain → 公有领域；timesharing → 分时；port/porting → 移植；repository → 存储库（禁“仓库”）；copy → 复制（禁“拷贝”）。
* “UNIX” 保持原书大小写；原书刻意用 “Unix” 处（如刊名 *Unix World*）保持原样，禁止机械统一。
* 有正式中文译本的书名采用中译并括注英文原名，如《C 程序设计语言》（The C Programming Language）；无中译本者保持英文原名；刊名、论文与手册名保持英文。
* 古典学引用编号原样保留：DK 编号（DK 12B1）、古代作品行号（Metaph. 986a22 ff.）。
* 参考文献条目：非中文条目原文照录不译；**中国文献条目（无论古代现代）译为中文**（用户裁定 2026-10-28，[ADR-0011](adr/0011-引文原文语言与中文文献翻译.md)；细则见 [07](07-academic-norms.md)、[02](02-style.md)）。
* 无法确定习惯译法的专有名词，保留英文原名并登记，**不得臆造译名**。
* **同一词条内锁定主形**（ADR-0020）：登记册“亦作”变体仅供读者对照，不构成写作自由度；同一词条的同一概念只用主形一形。跨词条既定名（相关词条行、条目标题等来自管线登记的译名）不因本词条主形改写；发现混形时提请统一裁定，不自行换用，登记册不因正文落地形倒挂补认变体。

## 术语落地与差异处置（ADR-0048，2026-11-15）

一致性的对象是**概念**，不是英文拼写：同一概念同一译名；英文同形而概念不同者，登记为**分行**（键加括注，如 `abhāva（胜论句义）`／`abhāva`、`absolutism（space and time）`／`absolutism`），各有主形，不构成违例。概念同一性以该词条**主题域**（题名、节标题、学科归属）与上下文判定。

* **条目主题优先**：该词条所属学科域已有权威译法者，用该域译法，即使别域另有通行形；跨词条不得以“全库统一”为由改写他条既定名——[ADR-0020](adr/0020-译文语言质量门禁.md) 的“锁定主形”只约束词条内部。引文、书目题名、原文照录区不适用正文主形（[ADR-0011](adr/0011-引文原文语言与中文文献翻译.md)）。
* **差异五分类**（发现差异先定性、后处置，定性记入任务 evidence）：D1 词条内混形/笔误 → 逐处人工订正；D2 未落地（登记译法在该词条零命中）→ 判“该概念未出现”或按 D1 处置；D3 涟漪（登记主形已变更、正文仍旧形）→ 按变更段逐处看齐，非变更段与跨词条不动；D4 语境分义 → 登记新分行、词条内锁定新形，不得反向改写他条；D5 登记有误/过时 → 走译法变更流程（不删旧行、另起一行注“已废弃，见新行”）。
* **禁止机械替换**（NON-NEGOTIABLE）：不应以 `sed -i`、编辑器全局 replace、脚本 `re.sub` 把某译形批量套进译文正文；不应以“与登记册一致”为由批量改词，也不应在旧译文上做词面级回改充当对齐。修复**以句/段为单位**：回 `en/`（必要时 `yuanwen/` 镜像）核对原义，整句重译或逐处人工改，改后复跑 `check_terms --docs`。批量清单只作工作台与验收账；纯符号层归一（连接号、空格、引号邻接）属 ADR-0041 另案授权，不构成本条改字词的例外。
* **差异必联网查证**：D3–D5 一律查证，D1/D2 定性不明时同样查证。依据档位照 [ADR-0012](adr/0012-译名依据源与人名表拆分.md)（权威译本／权威工具书／学界惯例；**禁维基百科**）；术语在线与 CNKI 翻译助手**不再新增查询**（2026-11-14 用户裁定），存量凭证可作证据。凭证记五要素：查证对象、来源（书名＋条目＋页码／URL）、查证日期、来源给出的对应译名、结论；落 `specs/008-terminology-campaign/results/` 或任务 evidence。查无 → 保留英文原词，“依据”列记“查无（日期）”，不臆造。
* **告警三出口**：`check_terms --docs` 每条告警须落到 ①修复（附改动位置）②登记（附新行位置或 ADR 编号）③豁免（附理由与复核人）之一，禁止“看到了不处理”；`term_coverage` 的“未落实”与 `term_relations` 的“匿名／重名”同此口径。
* **作业顺序**：①跑 `check_terms --docs <词条>`（必要时补 `term_coverage`／`term_relations`）取告警 → ②逐条定性 D1–D5 → ③D3–D5 或定性不明者联网查证并留凭证 → ④按出口处置（逐处改正文／登记新行或变更／豁免登记） → ⑤复跑门禁，把定性与出口写进任务 evidence；收口前对本次动过的词形跑机械替换回溯。

## 与同步管线的关系

* 术语登记不改变 `baseline/` 的版本钉；登记发生在译文定稿前，凭证是登记册的提交历史。
* 三审三校中三校（体例）的登记册一致性检查可人工执行；工具化校验已落地为 `tools/check_terms.py --docs`（登记册“首现”驱动的正文定点核对，告警级，specs/002），反向缺口用 `tools/term_coverage.py`（英文源出现、中文零变体＝未落实）与 `tools/term_relations.py`（重名／别名／一词多义／匿名）复核；告警按上节“告警三出口”收口。
