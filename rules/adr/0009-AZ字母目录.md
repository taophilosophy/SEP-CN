# 0009. A–Z 字母目录 + SEP slug 单文件

状态：accepted | 日期：2026-10-27

## 背景

用户裁决（2026-10-27）：不要根目录平铺，根据上游网页的命名从 A–Z 排序（目录）。本 ADR 修订 ADR-0008 的"根级 `<slug>.md` 平铺"形态，回到**字母目录**组织，同时保留 ADR-0007/0008 的 slug 命名、单文件形态（无 index.md）与上游镜像原则。

## 决策

1. **词条形态**：中文词条为 `<letter>/<slug>.md`（letter = slug 首字符；非字母如数字按该字符建目录，如 `1/`）；英文原文为 `yuanwen/<letter>/<slug>.md` 逐字符镜像。字母目录按 A–Z 排序，目录内按 SEP slug 命名。
2. **SUMMARY/mu-lu-s**：条目链接 `<letter>/<slug>.md`；别名行保留并链到目标 `<target 首字母>/<target>.md`；导航节点链 README。
3. **补充材料**：`<slug>.<x>.md` 点号命名，与主文件同目录平铺（如 `yuanwen/s/set-theory.basic-set-theory.md`）。
4. **图片**：本地化于 `yuanwen/assets/<slug>/`（上游同名），md 内 `assets/<slug>/<文件名>` 相对引用；抓取原始 HTML 存 `en/<slug>/`。
5. **存量迁移**：根级 `<slug>.md` → `<letter>/<slug>.md`（中文侧 git mv 保历史）；`yuanwen/<slug>.md` → `yuanwen/<letter>/<slug>.md`；`yuanwen/<slug>.<x>.md` → `yuanwen/<letter>/<slug>.<x>.md`；SUMMARY/mu-lu-s 链接同步改写。
6. **工具对齐**：rebuild_dir.py（stubs/check/toletters）、yuanwen.py（输出 `<letter>/<slug>.md`）、common.py find_zh_doc、summary_sync.py、progress.py 同步；migrate_exec.py 维持废弃。

## 后果

* ADR-0008 的根级平铺被本 ADR 取代；ADR-0005（字母分目录）、ADR-0007（上游同构命名）、ADR-0008（单文件、无 index.md、点号补充材料、assets 图片）的有效部分合并为本 ADR 的现行形态。
* 目录即索引：字母目录天然按 A–Z 排序，与 SUMMARY 的字母序列表互为映照。
