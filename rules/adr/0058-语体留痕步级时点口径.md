# 0058. 语体留痕步级时点口径（生效前历史步不追溯）

accepted | 2026-11-16

## 背景

rules/02“语体与文风”（[ADR-0033](0033-译文语体门禁.md)）的复核留痕要求由 `tools/check_academic.py` 的 `task-style-attest` 落地：done_at ≥ `STYLE_ATTEST_FROM`（2026-11-10T15:00Z）的 done 任务，检查其**全部历史** s2/r1 步 evidence 是否含“语体”结论，步级无时点概念。

[ADR-0053](0053-全量done回炉重走前置环节.md) 全量回炉（413 件）重走 done 时必撞此门：旧 s2/r1 凭证系生效前所写且 append-only 留史，不可能补含该结论。autrecourt／antiochus-ascalon（2026-11-15 回炉置 done）首例红灯共 6 处，其中 4 处为生效前历史步（各 1 s2＋1 r1）、2 处为 2026-11-15 生效后新 r1。用户 2026-11-15 挂起待议（补记凭证 vs 检查器步级豁免），2026-11-16 指示解决缺口。

## 决策

1. **步级时点豁免**：`task-style-attest` 只查 `at` ≥ `STYLE_ATTEST_FROM` 的 s2/r1 步；生效前历史步不追溯，append-only 留史不动。依据：规则不溯及既往——生效前的步骤在其时的规则下无从要求该留痕。done_at ≥ 生效时点的触发面维持不变（done 件不因本裁定免检）。
2. **缺 at 视同生效前**：`task_ops.py` 恒写 `at`（全库 4550 步实证无一缺失、格式统一 `YYYY-MM-DDTHH:MM:SSZ`）；手工文件的缺 at 步按生效前豁免，不虚构时点。
3. **生效后步骤照查，缺留痕以“语体补记”补录**：生效后重走的 s2/r1 步仍须留痕；确缺的由复核人**真做语义通读后**补录，标注“语体补记”＋日期＋依据（机检结果与定性去向），先例为 6b3ae8b7 的订正凭证式留痕。本裁定落地当日对 autrecourt／antiochus-ascalon 两件生效后 r1 各补记一处（2026-11-16 收口会话通读两篇全文后落笔）。
4. **回炉流程对齐 rules/02 原文**：回炉重走（specs/028 工序）的 r1 evidence 自此须含语体结论——rules/02“初审（r1）通读全文并留痕”本就如此要求；后续回炉件不得再依赖补记。

## 后果

* **正面**：413 件回炉池的生效前凭证不再挡 done（autrecourt／antiochus-ascalon 当即转绿）；门禁对生效后新增/重走步骤照常实拦；历史记录零改写（零信任）。
* **代价**：done 任务的生效前步骤本身无语体留痕——其语体由回炉重走步骤（生效后时点、照查）覆盖；纯靠翻转状态的 done 件若全程无生效后 s2/r1 步，留痕检查为空转，属已接受的口径边界。
* **落地面**：`tools/check_academic.py`（步级豁免＋docstring）＋单测 3 例（fixture 三件）；rules/02 §复核留痕补口径句；本 ADR。
