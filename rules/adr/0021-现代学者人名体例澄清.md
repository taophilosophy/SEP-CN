# 0021. 现代学者人名体例澄清（有通行汉名者汉名＋首现括注）

proposed | 2026-11-01

## 背景

A 批纠正与补遗轮（qa-traverse-2026-10-31）暴露体例张力：`rules/03` 译名总则现行条文「现代学者人名一律保留英文（Vlastos、Zhmud、Huffman 等）」与全库实形态不一致——

* done 词条正文对**有通行汉名**的现代学者普遍用「汉名＋首现括注」：威廉姆森（Timothy Williamson）、李普顿（Peter Lipton）、普西洛斯（Stathis Psillos）、范弗拉森（Bas van Fraassen）、金在权（Jaegwon Kim，人名表已登记）等；
* 对**无通行汉名**者保留英文：Vlastos、Zhmud、Huffman（条文所举例恰属此类）；
* 补遗轮登记行两形并存：Fish/Butler/Post 保留英文，Resnik/Linnebo/Bridgeman/西拉吉 汉名＋首现括注（abstract-objects、academic-freedom、action-perception、abraham-daud 各词条纠正时按语境定形）。

条文按字面执行将迫使全库把威廉姆森改回 "Timothy Williamson"，与已 done 词条大面积冲突；不执行则条文形同虚设。

## 决策（提请用户裁定）

将 `rules/03` 该条澄清为以**有无通行汉名**为准，不以古今二分：

* **有通行汉名**（学界文献与权威工具书惯用）→ 汉名＋首现括注原文：威廉姆森（Timothy Williamson）、波菲利（Porphyry）；
* **无通行汉名或学界无惯译** → 保留英文：Vlastos、Zhmud、Fish、Butler、Post。

判定依据档位沿用 ADR-0012（知网系权威源 → 权威译本通行译法 → 学界惯例）。登记册人名行按正文实际用形登记，备注注明另一形（如「保留英文；通行汉译『费什』备查」）。条文修订随本 ADR 状态转 accepted 时落入 `rules/03`。

## 后果

* 正面：条文与全库实形态、登记行一致；「汉名/英文」两形混用于同一学者的情况以「有无通行汉名」单一判据消解。
* 负面：存量正文若存在同词条两形混用（如 abelard 的 deflationary 类），随各词条 qa-rework/更新轮消化，不另开专项。
* 不通过本裁定则按现行字面条文回改正文与登记行（影响面大，不建议）。
