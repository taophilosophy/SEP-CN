# 0077. 页面级逆向装配（B3.2）：版式账、结构账与装配补集池

accepted | 2026-11-19（权威＝用户指令“必须100%闭合”＋此前对 B3 阶梯与 specs/053 v1.4 §7/§9 的批准；承接 ADR-0076 的 T 类目）

## 背景

B3（逆向装配等值，specs/044 §1.3）分两档：B3.1＝往返不动点 `C(R(md)) == md`（已实施，79.1%）；B3.2＝页面级 sha 全等 `sha256(H0') == sha256(H0)`，其中 `H0' ≜ R_page(md) ⊕ P_s`（specs/053 §9.1）。§9 已给出公理 A4/A5、定理 T5–T8 与“残差面谓词：正文文字层禁入”的规范表述，本轮是它的**可执行落地**。

实测结论（本轮普查，非估计）：页面骨架极度规整——1,873 件 `en/*/index.html` 中，剔除词条字段后 head 仅 2 类、body 前导 5 类（含 3 件孤例）、页脚主体 5 类（含若干孤例）、head 中段 1 类；字段面（标题／作者／日期／版权年／作者主页 URL／邮箱混淆形）完全规则化，邮箱混淆 `m&#97;ilto:`＋`&#37;40`／`&#37;2e` 与 `<abbr title=" at ">` 可逆推。正文段则相反：区段脚手架（preamble／toc／main-text／bibliography／academic-tools／other-internet-resources／related-entries／acknowledgments）规则稳定，但**硬换行、实体编码策略、表位形、文献区条目序**属 C 转换时丢失的信息，须由补集承载。

## 决策

1. **`baseline/en-template/` 增四件（T 类目内，ADR-0076 职能分类不变）**：
   - `skeleton/`：冻结骨架模板 19 件（`headA`×1、`headmid`×1、`headrest`×2、`pre`×5、`postrest`×10），每件为含 `@S@`／`@CR@`／`@SY@` 槽位的原文模板；孤例词条各自成件。
   - `page-layout.json`：版式账，逐词条记字段（title／meta_authors／pub_date／issued／modified／copyright_year／copyright_authors［display＋url＋email］／site_year）与三处时代号。
   - `article-ledger.json`：结构账，逐词条记 `hids`（标题 id 形态：`id` 属性／`name:`／`aid:` 包裹三种）、`bib_seq`（文献区块序：题／散文／定义段索引，支持 `sd` 形式＝被 C 折成定义行的散文）、`bib_groups`／`bib_indices`／`bib_ids`（条目序与 `li` id）、`rel_links`（相关条目 href／死链注释）、`acad_icons`、`tables`（表属性、thead/tbody、逐行逐格 th/td/空位）、`links`（C 丢弃的内部链接：`../slug/` 与 `#anchor`）、`entities`（按件实体策略：codepoint→实体串）、`toc_block`（导航区逐字）、`wrap_width`（折行宽度）。
   - `assembly-patches/<slug>.json`：装配补集池，一词条一文件（与 `en-patches/` 同律）。
2. **补集池语义（A5 的机读化）**：页面按 `<标签>|[^<]+` 切为分段，块级标签／注释／空白为标记段，其间为文字段；装配侧与 H0 按“文字段去空白字符流”对齐，产出三类补丁：
   - `m`：标记段整体替换（只含标签／空白／注释）；
   - `u`：文字段布局账（`mk`／`tx` 项序列，`tx` 以装配侧字符流的 `[起,长]` 切片引用）；
   - `r`：未对齐区段的纯布局替换（仅当涉事文字段去空白后皆空——空 `<p></p>`、`<div class="indent">` 包裹、表位空单元等）。
   **硬谓词**：P1 文字等值（`u` 键逐段相等；`r` 涉事文字段去空白为空）——不等即文字层差异，**拒录**并转“规则缺口”；P2 命中即消耗（补丁带切片哈希，失配即 `PatchMiss`）；P3 全覆盖（应用结果与 H0 逐字节相等）。补丁按字符偏移降序应用，偏移不受前序补丁位移影响。
3. **散文来源唯一**：`m`／`r` 补丁不含文字段；`u` 补丁只引装配侧文字。账内允许出现的文字仅为**导航标签**（TOC 题、相关条目链接题、文献题）与**字段值**（作者名／邮箱／日期），且账↔正文一致性另设核对（TOC 标签与被 C 折成定义行的散文均以可见文等值匹配，失配即该件不入账或转缺口）。
4. **判定与冻结**：`page_assemble.py` 为判定器（只读 H0）；`assembly_pool.py --build` 为建池器（唯一写者）；账与池一经提交即冻结，重抽须人工复核并在 execution-log 留痕。CI 只报告变动（沿用 `en-roundtrip.yml` 的差集口径），不写 baseline。
5. **证据语义（T7 的落地）**：`pool_bytes / page_bytes` 为**规则闭合率的补数**，逐件与全库同报；B3.2 绿只证明“页面文字全部由 md 再生、差异不超出格式层”，不证明转换器最初无信息损失（后者由 B3.1／B2／I2 承载，两层互证不冒充）。

## 标准与先例衔接

无国标规定装配账格式；本决策沿用 ADR-0076 的三类目职能划分（GB/T 26162-2021 分类方案／IEEE 828 受控库），补丁池的“清单＋校验值＋命中计数”形态与 OAIS fixity、BagIt manifest（RFC 8493）同律，但**不引入 BagIt 格式本身**。形式语义仍为收缩对（lens PutGet／GetPut）与带补集存储的 GetPut，specs/053 §9.5 六锚点不变。

## 后果

- 增派生件：`page-layout.json`≈1.4 MB、`article-ledger.json`≈18 MB（体量最大，因含 TOC 逐字块与实体表）、`assembly-patches/` 按闭合件数一件一文件（当前数百件、合计不足 1 MB）；`skeleton/`≈0.1 MB。账体量大但为单一事实源，重抽全量约 5–10 分钟（可复算）。
- 判定器与建池器分离、账池冻结，故规则迭代后旧池会“陈旧”（哈希失配）——这是设计内的红信号，处置＝重抽该族并更新 execution-log。
- 未闭合件（文字层差异）不入池：它们是真缺陷族（表位空单元、松散列表 `<li><p>`、个别文献条目在 md 中缺失等），逐族修 R 或改账，修复前保持红。
