# 0074. 术语在线解禁重抓（JWT 直连、凭证作证据、登记仍人工）

accepted | 2026-11-18（用户指令“开始抓取术语”→“1”＝解禁重抓）

## 背景

[ADR-0012](0012-译名依据源与人名表拆分.md) 曾于 2026-11-14 由用户裁定“术语在线与 CNKI 翻译助手两源不再新增查询”，`rules/03` 相应条文据此收紧。2026-11-18 用户下达“开始抓取术语”，经确认选择“解禁重抓”——恢复术语在线（termonline.cn 全国科学技术名词审定委员会审定名词库）抓取，为 A/B 档候选补权威译名凭证。

前置探测（2026-11-18）已确认：`.secrets/termonline-session.json` 的 JWT 有效期至 2026-11-27；裸 JWT 直发 `tmDatabase/listFront`（激活窗口）+ `tmWord/allSearch` 即返回四库齐全（`abductive reasoning` 实测 408/106/18/31 条真实总数），无需浏览器 profile。

## 决策

1. **解除范围**：仅解除对**术语在线**的新增查询限制；**CNKI 翻译助手维持不新增**（用户本轮指令只指向术语抓取，CNKI 待另行裁定）。
2. **抓取实现**：`tools/tl_jwt_crawl.py`（JWT 直连 `.secrets/termonline-session.json`，无浏览器 profile；激活窗口 TTL≈120s，主动续窗）。凭证落 `specs/008-terminology-campaign/results/queries/termonline-all/<safe_key>.json`，schema 与 `tl_crawler` 批次一致，`term_audit` 可直接入库。
3. **限速**：沿用术语在线实测校准节流（base 8s；降级自适应升至 30s；不破 AGENTS.md ≥5s 下限）；断点续抓（state 文件），幂等覆盖写。
4. **证据定位不变**：凭证只作**证据**，登记仍走人工 A/B/C 分档裁定（ADR-0070 机检为筛、人审为判）；禁机械替换（ADR-0048）；“查无”同样落 `empty` 凭证，不作否定证据（ADR-0012 口径）。
5. **授权链**：本 ADR 取代 `rules/03` 中 2026-11-14“两源不再新增查询”对术语在线的部分；条文改为指向本 ADR，CNKI 限制保留。

## 后果

* 正面：A 档 12,721 条待抓候选可获审定库译名凭证，B 档存疑项亦得联网核证来源；证据链与既有 `termonline-all`（10,376 件）同构，可直接进 `term_audit` 四态审阅。
* 负面：抓取耗时（8s/词，全量约 28 小时，须多会话断点续抓）；术语在线非哲学全覆盖，未命中项仍走档位 2/3（权威译本／学界惯例）。
* 跟进：抓取进度账与命中率落 `specs/008-terminology-campaign/results/`；CNKI 是否解禁待用户裁定。
