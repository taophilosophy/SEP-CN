# 0084. 三审分离、译后编辑定位与记录偏离

状态：accepted　日期：2026-11-25（用户对 specs/061 决策点 D1–D5 的裁定：全部按建议案批准）

## 背景

specs/061 对照《图书质量保障体系》、ISO 17100、ISO 18587／GB/T 40036、ISO 5060、GB/T 19682 与 ISO 15489 后发现五项需裁事项：三审人员分离（D1）、LLM 辅助初译的定位（D2）、GB/T 19682 是否采标（D3）、记录清史偏离如何登记（D4）、术语概念字段（D5）。用户 2026-11-25 全部批准建议案（C／B／B／B／B）。

## 决策

1. **D1＝C：终审强制分离，前两审登记偏离。**
   * `sg-03` 的 actor 不得等于初译 actor（`tr-02`），也不得等于 `sg-01`／`sg-02` 的 actor；违反直接拒绝，不再接受“冷置／密度”补偿。机检在 `task_ops._independence_gate`。
   * `sg-01`／`sg-02` 允许与初译同人，但须在 evidence 记明冷置或密度补偿（ADR-0020 原条款保留），并在 `standards.json.deviations` 登记为对《图书质量保障体系》第八条与 ISO 17100 复核分离要求的**部分偏离**。
2. **D2＝B：LLM 辅助初译按译后编辑定位。**
   * 采用 GB/T 40036-2021（IDT ISO 18587:2017）作为现行基准；ISO 18587 第 2 版（DIS，范围扩至非人类译文输出）发布后自动升级引用，不另立 ADR。
   * 任务 JSON 增 `translation_mode`（`human`｜`llm-pe`）与 `pe` 块（`level`：`full`｜`light`；`system`：引擎与版本；`disclosure`：披露位置）。`llm-pe` 任务在 `tr-02` 推进时，机检要求 `pe.level` 与 `pe.system` 非空、evidence 含“译后编辑”或“PE”，否则拒绝。
   * 默认 `human`；`pe.level` 默认 `full`（轻编辑须用户逐件裁定并记入 `pe.light_basis`）。
3. **D3＝B：GB/T 19682-2005 采“基本要求／特殊要求”，评定仍用 CY/T 266＋ISO 5060 评分卡。**
   * `standards.json.adopted` 增条目：GB/T 19682 基本／特殊要求（owner `rules/04`、`rules/02`；tool 人工核验＋`check_style`）。
   * 不采用其“评定与检测”作为第二套差错率，避免双评分；`not_adopted` 不列（部分采纳）。
4. **D4＝B：登记历史偏离，未来记录恢复留存。**
   * `standards.json.deviations` 登记：journal 与 `tasks.steps` 的历史清空（ADR-0082）偏离 ISO 15489-1／GB/T 26162／GB/T 18894／DA/T 22；依据为用户 2026-11-25 授权；范围限 2026-11-25 之前的历史事件。
   * 自本 ADR 起，新事件与 steps **恢复只追加、不删除**；`clear`／`reopen` 等动作照常留痕。
5. **D5＝B：术语概念层先加“定义＋学科域”。**
   * 新建 `baseline/term-concepts.md`（键｜定义｜学科域｜概念关系｜依据｜裁定日期），与 `shu-yu-biao.md` 的“词形—译法”层分工（ISO 704 概念与指称分离；ISO 1087 术语；ISO 10241-1 条目结构）。
   * 2026-12-01 起新登记术语必须同时有概念行；存量术语随重译逐条补齐，不一次性回填。
   * 校验器 `tools/check_term_concepts.py` 先作告警级（不计入 `check_all`），存量清零后再议升档（`rules/08` §14）。

## 后果

* 正面：终审独立性可机检；LLM 使用可审计、可披露；GB/T 19682 有了明确承接；记录偏离与未来留存边界清楚；术语层向 TBX 可迁移（GB/T 44227-2024）。
* 代价：单会话完成全流程的旧路径在 `sg-03` 被阻断（须由另一 actor 签终审）；`llm-pe` 件多两项字段与一句 evidence；术语新行多一次概念登记。
* 回退：`git revert` 本批；已填 `pe`／概念数据保留。
