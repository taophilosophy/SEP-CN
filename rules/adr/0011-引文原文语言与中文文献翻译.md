# 0011. 引文原文语言还原与中文文献条目翻译

状态：accepted | 日期：2026-10-28

## 背景

用户裁定（2026-10-28）两点翻译要求，影响全部词条译文的引文与参考文献处理，是对既有口径的修订：

1. 引用的原文若是中文或日语，优先使用中文或日语（不以英译回译）。
2. 参考文献若是中国文献，一并翻译，无论古代现代。

此前 `rules/02`（编写体例）与 `rules/07`（哲学学术规范）规定参考文献节一律「原文照录不译」，对 SEP 大量引用的中国古典文献（如《论语》《孟子》）与中国学者论著不友好：中文读者读到的书名、篇名与引文反而是英译的回译。本 ADR 修订规则文件（依 [06](../06-governance.md) 先立决策记录再改条文）。

## 决策

1. **引文原文语言还原**：SEP 引用的原文若是中文或日语，译文优先还原为中文或日语原文；无法可靠还原时照录英译并以译注说明（存疑纪律见 [07](../07-academic-norms.md)）。标点与体例仍按 [02](../02-style.md)（弯引号等），不因原文语言引入直角引号。
2. **中文文献条目翻译**：参考文献节中的中国文献条目（无论古代现代）一并译为中文——古籍与现代著作回译为通行中文学名、书名与出版信息；其余语种条目维持照录不译。节首斜体说明相应调整为「*非中文文献从原文照录，不作翻译；中国文献译为中文。*」
3. **幻觉禁令照旧**：中文条目的回译只能依据英文源所载信息与可核实的原始文献进行；英文源缺的信息照缺，存疑处译注说明，不得凭记忆臆造（[07](../07-academic-norms.md) 禁止幻觉引文条款不变）。

## 实施细则（2026-10-28 复核后批准，全项落地）

全库盘点结论（232,608 条文献、约 10–15% 词条含中国文献）之上，补充可执行细则：

1. **条目现制位置**：yuanwen 转换把上游文献节溶解为 `## References（引用注释）` 节说明 + 文末脚注定义（`[^key]: 条目`），ADR-0011 的翻译对象即脚注定义条；zh 文档随之镜像该结构，不再要求重建列表式「参考文献」节（rules/07 结构完整性措辞同步修订）。
2. **著录格式标准**：保留西文著录骨架（拼音/西文作者、年份、出版地：出版社、页码）与引注键对应，汉名与中文书名括注还原，例：
   `[^yan-2001]: Yan Buke 阎步克, 2001, 《乐师与史官：传统政治文化与政治制度论集》, 北京：生活·读书·新知三联书店。`
   汉字一律通行**简体**（上游繁简混用，如 閻步克→阎步克）；西文译名可保留括注；条目内链接（ctext.org/archive.org/doi 等）是回溯通道，翻译时一律不动。
3. **幻觉防线三来源**：中文书名/篇名回译只允许 ① 上游已印汉字（实体解码后原文）、② 典籍通行名（yi-zhe-shuo-ming.md「文献译名」区登记）、③ 条目自带英译中括号回推；三路皆查不到的保留罗马化 + 译注。禁止凭记忆臆造。
4. **古典学编号中文形态**：文内 `(Analects 2.3)` → 《论语》2.3、`(Mencius 6A.1)` → 《孟子》6A.1（篇码原样，rules/07 例句同步）。
5. **机检配套**：tools/biblio_audit.py（三探针：实体解码汉字/典籍专名/作者位拼音）；check_academic 增 biblio-note-outdated 与 biblio-chinese-untranslated 两条告警（--strict 升硬）；check_style 文献节豁免细化为「非中文行豁免，含汉字行按正体例」。

## 后果

* `rules/02`、`rules/07` 按本 ADR 修订；`tools/check_academic.py` 的 biblio-note 门禁只要求节首说明含「照录」字样，新样文兼容，机检无需改动。
* 已完成词条 done=0，无存量改译负担；在途与后续词条自本 ADR 起执行，三审三校把两条款项纳入核对点。
* 中国文献条目译名以通行学术译名为准（与 [03](../03-terminology.md) 术语登记衔接：同一著作在引文与文献中译法一致）。
