# 0031. 人名表“籍属／生卒”取证来源扩展（与 ADR-0030 对齐）

accepted | 2026-11-10

## 背景

`rules/03-terminology.md` 规定人名表“籍属”“生卒/鼎盛年”两列**每行必填**，写作 `生年–卒年`，仅知鼎盛期者写 `fl.`，不确定加 `c.`。现行数据欠账 3 007 行（占人名表 3 673 键的 82%）。

ADR-0030 已为“原文”列开放两级取证来源（来源页 → 权威工具书），但该开放**未覆盖本两列**，形成规则不同步：同一行的三列里，原文列可用工具书，籍属/生卒列却无来源可依。

同日取证结论（`specs/008-terminology-campaign/results/orig-structural-finding.md`）：`en/` 语料对“姓名 + 生卒”的可自动回填量为 **0**——宽松判据命中的 76 行全部是 DOI 串、期刊卷页与出版年；严格判据下仅存 3 条时期跨度（著述时段、家族世代），亦非生卒。故本两列不可能靠语料自足。

## 决策（用户 2026-11-10 批准）

1. **取证来源与 ADR-0030 对齐**：籍属与生卒两列采两级来源——① 来源页面显式叙述（如正文“康德（1724–1804）”）；② **权威工具书／人名辞典**（《世界人名翻译大辞典》《中国大百科全书·哲学卷》、各国国家图书馆规范标目等），须在依据列写明书名、条目与查证日期。
2. **禁止推算**：不得由生年与常见寿数、朝代起讫、上下限交集等方式倒推；不得由同一学派/家族其他成员代填。工具书未载者，籍属留 `—`、生卒写 `fl.` 或 `不适用` 并注明依据。
3. **非历史人物**仍按原规定写“非历史人物（…）”与“不适用”（神祇、菩萨、经中人物）。
4. **优先级不变**：告警不阻断；每批补录须逐行留凭证，并跑 `check_terms` 确认无新冲突（补录不得改变已有译法）。
5. **实现**：本轮无代码改动（`person_missing` 判定口径不变，仍逐行告警）；变化在“依据”可采来源，属规则层开放。

## 备选方案与被否理由

| 方案 | 否决理由 |
| --- | --- |
| 仅靠语料挖掘 | 实测可回填量为 0（见上），继续挖掘只是耗时而已 |
| 由模型知识直接填写 | 无可核凭证，违反零信任与可追溯；且 3 000 行规模下错误率不可接受 |
| 取消两列必填 | 籍属与年代是人物身份判据，取消等于放弃可核性；且既有 660 余行已填，标准不能倒退 |

## 影响

* 3 007 行欠账从“无路可走”变为“可分批考订”：每行需工具书条目 + 凭证日期，估每批 50–100 行为一个作业单元。
* 不改变任何既有译法，故 `check_terms` 冲突面为零；新增填写只在 `籍属`／`生卒` 两列。
* 与 ADR-0030 合观：人名表三列（原文、籍属、生卒）首次共用同一取证标准，规则内部一致。

## 验收

`python tools/check_terms.py` 硬错误 0、冲突 0；人名表新填行逐一可回溯到依据列所列工具书条目；`check_all` 8 项全绿。
