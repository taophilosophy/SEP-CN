# 0033. 译文语体门禁（禁文言与破折号滥用，语义判定）

accepted | 2026-11-10

## 背景

2026-11-10 用户发现 `j/jayaraasi.md` 正文（除引用外）通篇为文言：句末“矣／焉／哉”，判断句“……者，……也”，文言代词“吾人／彼”，以及仿古的四字、对偶句式。既有的体例标尺沿自另一技术书项目（“像中文技术作者直接写作：直白、口语化”），与 SEP 哲学百科的学术语体不合；`rules/02-style.md` 只治理欧化与格式，没有一条约束语体，因此三校、复审全部通过而无人拦截。

语体问题无法用关键词可靠判定：“之／其／而／则”等字现代汉语照用，命中数不能作为证据；按关键词拦截会同时误伤正常译文与放过半文半白。故门禁只能建立在**语义复核留痕**上。

## 决策

1. `rules/02-style.md` 标尺改为“像中文学术作者直接写作的论文”：现代汉语学术书面语，准确、平实、可读；不译成文言或半文半白，也不译成欧化汉语或翻译腔。
2. 新增“语体与文风（语义判定）”条款：
   * 译文自己的叙述（标题、导言、正文、译注、脚注说明）禁文言句式、文言虚词与仿古修辞；
   * 破折号只承担插入、转折、解释，不得当作默认停顿或连接手段，同段多处或可替换为冒号／括号／分句的一律改写（AI 生成文本的典型腔调）；
   * 直接引文、典籍原文、碑铭、题记原引文与参考文献照录条目豁免；
   * 二校与 r1 各通读一次全文，结论写入任务 evidence。
3. 门禁分两层：
   * **语义层**（真正的判断）：复核人通读后判断语体，禁止以关键词命中数代替判断；
   * **留痕层**（可机检）：`tools/check_academic.py` 新增 `task-style-attest`，对生效时点（`STYLE_ATTEST_FROM = 2026-11-10T15:00:00Z`）之后 done 的任务，校验 s2 与 r1 的 evidence 都记录了语体结论。该检查只查“语义复核是否发生”，不判断文本语体。
4. 存量 done 词条（约 302 条）由 `specs/015-style-register-review/` 全局语义复核逐条通读，产出台账与修复清单；发现的文言件重写为现代汉语。

## 后果

* 正面：语体有了明文标尺与可追溯的复核留痕；`jayaraasi` 类整篇文言不会再以“格式全绿”过关；破折号滥用与文言同属语体问题，一并纳入。
* 负面：每条译文增加两次通读成本；留痕门禁只能证明复核人声明做过判断，判断质量仍取决于复核人，不能替代编辑责任。
* 跟进：`specs/015` 复核完成为止，存量词条的语体结论不完整；`j/jayaraasi.md` 需按新标尺重写并重走校次。
* 已知不一致（非本 ADR 范围）：`rules/05-ci-and-tools.md` 引用的 ADR-0032（运行时基线）在库内缺文件，待治理会话补齐。
