# 0090. 配对判据收紧与引证库名如实机检

状态：accepted　日期：2026-11-26（承 ADR-0088／0089，修其机检实现）

## 背景

ADR-0088 落了“审定引用须配对”，`tools/check_terms.py` 跑出的告警是 0。2026-11-26 复核
“无直接收录”族 43 行时发现这 0 是假的：判据本身有四处漏。

1. **豁免词表收了单字**。“义”“异”会撞进“义务论”“差异”，“作“”会撞进“亦作“X””，
   裸“复核”更是把一切带日期的复核句一律豁免。实测 3,008 条审定断言里，按旧表只有
   13 条进入配对判定，按精确短语表有 38 条。
2. **匹配串把译法列并了进来**。`needs_pairing('%s；%s' % (译法, 依据))`——译法列几乎
   人人身带“亦作“”，于是“作“”必然命中，等于整表豁免。
3. **多形译法没拆开**。`构造主义；建构主义` 整串归一成一串无意义字符，与审定
   “构造主义”配不上（constructivism 因此假告警，反向漏 also 存在）。
4. **库名写错无人管**。16 行 2026-11-18 JWT 直连批量查证把 `termonline-all` 整站统称
   “审定名词库”，而命中的分册实际属海峡两岸名词对照库（心理学／地理学／信息科学技术／
   植物学／经贸／航海／大气科学／化学工程）或中华思想文化术语传播工程（哲学／文艺）；
   另有 7 行同段既称审定又称对照库。ADR-0088 第 2 条“库名如实”当时只写在文字里，没落地。

## 决策

1. **豁免词表只收精确短语**（`tools/term_pairing.ACK_RE`）：删除 义／异／作“／复核，
   补 同名噪声／同形噪声／英文对／英文列作／异构形／相邻形／通名／全称形／形容词形／
   语序／并行／分立／复数形／省略／缩略／佐证／撞形／降为亦作／无该条 等。
2. **待判文本按列取**（新增 `claim_text`）：默认只看依据列；译法列自身写有“审定…”时
   才并入。
3. **显式引证即已交代**（新增 `explicit_citation`）：同一分号段内出现“审定 … 作“X”／＝X”
   视为已写明所引之形，不再要求配对——形异、义异、英文侧不同都由文字自证；裸断言
   （只写库名不写形）仍要求配对。
4. **多形译法拆开**（`zh_forms`）：译法列按 ；／、／／ 拆形后逐一参与配对，括注先剥。
5. **新增第三项机检：引证库名如实**（`citation_claims` + `audit_citation_libs`）。取
   `作“X”` 之前、且不越过最近分号的窗口判所声称的库别，再与索引内该形的实际库别对账：
   不符即“引证库名失实”；同段既称审定又称对照库／其他库记“混标”。三类噪声跳过——
   `亦作“X”` 不是引证；带条文号（`01.0125` 式）的多为纸质审定本引证，索引未必覆盖；
   索引内查无此形的不作判定。清单落
   `specs/058-term-full-reextraction/results/citation-lib-warnings.txt`，告警级，不计硬错误。
6. **存量清账**：批 53 复核“无直接收录”族 43 行（直配 8／形近不采 12／确认 0 条 23，
   `norm` 译法归“范数”）；批 54 改正 29 行（库名失实 19／裸断言写实 10，有重叠）。
   清账后三项告警全为 0。

## 补裁（同日，分句判据）

首批收紧后仍有整行豁免的残余，实测三例，逐条补：

7. **按分句判，不按整行判**（`needs_pairing` 逐段扫）。一行常并列两种主张——GB 标准库
   “首屏无该键配对条目”＋“审定库复核一致”，整行匹配时标准库的负证词会把审定的正断言
   一起豁免（academic freedom、cognitivism、connectionism 三行）。分句后暴露 96 行，
   逐层收口至 0。
8. **括号内的分号不切句**（`split_segments` 记括号深度）。`（…复核：未审定；原“复核一致”
   表述作废）` 若从括号内切开，后半段会变成无主的裸断言（absolute idealism 判例）。
9. **引形的判据放宽到“引号即可”**：`审定(?!库?无|库?未|公布库无)[^；“”]{0,60}?“` 与
   `审定…＝X`。行内写法有“审定名词库“性别歧视””“审定《音乐名词》形“纯音乐””
   “审定 homunculus fallacy＝微型人谬误”等多种，只认“作“”会漏。
10. **译法列的自证也算**：译法括注写“（审定收“X”）”时整行放行（`explicit_citation(trans)`）——
    读者在译法列已看到审定形。

**补裁后的清账**：批 59 改正 8 行——大弃赌论证、平等主义（equalitarianism）、直觉主义逻辑
（intuitionist logic）、潜变量写实；缘起、业改其他术语库，命题逻辑改海峡两岸；尽责性的
“严谨性”实为海峡两岸形。另判据补 `无 … 对口`（带空格）负证。

## 后果

* 正面：告警 0 变成可辩护的 0；“审定作 X”一旦写进依据就同时受配对与库名两重核验；
  批量查证里“整站统称审定”这一类系统错误有了出口。
* 代价：精确短语表需要随行内新措辞维护（新增措辞未入表时会假告警，按提示补词或改写行）。
* 回退：`git revert` 本批；三处判据与第三项检查集中在 `tools/term_pairing.py`，
  行内数据改动见 `specs/058-term-full-reextraction/bin/patch_b5{3,4}_*.py`。
