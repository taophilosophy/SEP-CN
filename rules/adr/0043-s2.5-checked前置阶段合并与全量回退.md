# 0043. s2.5_checked 前置阶段合并与全量回退（审计环节更名、术语校独立、done 回退、r 链全重走）

accepted | 2026-11-14（用户裁定三连：185 全口径含 done、r 链全重走、新立 specs/028 合并；术语校升独立环节）

## 背景

specs/026 双任务书（ren-wu-shu.md T0–T5 与 ren-wu-shu-a2.md W1/W2）与 specs/027（审计环节增项 T1–T4）在「仅出任务书」指令下并行签发，遗留 185 vs 24 回退口径未决对表。用户随后裁定合并：把 027 与 026 双书合并为一个整体任务，作为 s3_checked 的前置阶段，**命名为 s2.5_checked**；全部「已经完成和正在进行的、未到 s3_checked 但已完整全文段落翻译」的任务回退到该阶段，之后重走一轮 s3_checked；并以新增软件工程理论增补修订 s3_checked；s2.5_checked 与 s3 等阶段一样按字头 A–Z 并行认领；不计成本。追加裁定：**术语/人名表校对升为独立环节**（s2.4_termchecked）——现仅内嵌于 s1（术语漂移）/s3（登记册一致性）/r2（语境分流），无独立核验位。

## 决策

1. **状态机重构**：`s2_checked → s2.4_termchecked（术语校，新增独立环节）→ s2.5_checked（审计已译，由 audited 更名并扩容）→ s3_checked → r1_reviewed → r2_reviewed → r3_reviewed → done`；update 序列同位插入两态（s2.4 仅变更段，s2.5 默认仅变更段、基准变更全文档）。`audited` 状态名废止（存量迁移）；step `audit` 保留为 `s25` 的兼容别名。**本书取代 ADR-0040 决策 5 的「done 不走 reopen/不回状态机」口径**（仅就该口径而言，其余条款有效）。
2. **s2.4_termchecked（术语校，新增）**：逐词条对照两登记册（shu-yu-biao、ren-ming-biao）核验正文用词；未登记词「先登记后使用」复查；登记册生卒列等修正（a2 W2）同步于本阶段执行；机检挂钩 `check_terms --docs`（硬错误拦，告警留 evidence）。MQM 映射 Terminology 由 s3 移至 s2.4（s3 保留 Locale Convention）。
3. **s2.5_checked（审计已译，扩容合并）**：原 ADR-0040 审计六项（三向比对、密度统计、AI 腔、题注、[……]、文字技术整理）并入 specs/026 双书语料收尾项（顿号 147/14、括号套用 335、多段引文 2、连接号漏网 W1 括注生卒年/年代、登记册生卒列 W2 联动）——全部为 s2.5 阶段逐词条作业面；`audit` 挂钩（check_math_zh 默认档）与独立性机检（与初译 actor 全同须冷置/密度记明）随迁。
4. **全量回退（185 全口径执行细则）**：①026 T1 清单 185 件（A1 波及：done 170＋r1_reviewed 3＋s3_checked 12）经受控回退原语回滚到 s2.5_checked；②非 A1 波及的现存 s3_checked 与 r1_reviewed 在途件（未做过 s2.4/s2.5）**一并回滚**（体例基准变更同理由，差额 13 件在案）；③非 A1 的 done 存量（约 224 件）不回状态机，由 specs/023（并入 028）按增项补课、台账为凭证；④cleared/pending 不涉及；drafted/s1/s2 任务经新状态机自然推进。**回退件 r 链全重走**（s3→r1→r2→r3，旧 r 凭证留史不删）。
5. **回退原语**：`task_ops.py` 新增 `revert-state <slug> --to s2.5_checked --reason <凭>`——仅接受该目标态，仅适用于 state ∈ {s3_checked, r1_reviewed, r2_reviewed, r3_reviewed, done}；steps 追加 revert 记录（append-only）；不触碰正文（026 T0 设计照用，目标态按本决策更名）。执行批次以清单卡钉＋快照对账（specs/028/bin）。
6. **s3_checked 增补修订（软件工程理论）**：三校定义挂 ADR-0041 规范清单（连接号三形、表身空值、表号表题、顿号新规、题注细则）＋ADR-0042 规范基线筛查义务；s3 凭证增记「适用规范基线筛查结论」。s3 的 MQM Locale Convention 不变，Terminology 移 s2.4。
7. **战役合并与销案**：新立 **specs/028-s25-termchecked-rollout** 承接 026 双书＋027 全部未执行项与回退执行；026 双任务书、027 **销案**（文头注记并入去向）；**specs/023 三向回归审校战役并入 028**（台账与已审结论沿用，其 done-补课口径按决策 4③执行）；026 已完成的连接号归一（194 词条）与 G9① 结论作为 028 输入凭证。
8. **并行认领**：s2.4/s2.5 阶段作业按字头 A–Z 批次并行认领（campaign.py 认领机制沿用，同 s3 等阶段），批次开工按 rules/08 §9 立卡钉基准。

## 后果

* 正面：三份任务书并一，回退口径终局（185vs24 未决对表销案）；术语校从内嵌子项升为有名目、有机检、有凭证的独立环节；s3 带着新标准增补重走，体例基准一致。
* 负面：185＋13 件状态回退、r 链凭证作废重做，done 170 件的 r1–r3 全部重来（用户裁定不计成本）；状态机更名牵动 rules/tasks/契约/工具四处同步与一次存量迁移。
* 跟进：specs/028 立卡执行回退与阶段作业；`check_terms --docs` 告警级不升硬（008 查证覆盖面继续扩）；复审随 doctrine 周期（2027-01-21）。
