# 0078. 目录条目标题体例判据：三段式、作者顿号、别名“——见”、连词双轨不归一

accepted | 2026-11-25（权威＝用户 2026-11-25 裁定“与和不必强制归一化。甲乙丙全部批准，任何机械处理必须事后全量复核”；依据＝`jian-yi-shu/mu-lu-tiaomu-ti-li-gui-fan-jian-yi-shu.md` 与 specs/059 实施凭证）

## 背景

`SUMMARY.md`（3,738 行条目、638 行别名、182 行分组）与 `mu-lu-s.md`（1,866 行条目＋1,244 行标题）此前只有结构规则（rules/01：条目格式、无链接行、标题同步），**文字与符号层无判据**：作者栏分隔、标题内并列连词、别名行中文连接、间隔号码位、连接号形态均靠逐次人工判断。2026-11-25 全量审计（specs/059 `results/before.json`）实测：作者栏 1,276 行 100% 用顿号（健康）；标题内 en “and” 的中文连词“与”129／“和”71 双轨并存、无判据；别名行中文连接三形态（——见 623／：见 4／缺连接 11）；U+2027 间隔号混码 1、`&ndash;` 实体泄漏 1、mu-lu-s 标题 en dash 2（违 rules/02 已登记的一字线裁定）。

标准依据（条款级，2026-11-25 检索）：GB/T 15834-2011 §4.5（顿号用于并列词语）、§4.10/§5.1.4（破折号两字位）、§4.13（连接号三形）、§4.14.3.1（间隔号分隔外国人名）、§4.17.3.3–4；CY/T 154-2017（中文句内并列英文单词／词组中间宜用中文顿号）；GB/T 15835-2011 §5.1.1（世纪年代用阿拉伯数字）；GB/T 22466-2023（索引“见”参照；2008 版已废止）；ISO 999:1996（see 交叉引用与无盲引）；CMOS 17/18（标题拼 and 不用 &）；SEP contents.html（“X — see Y”与括号署名）。

## 决策

1. **条目行三段式（应）**：`中文题`＋半角空格＋`英文原题`＋半角圆括号 `作者栏`。作者栏并列姓名之间用顿号，禁用逗号／分号／`&`／`and`（CY/T 154-2017）。现库 1,276 行合规，机检谓词即此。
2. **作者缩写点（宜）**：从作者惯用式（`C.A.J. Coady` 与 `C. D. C. Reeve` 并存为合法），以 `ren-ming-biao.md` 为准，禁机械归一（署名是上游事实，零信任）。
3. **译注括注双轨（宜）**：中文题内增补性括注用全角（），英文原题内括号与作者栏用半角；en/full-width 不得互串。
4. **别名行连接（应）**：`中文索引词——见中文目标题 英文段 — see 索引名`。“——见”为两字位破折号（GB/T 15834 §4.10）＋“见”（GB/T 22466-2023 直接参照）。“：见”、缺连接、“——见”前空格均违例；“——见”后接西文／数字时保留半角空格（偏离① CY/T 154 法定形态，与引号边距空格同律）。
5. **分组行语序（宜）**：`中文名`＋半角空格＋`英文索引名`；en 侧照录 SEP 原样，禁改。
6. **间隔号与连接号（应）**：人名间隔号一律 U+00B7（禁 U+2027）；数字区间连接号遵 rules/02（ADR-0041）三形裁定，标题层同受管辖。
7. **标题内并列连词（可，不设机检）**：en “and”／“vs.” 的中文连接词在“与／和”之间**自由择用**，以语体自然为准，**不强制归一、不建白名单、不设门禁**（用户 2026-11-25 裁定）。改判记录：2026-11-25 建议书 §4 T2 的案 A（全量“与”）与案 B（白名单）均不采纳；两案呈裁后用户裁定“不必强制归一化”。
8. **en 侧禁规范化（应）**：`yuanwen/SUMMARY-en.md` 为生成物（`gen_en_summary.py`），别名行左侧英文段系上游照录面，`en/` 与 `yuanwen/` 冻结承 ADR-0062；体例归一仅施于中文段。
9. **判据机检面**：`specs/059-toc-title-normalize/bin/recheck.py` 为本判据的独立复算器（P1–P8 谓词，全 0 命中为 PASS）；后续回归可复跑。写回器与复算器分离（判定权只读，ADR-0063 三权分立同旨）。

## 标准清单增补（rules/README“规范性引用标准”）

新增三行：GB/T 22466-2023（索引编制规则，含“见”参照）、ISO 999:1996（索引交叉引用）、世界人名翻译大辞典（新华社译名室，外国人名汉译工具书档位）。

## 取舍与替代

- 不采纳“标题连词白名单”：白名单把语体判断变成机检，会制造新的“已核实型授权”（rules/08 §14 禁用），且“阿拉伯和伊斯兰哲学”家族（11 条）之外仍有大量中性并列。
- 不改 103 行别名行左侧英文段（catalog `label` 与左侧标题式不一致的存量）：ADR-0024 明文左侧写目标完整标题、`check_summary.alias_fragments` 亦按此放行，判为有意偏离，维持现状（specs/059 §6 结案）。
- 一行回退：实施批次单提交，`git revert <commit>`；判据回溯仅需删除本 ADR 对应 rules/01 节与 README 三行。
