# 0020. 译文语言质量门禁（反欧化条款、六道 MQM 映射与复核独立性）

accepted | 2026-10-31

## 背景

用户指令（2026-10-31）：复核 A 开头词条翻译流程——"译文不够清晰，流程、准确度有问题，存在欧化汉语等问题"，要求结合联网调研、既有规则与软件工程理论修订。

复核证据（明细见 `specs/005-translation-campaign/qa-findings-2026-10-31.md`）：

* abduction（done 词条）实锤 4 处误译（warrants→"只配"、made likely→"使之变得可能"、reasoner→"说者一方"、ABD1 可靠性句破义）＋术语同段混形（不完全决定／不充分决定性／非充分决定性三形并用），且登记册变体系因"正文落地形"倒挂补认——与宪法 III 单一事实源方向相反。
* 欧化密度（正文）：abduction 被字 38／≥70 字长句 26／三连"的"21；action.md 70／42／69。
* 流程：abduction s1→r3 同一 actor 十分钟连走六道（`tasks/a/abduction.json` 时间戳），复核独立性无制度；s2（语言）是六道中唯一无检查器的一道。

联网调研对接：余光中《怎样改进英式中文》（的的不休、弱动词、被字句）与思果《翻译研究》提供反欧化条款底本；MQM Core（Accuracy／Fluency／Terminology／Style）映射三审三校分工；ISO 17100 提供"校者独立于译者"标准；名词委审定原则（单义性优先）支撑术语主形锁定；MTPE（ISO 18587／WMT24 风险清单）给出 LLM 初译验收顺序（先 accuracy 后 style）；现成工具（autocorrect、zhlint）只管排版，欧化检测无现成轮子——按 textlint 思路自研规则脚本。

## 决策

1. `rules/02-style.md` 增「反欧化条款」：可判定阈值（长句 70 字、单句被 ×2、的 三连或 ≥6、类名"们"等）＋A 批实译判例＋二校收尾脱稿通读。
2. `rules/04-translation-workflow.md`：s2 合格凭证补 `check_prose` 告警清零或豁免留痕；六道补 MQM Core 映射、问题分级（Critical／Major／Minor，Critical 不得带入 done）、复核独立性阶梯；逐句校对补 LLM 初译验收顺序。
3. `rules/03-terminology.md`：同一词条内锁定登记册主形，"亦作"变体仅供读者对照；登记册不因正文落地形倒挂补认变体。
4. 新工具 `tools/check_prose.py`（八则反欧化模式，JSON 输出，**告警级**不进 CI；单测 10 例入库 tests/）；`rules/05-ci-and-tools.md` 登记。
5. 既有体例、术语、学术门禁不动，本决策只补语言道缺口。

## 后果

* 正面：语言道获得机检底座；三审三校获得 MQM／ISO 映射与分级留痕；术语主形锁定止住混形漂移。
* 负面与成本：告警级工具有误报（豁免逐条人工判断）；主形统一可能触动存量登记行（按译法变更流程留痕）；复核独立性增加会话协调成本。
* 待用户裁定：①A 批 done 词条返工范围（按 qa-findings 定点返工，还是全量复查后再定）；②复核独立性默认形态（双会话交叉认领 r1–r3，还是单会话冷置重读）；③`check_prose` 经 A 批收口校准白名单后是否升 `checks.yml` 硬门禁。
* 2026-10-31 提问未获作答，以下按**推荐项登记为待确认默认值**（[假设]，用户一句即可推翻）：①存量暂不返工，A 批后续词条即适用新规，qa-findings 清单交由更新流程与批次收口消化；②混合制——r2 复审交叉、r3 终审冷置重读（rules/04 阶梯条款的默认解释）；③`check_prose` 维持告警级，A 批收口校准白名单后再议升硬。
