# 0015. 仓库 Wiki 折叠退役与派生文档边界

状态：accepted | 日期：2026-10-28

## 背景

Qoder 知识中心于 2026-10-28 基于提交 `281a0774` 为仓库生成了一套 Repo Wiki（`.qoder/repowiki/`：8 个根级内容页、4 个模块组 40 页、9 张知识卡，共 63 个文件约 1.5 MB）。本地导出后被 `.gitignore` 忽略、从未入库，也未在 `rules/README.md` 的规则地图登记——它事实上构成了第二叙述层：结构、门禁、流程、构建各有一份平行说法。

2026-10-28 全量审计（按 `project-rules-audit` 三轴法，逐页比对 `rules/`、`specs/`、`tools/` 与磁盘实况）结论：

* 主体忠实于生成基点，但有系统性偏差：教程式假名（`tools/check_example.py`、`check_my_rule.py`、`check_xxx.py`、`new_check.py`）、不可执行命令（`fetch_all.py --period`、`fetch_entry.py --retries`、`bun build`）、规则复述失真（把手工维护的 `mu-lu-s.md` 说成禁改，把参考方法论说成上位）、数字随基点漂移（1791/74 已被 1878/75 与 D3 清零取代）。
* 最危险的偏差在“谁说了算”：Wiki 自称可据以重估规则；规则地图明确参考方法论与一切生成物不具约束力。
* 审计同时暴露权威层自身滞后：门禁计数（`rules/06`、`AGENTS.md` 写“七项”）、任务路径（`tasks/<slug>.json`）、CI 触发（`links.yml` 非 push）、lint 调用（`tools/README` 仍写裸命令）、进度数字硬编码（`AGENTS.md` 1791/74）。

## 决策

1. **单一事实源不变**：`rules/` 与 `specs/` 仍是唯一权威。任何生成物（Wiki、知识卡、检索摘要）与其冲突时以权威层为准；生成物不手改，也不作修改依据。
2. **择优折叠**：只回灌“Wiki 有、权威层没有、且经代码核验为真”的操作知识，落点按规则地图归位：
   * 站点构建实现细节 → 新建 `.vitepress/README.md`（实现目录就近说明，标注“非规则”）；
   * 运行命令与硬约束 → `rules/05` 新增“站点运行（本地预演）”、`CONTRIBUTING.md` 新增“本地预览阅读站”；
   * 目录职责补齐 → `rules/01` 增 `.vitepress/`、`fang-fa-lun/`、`jian-yi-shu/`、`state/`；
   * 工具清单权属 → `tools/README.md` 声明全量清单以 `rules/05` 为准。
3. **权威层随审计修正**：门禁口径统一为六项门禁 + 单元测试（`--all` 共九项）；任务路径改 `tasks/<首字母>/<slug>.json`；CI 触发表按实测更正；lint 命令改 `bunx`；`AGENTS.md` 不再复制进度数字。
4. **Wiki 退役**：`.qoder/repowiki/` 不再作事实源、不进发布站点（`config.mts` 的 `srcExclude` 增 `.qoder/**`）；本地副本是可再生缓存，不维护、不手改、不入库。需要跨模块导览时重新生成即可。
5. **派生文档边界**：解释实现的文档就近放实现目录（`.vitepress/README.md`、`tools/README.md`），并在规则地图登记类别与“非规则”性质；不得另起平行于 `rules/` 的规范叙述。

## 后果

* 正面：恢复单一事实源；阅读站不再构建治理文档或把其纳入搜索索引；站点构建知识有稳定落点，不再依赖可再生的 Wiki。
* 代价：Wiki 的跨模块导览能力不再保留，通读需按规则地图逐层进入。
* 待跟进（已登记 `specs/004`）：D19 `AutoCorrect.yml` 仍用 yarn（ADR-0014 残留）；D20 `create-pdf.yml` 检出第三方仓库并推 tag；D21 根级 `sm.xml` 为上游 404 快照入库；D22 `tasks/` 根级非字母目录任务 JSON 不被 `task_ops` 读取；D23 许可证 BSD-2 与 `qian-yan/ban-quan-shuo-ming.md` 的 BSD-3 二义待裁。
* 审计取证：7 个模块中 3 个由并行只读代理完成、4 个因网络中断改主线直接核验；证据以 `文件:行号` 记入对应提交说明，未采信 Wiki 自述。
