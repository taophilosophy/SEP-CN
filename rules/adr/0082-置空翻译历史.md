# 0082. 置空翻译历史

状态：accepted　日期：2026-11-25（用户追加授权：“允许置空翻译历史。”）

## 背景

ADR-0081 置空了正文与任务游标，但保留 journal 事件与 `tasks.steps` 作过程凭证，进度归零靠“纪元”过滤实现。用户随后明确授权置空翻译历史——不再保留旧体系下的过程记录。

这一授权解除了两条约束：P5“日志只追加”与 ISO 15489-1 的记录不可篡改——属于用户对自身数据的处分，且指向的是**翻译过程记录**，不是源钉、登记册或勘误事实。

## 决策

1. **journal 事件清空**：1,199 个 `<letter>/<slug>.ndjson` 全部截为 0 字节（7,566 行事件移除）；文件保留，条目仍在账内，`seq` 从 1 重新计。
2. **过程凭证清空**：1,200 条 retranslate 任务的 `steps` 置 `[]`（共 6,536 条 step 记录）；保留 `state=cleared`、`version_pin`、`zh_doc`、`created_at`、`state_migrated`。
3. **六轴工单清理**：`state/axis/*` 19 个旧工单删除（旧译文的工作产物，重译时 `--init` 重建；留着会让门禁对着不存在的正文误判）。
4. **撤除纪元机制**：删除 `rules/epoch.json` 与 `tools/epoch_lib.py`，`progress.py`／`journal_view.py`／`check_taskfile_invariant.py` 去掉纪元过滤——历史既已为空，过滤器失去对象。
5. **不动**：`en/`、`yuanwen/`、`baseline/`（版本钉与登记）、`shu-yu-biao.md`／`ren-ming-biao.md`、勘误表、补丁池、SUMMARY／目录、ADR 正文。
6. 执行器 `tools/wipe_history.py`（幂等；先干跑后执行），逐项报告 `specs/060-*/results/wipe-history-2026-11-25.json`。

## 后果

* 正面：全库只有“待译”一个事实面；不再有新旧两套记录需要解释；`task_ops` 从 cleared 起按 identifier 写新事件，seq 与 attempt 从干净状态开始。
* 代价：旧过程证据不可回溯（译文本身已在 ADR-0081 置空，二者一致）；如需复核历史，只能依 git 历史中的提交（journal 在 `8fd741ade` 及此前提交里）。
* 取代：ADR-0081 的纪元机制（其第 4 条）由本 ADR 取代；置空正文与游标归零的决策继续有效。ADR-0081 保留原文，仅标注取代者。
* 回退：`git revert` 本批提交可恢复 journal 与 steps（因为都还在 git 历史里）。
