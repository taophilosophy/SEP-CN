# 0007. 上游同构重建：词条目录化 `<slug>/index.md`，先删旧结构

状态：accepted | 日期：2026-10-27

## 背景

用户裁决（2026-10-27）：统一全书 SUMMARY 目录与对应磁盘结构规则；先把既有目录结构全部删除，然后 yuanwen（英文原文）采用与上游网页一模一样的结构，根目录（中文译文）也是。经问询确认：删除范围为词条内容目录（保留治理与项目设施）；路径形态**省掉 entries/ 层**（根 `<slug>/index.md`、`yuanwen/<slug>/index.md`）；SUMMARY 由本会话独自重写；别名条目保留并链到目标词条目录。本 ADR 取代 ADR-0005 的 a–z 平铺方案（其 slug 取证规则第 8 条继续有效）。

此前状态：词条散落在 20+ 混杂目录（`argument/`、`value-pluralism/`、`brentano/` 等）与根级字母目录；SUMMARY/mu-lu-s 链接经多次修复后虽可解析但语义错乱（前置区链接被指到任意存在的文件）；上游真实结构为 `entries/<slug>/`（词条=目录，含 index 与补充材料、脚注、图片）。

## 决策

1. **词条目录形态**：中文词条为仓库根 `<slug>/index.md`（含补充材料 `<slug>/<supplement>.md`、脚注 `<slug>/notes.md`、图片 `<slug>/imageN.jpg`）；英文原文为 `yuanwen/<slug>/` 下同构镜像。与上游 `entries/<slug>/` 一一对应，仅省掉 `entries/` 目录层。
2. **删除范围**：词条内容目录全部删除——`argument/`、`brentano/`、`divine-freedom/`、`feminist-bioethics/`、`goedel/`、`health-disease/`、`hume-freewill/`、`korean-philosophy/`、`logic-classical/`、`logic-justification/`、`nominalism-mathematics/`、`object/`、`philosophy-mexico/`、`rights-human/`、`scientific-reduction/`、`supervenience/`、`type-theory/`、`value-pluralism/`、`voting/`、`wittgenstein-atomism/`、`wittgenstein-mathematics/`、`wyclif/`、`zeno-elea/`、根级 `u/ x/ y/`、`pending/`，以及删除后悬空的词条图片。**保留**：`rules/`、`tools/`、`specs/`、`baseline/`、`tasks/`、`.github/`、`qian-yan/`、`guan-yu/`、`fang-fa-lun/`、`jian-yi-shu/`、根级登记册 md、`.specify/`。历史由 git 保留。
3. **SUMMARY 重写**：条目链接为 `<slug>/index.md`；**别名行保留**并链到目标词条 `<target>/index.md`（与上游 contents.html 一致），别名自身不建目录；子词条缩进保留；首行 `# Table of contents` 不变；前置区只保留真实存在的项目页（README、mu-lu-s、`qian-yan/`、`guan-yu/`），清理错乱链接与开发文档链接。
4. **mu-lu-s.md**：链接文本与顺序不动，仅同步改写链接路径为 `<slug>/index.md`。
5. **yuanwen 迁移**：既有扁平英文文件迁入新结构（文件名即 slug，集群前缀名原样；点号补充材料 `slug.supplement.md` 拆入 `<slug>/supplement.md`）；快照有而库内无的词条建仅含英文标题 H1 的桩。已跟踪演示文件用 `git mv` 保历史。
6. **取证**：slug 映射以官方快照（`.github/sep-baseline/official-snapshot.json`）为权威，沿用 ADR-0005 第 8 条四级优先级；ADR-0005 执行记录中的 4 个存疑 slug 清单（on-utopia、and-the-pineal-gland、action-at-a-distance-in、health-well-being-personal-relationships）继续挂起待抓取核对。

## 后果

* rules/01 目录职责表同步改写；ADR-0005 的 `<letter>/` 与 yuanwen 镜像条目被本 ADR 取代，其执行记录（specs/001-sep-sync-pipeline/dir-rebuild/）留档作废凭证。
* 旧混杂目录内的既有中文译文随删除入 git 历史，全量重译管线按新结构重建；零信任原则下旧译文本不作为底稿。
* 中文侧本轮只建 `<slug>/index.md` 桩（H1=SUMMARY 条目文字），译文由管线后续填充。
* 删除 pending/ 前置页不丢内容：同名主题页已在 `guan-yu/`（7 页）与 `qian-yan/`（3 页）。
