# 0013. 伊斯兰阿拉伯人名与术语的识别、区分与翻译体例

状态：accepted | 日期：2026-10-28

## 背景

用户裁定（2026-10-28）：加强对伊斯兰阿拉伯人名、术语的识别、区分、翻译。

现状问题（specs/008 首轮实跑发现）：① 提取器 ASCII 词元正则把变音符截断（Fakhr al-Dīn→"Fakhr al-D"、al-Kātibī→"al-K tib"、Ikhwān al-Ṣafāʾ→"Ikhw al-Saf"），池中 410 条阿位候选大半残形；② 定冠词 al-/谱系词 ibn/尊称 Abu 的小写形态不在人名路由覆盖内（只抓 "Ibn X" 大写形）；③ 区分缺陷：发布词汇表 al-Farabi 与 Al-Fârâbî 两行登记同人未归并，Avicenna（阿维森纳）与 Ibn Sīnā（伊本·西那）、Averroes（阿威罗伊）与 Ibn Rushd（伊本·鲁世德）为同一人物的拉丁通行名与阿拉伯本名，各自登记且无互见。

## 决策

1. **同人归并（区分）**：拉丁通行名（Avicenna、Averroes、Avempace 等）与阿拉伯本名（Ibn Sīnā、Ibn Rushd、Ibn Bājja 等）指同一人物时，登记册**一行归并**：原文列取「主形 / 他形」（如 `Ibn Sīnā / Avicenna`），译法列取学界主译并括注他译（伊本·西那（阿维森纳））；罗马化变体（al-Farabi / Al-Fârâbî）按**变音符折叠**归并为同一键，展示保留首见形。发布词汇表按登记册归并行修正并互见。
2. **识别（提取器）**：词元正则扩展拉丁扩展区（Latin-1/Ext-A/B/Additional）与 ʾ ʿ 及弯撇号；新增阿位专名路由：含定冠词 al-（及其同化形 ad-/as-/at-/an-…）、谱系词 ibn/bin、尊称 abu/abū/umm/abd 的专名序列，type=arabic 入池；键一律变音符折叠（NFD 剥组合记号后 casefold）。
3. **翻译（体例）**：汉译以**学界通行与权威工具书**（《世界人名翻译大辞典》、《中国大百科全书》、权威哲学史译本）为准，档位沿用 ADR-0012（知网系查证记录在案，查无即标注工具书/学界惯例档）；音译连接号用间隔号「·」；ibn 译「伊本」、abu 从通行（阿布/艾布并存时从众并登记）；定冠词不单独音译出「阿尔」，全名含之者从通行；阿拉伯术语（kalām、ijmāʿ、ijtihād 等）译名优先取中国伊斯兰研究界与哲学史通行译法，原文列括注罗马化原词。
4. 本体例适用于 `yi-zhe-shuo-ming.md`、`ren-ming-biao.md` 与 `qian-yan/ci-hui-biao.md` 三表。

## 后果

* `tools/term_harvest.py`：词元正则、ARABIC 路由、fold 键规范化三处升级，全库 `--refresh` 重提；`check_terms.py` 表头词表不受影响，归并行以「 / 」分隔变体、比对键按折叠形归一（norm_key 折叠升级，测试随行）。
* `ren-ming-biao.md` 增补伊斯兰人物种子区；`yi-zhe-shuo-ming.md` 增补伊斯兰术语种子区；`qian-yan/ci-hui-biao.md` 阿位行按归并裁定修正（重复行互见化）。
* 存量发布词汇表行（如 al-Kindi 肯迪）不删，按登记册裁定补互见注记。
