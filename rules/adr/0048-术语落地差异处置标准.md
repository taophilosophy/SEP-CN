# 0048. 术语落地与差异处置标准（条目主题优先、禁机械替换、差异必查证）

accepted | 2026-11-15（用户指令：对术语登记到正文落地的流程标准化、规范化，禁止机械替换，必须符合条目主题；存在差异时不机械替换、联网查证）

## 背景

工具链已齐而处置口径未成文。从候选提取到落册再到核验，各环节都有工具（`term_harvest` → `cnki_query` → `term_audit` → `term_flow` → `check_terms` / `term_coverage` / `term_relations`，s2.4 校次挂钩 `check_terms --docs`），但"**发现差异之后怎么办**"只散落在会话经验里：`check_terms --docs` 的告警只报不改，判读无标准，出口无定义。

三处实案说明缺口的代价：

* **无法定性**：`check_terms --docs a/abelard.md` 报"Diderot「德尼·狄德罗」未见于正文"。这可能是笔误、可能是该概念在该词条确实没出现、也可能是登记册"首现"挂错了词条——没有分类标准，处置只能靠临场感觉。
* **合法体例无依据**：同键多义已在库内运行，却没有条文承认其法源。`abhāva`（胜论句义）＝非存在／`abhāva`（因明）＝无体量；`absolutism`＝绝对主义／`absolutism（space and time）`＝绝对论；`a priori`＝先天／`transzendental`＝先验。这些是"键加括注"的分行，写在登记册里，规则文本却只讲"以登记册为准"。
* **最省事的错法没有明文禁止**：登记译法一旦变更或出现不一致，最省力的路径是全局 grep-replace 把某形套进正文。2026-11-12 破折号裁定（禁止机械替换、必须整句重译）与 [05](../05-ci-and-tools.md) 批量改写五纪律已证明该路径必伤语义；术语场景更险——同一英文字串在正文里可能同时是术语义、普通义、书目题名、引文内原文。

依据与筛查（[08](../08-intent-first.md) §13，ADR-0042）：ISO 704:2022、GB/T 10112-2019（概念优先、概念—术语对应）、ISO 1087:2019（术语工作词汇）、CY/T 123（"译名全书统一"）、GB/T 19682-2005（"术语前后一致"）。**口径冲突必须解**：行标要"全书统一"，用户要"符合条目主题"；解法见决策 1——统一性的对象是概念，不是英文字符串。

## 决策

1. **一致性约束的对象是概念，不是拼写。** 同一概念同一译名（CY/T 123、GB/T 19682-2005）；英文同形而概念不同者，**登记为分行**（键加括注），各有主形，不构成违例。概念同一性以该词条的**主题域**（题名、节标题、学科归属）与上下文为准。
2. **条目主题优先，并明确 ADR-0020 的适用边界。** [ADR-0020](0020-译文语言质量门禁.md)"同一词条内锁定主形"只约束**词条内部**；跨词条不得以"全库统一"为由改写他条既定名；该词条所属学科域已有权威译法者，用该域译法，即使别域另有通行形。引文、书目题名、原文照录区不适用正文主形（[ADR-0011](0011-引文原文语言与中文文献翻译.md)）。
3. **差异五分类（D1–D5）：先定性，后处置；定性写入任务 evidence。**
   * **D1 词条内混形/笔误**：同一概念出现漏字、异体、简繁、旧形残留 → 逐处人工订正。
   * **D2 未落地**：登记译法在该词条正文零命中 → 判"该概念未出现"或"写错/改写用同义表达"；后者按 D1 处置。
   * **D3 涟漪**：登记主形已变更而正文仍旧形 → 按变更段逐处看齐；非变更段与跨词条不动。
   * **D4 语境分义**：该词条主题域要求另一译法 → 登记新分行（键加括注）、词条内锁定新形；**不得反向改写其他词条**。
   * **D5 登记有误/过时**：依据失效、权威译本或工具书更新、生卒错 → 走译法变更流程：不删旧行、另起一行注"已废弃，见新行"、依据列记新凭证。
4. **禁止机械替换（NON-NEGOTIABLE；宪法 III 零信任、[02](../02-style.md) 破折号条款、[05](../05-ci-and-tools.md) 批量改写纪律）。**
   * 不应以脚本或编辑器全局替换（`sed -i`、replace-all、`re.sub`）把某译形批量套进译文正文；
   * 不应以"与登记册一致"为由批量改词，也不应在旧译文上做词面级回改充当"对齐"；
   * 修复**以句/段为单位**：回 `en/`（必要时 `yuanwen/` 镜像）核对该句原义，整句重译或逐处人工改，改后复跑 `check_terms --docs`；
   * 批量清单只作工作台与验收账，不构成写回手段；确需批次作业时按 [05](../05-ci-and-tools.md) 五纪律执行，且每处改动须能指出其源句与语境；
   * **唯一例外**：纯符号层归一（连接号、空格、引号邻接）不涉语义，按 ADR-0041／specs/026 口径另行授权并带体检与复算；即便如此不得顺手改字词。
5. **差异必联网查证。** D3／D4／D5 一律查证；D1／D2 无法定性时同样查证。
   * 依据档位照 [ADR-0012](0012-译名依据源与人名表拆分.md)：权威译本、权威工具书（《中国大百科全书》《世界人名翻译大辞典》、学科名词审定存量凭证）、学界惯例；**禁维基百科（含英文维基）**；
   * 术语在线与 CNKI 翻译助手**不再新增查询**（2026-11-14 用户裁定），存量凭证可作证据；
   * 每处查证留**凭证五要素**：查证对象、来源（书名＋条目＋页码／URL）、查证日期、来源给出的对应译名、结论（采纳／不采纳及理由）；凭证券落 `specs/008-terminology-campaign/results/` 或任务 evidence；
   * 查无 → 保留英文原词，"依据"列记"查无（日期）"，**不臆造**；模型自身知识不构成凭证。
6. **告警三出口（s2.4 及一切术语核验的收口口径）。** `check_terms --docs` 每条告警必须落到 ①**修复**（附改动位置）②**登记**（附新行位置或 ADR 编号）③**豁免**（附理由与复核人）之一；禁止"看到了不处理"。`term_coverage` 的"未落实"、`term_relations` 的"匿名／重名"同样照此。
7. **度量与回归。** 按批次记：判读率（已判／总告警）、D4 新分行数、D5 变更数。词条收口前对本次动过的词形跑一次**机械替换回溯**（先例工具 `specs/015-style-register-review/bin/mech_audit.py`），检出纯替换痕迹即返工（同 ADR-0039 返工防线）。
8. **不改门禁口径。** 本 ADR 不新增 `check_all` 项；`check_terms` 硬错误照旧拦（自洽违例），告警仍为告警——把告警升成硬门会把"语境判读"压成机检，与决策 1 相悖。

## 后果

* 正面：差异处置从会话经验变为可判读、可复核、可度量的标准；机械替换在术语场景有了明文禁令与替代路径；同键多义从"事故"变为"合法体例"，且与 CY/T 123、GB/T 19682 的口径冲突有了成文解法。
* 负面：D3–D5 每处都要查证与记录，单件成本上升；"未落实"告警不再能靠一句"统一了"结案。
* 跟进：判读台账是否工具化（`check_terms` 输出 D 类字段）待立项；`mech_audit.py` 是否迁入 `tools/` 并常态化待批。
