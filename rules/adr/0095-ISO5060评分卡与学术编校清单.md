# 0095. ISO 5060 评分卡与学术编校清单

状态：accepted　日期：2026-11-28（064 T173；CP-S14-19–25）

## 背景

`rules/10` §10.4 已有 ISO 5060 七维评分卡、抽样与评估者能力的文字，但缺机读评分卡、计分器、抽样器、评估者校准模板与学术编校清单；出版编校 1/10000 与服务口径 1.5‰ 仍未分写。

## 决策

1. **七类映射**：ISO 5060 七类分别落在 rv-01、tr-03／rv-02／q1／q2、q3／tr-04、q4／tr-04、q5／q6／rv-09、sg-01／sg-02、ex-05／rv-09；不另造七套新工序。
2. **评分卡**：`rules/qa-scorecard.json` 记录七类、类别权重、Critical／Major／Minor 权重、公式、出版／服务阈值、口径与抽样；`tools/check_qa_scorecard.py --score` 可按件计分，Critical 一票否决。
3. **抽样**：`tools/qa_sample.py` 按 H2 分层、每层≥1 段、总量≥max(20, 10%)、`sha256(slug+段序号)` 定序；出版前必要审校不得用抽样替代，抽样只用于度量与抽审。
4. **评估者**：`rules/evaluator-registry.json` 定 evaluator／arbiter 的资格与独立性；个人资格沿用 T171 `competences`；双评不一致由第三人仲裁；校准阈值先测后定（当前 `pending_pilot`），模板见 `results/t173-calibration-template.md`。
5. **口径分写**：出版编校用 CY/T 266-2023 的 1/10000；GB/T 19682-2005 的 1.5‰ 只作服务基线；`project_spec.qa_level` 须写明所用门。
6. **学术编校清单**：`results/t173-academic-checklist.md` 列 copyedit、page proofs、索引、图表、注释、参考文献、出版信息、译者署名八项；每项须有样本与验收证据；不设权利门。

## 后果

* 正面：质量评估从文字评分卡变为可计分、可复算抽样、可登记评估者的工具链；出版与服务口径不再混用。
* 代价：评估者校准阈值尚未实测，当前只出模板；评分卡权重需 pilot 后复算；学术编校清单尚无真实样本，待 P5 pilot。
* 回退：`git revert` 本批；评分卡与抽样器为新增文件，删除不影响既有六轴与三审门。
