# 0069. 废除礼貌抓取间隔规则：宪法 V 改题“抓取失败显式化”，抓取层不再设最小请求间隔

accepted | 2026-11-18（权威＝用户指令"把礼貌抓取规则删除"；联动宪法 v1.4.0）

## 背景

宪法 V“礼貌抓取与失败显式化”自 2026-10-26 立项起要求相邻 HTTP 请求 ≥5 秒，并在抓取层形成一套执行设施：`tools/fetch.py` 的 `MIN_DELAY`/串行节拍/`Pacer`、`fetch_all.py` 与 `drift_scan.py` 的节拍配置、`en_source_audit.py --net` 的 `NET_GAP_S`、`cnki_query.py` 的 `--interval`。用户 2026-11-18 指令删除该规则。需区分：≥5 秒间隔是礼貌规则；退避重试、逐请求留痕、禁止静默跳过是正确性与可追溯纪律（宪法 I/II），与礼貌无关，保留。

## 决策

1. **宪法 V 改题“抓取失败显式化”并删间隔句**（v1.3.1 → v1.4.0，Last Amended 2026-11-18）：保留"4xx/5xx/超时退避重试并记录最终状态；缺省件显式登记为缺省而非错误；禁止静默跳过"；删除"相邻 HTTP 请求 ≥5 秒"。条目编号不变（VI/VII 引用广泛，重编号代价高于收益），条内注明废止依据。
2. **`tools/fetch.py` 重写**：删 `MIN_DELAY`、`_last_ts` 串行节拍、`_wait`、`Pacer` 类与 `delay`/`pacer` 参数；`get(url, dest=None, retries=3, timeout=60)`。退避基数改独立常量 `BACKOFF_S = 1.0`（第 n 次重试前睡 `BACKOFF_S * 2**n`，属重试策略非请求间隔）。逐请求留痕 `script/http-log.jsonl`、`FetchError` 显式失败、4xx 不重试直返（缺省件登记）三项不变。
3. **全部调用方去节拍**：`fetch_entry.py`（`fetch_one(slug, force, archive_edition=None)`，删 `--delay`）、`fetch_all.py`（`CONFIGS` 改纯路数 A=16/B=64，worker 无 pacer）、`drift_scan.py`（删 `--period`，保留 `--channels` 并发）、`fetch_audit.py`、`fetch_catalog.py`、`compare.py`、`en_source_audit.py`（删 `NET_GAP_S` 与间隔 sleep，`--net` 保留缓存＋退避）、`cnki_query.py`（删 `Pacer` 类与 `--interval`，`query_with_retry(provider, term, retries, timeout)`）。
4. **范围仅限 SEP 抓取层**：`tools/tl_crawler.py` 的自适应限速（按术语在线实测限流校准，base 8s/max 30s，2026-11-14 定型）与 `specs/007-review-campaign` 的 `CHANNEL_GAP` 是各自独立参数，不属"礼貌抓取规则"，不随本条废除；两处悬挂引用（"对齐 fetch.MIN_DELAY"）已改为独立参数说明。
5. **`specs/021` 六个探针脚本同步**（`tf.Pacer(5.0)` 删除后不再 import 报错）：`fetch_macros`/`fetch_subpages`/`probe_entryjs`/`probe_localjs`/`probe_texjax`/`upstream_fetch`；`script/tmp/` 两个一次性脚本去 `delay` 参数。
6. **文档同步**：`rules/README` 七原则表、`rules/05` 抓取行、`rules/08` 联网检索条、`engineering-doctrine/09` 外部源纪律；`specs/001` 事实区"爬取礼貌" bullet、FR-004、Assumptions 新增 2026-11-18 废止条（历史裁定原文按该节惯例保留，以新条为准），checklist Check 29 改判"留痕完整且无静默跳过"，plan.md 性能目标/约束/宪法映射表/目录注释同步；`tasks.md` T004 历史记录加废止标注不重写。

## 凭证

* 导入与签名实测：`fetch.get(url, dest=None, retries=3, timeout=60)`、`fetch_one(slug, force, archive_edition=None)`、`CONFIGS={'A': 16, 'B': 64}`、`scan_one(slug, pin)`、`query_with_retry(provider, term, retries=(15,30,60), timeout=30)`；`Pacer`/`MIN_DELAY`/`NET_GAP_S` 属性已不存在。
* 全量单测 503 项 OK（含改后的 `test_cnki_query` 退避用例）；`specs/021` 六探针与 `script/tmp` 两脚本 `py_compile` 通过。
* 符号清扫：`tools/`、`specs/`、`script/` 下 `MIN_DELAY`/`Pacer(`/`NET_GAP_S` 零残留（ADR 历史记录与废止标注除外）。

## 负面/跟进

* **不再有任何强制请求间隔**：全量抓取与 drift_scan 的请求速率由并发路数单独决定，触发上游限流（429/5xx）时的退避基数为 1s 起（原 5s 起）——若实测出现持续 429，应回调退避基数而非恢复间隔规则。
*  constitution 条目编号保留空义重编号（V 名称已变），后续引用"宪法 V"处均指失败显式化纪律。

## 回退

`git revert` 本提交即整体恢复；单独恢复宪法措辞需改回 v1.4.0 → v1.3.1 文本并在提交信息注明"修订宪法 v1.4.1"。

## 取代链

部分废止宪法 V 的间隔条款（v1.3.1 → v1.4.0）；不取代任何 ADR——0012/0042/0045/0052 中的礼貌抓取表述为历史决策记录，按 `rules/06` 变更管理以本条为准。
