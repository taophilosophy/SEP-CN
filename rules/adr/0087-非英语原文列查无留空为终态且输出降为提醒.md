# 0087. 非英语原文列查无留“—”为合规终态、检查器输出降为提醒

状态：accepted　日期：2026-11-26（用户批准 specs/058 建议项并修订：“并不免除警告，仅改为提醒”）

## 背景

术语表 131 条非英语术语（梵、藏、阿拉伯、希伯来、希腊等）原文列留“—”。`check_terms`
自 2026-11-06 起按“告警”逐条输出（specs/008 原文列迁移），意在催促补形；但 ADR-0030
（2026-11-10）已判明：来源页与权威工具书均未给原生文字者，**只能留空，不得推演填形**，
“查无”是必然而非偷懒。告警与“不得填”的判据互相矛盾：告警在催促一件规则禁止做的事。

specs/058 建议线（2026-11-26 用户原话“批准所有建议项目。但是非英语原文豁免 ADR 并不免除
警告，仅改为提醒”）把这一族从“告警”降为“提醒”：清单照常落盘、计数照常输出，但定性
为长期提示信息，不作为缺陷、不催促填形。

## 决策

1. **留“—”为合规终态**（承接 ADR-0030）：原文列在来源页与权威工具书（含 Cologne 数字
   词典系）均查无显式配对时留“—”，视同已研判完毕；**推演填形（IAST／Wylie 反推等）
   仍然禁止**，判据不变。
2. **检查器输出由“告警”改“提醒”**：`tools/check_terms` 对 `非英语术语缺原文` 一族改用
   “提醒”措辞输出；计数、清单（`orig-missing.txt`）照旧。提醒不计入告警总量语义，二者
   都不是硬错误，区别在定性：告警＝数据欠账待补，提醒＝已知且合规的长期状态。
3. **如有原形可考则仍须填**：本决策只豁免“查无显式配对”；后续任何来源页／工具书给出
   显式配对时，登记原文并加凭证，与 ADR-0030 的“只采页面显式配对”同口径。
4. **人名表口径不变**：人名表原文列按 ADR-0030 早已豁免（warn_orig=False），不受本决策影响。

## 后果

* 正面：131 条长期挂账的告警定性清楚（已知、合规、长期存在），告警池不再被其淹没；
  “查无”与“待补”在输出上可区分。
* 代价：检查器输出措辞变化，依赖该字样做文本比对的脚本需同步。
* 回退：`git revert` 本批即恢复“告警”措辞；判据本身不受影响。
