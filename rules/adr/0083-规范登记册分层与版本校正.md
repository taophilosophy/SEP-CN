# 0083. 规范登记册分层与版本校正

状态：accepted　日期：2026-11-25（用户批准 specs/061 的 P0）

## 背景

`specs/061-standards-realignment-2026/spec.md` 复核发现：规范事实散在三处——`rules/standards.json`（9 项采纳＋1 项不采纳，供 `verify_standards` 求值）、`rules/README.md`（29 行引用清单）、`specs/025-standards-alignment/`（研读日志）。三者无交叉校验：正文引用了未登记的标准（CY/T 118／121／170／171、GB/T 8170）不会被任何门禁发现；同一标准可在一处“现行”另一处缺席。版本上，ISO/IEC/IEEE 12207:2017 已废止、ISO 15489-1 与 ISO 17100 已进入修订、ISO 18587 修订版在票。

## 决策

1. **登记册分两层**：`rules/standards.json` 的 `cited` 层管“引用事实”（标准号、题名、版本状态、适用范围、落点、来源与检索日），`adopted` 层管“采纳三元组”（标准—承接规则—承接工具/凭证），`not_adopted` 管明确不采纳，`deviations` 管合法偏离。`rules/README.md` 的标准表由 `tools/standards_table.py` 从 `cited` 生成（标记区间内不手改），消除双写。
2. **V5 谓词**：`specs/046-standards-compliance/bin/verify_standards.py` 增“引用可解析”——`rules/` 下非 ADR 正文出现的标准号，必须能解析到 `cited` 或 `not_adopted` 的 `std_key`；解析失败即失败。ADR 正文保留年代名，不纳入扫描（ADR-0080 先例）。
3. **版本校正**（按 `specs/061/version-audit.md`，检索日 2026-11-25）：12207:2017→`12207:2026`（2017 已废止）；ISO 15489-1:2016 标 90.92 修订中；ISO 17100:2015 标 90.92（AWI 在研）；ISO 18587:2017 标 DIS 第 2 版在票（预计 2026 年底）；ISO 5060:2024 更正为 2024-02；ISO 24229 补版本 2022；ISO 999 标 FDIS 在研；ISO 25964-1 第 2 版在版；GB/T 10112-2019 与 GB/T 3101-1993 标“复审结论修订”。
4. **补登缺失项**：GB/T 19682-2005、GB/T 19363.1-2022、CY/T 123-2015、CY/T 118-2015、CY/T 121-2015、CY/T 170-2019、CY/T 171-2019、GB/T 8170-2008、GB/T 44227-2024、ISO 11669:2024、ISO/IEC 11179-5:2015、ISO 10241-1:2011、图书质量保障体系（1997）、图书质量管理规定（2004）。
5. **不采纳补评**：ISO 20771（法律翻译）、ISO 20252（市场研究）、ASTM F2575（服务协议框架）、SAE J2450（汽车行业指标）、ISO 999／GB/T 22466 对网页词条正文（索引对象不存在；别名行另按 ADR-0078 借用）。理由入 `not_adopted`。
6. ADR-0080 引用 12207:2017 之处以补记注明现行版本（ADR 只追加，不改原文）。

## 后果

* 正面：引用与登记闭环；README 表不再手改；新增标准必须同时登记 `cited`（否则 V5 红）；版本状态带检索日，可复核。
* 代价：`standards.json` 变大（约 50 条 cited）；生成器与 V5 需维护。
* 回退：`git revert` 本批；`standards.json` 的 v1 结构在 git 历史中可用。
