# 架构决策记录（ADR）

本目录记录影响面超出单词条的结构性决策。规则见 `rules/06-governance.md` 变更管理一节。

## 编号约定

* 文件名 `NNNN-标题.md`，NNNN 四位递增，标题用中文短句。
* 状态：proposed（提议）→ accepted（已采纳）→ superseded（被 NNNN 取代）。
* 只追加、不删除；被取代的记录保留原文并标注取代者。

## 记录格式

```
# NNNN. 标题

状态 | 日期

## 背景

（为什么需要做这个决策）

## 决策

（决定了什么）

## 后果

（正面与负面影响、需要跟进的事项）
```
