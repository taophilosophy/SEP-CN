# 0079. 六轴独立质量工序（q1–q6）与状态机 v3

proposed | 2026-11-25（权威＝用户 2026-11-25 四次裁定：工序层独立、全量回炉、结构化人工判据、只禁未定型日源词；同日补裁：目标态 r2_reviewed、现代著作也逐条查原文、方括号承载、术语级全部首现括注。依据＝`specs/060-six-axis-quality-gates/`）

## 背景

用户判定现行翻译全流程有结构缺陷。2026-11-25 审计（`specs/060/spec.md` §2.1）：标点、语法、语域、引文、计量、逻辑六类**均未独立实现**——标点四器分散挂 S3/global/s2.4 三节点，语法与语域混装 s2，引文只有 ADR-0011 的中文/日文窄条款，计量只有“照录源”一句，句级逻辑完全空白。这违反 `rules/pipeline.json` 自述原则“一个节点只对一个对象负责”。

国际与国内标准均已把六类切为独立维度：ISO 5060:2024（Linguistic conventions 含 Grammar／Punctuation，Style 含 register，Locale conventions 含 Measurement format）、CY/T 266-2023 表 1 第 1-11 类（逻辑性语法性差错每处 2 错）、表 2 第 2-1／2-3 类、ISO 690:2021、GB/T 7714-2025 5.1、ISO 80000-1:2022、GB 3100。机检能力边界亦有硬数据：FCGEC 上中文语法错误检测 F1 约 77.5（人类约 82.6）、纠错 Exact Match 约 34（人类约 65），故语法与逻辑不得设机检裁判。

## 决策

1. **六道独立工序**，位次：
   `s2.5_checked → q1_cite_checked → q2_logic_checked → q3_grammar_checked → q4_register_checked → q5_measure_checked → q6_punct_checked → s3_checked → r1_reviewed → r2_reviewed → r3_reviewed → done`。
2. **顺序依赖五条**（不可换位）：q1 先于 q2（引文锁定，其命题不属译者责任）；q2 先于 q3（先定“说什么”再定“说得对不对”）；q3 先于 q4（ISO 5060：Style 以语法可接受为前提）；q5 先于 q6（量值形态牵动连接号与空格）；q6 先于 S3（标点独立后 S3 只留结构与交付格式）。
3. **判据所有权单表**：`cite_audit`／`logic_audit`／`grammar_audit`／`register_audit`／`measure_audit`／`punct_audit` 各归一个节点；`check_style` 交出标点项，`check_prose` 并入 `grammar_audit` 第二层，`check_quotes`／`check_pairs` 的标点轴交出，`check_math_zh` 只管公式内部。
4. **结构化人工判据**：六类一律“机检为筛、人审为判”（ADR-0070）；LLM 只产候选，不得作裁判；逻辑形式化只登记可判项，不可判项标 `unformalized`。
5. **用户补裁四项**：目标态 r2_reviewed；英文直引的原文补齐对现代著作也逐条查初版或权威版；补入原文与英译统一方括号；术语级全部首现括注原文与通行英译。
6. **门禁升档**：T0 报告档（退出码 0）→ T1 新件硬拦 → T2 存量清零后全库硬拦 → T3 入 CI。pipeline 节点首期 `gate_owner=false`，T1 起改 true（S5 允许非硬拦节点登记 criteria_owner）。
7. **全量回炉**：`s2.5_checked` 及其后状态（含 done）经 `revert-state --to s2.5_checked` 重走 q1–q6 与 r 链；pending／cleared 自然走新链；s2.4 及以前继续推进。q 链重入上限 1，二次退回按 rework 记 Critical。

## 迁移成本

* 状态机：ORDER 由 `pipeline.json` 推导（ADR-0068 W5），**无需逐任务改 JSON**；已过 s2.5 的件停留在 `s3_checked`／`r*`／`done`，revert 后才识别 q 链。
* 人工：全库约 1800 件回炉，q1（引文）200–400 人时、q2–q4 语义三轴按每件 1–3 小时、q5–q6 机检为主。分批 A–Z，试金石 3 件先行。
* 工具：六器＋`qchain.py` 全部 Python 3 标准库；新增 `tools/data/units.json`、`ja-loanwords.json`、`register-lexicon.json`、`punct-rules.json`。

## 取舍与替代

* **不合并进 s2／S3**：合并即回到“一节点多对象”，与 ISO 5060 维度切分相悖；s2/S3 也无法承载六套凭据。
* **不设 LLM 裁判**：中文病句机检 F1 上限约 77、逻辑一致性无可用自动判据，设裁判即造可写 oracle。
* **不把 q1 设为回退 checkpoint**：回炉目标态统一 `s2.5_checked`，q 链从 s2.5 之后重走；如需单类重跑，用工具 `--scan` 而非回退状态机。
* **术语级不并入引文清单**：1.27 万片段入清单会使 q1 不可完成；改走术语轴首现括注（用户裁定）。
* **不做“原文一律补齐”**：现代著作逐条查初版或权威版，查不到标 `unavailable` 并说明，不代造。
