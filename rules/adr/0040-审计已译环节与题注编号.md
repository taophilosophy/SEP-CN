# 0040. 审计已译环节（二校后独立环节）与题注编号（表 N 必配、公式编号对应）

accepted | 2026-11-14（用户裁定：修订翻译流程，把审计已译增补为三审三校中二校后的独立环节；已完成条目回炉）

## 背景

现行三审三校六道（s1–s3、r1–r3）对“已译内容与源的三向一致性”没有固定环节：一校、复审对照英文源查内容，三校查体例，但 **yuanwen 镜像轴（转换保真）与“逐段格式＋内容、全局内容＋格式”的三向比对**在流程中没有位置，历史上只能以战役形式事后补课——specs/018（en↔yuanwen 逐段人审）、specs/022（zh↔yuanwen 偿还校对）、specs/023（三向回归审校，en↔yuanwen↔译文）反复出现“已 done 词条被重转、勘误打回”的回归（ADR-0038 转换器修正、022 重转均属此类）。2026-11-14 用户裁定：把该审计固化为流程环节，并令已完成条目回炉重走。

公式、表格、图片、引用、注释等非文字资产的体例已有部分条款（ADR-0037：图注 `图 N：说明`、图前标签行 `图 N`、表内文字翻译），但**表格无题注要求**、公式编号无条款，审计环节需要一份明确的资产核验清单。同日用户两项裁定：表格一律补“表 N”编号（与图 N 同构）；公式源有编号才对应、源无不补。

## 决策

1. **状态机增补 `audited`（审计已译）状态**：位置在二校之后、三校之前。retranslate 序列：`pending → cleared → drafted → s1_checked → s2_checked → audited → s3_checked → r1_reviewed → r2_reviewed → r3_reviewed → done`；update 序列同位插入 `audited`（默认仅变更段；基准变更——重转、上游勘误、口径修订——时全文档，承 rules/04“不复查旧错”的基准变更例外）。操作 `python tools/task_ops.py advance <slug> --step audit`；update 任务的 audit 证据必须以 `changes:` 开头（与 s1/s2 同款）。
2. **审计已译环节的作业定义**（依次比较校对 yuanwen → en → 译文；先逐段比较格式、内容，再全局比较内容、格式）：
   * **镜像轴（yuanwen↔en）**：转换保真逐段人审，specs/018 协议原样沿用（完整性、格式一致性、无凭空多出；书目逐条计数比对）。
   * **译文轴（译文↔en）**：逐段回 en 零信任核对内容（漏译、增译、错译），格式按 rules/02/03/07（结构、脚注、书目、题注）。
   * **全局**：内容——节集合与结构对账、脚注键位总数、书目条数、术语登记册一致性；格式——rules/02 体例、题注齐全。
   * **机检拦截网**（不作裁判，逐段人审是裁判——specs/018 先例）：`check_math_zh`、`check_tables_images`、`check_math`、`check_academic --strict`、022 `scan_zh_vs_yuanwen`、重转后 018 `regression_scan`。
   * **凭证**：三向比对记录（逐段＋全局，可复核形态）＋机检输出，登记任务 steps evidence。
3. **资产核验清单**（正确性、一致性、可识别性）：
   * **公式**：定界符正确（`check_math_zh` C1–C9）、与源逐条对应；源公式自带编号（如 (3.1)）者对应保留，源无编号不补；公式盒子标签语（Definition. 等）译中文（ADR-0037）。
   * **表格**：结构完整（表头与数据行列数一致）、**必有“表 N”编号**——源表自带题注者统一“表 N：说明”（全角冒号，与图注同形态），源无题注者表前标签行“表 N”（原加粗者 `**表 N**`）；N 按词条内出现顺序编号；表内文字按 ADR-0037。
   * **图片**：必有“图 N”（ADR-0037 决策 8）、alt 与图注译中文、引用基座一律 `../assets/<slug>/`。
   * **引用**：引块形态与书名斜体体例、照录豁免正确（rules/02）。
   * **注释**：脚注键位配对（marker↔定义，`check_academic` orphan 硬拦）、回链可解析。
4. **修复路径（发现问题时，三层落位，承 specs/023 裁定 A1）**：yuanwen 轴系统性缺陷→**逐条独立修订 `tools/yuanwen.py` 等转换器（每缺陷一处修订＋单测锁定）→定点/全量重转 HTML→markdown→回归扫描 OTHER=0**，禁止手改转换产物；en 轴→ADR-0038 四类并登记 errata；译文轴→证据链修复（禁经 clear、禁机械批量替换）。问题按条目独立处置，禁止跨条目批量套改。
5. **已完成条目回炉**：所有已译词条（drafted 及其后，含 done）必须重走审计已译环节＋一次独立校对（独立于初译 actor，ADR-0020 复核独立性）；执行载体为 specs/023 三向回归审校战役（其 A2 范围口径即 drafted 及其后 ≈422 条，协议与本环节一致，该战役 Assumptions 增补登记本裁定）。回炉发现的问题按决策 4 修复，已 done 词条不走 reopen（023 A1：修复走证据链）。
6. **门禁接线**：`tools/task_ops.py` 增 `audit` 步（STEPS/ORDER/STEP_EXPECT_PREV 与两个状态序列、docstring）；audit 步挂钩 `check_math_zh`（默认档 0 硬错误——公式完整性硬伤在审计即拦，strict 升档仍留 s3/r3）；`tools/progress.py` STATES 同步；契约 `specs/001-sep-sync-pipeline/contracts/cli.md` 增补 audit 步与挂钩说明；本文件与 rules/04/02/06/07、tasks/README 同步修订。
7. **表格题注与公式编号条款落 rules/02**“排版元素”节（决策 3 的表格、公式两条），由审计已译环节逐表逐式核验；`check_tables_images.py` 后续可增表 N 告警项（登记 rules/05，跟进项不阻塞本决策）。
8. **语体审阅增项**（同日用户裁定）：破折号审阅增补进审计已译环节；量词“一个”节制仿破折号限制（语义判定、不按个数机械计数、不设关键词机检），条款落 rules/02“语体与文风”，并计入 s2/r1 复核留痕范围。审计环节另增**全局密度统计**（破折号数、“一个”频次、AI 词共现）与**同源盲区对冲**（审计宜独立于初译 actor，单会话以密度统计＋冷置补偿），归因登记 specs/004 W11（[ADR-0041](0041-标准规范对齐落地.md) 落地）。
9. **欧化与 AI 腔标准增补**（同日用户裁定：联网研究维基百科翻译指南与 AI 写作标准后增补）：依据中文维基《翻译腔》论述、《欧化中文》条目与英文维基《Signs of AI writing》，rules/02 增补——反欧化条款八则（动词优先与以人作主语、时态词节制、并列连词节制、话题优先、时间地点前置、译名与称谓一致、用词直白、初译自检三步）＋“被”的语义方向扩展；新增“AI 腔与套话”小节（增译套话与对冲、空洞拔高与泛化、模糊归因与模糊关联、公式化排比、中文 AI 高频词密度、优雅变换——语义判定不机检，增译类由审计译文轴回 en 核对硬拦）；新增“哲学翻译方法论锚点”小节（概念层直译×句法层归化、术语链一致性、引文回译核对、“信”字当头平实晓畅），调和陈康“宁硬勿意”与王太庆/思果“达是信的前提”的两层适用。

## 后果

* 正面：三向一致性首次有了流程内的固定位置与状态机强制（禁跳步实拦），“已译被打回”类回归在入库前被拦；题注编号使图表可定位、可引用、可审计；回炉有法可依，specs/023 不再是无源战役。
* 负面：每词条多一道环节，422 条存量回炉成本显著（用户已裁定不计成本，specs/023 在跑）；表格“表 N”为源外增补的结构性标识（与图 N 同构的体例性增补，非内容增补），站点渲染形态需 020 战役顺手验证。
* 跟进：`check_tables_images.py` 增表 N 告警项后回填 rules/05 登记；023 战役每条目凭证按本环节口径（三向比对记录＋独立校对留痕）执行。
