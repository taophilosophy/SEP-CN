# 0008. 词条文件化：`<slug>.md` 单文件，去 index.md 层

状态：accepted | 日期：2026-10-27

## 背景

用户裁决（2026-10-27）：index.md 过于赘余，去掉；都是本会话的工作，全部完成。本 ADR 在 ADR-0007 上游同构的基础上，把词条形态从"目录 + index.md"改为**单文件** `<slug>.md`，其余上游同构原则不变。

## 决策

1. **词条形态**：中文词条为仓库根 `<slug>.md`；英文原文为 `yuanwen/<slug>.md`。SUMMARY/mu-lu-s 条目链接为 `<slug>.md`。
2. **补充材料**：`<slug>.<x>.md` 点号命名（如 `set-theory.basic-set-theory.md`），与主文件同层平铺。
3. **图片**：本地化于 `yuanwen/assets/<slug>/`（上游同名 imageN.jpg，复制而非外链），md 内以 `assets/<slug>/<文件名>` 相对引用。
4. **抓取原始 HTML**：一律存 `en/<slug>/`（不可变原始物，不入库），yuanwen/ 只存转换后的 md 镜像。
5. **存量迁移**：`<slug>/index.md` → `<slug>.md`（中文侧 git mv 保历史）；`yuanwen/<slug>/index.md` → `yuanwen/<slug>.md`；`yuanwen/<slug>/<x>.md` → `yuanwen/<slug>.<x>.md`；图片归 `yuanwen/assets/<slug>/`；空目录删除。
6. **别名行**保留并链到 `<target>.md`；导航节点链 README；与 ADR-0007 一致。
7. **工具对齐**：yuanwen.py（输出 `<slug>.md` + 点号补充材料 + assets 图片）、rebuild_dir.py、common.py find_zh_doc、summary_sync.py（无字母节插入、`<slug>.md` 路径）、repair_loop.py、progress.py 同步改造；migrate_exec.py 标记废弃（一次性旧方案迁移器，被 rebuild_dir.py 取代）。

## 后果

* ADR-0007 的"词条目录 + index.md"形态被本 ADR 修订；其上游同构、别名链目标、SUMMARY 独立重写等原则不变。
* 中文侧 `<slug>.md` 骨架（仅 H1）继续作为未翻译占位；译文由管线填充。
* 本地阅读站（VitePress/GitBook）按 SUMMARY 链接解析，`<slug>.md` 为标准形态。
