# 0039. 知难行易充分落实与返工防线（五机制）

状态：accepted | 日期：2026-11-14（当日用户批准全部三件：理论篇 09、本 ADR、specs/004 归因登记）

## 背景

用户 2026-11-14 指令：“把项目至今目前发现的问题总结到软件工程理论并报我批准”；追加要求：“把知难行易充分落实，目前发生了多次大规模返工现象”。

知难行易规则（ADR-0018，2026-10-29；宪法 VII、rules/08、理论底稿 00b）先于下述全部返工发案在位，返工仍连发，说明缺口不在规则缺位而在**规则没咬合**（落实不到位）。已发案归因（明细见 specs/004 §五返工归因登记、理论沉淀见 doctrine 09）：

* **R1 验收维度缺口**：语体维度缺位，文言/仿古词条以“格式全绿”过关进入存量（ADR-0033）；发现后 306 条 done 逐条复核、11 条置空回炉、破折号线 92 判定中 50 条需整句重译（specs/015）。QA A 批欧化 15 词条返工（specs/004 D25）同类。
* **R2 手段先行**：破折号符号层机械替换被采用时未做手段-目标论证，后裁定禁止并回溯审计 438 处候选（specs/015 dash-handoff）；语义类改写用机械手段违反 rules/02、ADR-0033。
* **R3 基准漂移**：ADR-0038 en 勘误＋全量重转改变对照基准后，全部已译段落须按新基准重校、124 条引注重挂（specs/022）；翻译批次开工时未钉 yuanwen 基准 commit。
* **R4 写入路径脱核**：子代理扇出深工率约 35%（ADR-0034）；自报“224 处整句重译”约八成实为符号替换、全部重做——自报完成无独立复算。
* **R5 证据推演**：IAST 映射推演梵语批 51 行作废（specs/012），违反 rules/08 §2“禁止把业界惯例当需求来源”。

五类成因与防线理论沉淀为 `rules/reference/engineering-doctrine/09-rework-lessons.md`（随本 ADR 新增）。本 ADR 把防线落成约束性条文。

## 决策

1. **rules/08 增补**（节号顺延，避免重排既有节）：
   * §1 方向声明字段表增一行**“作废条件”（必填）**：枚举何种发现会使本任务/批次产物作废（语言、语体、保真、基准、证据、结构等维度），并声明各维度的验收层（机检层／语义留痕层）；“检查器全绿”不得替代未设验收层的维度。
   * 新 §9 **批量批次立卡与基准钉**：长线批次（波次/战役）开工须立卡（specs/<NNN>-*/spec.md 方向声明节或任务 JSON evidence），并钉对照基准（源 commit/版本/转换器版本）入卡；基准变更（重转、上游勘误、口径修订）必须先评估存量回归面并登记偿还战役，未评估不得继续铺量。
   * 新 §10 **手段试金石**：大规模采用新手段（新脚本、新替换策略、新工具链、新写回流程）前，先小样本（≥3 件）＋回源定性＋与目标对齐的论证留痕（为何此手段、替代方案、替换条件）；样本不过即停。语义类改写禁机械手段（呼应 rules/02 破折号条款、ADR-0033）。
   * 新 §11 **自报完成独立复算**：凡“已重译/已修复/已收口”类自报主张，验收以独立复算为准（逐处定位比对、diff、守恒检查）；主张本身不作证据，不以“流程走完”代验收。
   * 新 §12 **返工归因登记**：返工按五类成因（R1 验收维度缺口、R2 手段先行、R3 基准漂移、R4 写入路径脱核、R5 证据推演）归因，按四元组（规模/作废维度/被跳过条款/新防线）登记入 specs/004 登记表；同一成因二次发案，防线必须升级（约定→门禁→硬门禁）。
2. **specs/004 增“五、返工归因登记”**：登记 2026-10-26～11-14 已发案十起（含 R 编号归因）。
3. **doctrine 09 新增**（参考方法论，非约束）：`rules/reference/engineering-doctrine/09-rework-lessons.md`；目录表与 NOTICE.md 变更记录同步。
4. **AGENTS.md 硬约束速览增一行**：知难行易落实｜作废条件前置、基准钉、手段试金石、自报独立复算、返工归因登记｜ADR-0039。
5. **rules/README.md 快速判例增一条**：批量批次开工 → 先立卡钉基准、列作废条件；返工 → 先归因登记再返工，同缺口二发必须升级防线。

## 后果

* 正面：返工面在零存量时收敛（作废条件前置）；基准漂移不再静默累积（钉基＋回归评估）；手段性返工（机械替换、映射推演）被试金石与独立复算阻断；同缺口重复发案被升级律终止。
* 负面：开工与手段采用增加留痕成本；小样本试金石延迟放量；归因登记有维护成本。
* 跟进：生效时点起的新批次适用；在途批次（022、015 余量、023）按可行性对照执行，不强溯。本 ADR 与 doctrine 09、specs/004 登记表同期复审（2027-01-21）。
