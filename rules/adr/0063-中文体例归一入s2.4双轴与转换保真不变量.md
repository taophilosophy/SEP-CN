# 0063. 中文体例归一入 s2.4 双轴与转换保真不变量

accepted | 2026-11-16

## 背景

用户目标经三轮收敛（2026-11-16）：**标准化中文 markdown**；英文 markdown 仅执行格式归一，文字与 `en/` 保持一致；不走 LaTeX，不增设 markdown 标准化以外的 CI 步骤。

评估底数（实测，凭证见 `specs/039-md-standardization/results/`）：

* HTML 侧（1877 包）：四尾节 `Bibliography｜Academic Tools｜Other Internet Resources｜Related Entries` 齐备率 1877/1877；但正文标题 id 共 18754 个、其中 17821 个全库仅用一次——**骨架封闭、正文自由**。
* `yuanwen/` 侧（主件 1873 件）：30 件重复 H1——生成器以 `citation_title` 前置标题，而旧模板正文自带 `<h1>`（`en/russell/index.html` 实测 `<h1>` 计 1，`yuanwen/r/russell.md` 计 2）。
* 中文侧（实件 437 个，桩件 1442 个）：`脚注` 段位置三变体（前置 72、夹中 15、末位 9，EN canonical 为末位）；小节编号裸号 2076 对点号 346；H1 缺作者括号 9。

既有口径缺口三处：ADR-0062 要求 `yuanwen/` 忠实于 HTML 文字，但**无机检不变量**（只校 `en/` 与钉，不校派生物）；s2.4 只有术语轴（ADR-0043），体例判定散落于 s3 与 r2；`revert-state` 目标态仅 `s2.5_checked`。

返工归因（[08](08-intent-first.md) §12）：**R3 基准漂移**——建议依据会话开头规则快照作出，期间 ADR-0062 落地；**R5 证据推演**——裸正则与六行窗口截断产出“290 件内侧空格粗体”“28 件缺 pubinfo”两个假数字，实测为个位数与 0。本 ADR 把“可判性”与“测量效度”写成条文以防复发。

## 决策

### 1. 不变量（I1/I6 引用既有，I2–I5 新增）

| 号 | 不变量 | 判官（只读） | 状态 |
| ---- | ---- | ---- | ---- |
| I1 | `en/` 字节 == `files[].sha256` 原始钉 | `divergence.py verify` | 已有（ADR-0045/0062） |
| I2 | `yuanwen` 字节 == `convert(en ⊕ patches)` | `tools/check_yuanwen_fidelity.py` | 新增 |
| I3 | `yuanwen` 文字流 == `en` 文字流（模转换器构造白名单） | 同上 | 新增 |
| I4 | 补丁 ⇄ 全局勘误表 双向可追溯（孤儿即红） | `tools/check_en_patches.py` | 新增（扩既有） |
| I5 | 中文条目体例 canonical（见第 3 条判定表） | `tools/check_pairs.py` 扩则 | 新增 |
| I6 | 译文禁机械替换，回源逐句改 | `mech_audit.py`＋人工 | 已有（rules/05、ADR-0048） |

**I3 是主不变量**：`yuanwen` 的文字层禁止任何偏离；唯一合法偏离来源是 I1 之上的**格式补丁**，而"是否属格式"由第 6 条谓词判定，不由人判。30 件重复 H1 即由 I3 自动定性（生成器多写了正文没有的文字），无需另行裁定。

### 2. s2.4 由单轴扩为双轴

状态名 `s2.4_termchecked` 与位次不变（避免 1219 份任务 JSON 与历史 evidence 迁移），职责扩为：**术语轴**（现行）＋**体例轴**（新增）＋**勘误轴**（新增）。`advance --step s24` 顺序挂 `_term_gate`（既有）与 `_style_gate`（新增）。

### 3. 体例轴判定表

| 项 | 判据 | 档 |
| ---- | ---- | ---- |
| 尾节齐备与顺序 | `参考文献 > 学术工具 > 其他网络资源 > 相关词条 > 脚注`；`脚注` 恒**末位**（随 EN canonical：`Notes（原文脚注）` 在 `Related Entries` 之后） | 硬 |
| 小节编号 | `## N. 标题`、`### N.N 标题`——**点号式，与原文一致**；不跳号，层级 ≤6 | 硬 |
| H1 形态 | `# 中文题 英文题 (作者)`，英文题与 `yuanwen` 同件 H1 一致 | 硬 |
| 出版信息 | `> *首次发表于 …*` 引块形（承 `check_pairs` pubinfo-form，升硬） | 硬 |
| 参考文献承载 | `[^key]:` 脚注定义形态，marker ↔ 定义配对闭合 | 硬 |
| 正文体例 | 复用 `check_style`、`check_quotes` 定点档 | 硬 |
| 空白类 | 行尾空格、3+ 空行、标题前后空行、列表符统一、围栏语言标注、BOM/LF/收尾换行 | **告警**（归一次性修复轮，不拦门） |
| 豁免 | 桩件、`glossary-maintenance`、带点子文档（supplement/vita/bibN/figdesc 另档） | — |

空白类列为告警的理由：可机修、读者不可见；以门禁拦 776 行列表符只会堵死流水线，而结构类缺陷读者可见且须人判定位置，才值得硬拦。

### 4. 明确不做的两件事

* **不加跨语槽位键**（用户裁定）：中英配对依赖标题词表与顺序，不引入 HTML 注释键位；其代价（`脚注` 三变体会造成错配）由第 3 条把位次钉死来补偿。
* **不建第二套结构校验体系**：体例轴扩进 `check_pairs`（ADR-0046 已管跨源格式配对），不新建契约文件与平行 checker。

### 5. 全局勘误表在中文译文的落地机制

勘误表"中文承载"列即**逐行裁定**，三值三动作，检查器按行取值判定，不允许临场发挥：

| 承载值 | 中文侧动作 | 例 |
| ---- | ---- | ---- |
| 译注 | 正文取正确读法，紧随该句/该引块后加译注：`（译注：上游原文作“…”，系…之误，译文按…处理。）` | zhu-xi `the Mean of the the nature`；吕祖谦生年 1134→1137 |
| 照录区，无需译注 | **零动作**：书目照录区不夹中文、不夹译注 | yorck 书目 11 行 |
| 纯排版，无需译注 | **零动作**（只入表＋入池） | yorck `pp.23–69` |

三态机械断言（s2.4 勘误轴，硬）：承载=译注者，zh 文件**禁含**上游错字形、**必含**参考读法、**必含**就近 `译注：`；承载=照录区者，允许含上游形（照录合法）但**禁含**译注；承载=纯排版者不检。引块照录英文原文的，原文不动（引文豁免），译注置于引块之后。

落地定位：勘误表"位置"列是散文地址，机器不可用——须按 `slug ＋ 锚（引文首词／书名／年份／书目键）` 解析出 `zh 文件:行`，人工确认一次后写入表内新增两列 `中文落地`（未落／已落／不适用／存档）与 `落点`。**状态记在勘误表本表，不另建第二份状态账**（单一事实源）。

### 6. 补丁准入谓词与四关联检（把"格式被破坏"变成可判事实）

一条 `find → replace` 允许进 `baseline/en-patches.json`，当且仅当**至少满足其一**：

* **(a) 空白差**：去掉全部空白后 `find ≡ replace`（覆盖现存 P-001~P-003 缺空格类）；
* **(b) 标记差**：剥除标签与注释后 `find ≡ replace`（覆盖补 `</div>`、`-->` 一类配对修复）。

二者皆不成立 ⇒ 改动落在字母数字或词序 ⇒ **文字层**，禁入池、禁改 `yuanwen`，只走勘误表＋译注。

四关依次过，任一不符即该件硬失败：

| 关 | 断言 | 判官 |
| ---- | ---- | ---- |
| C1 结构有效性 | HTML 可解析、标签/注释配对 | `en_source_audit`（既有）＋标准库 `html.parser` 兜底 |
| C2 准入谓词 | 上述 (a) 或 (b)，且命中数 == `expect` | `check_en_patches`（扩） |
| C3 单调改善 | 应用补丁后该件 I3 差异严格减少，**全库其余件 diff 为 0** | `check_yuanwen_fidelity`（新） |
| C4 重放等值 | `convert(en ⊕ patches)` 字节 == 盘上 `yuanwen` | 同上 |

### 7. 判定权与写权分离

| 动作 | 归属 | 不应 |
| ---- | ---- | ---- |
| 判 `en/` 结构有效 | `en_source_audit`＋`en_integrity`＋HTML 解析（只读） | 交给 markdown 格式化工具或 LaTeX |
| 判补丁合法 | `check_en_patches`（谓词＋计数＋追溯） | 以"已核实"人判授权 |
| 判转换保真 | `check_yuanwen_fidelity` | 手改 `yuanwen` |
| 判中文体例 | `check_style`／`check_quotes`／`check_pairs`（门禁） | 让 fixer 判内容对错 |
| 修中文格式 | `format.yml` 三工具（CI，出 PR 人工核） | 判 `en/` 是否坏 |
| 写 `en/` | **无**（绝对冻结） | — |
| 写 `yuanwen/` | 只经 `tools/yuanwen.py` | 手改产物 |

据此，**LaTeX 第三轮评估否决并存档**：它看不见 HTML 嵌套与注释配对，要判上游破坏须先有一个能容错坏输入的转换器，错误面又被 TeX 与数学噪声淹没，且会造出第二个可写派生层——正是本条要避免的形状。HTML→LaTeX→MD 中转此前已否决（specs/024 在案），勿再重开。若需第二实现对照，用标准库 HTML 解析器，零依赖且只说 HTML。

### 8. 受控回退扩位与全量回退面

* `task_ops.py revert-state` 目标态扩为 `{s2.5_checked, **s2.4_termchecked**}`，源态集加 `s2.5_checked`（原仅 `s3_checked` 及之后）；`--reason` 必填、`steps` 仍 append-only、不触碰正文与既有 evidence。此条**扩展** ADR-0043 决策 5，不废除其 s2.5 目标态。
* 回退面 **416 件**：s2.5_checked 395＋r2_reviewed 16＋r3_reviewed 1＋checked 1＋**done 3**（用户裁定 done 亦回退）。**回退的是状态位次，不是译文文字**——与 ADR-0062 决策 7"中文成品不回退为错字"不冲突；done 三件的 `yuanwen` 与照录区已同步过的正确读法保留。
* 重走路径：s2.4（双轴＋勘误轴）→ s2.5 → s3 → r 链全重走（承 ADR-0043/0053 语义）。

### 9. 可判性与测量效度入则

* [08](08-intent-first.md) 新增 §14：任何规则升门或入 `rules/` 前须填**四件套**——机检谓词／预期命中数／幂等证明／一行回退命令；填不出者只能作人读登记册条目存在，不得授权改动或升门。**"已核实"型授权谓词禁用**；不可逆（单向门）决策按架构变更对待。
* [05](05-ci-and-tools.md) 新增**判定权与规则所有权**一节：每条格式/结构规则唯一 owner；用作决策证据的计数脚本必须语法感知（成对或栈解析，禁跨元素裸正则）、无隐式窗口截断、关键数字第二口径复算——把 §11"自报完成须独立复算"扩展到**自报测量须独立复算**。

### 10. 门禁挂载

`check_all` 增两项：**转换保真**（`check_yuanwen_fidelity`，I2/I3/I4）与**中文体例**（`check_pairs` 体例档，I5），11 项 → 13 项；CI 矩阵经 `--list-gates` 自动跟随（ADR-0061）。保真项在 CI 只跑本批变更 slug，全量重放走本地与夜间任务（成本考量，见后果）。

## 后果

* **正面**：`yuanwen` 从"无人核对的派生物"变成有不变量守护的可重放产物，30 件重复 H1 这类缺陷由机器定性；中文体例获得有名目、有机检、有凭证的独立判定位（s2.4 体例轴），不再散在 s3/r2；勘误落地从"记得改过"变成三态可判；"格式被破坏"从判断词降为一条断言；判与改分离，杜绝 ADR-0038 型越界复发动。
* **代价**：① I3 词元流比对需要一份**转换器构造白名单**（书目转 `[^key]:`、节题括注、补充材料包首说明行、定界符与上下标记法、实体反解、孤立希腊字母文字化等），白名单错配会造成假红，须先小样本校准；② 全量重放 1873 件耗时，CI 不能每次全跑；③ 416 件回退重走与既有回炉池（ADR-0053）叠加，工期以周计；④ 编号加点波及 2076 处、脚注移段 87 件，是一次大宗机械归一，须按 rules/05 批量改写五纪律执行；⑤ 勘误表要加两列并逐行填实，`待定` 一律按未完成处理。
* **取代链**：扩展 ADR-0043 决策 5（回退目标态）；不改写 ADR-0062（其 en 冻结、补丁池、勘误表、译注承载全部沿用，本 ADR 只补"派生层不变量"与"准入谓词"两面）；ADR-0046 的 `check_pairs` 由告警级扩出硬档（体例轴），原七则语义不变。
* **保留**：零信任、单一事实源、禁机械替换、提交即推、s0 前置顺序、R3 须用户显式指定（ADR-0054）。
