# 哲学学术规范

本规则把“符合哲学学术规范”落为可执行、可机检的条文，约束全部词条译文（含集群子词条与补充材料）。它不替代 [02](02-style.md)、[03](03-terminology.md)、[04](04-translation-workflow.md)，是在其上的学术层要求；机器可判定部分由 `tools/check_academic.py`（specs/003）执行（宪法 VI），推送后 CI 复核。决策记录见 ADR-0006。

学术任务是知难行易的典型：先确认词条的版本事实、节集合与文献范围（知），再动笔与校对（行）；验收判据是结构完整性与 `check_academic --strict` 0 硬错误（[08](08-intent-first.md)）。

## 版本事实与溯源

* 非存根译文在 H1 之后、正文之前必须保留出版信息行，如：

  > *首次发表于 2003 年 4 月 10 日；2025 年 7 月 18 日实质修订。*

  原文无实质修订日期时只写首次发表。日期必须与 `baseline/entries.json` 的 `pubinfo` 一致——版本事实由登记数据说了算，译者不得改写（宪法 I/II）。
* 作者署名随标题由 SUMMARY 同步保留，不得增删作者名单。
* `## 学术工具` 节的“如何引用本词条” archinfo 链接是读者回溯英文版本的通道，必须原样保留，不得改写或删除。

## 引文与参考文献

* 参考文献节标题用 `## 参考文献`，节首保留加粗说明行（正典样文，[ADR-0017](adr/0017-参考文献双形态澄清.md) 收口 2026-11-13）：`**以下文献从原文照录，不作翻译；中国文献条目（古今）一律译为中文。**`——**中国文献条目（无论古代现代）一并译为中文**（用户裁定 2026-10-28，[ADR-0011](adr/0011-引文原文语言与中文文献翻译.md)）：保留西文著录骨架与引注键，汉名与中文书名还原为通行简体，如 `[^yan-2001]: Yan Buke 阎步克, 2001, 《乐师与史官》, 北京：三联书店。`——依据英文源所载信息与可核实文献，幻觉禁令照旧。
* 工作底稿形态另计：`yuanwen/` 底稿经转换器产出 `## References（引用注释）` 节说明 + 文末脚注定义区（条目即 `[^key]:` 行），服务于校对跳转，站点渲染层已补全其显示（ADR-0017 裁定 2026-10-31）；zh 译文发布形态一律以上一条的 `## 参考文献` + 加粗说明行为准，两类形态不得混写在同一句条文里（ADR-0017 拆句裁定）。
* **GB/T 7714 适用边界（ADR-0041）**：`## 参考文献` 节是**引用还原**（照录 SEP 房屋样式＋中国文献条目还原），不是自著录，**不适用** GB/T 7714-2025《信息与文献 参考文献著录规则》（2025-12-02 发布、2026-07-01 实施，全部代替 2015 版）的著录格式；但还原中文文献条目时，应以其著录要素清单（责任者、题名、版本、出版地、出版者、出版年、文献类型标识）为**防漏核对基准**——要素从英文源所载信息逐项核对，缺什么登记什么，幻觉禁令照旧。仅当未来出现自著录场景（如项目说明页新著录文献）时按 GB/T 7714-2025 执行。
* **引文原文语言还原**（用户裁定 2026-10-28，[ADR-0011](adr/0011-引文原文语言与中文文献翻译.md)）：SEP 引用的原文若是中文或日语，译文优先使用中文或日语原文（如中国古典引文还原为通行原文），不以英译回译；无法可靠还原时照录英译并以译注说明。标点与体例仍按 [02](02-style.md)，不因原文语言引入直角引号。
* 文内作者-年份引注（如 `(Zhmud 2012a, 366)`）与古典学编号原样保留编号部分：DK 12B1、《形而上学》986a22、VP 104；中国典籍用通行中文名（`(Analects 2.3)` → 《论语》2.3、`(Mencius 6A.1)` → 《孟子》6A.1，篇码不动）；不得“顺手补全”或改写页码、年份。
* 脚注式引注 `[^key]` 与文末定义必须一一对应，孤立引用或孤立定义均为学术事故（机检硬错误）。
* **禁止幻觉引文**（AI 会话纪律，NON-NEGOTIABLE）：参考文献与引注只能逐条对照英文源（`yuanwen/`、`en/`）搬运；禁止凭模型记忆生成、补全或“规范化”任何文献条目、页码、年份；原文缺的信息照缺，需要说明时用译注，不得臆造。

## 结构完整性

* 非存根译文必须完整保留 SEP 原文的节集合：导言、编号正文节、文献（现制：`References（引用注释）` 节 + 文末脚注定义区，[ADR-0011](adr/0011-引文原文语言与中文文献翻译.md)）、学术工具、其他网络资源、相关词条；原文没有的节不添加，原文有的节不丢失。验收以原文节标题集合为基准。
* `## 相关词条` 保留原词条名对照；站内链接由管线统一挂接，翻译时不得先造死链。

## 译注纪律

* 译注格式 `（译注：……）`，单独成段、谨慎克制（[02](02-style.md)）；一条译注只说一件事，置于所说明内容之后。
* **译注＝“他人注”**（CY/T 121 §5.2，2026-11-14 采纳，[ADR-0041](adr/0041-标准对齐基线与偏离登记.md)）：SEP 原文自带的注为“作者注”，本会话所加译注为“他人注”——他人注的行规形态是注文末破折号加注者（“……——编者注”）；本库契约取 `（译注：……）` 括注形（属 CY/T 121 §5.1.1 夹注），两类形态不得混用于同一处：引文整段的说明用译注括注或脚注，不得写入引文内部。
* 译注只能补充背景或说明翻译取舍，不得改写、评判或引申原文立场；译注不得出现在参考文献节。
* **禁幻觉引文的行标同源**（CY/T 174—2019，2026-11-14 登记）：伪造＝编造或虚构数据、事实、研究结果；篡改＝故意改动真实获得的结果使其失真——“禁止幻觉引文”条款即翻译场景下的伪造/篡改禁令，分级按 Critical 处置不变。

## 存疑与学术诚信

* 对 SEP 正文断言存疑（史实、引文、年代）时，回原始 HTML 或权威文献核对（宪法 I），禁止凭“常识”改写；无法核对的，译注说明存疑，不得静默取舍。
* 各校次在任务 JSON 留凭证时，涉及文献与引注的修改必须可回溯到英文源行（锚点或 diff）。

## 与三审三校的衔接

| 校次 | 本规则的落点 |
| ---- | ---- |
| s1 一校 | 逐节核对版本事实行、引注与文献条目（对照 `yuanwen/`/`en/` 逐条搬运，留凭证） |
| s2.4 术语校 | `python tools/check_terms.py --docs <路径>` 0 硬错误（登记册自洽；告警留 evidence）；逐条对照两登记册核验正文用词（ADR-0043） |
| s2.5 审计已译 | `python tools/check_math_zh.py <路径>` 0 硬错误（默认档；strict 升档留 s3/r3）；三向比对记录、密度统计与脚注键位配对核验入 evidence（ADR-0040/0043） |
| s3 三校 | `python tools/check_academic.py --docs <路径> --strict` 0 硬错误；`check_style.py` 照旧 |
| r3 终审 | 复核结构完整性；CI 全绿（含 check_academic）为验收线 |

## 缺陷分类与处置（2026-11-15 自散页《翻译工程标准》S5 折叠收编）

| 类 | 定义 | 处置 |
| ---- | ---- | ---- |
| A 事实性 | 人名、年代、版本、指称对象错误 | 联网核查后改，登记册同步 |
| B 术语性 | 译名误用、正反误用、键值冲突 | 逐条修正＋lint 规则化 |
| C 语言性 | 欧化、生硬、语法 | 二校逐条清单 |
| D 格式性 | 坏行、重复、标点、异体字 | lint 捕获，修复后 0 问题验收 |

原则：**一次性缺陷逐条修，重复性缺陷工具化**——同类问题出现两次以上，必须沉淀为 lint 规则或 [03](03-terminology.md) 手册条目。与 ADR-0020 问题分级（Critical/Major/Minor）正交使用：分类定"是什么"，分级定"多严重"；specs/004 四方分类对照表承载跨体系换算。

## 检查

* 全库门禁：`python tools/check_academic.py`（词条文档 + 任务版本钉）；定点：`--docs <路径>...`；`--strict` 把告警升为硬错误。疑似中国文献条目定位：`python tools/biblio_audit.py <slug>...`（[ADR-0011](adr/0011-引文原文语言与中文文献翻译.md)）。
* 存根词条（仅 H1，非空行 ≤10）与别名/占位词条不适用结构类检查。
* 检查器只报告不修复；修复由译文会话按报告执行，修弱势方。
