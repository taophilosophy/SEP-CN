# 源侧工序规范（ex-01–ex-05）

本文件承载**源侧五道工序**（源镜像的抓取、转换、保真、审计、格式闭合）的作业规范。此前这些规范散在 `ADR-0027`／`ADR-0045`／`ADR-0062`／`ADR-0063`、`specs/001-sep-sync-pipeline` 与 `specs/062-phase12-recheck` 的 SOP 中，本文件做**归集与索引**（引用既有条款，不复制、不改写 ADR），并补充 2026-11-26 由 `specs/064` G13 发现的**候选定性豁免清单**（§5.3）。

阶段对应（specs/063 §1.3）：ex-01→1.2.1、ex-02→1.2.2、ex-03→1.2.3、ex-04→1.3.3、ex-05→1.3.4。

## 1 工序表与总则

| 工序 | 职责 | 判据 | 权威 |
| ---- | ---- | ---- | ---- |
| ex-01 抓取与版本钉 | 原样保存上游页面，算 SHA-256，写 `version_pin` | `fetch_audit` | ADR-0027、ADR-0045 |
| ex-02 转 Markdown | HTML→MD 忠实转换；格式差异生成补丁，实质差异登记待勘误 | `check_en_patches`、`divergence` | ADR-0009、ADR-0062、ADR-0063 |
| ex-03 保真校验 | I1–I6 不变量；I2 重放等值、I3 词元流等值为主判据 | `check_yuanwen_fidelity` | ADR-0063 |
| ex-04 源审计 | HTML 本体核查＋镜像轴保真；零信任放行门 | `en_integrity`、`en_source_audit` | ADR-0052、ADR-0062 |
| ex-05 格式闭合 | markdown 语法层：标题不跳级、表格对齐行、代码块闭合、定界符配对、实体转义、行尾空白、末换行 | 无独立判据（由 rv-09 `check_style` 与 `en_integrity` 部分覆盖） | 本文件 §6 |

**总则三条**（对五道工序一律适用）：

1. **`yuanwen/` 绝对冻结**（ADR-0062）：与原始网页钉逐字节一致，文字层与格式层一律不改；任何“顺手修正”都禁止。
2. **机检为筛、人审为判**（ADR-0070）：所有 `check_*`／`en_*` 输出是候选，定性由人按四类（拼写／词序／年份／结构）或格式类处置。
3. **禁静默跳过**（宪法 V）：抓取失败、校验异常、退避重试均须逐件留痕。

## 2 ex-01 抓取与版本钉

* 原样保存到 `yuanwen/<slug>/`，不清洗、不加包裹层；计算 SHA-256，记录 `pubinfo_date` 与 `archive_edition`。
* 上游未变件走 `unchanged`：**不写盘、不动钉账**（ADR-0045），仍执行转换。
* 资产引用必须齐备：`fetch_audit` 闭包迭代至不动点（`rules/05`）。
* 抓取节律：ADR-0069 已废除强制 5 秒间隔；**重试退避、逐请求留痕、禁静默跳过**三条不变。

## 3 ex-02 转 Markdown

* 转换边界：**格式层**差异（序号、缩进、空白、无语义标签）生成补丁写入 `baseline/en-patches/`，由转换层应用（命中计数硬校验，不符即硬失败）；**实质差异**（缺字、错字、标签致语义丢失）登记待勘误，**不在转换处修**。
* `en/` 与 `yuanwen/` 逐字符镜像（ADR-0009）；上游错字照录。
* 禁手改转换产物（ADR-0063）。

## 4 ex-03 保真校验

* I2：`yuanwen` 字节 == `convert(en ⊕ patches)`；I3：`yuanwen` 文字流 == `en` 文字流（模转换器构造白名单）。
* 唯一合法偏离来源是格式补丁；“是否属格式”由准入谓词判定，不由人判（ADR-0063）。
* 差异三分：转换器缺陷回 ex-02、源缺陷转 ex-04、格式类入补丁池。

## 5 ex-04 源审计

### 5.1 核查清单（五面）

页面真实性（标题、作者、SEP 编号）｜截断（标签闭合、末段完整）｜结构（锚点可跳、注释配对、脚注定义与引用一一对应）｜内容嫌疑（typo、重复段落、乱码、编码）｜资源（图片可达、公式渲染、表格错行）。

### 5.2 处置出口

**文字层**缺陷入全局勘误表（`baseline/en-errata/en-errata.md`，ADR-0076），中文按正确读法呈现并加译注；**格式层**入补丁池；**死链只登记不改正文**（上游时效，不属缺陷四类）；**typo 候选由人按四类定性**，机检只产候选。

### 5.3 候选定性豁免清单（2026-11-26 新增，来源 specs/064 G13）

机检（`en_source_audit`）的 typo 候选须先按下表分流；命中豁免类者**不计缺陷**，但必须在 ex-04 记录中注明“命中 X 类、判为误报”，不得静默忽略。

| 类 | 形态 | 判定 | 依据 |
| ---- | ---- | ---- | ---- |
| A 存档与 URL 片段 | `archives/sum2023/`、`/entries/<slug>/`、`#ref-N`、`hdl.handle.net` 等 | **豁免**（非正文文字） | 064 E2E 实测：`sum2023` 被 `word_digit_eq` 误报 |
| B 年代与数字缩写 | `80s`／`90s`／`1990s`、`pp.`／`vol.`、标准编号（`ISO 17100`） | **豁免**（规范用法） | GB/T 15835；064 E2E 实测 `80s`／`90s` 各一误报 |
| C 标题接正文 | 节标题与正文首词相接（如 `3.1 Discourse` 后紧跟 `Discourse is not…`）、目录行与正文重复 | **回原文确认**；多判误报 | 064 E2E 实测 `Discourse…Discourse` |
| D 标点连串 | `,,`、`;;`、`.””`、重复句号等 | **真候选**，按四类定性 | 064 E2E 实测 `Ritus”,,` 疑真错 |
| E 外链失效 | 外部域名 4xx／超时 | 只登记不改正文 | ADR-0062（既有） |

**记录要求**：ex-04 的 evidence 须含“候选总数／豁免类计数／真候选定性结论”三段摘要；豁免类不改变缺陷计数，但须可复核（候选清单与判定逐条对应）。

## 6 ex-05 格式闭合（markdown 语法层）

标题不跳级｜表格有对齐行｜代码块闭合｜公式定界符配对｜HTML 实体转义正确（`&amp;`、`&#124;`）｜行尾空白｜连续空行｜文件末换行。**零差异也写一条 pass**，否则无法区分“没查”与“查了没问题”。
