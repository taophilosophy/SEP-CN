# 编写体例

译文以“像中文学术作者直接写作的论文”为标尺：用现代汉语学术书面语，准确、平实、可读；忠实原文的论证与语气，不译成文言或半文半白，也不译成欧化汉语或翻译腔。原文的讽刺、调侃与举例色彩在学术语域内保留，不拔高成官样文章。本规则的机器可判定部分由 `tools/check_style.py` 执行（宪法 VI），推送后由 CI 复核；语体与文风（是否文言、破折号是否滥用）由复核人通读后作语义判断，不设关键词命中规则。

体例修改同样是任务：先确认要修哪类问题、以 `check_style.py` 0 issue 为验收，再逐处手动修改；禁止以“跑了格式化工具”代替判断（[08](08-intent-first.md)）。

## 引号

* 正文必须使用中文弯引号：双引号 `“ ”`、单引号 `‘ ’`（外层双引号，引内层用单引号）。
* 引号必须成对、方向正确：左引号只用于开启，右引号只用于收束。
* 禁止英文直引号 `"` `'`、直角引号（U+300C、U+300D、U+300E、U+300F）、日式半角引号与全角直引号。
* 代码块与行内代码内保持原样；英文单词内部的撇号（O'Brien、don't）不算引号。
* 引号与相邻汉字之间不加空格；引号与西文、数字之间保留半角空格；引号内部的中英文之间照常加空格。
* 发现错误引号逐个手动修正，禁止机械替换。

## 空格

* 中英文、中文与数字之间必须加半角空格；**书名号内的中英混排同样加空格** （写《C 程序设计语言》，不写 `《C程序设计语言》`）。
* `**加粗**` 两侧与相邻正文恰好一个半角空格（段首、块首例外；与中文标点、全角括号紧贴；行尾、表格竖线、破折号允许紧贴或一个空格）。全角空格一律改半角。

## 代码块与终端摘录

* shell 命令与终端会话用 ` ```sh `，C 代码用 ` ```c `，配置/数据按内容选语言，无法判断时用无语言标注的 ` ``` ` 兜底，**禁止 `text` 作为语言标注**。
* 终端会话保留原书提示符：`%`（csh）、`$`（sh）、`#`（root）。
* 代码块内的英文注释必须翻译为中文；只译注释，不得改动命令、代码、变量名与格式。
* **禁止篡改** 代码块内容：软件版本号、错误信息、文件名、变量名一律原样（错误信息在正文中可译、代码块内保持英文）。
* 数学定界符与 LaTeX 内容原样保留（宪法 VI）。

## 排版元素

* 信息框统一用 `>` 引用块，关键词加粗，与正文空行分隔。
* 表格对齐以源表性质为准（2026-11-13 修订，取代原“一律居中”，[ADR-0037](adr/0037-表格与图片体例.md)）：公式盒子、数据表等源 `<table class="centered">`/`cell-center` 者居中（`:---:`）；文献条目表、长文本列与源默认 `vert-top` 者左对齐（`---`）——en 源 576 处以 `vert-top` 为默认，整段文献居中不可读。表头几列，数据行就必须几列，缺列写 `| |`；表格单元格用紧凑风格（管道内侧不留空格）。
* 学术工具节一律列表形态（全库 359 列表 / 71 旧表形态，2026-11-13 归一）：`* [如何引用本词条](…)` 起四条，不用带空表头的上引表。
* 表格文字（用户裁定 2026-11-13，[ADR-0037](adr/0037-表格与图片体例.md)）：表头与单元格的说明、描述性文字一律译中文；表内西文文献条目骨架照录＋书名括注通行汉译（查证到实书才译，查不到保持原样并登记）；中国文献条目（古今）译为中文；公式与数学记号原样保留，公式盒子表标签语（Definition. 等）译中文。门禁：`tools/check_tables_images.py` 预检＋逐表人眼复核。
* 图注形态（[ADR-0037](adr/0037-表格与图片体例.md) 决策 8）：图注行统一 `图 N：说明`（全角冒号，禁半角句点/句号作分隔）；图前标签行（无说明）统一 `图 N`，加粗者 `**图 N**`；正文句中引用不动。
* 图片（用户裁定 2026-11-13，[ADR-0037](adr/0037-表格与图片体例.md)）：alt 与图注一律译中文，SEP 源占位 alt（missing text, please inform）译说明性中文；中文词条图片引用一律 `../assets/<slug>/<文件名>`（解析到根级 `assets/`，[01](01-repository-structure.md)），禁引 `../yuanwen/assets/`；reprinted with permission 图片在图注标明来源。
* **表身空值细则**（CY/T 170 表身条款，2026-11-14 采纳，[ADR-0041](adr/0041-标准对齐基线与偏离登记.md)）：不适用＝空白单元格，无法获得＝一字线“—”，数值为零填“0”；全表单位一致时在表右上方统一标注；同一量的数值修约数位一致。连接号三形见下节（ADR-0041 裁定）。
* **表号表题细则**（CY/T 170，2026-11-14 采纳，承 [ADR-0040](adr/0040-审计已译环节与题注编号.md) 表 N 裁定）：表号与表题置于表格上方、居中、一字空；**正文须先提及后出现**（“见表 N”）；编号全文统一，与插图、公式编号方式一致；表头禁斜线；量与单位标“量的名称或符号/单位符号”。
* 禁止任何 HTML 语法；禁止 AsciiDoc 残留（`xref:…[…]`、`link:…[…]`、行尾 `+` 软换行）；所有段落同一行内完成。
* 命令、选项、参数用行内代码（`ls -l`）；不带选项参数的裸命令一般不加反引号。
* 正文路径与 IP 用 **加粗**，不用反引号；代码块中的路径保持原样。
* 上下标（用户裁定 2026-10-28）：有 Unicode 原生字符的直接用原生字符（`x²`、`u(a₁)`、`Sₓ`、`E⁻¹`），与英文镜像 `yuanwen/` 的转换约定一致；无原生字形的（如 `q` 下标、`⊥` 上标、含斜线的 `^{−1/2}`）保持记号 `_{…}`/`^{…}`，由站点渲染层转 HTML sub/sup 兜底；真公式一律入数学定界符 `$…$`/`$$…$$`，公式内部用 LaTeX 记法，不适用本条。
* 斜体与加粗（用户裁定 2026-10-29）：**中文强调不使用斜体 `*中文*`，使用加粗 `**中文**`**（中文排版无斜体传统，CJK 斜体渲染歪斜难读）；拉丁/希腊/希伯来字母的书名、术语与逻辑符号（如 *dharma*、*svabhāva*、*A*、*B*）保留斜体不改（斜体拉丁字母渲染正常且是中文学术出版引用外文术语的标准做法）；`**` 两侧空格遵守 bold-spacing 规则；参考文献节照录条目豁免本条。门禁：`tools/check_style.py` 规则 `italic-cjk`。
* 孤立希腊字母（用户裁定 2026-11-15，[ADR-0049](adr/0049-孤立希腊字母文字化体例.md)）：正文行间**孤立**希腊字母不用公式定界符，转裸 Unicode——变量加斜体（`$\varphi$`→`*φ*`），算子与专名成分正体不加斜体（算子 `$\Delta$`→`Δ`）；派生形（`$\omega'$`、`$\alpha_1$`）、复合式（`$\neg\varphi$`）与公式段（`$$…$$`）保持定界符；`\phi` 与 `\varphi` 同归 `φ`（U+03C6），同词条兼用两形作不同变元时 `\phi` 转 `ϕ` 保区分。`yuanwen/`、`en/` 原始物不适用本条。门禁：`tools/check_math_zh.py` 规则 `C10`（告警级）。
* 强调语法有效性（用户裁定 2026-10-30，ADR-0019）：**`**` 星号内侧禁空格**——`** 内容 **` 违反 CommonMark 翼规则永不渲染，页面显示裸 `**`（A 批 9 词条 237 对实测）；编号记号（ABD1、CP 等）在英文源无强调标签时保持纯文本；正文强调形式以英文源标签为准映射（源 `<em>` → 中文粗体/拉丁斜体），不得无凭据改样式。验证走渲染产物级扫描 `tools/check_render_artifacts.py`（源合法 ≠ 产物正确）。

## 连接号（GB/T 15834-2011 §4.13，ADR-0041）

* 连接号三形分工，混用即违例；破折号“——”（两字位，U+2014 两个）与连接号一字线“—”（一字位，U+2014 一个）同字符不同用量，按占位区分：
  * **短横线“-”**：复合名词与外来语内部分合（盎格鲁-撒克逊、让-雅克·卢梭）、产品型号与编号（WZ-10、表 2-8）、门牌/电话号码、年月日简写（2011-02-15，同 ISO 8601；GB/T 15834 附录 A.4.2）。
  * **一字线“—”（U+2014）**：时间与地域起止——沈括（1031—1095）、2011 年 2 月 3 日—10 日、北京—上海（2026-11-14 用户裁定方向）。
  * **浪纹线“～”（U+FF5E）**：数值范围（25～30）；数值范围亦可取一字线，全库取其一须一致。
* 豁免：参考文献照录段（含 SEP 房屋样式的 en-dash 页码区间）、代码块与行内代码、URL、数学定界符、直接引文原文。
* 机器预检：`--connector-scan` 告警级（见“检查”节）；**存量违例约 196 件 1141 处待 Tier 3 战役归一（摸底 2026-11-14：括注生卒年 860＋年份区间 281，specs/025 §5），未立项前禁止铺量修改**——连接号为纯符号层归一，与破折号滥用的“禁机械替换、必须重译”条款分属两类（后者涉句法语义，前者不涉）。

## 数字与计量（GB/T 15835-2011 / GB/T 19682-2005，ADR-0041）

* **译文数字主随源**：正文数字照英文源形态转写（千分撇、单位、百分比原样），不强改汉字/阿拉伯形态。
* **自产数字**（译注、说明行、表格标签语、图注等中文自写内容）按 GB/T 15835 两原则裁决：**得体**——计量、编号、现代生活事件用阿拉伯数字，概数、成语、非公历纪年用汉字数字（“三四个”“五十多岁”）；**一致**——同类场合同一形态。
* **“零”与“〇”**：“零”用于计量与计数；“〇”用于编号（年份如二〇〇三，仅限照录与引文还原）。
* 单位与量值照录源（GB 3100 量和单位系列豁免，宪法 VI）；本条语义判定，不设关键词机检（承 ADR-0033 口径）。

## 内容纪律

* 禁止篡改：软件版本号、人名、书名、URL、邮箱、带圈数字必须与原文一致，位置和数量不得变动。
* 避免滥用“已”字：“XX 已新增”改为“新增 XX”。禁止机械替换。
* 避免章节交叉引用：原文“see Chapter 11”等改写为语义化描述或指向对应中文页面的相对链接。
* 第二人称一律用“你”，不用“您”。
* 原书写于特定年代的内容按当时视角陈述，**不要用今天的现状改写原文**；确需补充现状，以译注承载（形态见下条“译者注释节”），谨慎克制。
* **译者注释节**（用户裁定 2026-11-17，[ADR-0065](adr/0065-译者注释节与圈号锚点.md)）：勘误承载与内容性译注写入文末独立小节 `## 译者注释`——位次恒在 `## 脚注` 之后、全文最末；**非强制**（有需才设，空节违规）；**仅中文词条适用**（`yuanwen/`、`en/` 禁有）。正文对应句的句末标点**之后紧贴**标圈号锚点（①②…，U+2460–2473，21+ 用 U+3251–），全篇连续编号 1..N，增删后其后各号前移重排（机检 `note-anchor` 查对称与连续）；节内条目以同号圈号开头，半自由句式：`① 位置：第 2 节 B16 引文。上游作"theirs are are"，系衍字；译文按"theirs are"处理。`。存量句内 `（译注：…）` 为过渡形态，迁移随回炉批（ADR-0065）。
* 参考文献节（“参考文献”/“Bibliography”/“References（引用注释）” 标题及其下内容）非中文条目原文照录不译，豁免引号与中西文空格规则；**中国文献条目（无论古代现代）一并译为中文**（用户裁定 2026-10-28，ADR-0011；[07](07-academic-norms.md)），翻译后的含汉字行按正体例检查。
* **译者省略与插注**（CY/T 122 §7/§8，2026-11-14 采纳，ADR-0041）：译者在引文中自加的省略用“[……]”（方括号裹六连点）与原文自带的“……”相区分；引文前不用省略号，引文后不宜用省略号；插入引文的说明文字置方括号内，对引文整体的说明用脚注/尾注；引文自身携带的注释信息原样保留。

## 语体与文风（语义判定）

**标尺**：现代汉语学术书面语。合格的译文读起来应像当代中文学术著作的正文，而不是文言、半文半白或翻译腔。

* **禁文言与仿古**：译文自己的叙述（标题、导言、节下正文、译注、脚注说明）一律用现代汉语；不得使用文言句式、文言虚词与仿古修辞。典型形态：句末“矣／焉／哉／耳／乎／耶”，“……者，……也”，文言代词“吾／吾人／彼／厥”，文言连词“然则／何则／是以／若夫／至若／盖”，以及为求凝练而堆叠的四字、对偶、骈句。不得以“古雅”“凝练”为由把现代汉语改写成文言。
* **判断方式（语义）**：整段通读，以“当代中文学术读者能否不借助白话翻译自然读懂”为准；不按“之／其／而／则”等字的关键词命中数机械判定——这些字现代汉语照用，命中数不构成证据。发现疑似文言段落，回读上下文与英文源，确认是译文语体问题还是引文照录。
* **破折号节制**：破折号只承担真正的插入、转折与解释，不得当作默认的停顿或连接手段。同段多处破折号，或用破折号替代冒号、括号、分句更顺的，一律改写（AI 生成文本的典型腔调之一）。判断看句法功能与可读性，不按个数机械判定。
* **破折号滥用的修复方式**：修复滥用时，以含破折号的原句为单位、回英文源句（`yuanwen/` 镜像）整句重新翻译，按新句法自然安置破折号（真正的插入语可保留）；禁止在旧译文本上做符号层机械替换（如一概把“——”换成冒号或括号）——那是把旧译文当修改底稿，违背零信任（宪法 III）。重新翻译只重整句法与停顿，不得改变原句的命题内容。
* **量词“一个”节制**（用户裁定 2026-11-14，仿破折号限制）：英文可数冠词 a/an 与“一 + 量词”结构对中文不是语法要求——泛指种类与抽象名词前的填充“一个”删去或改写；真实数量、同一性与习语保留。判断看句法功能，不按个数机械判定。判例：“提供了一种解释”→“提供一种解释”；“作为一个哲学家”→“作为哲学家”；“这是一种社会建构”→“这是社会建构”；保留形态：“等了一个小时”“同一个时代”“一个接一个”。列举事物按种类罗列不加量词（“电风扇、文具盒、台灯”，不写“一台电风扇、一个文具盒、一盏台灯”）。
* **豁免**：直接引文、典籍原文、碑铭，以及题记中的原引文与参考文献照录条目，保持原文语体，不受本条约束；译文对引文的说明与评论仍须用现代汉语。
* **复核留痕**：二校（语言）与初审（r1）各通读一次全文（排除上述豁免内容），在任务 evidence 写下语体结论（如“语体：现代汉语学术书面语；破折号仅用于插入与转折，无滥用；“一个”无滥用；无 AI 腔套话”）。破折号、量词“一个”与 AI 腔的审阅同属审计已译环节（[04](04-translation-workflow.md)）的语体留痕范围。门禁只校验该结论是否留痕，语体好坏由复核人语义判断。留痕按**步级生效时点**查验（2026-11-10T15:00Z 起的 s2/r1 步；此前历史步不追溯，生效后步骤缺留痕的以“语体补记”补录——[ADR-0058](adr/0058-语体留痕步级时点口径.md)）。

### AI 腔与套话（语义判定，2026-11-14 增补）

依据英文维基百科《Signs of AI writing》研究增补（ADR-0040）。本项目采用 LLM 辅助初译，AI 写作的公式化痕迹必须在逐段对照与通读中识别并消除；该清单为描述性经验，判断靠语义与密度综合，**不设关键词命中机检**（承 ADR-0033 口径；英文维基亦明确风格检测不可单靠，误判率高）。形态与处置：

* **增译套话与对冲**：原文没有的“值得注意的是／需要指出的是／总的来说”式对冲、免责与总结段（含“面临挑战……未来可期”式收尾公式）——回 en 核对即现形，一律删除（增译非翻译，审计译文轴硬拦）。
* **空洞拔高与泛化**：具体事实被抹成泛化正面评语（“革命性巨擘”式）、夸大意义／遗产／影响、把细粒度断言平滑成放之四海皆准的话——回 en 重译，恢复原文的具体与克制。
* **模糊归因与模糊关联**：无出处的“人们普遍认为”“学界多认为”，把一两家的意见说成“普遍”，用“与……密切相关”回避具体关系——按 [07](07-academic-norms.md) 禁幻觉归因，逐处补实或删除。
* **公式化排比**：三连排比（X、Y、Z）与“不是……而是……”负平行公式化堆叠——按句法功能拆解，非公式处保留。
* **中文 AI 高频词密度**：“彰显／赋能／维度／层面／梳理／勾勒／至关重要／深入探讨”等词的高密度共现是 AI 腔信号；个别出现不算，密度异常整段复核重写。
* **优雅变换**：同一对象频繁换称、同义词回避重复——与“译名与称谓一致”条款同向修整。

## 哲学翻译方法论锚点（2026-11-14 增补，联网研究：严复“信达雅”校正、陈康、王太庆、贺麟、思果、余光中；学理底座：王力《中国现代语法》欧化七类、连淑能《英汉对比研究》13 章对比）

* **概念层直译，句法层归化**：陈康“宁可生硬的直译，不用意译”在**概念与命题层**采纳——术语严格对应、不迁就流畅牺牲准确；王太庆“达是信的前提”与思果“像中文”在**句法层**采纳——直译指概念忠实，不指句法模仿，句子按中文习惯重排。两层不冲突：术语宁硬，行文宁顺。学理依据：王力（1943）最早系统描述欧化语法七类（复音词、主语系词增多、句子延长、被动式、联结成分、替代称数法、省略倒装插入法）；连淑能英汉 13 章对比（形合↔意合、物称↔人称、静态↔动态、被动↔主动等）给出每条反欧化条款的类型学定位——英“形合、物称、静态、被动”，中“意合、人称、动态、主动”。
* **术语链一致性**：同一概念全库同译，以登记册为唯一事实源（[03](03-terminology.md)）；引文中出现的术语与正文同译。术语首现可括注原文，后文一律用定译。
* **引文回译核对**：正文所引文献名与引文，有通行中译本者依通行译本（查证到实书才引，幻译禁令照旧）；无通行译本者回英文源核对自译，同一引文前后译法一致。
* **“信”字当头，平实晓畅**：学术译文是说明文，不作文学式雅译（雅而失信）；原文的论证结构、让步与转折、反讽语气如实保留，不拔高不抹平。

## 语言质量

清除以下毛病，逐句对照原文校对：

| 问题类型 | 示例 |
| -------- | ---- |
| 欧化汉语 | 滥用“被”字句、“进行/作出/加以 + 动词”、超长“……的”定语、滥用“们” |
| 后置与倒装 | 从句后置按汉语习惯重排：先因后果、先条件后结论 |
| 偷换主语 | 长句主语变化时显化或断句 |
| 虚词冗余 | 多余的“的、了、着、是、被、所、会、将” |
| 死译 | 双关与玩笑语按中文习惯改写，宁可意译不留硬译 |

### 反欧化条款（ADR-0020，2026-10-31）

上表之外，以下条款给出可判定阈值与 A 批实译判例；机检部分由 `tools/check_prose.py` 预检（告警级，登记见 [05](05/index.md)）。告警逐条人工判断后修改或豁免，机器不替代逐句校对：

* **长句拆分**：单句（以 。；！？ 计）≥70 汉字原则上拆分或重组——主语先行、先因后果、先条件后结论。判例：“把你引向这个结论、而在相当多的哲学家看来也能为这一结论提供辩护的，恰恰是这样一个事实：……”→“你之所以得出这个结论，是因为这样一个事实：……；而且在相当多的哲学家看来，这一事实也为结论提供了辩护。”
* **被动句**：非必要不用“被”；可改主动，或换“受／遭／由／给／为……所”。判例：“不久之后，这颗如今被称为‘海王星’的行星被发现了。”→“不久人们便发现了这颗行星，即今天所说的海王星。”单句 ≥2 个“被”须复核。
* **“被”的语义方向**：“被”用于受害、不如意事；中性或褒义事改“当选／获／受／遇”或主动句（“被选为部长”→“当选部长”；“被杀害”→“遇害”；“被发现”→“被发现之处可改‘见于’”）。句式优先级：普通句＞把字句≫被字句。
* **弱动词**：“进行／作出／加以／予以 + 抽象名词”恢复动词本力（“作出决定”→“决定”；“在……时所起的作用”能省则省）。
* **定语链**：“的”三连或单句 ≥6 个“的”须重排（拆句、并列、去“的”）：“我们对他人的证言的信任”→“我们对他人证言的信任”。
* **类名“们”**：作者们、科学家们→论者、学界，或径去“们”；人称代词不受限。
* **冠词与存在句**：“作为一个 X”→“作为 X／身为 X”；“存在着”→“有／存在”接实义成分。
* **直译框架**：“当……的时候”多可只留“……时”；“如果……那么”能简则简。
* **指代显化**：“它／它们／其”的先行词须在上文近句内可回指；句首“这”指代前文整句时改“这一点／这种做法”。
* **成语与判词**：成语主语须相容——“我们至今仍付之阙如”不通，“这样的判准至今付之阙如”才通；warrant／license 等规范性判词按语境译“许可／支持／有理由推出”，不得译“只配／够格”。
* **脱稿通读**：二校收尾须“忘掉原文通读中文”（思果：译文要像中文）；不通顺处常是未理解原意处，回核原文再改（王太庆：达是信的前提）。

以下增补自中文维基百科《翻译腔》论述与《欧化中文》条目（2026-11-14 联网研究，ADR-0040；语义判定，机检候选另议）：

* **动词优先、以人作主语**：名词化与“物作主语”句改回人作主语、动词作谓（“女朋友的失踪让他感到焦急”→“女朋友失踪了，他很着急”；“有着极高的知名度”→“非常知名”；“造成了如今的恶果”→“把事情弄成这样”能直白则直白）。
* **时态词节制**：中文动词无时态变化，“曾于”“已经”“已于”非必要不出现，时间靠语境与上下文（“曾于 1916 年担任校长，并已于 1927 年辞职”→“1916 年任校长，1927 年辞职”）。
* **并列连词节制**：“和”只连名词性成分；连接动词、形容词与小句改“并／且／或”或顿号（“帮助和支持”→“帮助并支持”；“完备的和充分竞争的”→“完备且竞争充分”）；三项以上并列去连词（“早饭、午饭和晚饭”→“早饭、午饭、晚饭”）；否定与假设场景的列举用顿号不用“或”。
* **话题优先**：中文先话题后评论，主语不必跨句强求一致；“由于……导致……”不得把整句装进介宾造成主语残缺（“由于甲乙两国战火不断，导致两国民众积怨已久”→“甲乙两国战火不断，两国民众为此积怨已久”）。
* **时间地点前置**：时间线索先交代（“上午，江先生与人开会”）；时间地点并举时地点随后。生卒年等琐碎信息入括号。
* **译名与称谓一致**：同一对象通篇同称，不得在“父亲／约翰／史密斯”等称谓间来回切换；非专有名词一句内避免重复；换称须先建立对应。与 [03](03-terminology.md) 术语链一致性同向（同一概念全库同译）。
* **用词直白**：舍繁复书面腔取本义动词（“作出了巨大的贡献”→“贡献巨大”；“实在难以想象究竟是什么造成了如今的恶果”→“他不明白事情怎么落到这地步”）；能用短语概括的长串细节就概括，但不得引入方言口语。
* **初译自检三步**（维基《翻译腔》简要规则，参考不作硬门槛）：整句点号不超过 5 个、相邻标点间不多于 25 字、动词优先一句一主语——记不住就三个字：说人话。翻译时以整句为单位理解原文，忘掉原句式、按眼前情景用中文复述，再转成书面语。

以下增补自余光中《从西而不化到西而化之》（51 判例）与思果交稿前检查清单（2026-11-14 深度研读，ADR-0041；语义判定）：

* **“地”字副词节制**：成语降格副词的“地”删去代以逗点（“苦心孤诣地想出”→“苦心孤诣，想出”）；“成功地 X”既已做成即冗余（“成功地推翻”→“推翻”）。
* **无用代词与受词隔离**：受词代词省去（“买了它了”→“买了”；“喜欢它”→“喜欢”）；**受词紧接动词**——动词与受词被长串修饰隔开即尾大不掉（“委派了明天上午陪伴医生的轻松的任务”→“派给他的轻松任务，是明天上午陪伴医生”）。
* **伪术语与虚量词**：抽象名词装学术门面拆穿直说（“知名度很高”→“很有名”；“可读性颇高”→“很好看”；“难度很高的技巧”→“很难的技巧”；“内向型的人”→“内向的人”）；“一定的／一定程度的”模糊化改中文固有分档（“有一定的贡献”→“略有／颇有／甚有贡献”）。
* **前饰后饰与“最……之一”**：长修饰语后饰成开放句（“一个长得像你兄弟说话也像他的陌生男人”→“一个陌生男人，长得像你兄弟，说话也像他”）；“最伟大的……之一”“作为……之一的”多为蛇足（余光中判例 27/28 句），真枚举语境（竹林七贤之一）保留。
* **被动字谱**：被动义不止“被”——受／遭／挨／给／教／让／任按语义取用（“受难→遇害→挨打→遭殃→为人所重”），不套一字公式。
