# 10 标准条款锚点与判定细则（补遗）

> 定位：已登记标准中**真正落到节点上**的条款，集中锚定在本文件（ADR-0086；G9／G11／G14／G6 补遗）。
> `rules/04` 因此不再承载条款明细（该文件已逼近单体上限）；体例冲突时以本文件与 [02](02-style.md) 为准。
> 机器事实源仍是 `rules/standards.json`；本文件只写“哪条要求—落在哪—怎么判”。
> 条款原文取自 nppa.gov.cn 发布的行业标准全文（检索日 2026-11-25）；引标准时须带条款号，不得凭原文印象复述。

## 10.1 CY/T 123-2015（学术出版规范 中文译著）

| 条款 | 要求（摘） | 本库落点 | 判定方式 |
| ---- | ---- | ---- | ---- |

| 4.4.3 | 译者注与原文注释**不同注码序列** | 译者注释节圈号锚点独立编号 | `check_academic`（s2.4 三轴） |
| 4.4.5 | 译者注不用正文夹注 | 注释节／脚注承载 | 部分：存量句内括注为过渡形态，随重译收口（ADR-0065） |
| 5.2.4 | 人名间隔号“·”、缩写下脚点、原文连字符→半字线 | `ren-ming-biao.md`＋[03](03-terminology.md) | `check_terms`（形态）＋人工 |
| 5.2.5 | 首现译名后括注原文 | [03](03-terminology.md) 首现括注 | 人工 |
| 5.5.3–5.5.4 | 术语用规范／通行译名，首现括注原文 | `shu-yu-biao.md`、`baseline/term-concepts.md` | `check_terms`／`check_term_pool` |
| 5.6 | 缩写词首现译全并括注原文全称 | [03](03-terminology.md) 缩写处理 | 人工 |
| 5.7 | 世纪—年代保留阿拉伯数字 | [02](02-style.md) 数字主随源 | `connector-scan`（告警） |
| 5.8 | 量和单位符号按 GB 3100／GB/T 3101 | [02](02-style.md) 照录 | 人工 |
| 5.9.2.1–5.9.2.2 | 引文注释译出全信息，缩写补全 | [07](07-academic-norms.md) | `check_academic`（文献／脚注）＋人工 |
| 5.10 | 参考文献可不译，照原文排录 | [07](07-academic-norms.md) 照录原则 | `check_academic`（计数容差） |
| 5.14 | 原文错误用译者注说明更正，**不直接改正文** | `baseline/en-errata/en-errata.md`＋译注（ADR-0076） | `check_errata` |
| 6.1–6.2 | 标点符合 GB/T 15834；中外混排内外标点分层 | [02](02-style.md) | `check_quotes`／`check_style` |

## 10.4 ISO 5060:2024 评分卡、抽样与评估者

**评分卡**（七维，与落点对应；评分卡管“类型与严重度”，CY/T 266 管“差错率与分值”，二者不重复计分）：

| 维度 | 判据要点 | 严重度分档 |
| ---- | ---- | ---- |
| 术语 | 与 `shu-yu-biao`／概念层一致，同形不同义分行 | 术语错→Major |
| 准确性 | 对源无增删改；无伪引文、无漏段 | 意义反转／漏段／伪引文→Critical |
| 语言规范 | GB/T 15834／15835、正词法；语句可读 | 句意偏差→Major；标点体例→Minor |
| 风格 | 现代汉语学术书面语，禁文言腔（语体门禁） | 语体不合规→Major |
| 地区惯例 | 数字、日期、单位形态与全文一致 | Minor |
| 受众适宜 | 与 `project_spec.audience` 相符 | Major（偏离受众） |
| 设计与标记 | Markdown 结构、标题层级、链接与脚注承载 | Minor |

**抽样计划**：机检全量；人工抽样按 H2 分层，每层至少取 1 段，总量不少于 10% 且不少于 20 段；抽取序以 `sha256(slug + 段序号)` 升序取前 n（可复算、不靠人工挑）；任一样本出现 Critical 即转全量复核。

**评估者能力**（ISO 5060 §4）：评估者须登记资质依据与所属角色；终审评估者不得是初译者（D1=C，`sg-03` 强制分离）；双评不一致由第三人仲裁，仲裁结论写入 `evidence`。

## 10.6 术语数据导出（TBX）

* 依据：GB/T 44227-2024（MOD 采用 ISO 30042:2019）；ISO 30042 第 3 版 CD 已通过转 DIS（30.99，2026-09-09），现行仍为 2019 版。
* 本库只导 **TBX Core（DCT 风格）**，不启用方言模块（TBX-Basic／Min 的模块层暂不引入，避免空壳字段）。
* 字段映射：键→`conceptEntry/@id`；原文→`langSec[@xml:lang=en]` 的 `term`；译法→`langSec[@xml:lang=zh-Hans]` 的 `term`；定义→`descrip type="definition"`；学科域→`descrip type="subjectField"`；概念关系→`descrip type="relatedConcept"`。
* 生成：`python tools/term_tbx.py [--out PATH]`；只读两表、确定性排序、XML 良构校验；产物为生成物，**禁手改**。
