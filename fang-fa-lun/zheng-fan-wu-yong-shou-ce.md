# 正反误用手册：日常词的哲学术义

哲学翻译最大的陷阱是日常词的术语义：它们看起来毫不陌生，译错后却毫无违和感，最易蒙混过关，且常造成方向颠倒（正反误用）。本手册是词汇表（`qian-yan/ci-hui-biao.md`）的姊妹篇，供一校（准确性）与复审（逐句回核）作为必查清单使用。新发现的条目先登记 `yi-zhe-shuo-ming.md`，再回填本手册。

## 一、正反误用（译错即硬伤，必改）

## 二、语境分流（一词多译，按语境取舍）

| 英语 | 语境与译法 |
| ---- | ---- |
| experience | 经验主义、认识论语境译“经验”；现象学、存在主义语境（lived experience）译“体验” |
| awareness | 与 consciousness（意识）相区别：译“觉知”“觉察”；bodily awareness 身体觉知 |
| ethics / moral | 学科名译“伦理学”；作定语 moral 译“道德”；书名随既定中译（如《模糊性的道德》） |
| pragmatic | 语言哲学语境译“语用”；科学哲学语境译“实用”；pragmatism 才是“实用主义” |
| reason / rationality | reason 译“理性”“理由”（解释性理由）；rationality 译“合理性”（bounded rationality 有限理性） |
| idea / concept | idea 译“观念”（洛、贝克莱）；柏拉图 Form/eidos 译“理念”“相”；concept 译“概念” |
| representation | 认知科学语境译“表征”；康德、黑格尔的 Vorstellung 译“表象” |
| reflection | 认识论、康德语境译“反思”；反映论语境译“反映” |
| determination | 黑格尔语境译“规定”；因果语境译“决定”；determinism 决定论 |
| intrinsic / extrinsic | 译“内在的／外在的”；intrinsic value 内在价值 |
| inherence / immanence | inherence 依存、寓存（属性依存于实体）；immanence 内在（性）——两者勿混 |
| transcendental / transcendent | 康德：transcendental 先验的，transcendent 超验的；美国爱默生运动 Transcendentalism 超验主义；transcendental argument 先验论证 |
| consciousness / conscience | consciousness 意识；conscience 良知、良心——形近义远，切勿互串 |
| sympathy / empathy | sympathy 同情（休谟、亚当·斯密）；empathy 共情（20 世纪译名） |
| belief / faith | belief 信念（知识论对象）；faith 信仰（宗教语境）——詹姆斯《信仰的意志》书名即用 faith 义 |
| determinism / fatalism | determinism 决定论；fatalism 宿命论——正反对置的典型，译反则义反 |
| universal / particular | 共相／殊相（波菲利问题语境）；作形容词时 universal 普遍的、particular 特殊的 |
| state | 状态（state of affairs 事态）；国家（政治哲学 the State） |
| law | 法律（法哲学）；规律、定律（law of nature 自然规律） |
| property | 属性、性质（形而上学）；财产（政治哲学 private property 私有财产） |
| subject / object | 主体／客体（认识论）；主语／宾语（语法）；subject matter 题材 |
| function | 功能（生物学、社会理论）；函数（数学、逻辑） |
| good | 好（评价）；善（伦理学 the good） |
| right | 权利（名词，a right）；正当的（形容词，right action） |
| freedom / liberty | 均译“自由”；消极自由／积极自由（negative/positive liberty）依柏林用法 |

## 三、易混词对速辨

* **idealism**：形而上学译“唯心论”（贝克莱、黑格尔）， NEVER “理想主义”——“理想主义”只用于日常理想追求语境；观念论（德国古典哲学语境，德文 Idealismus）与唯心论并行使用时全库保持一致。
* **empiricism / positivism**：经验主义（经验论）≠ 实证主义（positivism，孔德）；empirical 译“经验的”或“实证的”，见表内登记。
* **rationalism**：唯理论／理性主义——与经验论对举时传统译“唯理论”，全库统一即可。
* **understanding**：康德 Verstand 定译“知性”，日常动词义才译“理解”；Vernunft 译“理性”。
* **validity / soundness**：逻辑学 validity 有效性，soundness 可靠性（有效且前提为真）——勿以“健康”直译 sound。
* **contradiction / refutation**：contradiction 矛盾；refutation 反驳——正反对置，译反则义反。
* **necessary / sufficient condition**：necessary condition 必要条件，sufficient condition 充分条件；“A 是 B 的必要条件”意为无 A 必无 B——方向切勿颠倒。
* **critique / criticism**：康德传统 Critique 定译“批判”（《纯粹理性批判》）；日常批评义译“批评”。
* **community**：哲学、社会本体论语境译“共同体”，勿用“社区”。
* **agent / patient**：agent 行动者（行为者），patient 承受者（受动者）——道德哲学对举时切勿把 patient 译作“病人”。

## 四、使用规则

1. 拿不准时先查 `yi-zhe-shuo-ming.md` 与本手册；两处皆无，先登记后使用。
2. 术语在词条内首次出现时括注英文原词，此后可用中文。
3. 一校（准确性）按本手册第一节逐词排查；复审（逐句回核）按第二节核查语境分流是否取对。
4. 新发现的正反误用例，随手回填第一节“本轮已见误例”列，保持手册与缺陷库同步。
